# `queryParamMap`
`queryParamMap` es una propiedad de la clase `ActivatedRoute` que proporciona una API estructurada para acceder a los **`query parameters` (parámetros de consulta)** de una URL en Angular. Estos son los parámetros que vienen después del símbolo `?` en una URL, como en `https://example.com/products?category=books&page=2.`

A diferencia de `queryParams`, que devuelve un objeto simple, `queryParamMap` es una instancia de la clase `ParamMap`, lo que permite un acceso más estructurado y seguro.

## ¿Para qué sirve?
`queryParamMap` sirve para:

* Acceder a los parámetros de consulta de la URL de manera estructurada.

* Validar la existencia de parámetros opcionales.

* Soportar múltiples valores para una misma clave de parámetro.

## ¿Qué resuelve?
queryParamMap resuelve los siguientes problemas:

* Acceso directo y seguro a parámetros de consulta. Evita errores comunes al acceder a claves inexistentes.

* Manejo de parámetros opcionales. Permite verificar si un parámetro está presente antes de usarlo.

* Soporte para valores múltiples. Facilita el manejo de escenarios donde un parámetro puede tener varios valores.

## ¿Cómo lo resuelve?
`queryParamMap` utiliza una instancia de la clase `ParamMap`, la cual incluye los mismos métodos que usa [paramMap](06.0.3.1-paramMap.md).

##  Accediendo a queryParamMap
* **Usando la suscripción al `observable`**, `queryParamMap` está disponible como un **observable** en la clase `ActivatedRoute`, lo que permite reaccionar a cambios en los parámetros de consulta:
```ts
import { Component, OnInit } from '@angular/core';
import { ActivatedRoute } from '@angular/router';

@Component({
  selector: 'app-product-list',
  template: `
    <h1>Category: {{ category }}</h1>
    <h2>Page: {{ page }}</h2>
  `
})
export class ProductListComponent implements OnInit {
  category: string | null = null;
  page: string | null = null;

  constructor(private route: ActivatedRoute) {}

  ngOnInit(): void {
    this.route.queryParamMap.subscribe(queryParamMap => {
      this.category = queryParamMap.get('category');
      this.page = queryParamMap.get('page');
    });
  }
}
```

* **Usando `snapshot`**, Si los parámetros no cambian mientras el componente está activo, puedes acceder directamente al `queryParamMap` desde el `snapshot`:
```ts
ngOnInit(): void {
  const queryParamMap = this.route.snapshot.queryParamMap;
  this.category = queryParamMap.get('category');
  this.page = queryParamMap.get('page');
}
```
