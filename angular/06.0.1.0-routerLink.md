# `routerLink`
El **RouterLink** es una directiva en Angular que se utiliza para crear enlaces de navegación dentro de aplicaciones **SPA (Single Page Application)**. Es parte del sistema de enrutamiento proporcionado por el módulo `@angular/router`.

## ¿Qué es el RouterLink?
El **RouterLink** es una directiva estructural que se utiliza para asociar una ruta a un elemento HTML (generalmente un `<a>`). Cuando se hace clic en el enlace, Angular actualiza la URL y renderiza el componente correspondiente a esa ruta, sin recargar la página.

## ¿Para qué sirve el RouterLink?
* **Navegación interna**: Permite a los usuarios navegar entre diferentes vistas o componentes de la aplicación.

* **Sincronización de URL y vista**: Mantiene la URL del navegador sincronizada con el estado actual de la aplicación.

* **Evitar recargas completas**: Aprovecha el enrutamiento SPA para evitar recargar toda la página.

* **Enlaces dinámicos**: Permite construir enlaces dinámicos basados en datos o parámetros.

## ¿Qué problemas resuelve el RouterLink?
* **Dependencia de `<a href>` tradicional**: En aplicaciones convencionales, usar href recarga completamente la página. **RouterLink** evita esto, mejorando el rendimiento y la experiencia del usuario.

* **Navegación manual** compleja: Sin **RouterLink**, sería necesario manejar manualmente los cambios de vista y URL mediante lógica personalizada.

* **Mantenimiento de estado inconsistente**: Con **RouterLink**, la URL siempre refleja la vista activa, lo que simplifica la depuración y mejora la consistencia.

## ¿Cómo lo resuelve?
El **RouterLink** utiliza el sistema de enrutamiento de Angular para interceptar los clics en los enlaces y manejar la navegación de manera declarativa. Esto significa que Angular procesa el cambio de ruta sin recargar la página y actualiza dinámicamente el DOM para mostrar el componente asociado.

## Uso básico del RouterLink
**Ejemplo básico:** Definimos algunas rutas en el módulo de enrutamiento:
```ts
import { NgModule } from '@angular/core';
import { RouterModule, Routes } from '@angular/router';
import { HomeComponent } from './home/home.component';
import { AboutComponent } from './about/about.component';

const routes: Routes = [
  { path: '', component: HomeComponent },
  { path: 'about', component: AboutComponent },
];

@NgModule({
  imports: [RouterModule.forRoot(routes)],
  exports: [RouterModule]
})
export class AppRoutingModule {}
```
En la plantilla:
```html
<nav>
  <a routerLink="/">Inicio</a>
  <a routerLink="/about">Acerca de</a>
</nav>
<router-outlet></router-outlet>
```
Cuando el usuario hace clic en uno de estos enlaces, Angular cambia la URL del navegador y carga el componente correspondiente en el `<router-outlet>`.

### Enlaces dinámicos con parámetros
El **RouterLink** permite pasar parámetros dinámicos en la navegación.

**Ejemplo**: Supongamos que tenemos rutas con parámetros:
```ts
const routes: Routes = [
  { path: 'user/:id', component: UserComponent },
];
```
En la plantilla:
```html
<a [routerLink]="['/user', userId]">Perfil de Usuario</a>
```
Aquí, `userId` es una variable que puede contener un valor dinámico, como **1**. Al hacer clic, Angular navega automáticamente a la ruta `/user/1`.

### Navegación con comandos relativos
El **RouterLink** puede usarse con rutas relativas en lugar de absolutas.

Ejemplo:
```html
<a [routerLink]="['../about']">Acerca de (Relativa)</a>
```
En este caso, el enlace se calcula en función de la ruta actual.

### RouterLink con Query Parameters
El **RouterLink** también soporta la adición de parámetros de consulta (**`queryParams`**).
```html
<a [routerLink]="['/search']" [queryParams]="{ q: 'angular', page: 1 }">Buscar</a>
```
Esto generará un enlace como:
```bash
/search?q=angular&page=1
```

### Uso avanzado: routerLinkActive
Para resaltar el enlace activo, se usa la directiva routerLinkActive.

Ejemplo:
```html
<a routerLink="/" routerLinkActive="active">Inicio</a>
<a routerLink="/about" routerLinkActive="active">Acerca de</a>
```
Aquí, Angular añade automáticamente la clase active al enlace que corresponde a la ruta actual.

## Consideraciones sobre RouterLink
* **Evita el uso de href junto con `RouterLink`**: Mezclar ambos puede provocar conflictos, ya que href recarga toda la página.

* **Rutas no configuradas**: Intentar navegar a una ruta no definida causará errores. Usa una ruta comodín para manejar estos casos:
```ts
{ path: '**', redirectTo: '/' }
```

* **Cuidado con rutas anidadas**: Usa rutas relativas (`../`) solo cuando sea necesario para mantener la claridad.

* **Manejo de navegación condicional**: Si necesitas decidir la navegación en tiempo de ejecución, considera usar el servicio Router:
```ts
import { Router } from '@angular/router';

constructor(private router: Router) {}

navigateToProfile() {
  this.router.navigate(['/profile']);
}
```
