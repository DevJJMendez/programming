# Property Binding
El Property Binding es una técnica de **data binding unidireccional** en Angular que conecta una propiedad de un componente con un atributo o propiedad de un elemento del DOM. Esto permite que los valores dinámicos definidos en el componente actualicen automáticamente elementos de la interfaz de usuario.

La sintaxis utiliza corchetes `[ ]` para enlazar propiedades del DOM con las propiedades del componente.

## ¿Para qué sirve?
* Configurar dinámicamente propiedades de elementos HTML o atributos específicos del DOM (por ejemplo, disabled, src, href).

* Actualizar propiedades del DOM automáticamente cuando los datos del componente cambian.

* Sincronizar valores entre el modelo de datos (componente) y la interfaz de usuario sin necesidad de manipular manualmente el DOM.

## Qué problemas resuelve?
* Evita manipular el DOM manualmente: Los valores de las propiedades se actualizan automáticamente sin usar código imperativo como document.querySelector o getElementById.

* Conexión eficiente entre datos y UI: Mantiene sincronizados los datos del componente con los elementos del DOM.

* Soporte para atributos y propiedades específicos del DOM: Permite trabajar con atributos y propiedades no accesibles mediante interpolación `{{ }}`, como `value`, `disabled`, `checked`, `src`, etc.

## ¿Cómo lo resuelve?
Angular utiliza su sistema de Change Detection para:

* Monitorear cambios en las propiedades del componente.

* Actualizar las propiedades del DOM vinculadas a través del Property Binding.

Esto se hace de manera declarativa y reactiva, sin necesidad de escribir código para manipular directamente el DOM.

## Sintaxis de Property Binding
* **Estructura básica**:
```html
[elementoPropiedad]="expresión"
```

* **Ejemplo simple**:
```html
<button [disabled]="isDisabled">Click me</button>
```

* **Componente**:
```ts
isDisabled = true;
```

## Ejemplo básico
* **HTML**:
```html
<img [src]="imagenUrl" [alt]="descripcion">
```

* **Componente**:pqu
```ts
imagenUrl = 'https://angular.io/assets/images/logos/angular/angular.svg';
descripcion = 'Logo de Angular';
```
