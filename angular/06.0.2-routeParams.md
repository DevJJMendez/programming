# Route Params
Las rutas con parámetros son una característica poderosa que te permite definir rutas dinámicas que pueden aceptar valores variables como parte de la URL. Estos parámetros pueden ser utilizados para pasar información específica entre diferentes componentes de la aplicación.

**Definición de la Ruta con Parámetros:**

Para definir una ruta con parámetros en Angular, puedes incluir un segmento de la ruta precedido por dos puntos `:` seguido por el nombre del parámetro en la definición de la ruta.

**Ejemplo**:

Dada la ruta `/products/:id`, el segmento `:id` es un **Route Param**, donde el valor real (por ejemplo, **123**) será proporcionado en **tiempo de ejecución**.

## ¿Para qué sirve?
Los Route Params se utilizan para:

* Identificar recursos específicos en la aplicación: Por ejemplo, acceder al producto con **ID 123** en una página de detalles.

* Navegar dinámicamente entre rutas: Cambiar la vista o contenido en función de los parámetros proporcionados.

* Transmitir datos a través de rutas: Facilitan el envío de información sin necesidad de usar almacenamiento temporal como servicios o variables globales.

## ¿Qué problemas resuelve?
* URLs estáticas: Permiten crear rutas dinámicas en lugar de tener que definir una ruta diferente para cada recurso.

* Gestión de datos en rutas: Evitan la necesidad de usar estados complejos o servicios adicionales para transmitir información entre componentes.

* Manejo de múltiples recursos: Permiten acceder de forma estructurada a recursos como productos, usuarios o categorías sin duplicar código.

## ¿Cómo lo resuelve?
Angular utiliza Route Params como parte de su sistema de enrutamiento, permitiendo:

* Definir rutas dinámicas: Se configuran parámetros en las rutas usando :paramName.

* Capturar parámetros en el componente: A través del servicio **`ActivatedRoute`**, los parámetros se pueden leer en tiempo de ejecución.

* Navegación programática: Se pueden generar URLs dinámicamente con parámetros usando el servicio `Router`.

## Configuración y uso de Route Params
* **Paso 1**: Definir rutas con parámetros, En el módulo de enrutamiento (`AppRoutingModule`):
```ts
import { NgModule } from '@angular/core';
import { RouterModule, Routes } from '@angular/router';
import { ProductDetailComponent } from './product-detail/product-detail.component';

const routes: Routes = [
  { path: 'products/:id', component: ProductDetailComponent }
];

@NgModule({
  imports: [RouterModule.forRoot(routes)],
  exports: [RouterModule]
})
export class AppRoutingModule {}
```
* **Paso 2**: Leer parámetros en el componente, En el componente que gestiona la ruta:
```ts
import { Component, OnInit } from '@angular/core';
import { ActivatedRoute } from '@angular/router';

@Component({
  selector: 'app-product-detail',
  template: `
    <h1>Product Details</h1>
    <p>Product ID: {{ productId }}</p>
  `
})
export class ProductDetailComponent implements OnInit {
  productId: string | null = null;

  constructor(private route: ActivatedRoute) {}

  ngOnInit(): void {
    this.productId = this.route.snapshot.paramMap.get('id');
  }
}
```
  * **`ActivatedRoute`**: Servicio que proporciona acceso a la información de la ruta activa.

  * **`paramMap.get('id')`**: Recupera el valor del parámetro **`id`**.
