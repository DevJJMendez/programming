# `<ng-content>`
El elemento `<ng-content>` es una característica de Angular que se utiliza para proyectar contenido en un componente desde el exterior. Proyección de contenido significa que se puede insertar contenido personalizado dentro de un componente, que luego se renderiza en una ubicación específica definida por `<ng-content>`.

## ¿Para qué sirve?
Sirve para permitir que los componentes sean reutilizables y flexibles, al aceptar contenido dinámico proporcionado por otros componentes o elementos que los usen. Esto permite construir estructuras más modulares y desacopladas en aplicaciones Angular.

## ¿Qué resuelve?
Resuelve la necesidad de diseñar componentes genéricos que no dependan de contenido fijo, sino que puedan renderizar contenido específico proporcionado por el componente padre o el usuario final.

**Por ejemplo:**
* Formularios que pueden aceptar diferentes tipos de campos personalizados.

* Contenedores que pueden mostrar contenido variable según el contexto de uso.

## ¿Cómo lo resuelve?
El `<ng-content>` actúa como un marcador de posición que Angular reemplaza con el contenido externo proporcionado. Funciona en conjunto con el ciclo de vida del componente, específicamente con hooks como `ngAfterContentInit`, para garantizar que el contenido proyectado esté disponible y correctamente renderizado.

## Sintaxis básica
Un componente puede usar `<ng-content>` para definir dónde se insertará el contenido externo.

**Ejemplo básico**, Componente contenedor (template):
```ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-contenedor',
  template: `
    <div class="contenedor">
      <h3>Contenido externo:</h3>
      <ng-content></ng-content> <!-- Aquí se proyectará el contenido -->
    </div>
  `,
  styles: [`
    .contenedor {
      border: 1px solid #ccc;
      padding: 10px;
      margin: 10px 0;
    }
  `]
})
export class ContenedorComponent {}
```
Uso del componente contenedor:
```html
<app-contenedor>
  <p>Este es el contenido proyectado</p>
</app-contenedor>
```
Resultado:
```ts
<div class="contenedor">
  <h3>Contenido externo:</h3>
  <p>Este es el contenido proyectado</p>
</div>
```
El texto Este es el contenido proyectado se inserta dinámicamente en el lugar del `<ng-content>`.

## Casos de uso de <ng-content>
* **Contenido dinámico en componentes genéricos**, Es útil para crear componentes como tarjetas, contenedores modales, o paneles de acordeón, donde el contenido interno puede variar según las necesidades del usuario.

## Limitaciones
* **Estático por defecto**: El contenido proyectado no puede ser cambiado dinámicamente después de la proyección inicial, a menos que Angular detecte un cambio en las referencias.

* **Dificultad en la interacción directa**: Aunque puedes usar `@ContentChild` y `@ContentChildren` para acceder al contenido proyectado, interactuar con él puede requerir lógica adicional.
