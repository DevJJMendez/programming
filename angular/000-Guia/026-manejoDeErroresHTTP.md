# HttpErrorResponse

Cuando realizas solicitudes **HTTP** en una aplicación Angular utilizando el servicio **HttpClient**, puedes encontrarte con situaciones en las que el servidor responde con un error. Para manejar estos errores de manera efectiva, puedes utilizar el objeto **HttpErrorResponse** y diferentes estrategias de manejo de errores en Angular.

El objeto HttpErrorResponse es un objeto que encapsula la respuesta de error devuelta por el servidor HTTP. Contiene información sobre el error, como el código de estado HTTP, el mensaje de error y otros detalles relevantes.
