# Interceptores

Los interceptores en Angular son clases que implementan la interfaz HttpInterceptor. Estos interceptores permiten interceptar y modificar solicitudes HTTP entrantes y salientes, así como las respuestas correspondientes antes de que lleguen a su destino final.

Los interceptores proporcionan una manera poderosa de centralizar y reutilizar la lógica común relacionada con las solicitudes HTTP en una aplicación Angular. Al utilizar interceptores, puedes realizar tareas como:

- Agregar encabezados HTTP comunes a todas las solicitudes.

- Manipular las solicitudes antes de que se envíen al servidor, como agregar parámetros de consulta, transformar datos de solicitud, etc.

- Manejar errores de solicitud de manera centralizada.

- Transformar las respuestas antes de que lleguen a los componentes de la aplicación.

- Realizar tareas de autenticación, como agregar tokens de autorización a las solicitudes salientes o manejar tokens de actualización de forma automática.

---

Para crear un interceptor en Angular, debes implementar la interfaz HttpInterceptor y sobrescribir el método intercept() para definir la lógica de intercepción. Aquí tienes un ejemplo básico de un interceptor que agrega un encabezado de autorización a todas las solicitudes salientes:

```ts
import { Injectable } from "@angular/core";
import {
  HttpInterceptor,
  HttpRequest,
  HttpHandler,
  HttpEvent,
} from "@angular/common/http";
import { Observable } from "rxjs";

@Injectable()
export class AuthInterceptor implements HttpInterceptor {
  intercept(
    request: HttpRequest<any>,
    next: HttpHandler
  ): Observable<HttpEvent<any>> {
    // Agregar el encabezado de autorización a la solicitud
    const token = "mi-token-de-autorizacion";
    const authRequest = request.clone({
      setHeaders: {
        Authorization: `Bearer ${token}`,
      },
    });
    // Continuar con la solicitud interceptada
    return next.handle(authRequest);
  }
}
```

Luego, debes proporcionar este interceptor en el módulo principal (AppModule) de tu aplicación Angular utilizando el proveedor HTTP_INTERCEPTORS proporcionado por Angular:

```ts
import { NgModule } from "@angular/core";
import { HttpClientModule, HTTP_INTERCEPTORS } from "@angular/common/http";
import { AuthInterceptor } from "./auth.interceptor";

@NgModule({
  imports: [HttpClientModule],
  providers: [
    { provide: HTTP_INTERCEPTORS, useClass: AuthInterceptor, multi: true },
  ],
})
export class AppModule {}
```

Al agregar el interceptor a la lista de proveedores con la clave HTTP_INTERCEPTORS, Angular lo reconocerá y lo utilizará para interceptar todas las solicitudes HTTP salientes en la aplicación.
