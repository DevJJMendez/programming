# Validators
Los Validators en Angular son funciones o reglas predefinidas (o personalizadas) que se aplican a los controles de formulario para verificar si cumplen con ciertos requisitos. Estas validaciones determinan el estado de un control, indicando si es válido o no.

## ¿Para qué sirven los Validators?
* Garantizar que los datos ingresados por el usuario sean correctos y cumplan con las reglas definidas.

* Validar automáticamente los valores en tiempo real o al momento de enviar un formulario.

* Controlar el flujo de entrada de datos en aplicaciones de forma eficiente.

* Mostrar mensajes de error o advertencia cuando las entradas no cumplen con los requisitos.

## ¿Qué problemas resuelven los Validators?
Problemas comunes resueltos por Validators:

* Errores de usuario: Verifican automáticamente los datos ingresados, evitando errores comunes como correos electrónicos mal formateados o campos vacíos.

* Validaciones manuales: Simplifican las validaciones al proporcionar un conjunto de reglas predefinidas y reutilizables.

* Control centralizado: Permiten manejar las reglas de validación en un solo lugar, facilitando el mantenimiento y las actualizaciones.

* Experiencia del usuario: Detectan errores de entrada en tiempo real, mejorando la interacción y usabilidad de los formularios.

## ¿Cómo resuelven los Validators estos problemas?
* Funciones predefinidas: Angular incluye validadores estándar como `Validators.required`, `Validators.email` y `Validators.minLength`.

* Ejecución automática: Los Validators verifican automáticamente el valor de los controles cada vez que estos cambian.

* Compatibilidad con validadores personalizados: Puedes definir tus propias reglas de validación para escenarios específicos.

* Integración con formularios reactivos: Los Validators trabajan estrechamente con `FormControl`, `FormGroup` y `FormArray`, facilitando la validación de formularios complejos.

## Tipos de Validators
* **Validadores predefinidos**, Angular proporciona un conjunto de validadores comunes:

  * `Validators.required`: El campo es obligatorio.

  * `Validators.minLength(length)`: Longitud mínima del valor.

  * `Validators.maxLength(length)`: Longitud máxima del valor.

  * `Validators.pattern(regex)`: Verifica que el valor coincida con una expresión regular.

  * `Validators.email`: Valida que el valor sea un correo electrónico válido.

## Validadores personalizados
Puedes crear validadores propios para reglas específicas.
```ts
import { AbstractControl, ValidationErrors } from '@angular/forms';

export function customValidator(control: AbstractControl): ValidationErrors | null {
  const value = control.value;
  if (value !== 'Angular') {
    return { invalidValue: 'El valor debe ser "Angular"' };
  }
  return null;
}
```

## Uso de Validators en formularios
###  Formulario Reactivo
```ts
import { Component } from '@angular/core';
import { FormGroup, FormControl, Validators } from '@angular/forms';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
})
export class AppComponent {
  form: FormGroup;

  constructor() {
    this.form = new FormGroup({
      username: new FormControl('', [Validators.required, Validators.minLength(3)]),
      email: new FormControl('', [Validators.required, Validators.email]),
      password: new FormControl('', [
        Validators.required,
        Validators.minLength(8),
      ]),
    });
  }

  onSubmit() {
    console.log(this.form.value);
  }

  get username() {
    return this.form.get('username');
  }
}
```
```html
<form [formGroup]="form" (ngSubmit)="onSubmit()">
  <div>
    <label for="username">Nombre de usuario</label>
    <input id="username" formControlName="username" />
    <div *ngIf="username?.errors?.['required']">El campo es obligatorio.</div>
    <div *ngIf="username?.errors?.['minlength']">Debe tener al menos 3 caracteres.</div>
  </div>

  <button type="submit" [disabled]="form.invalid">Enviar</button>
</form>
```

### Formulario basado en plantillas
```html
<form #form="ngForm" (ngSubmit)="onSubmit(form)">
  <input name="email" ngModel required email />
  <div *ngIf="form.controls['email']?.errors?.['required']">El campo es obligatorio.</div>
  <div *ngIf="form.controls['email']?.errors?.['email']">Correo inválido.</div>
  <button type="submit" [disabled]="form.invalid">Enviar</button>
</form>
```

## Métodos para verificar el estado de validación
Puedes verificar el estado de un control o grupo:

* **`control.valid`**: Indica si el control es válido.

* **`control.invalid`**: Indica si el control es inválido.

* **`control.errors`**: Devuelve los errores actuales.

* **`control.touched`**: Indica si el control fue tocado.

* **`control.pristine`**: Indica si el valor no ha cambiado.

## Validadores personalizados con parámetros
Puedes crear validadores personalizados que acepten argumentos.
```ts
export function minLengthValidator(minLength: number) {
  return (control: AbstractControl): ValidationErrors | null => {
    if (control.value && control.value.length < minLength) {
      return { minLengthError: { requiredLength: minLength, actualLength: control.value.length } };
    }
    return null;
  };
}
```
**Uso**
```ts
password: new FormControl('', [minLengthValidator(10)]),
```

## Validadores asíncronos
Los validadores asíncronos permiten realizar validaciones que dependen de operaciones como llamadas a servidores.

```ts
import { AbstractControl } from '@angular/forms';
import { of } from 'rxjs';
import { delay } from 'rxjs/operators';

export function asyncValidator(control: AbstractControl) {
  const value = control.value;
  return of(value === 'Angular' ? null : { invalidAsync: true }).pipe(delay(2000));
}
```
**Uso**
```ts
username: new FormControl('', [Validators.required], [asyncValidator]),
```
