# ActivatedRoute
ActivatedRoute es un servicio proporcionado por Angular dentro de su sistema de enrutamiento. Este servicio representa la ruta activa asociada al componente que está renderizado actualmente. Ofrece acceso a información importante sobre la ruta, como:

* Parámetros de ruta (**Route Params**).

* Parámetros de consulta (**Query Params**).

* Datos estáticos o dinámicos asociados a la ruta.

* El estado del historial de navegación.

## ¿Para qué sirve?
ActivatedRoute se utiliza para interactuar con la configuración de la ruta activa y para obtener información dinámica, como:

* **Acceso a Route Params**: Recuperar parámetros de ruta definidos en la configuración de rutas (`:id`, `:category`, etc.).

* **Acceso a Query Params**: Obtener parámetros adicionales pasados en la URL como consultas (`?key=value`).

* **Acceso a fragmentos**: Leer el fragmento de la URL (`#section1`).

* **Acceso a datos estáticos o resoluciones**: Obtener datos personalizados asignados a la ruta mediante la propiedad data.

* **Escuchar cambios en la ruta activa**: Detectar cambios dinámicos cuando la ruta cambia sin recargar el componente.

## ¿Qué resuelve?
Angular utiliza ActivatedRoute para:

* Sincronizar componentes con las rutas activas: Permite que los componentes respondan dinámicamente a cambios en la URL.

* Simplificar el acceso a datos de rutas: Evita soluciones complicadas para manejar parámetros y datos de navegación.

* Gestionar navegación dinámica: Soporta casos donde la ruta cambia, pero el componente no se destruye.

* Integrar con `resolvers` y `guards`: Facilita la obtención de datos antes de que se cargue el componente.

## ¿Cómo lo resuelve?
ActivatedRoute se resuelve automáticamente al ser inyectado en un componente. Angular lo mantiene sincronizado con la ruta activa y proporciona varios métodos y propiedades para acceder a información de la ruta.

* **Uso de `observables`**: Permite observar cambios dinámicos en parámetros, datos y estados.

* **Propiedades estructuradas**: Ofrece acceso directo a información importante como parámetros, datos y fragmentos.

## Principales propiedades y métodos
### Propiedades clave:
1. **`paramMap`**: Contiene un Map de los parámetros de ruta actuales.
```ts
this.route.paramMap.subscribe(params => {
  const id = params.get('id');
});
```

2. **`queryParamMap`**: Contiene un Map de los parámetros de consulta actuales.
```ts
this.route.queryParamMap.subscribe(query => {
  const sort = query.get('sort');
});
```

3. **`data`**: Proporciona datos estáticos o resoluciones asociadas a la ruta.
```ts
this.route.data.subscribe(data => {
  console.log(data);
});
```

4. **`fragment`**: Contiene el fragmento de la URL (`#section`).
```ts
this.route.fragment.subscribe(fragment => {
  console.log(fragment);
});
```

5. **`params`**: Versión **observable** de los parámetros de ruta.
```ts
this.route.params.subscribe(params => {
  const id = params['id'];
});
```

## Configuración de rutas
Define parámetros de ruta y datos estáticos en tu archivo de configuración (`app-routing.module.ts`):

```ts
const routes: Routes = [
  { 
    path: 'products/:id', 
    component: ProductDetailComponent, 
    data: { title: 'Product Details' } 
  },
  { path: '**', redirectTo: '/' }
];
```
* **Uso de `ActivatedRoute` en un componente**, En el componente que gestiona la ruta activa:
```ts
import { Component, OnInit } from '@angular/core';
import { ActivatedRoute } from '@angular/router';

@Component({
  selector: 'app-product-detail',
  template: `
    <h1>{{ title }}</h1>
    <p>Product ID: {{ productId }}</p>
  `
})
export class ProductDetailComponent implements OnInit {
  productId: string | null = null;
  title: string | null = null;

  constructor(private route: ActivatedRoute) {}

  ngOnInit(): void {
    // Leer parámetros de ruta
    this.route.paramMap.subscribe(params => {
      this.productId = params.get('id');
    });

    // Leer datos estáticos de la ruta
    this.route.data.subscribe(data => {
      this.title = data['title'];
    });
  }
}
```

## Métodos de acceso
* Lectura instantánea con [snapshot](06.0.4-snapshot.md)

* **Observación de cambios dinámicos**, Ideal para detectar cambios en la ruta sin recargar el componente:
```ts
this.route.params.subscribe(params => {
  console.log('New ID:', params['id']);
});
```
