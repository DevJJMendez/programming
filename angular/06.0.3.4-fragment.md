# `fragment`
Un fragment es una porción de una URL que comienza con el carácter # y representa una referencia a una parte específica de un documento o página web. En Angular, los `fragments` son usados en el enrutamiento para navegar a secciones específicas dentro de una vista o página.

Por ejemplo, en una URL como:
```bash
https://example.com/page#section1
```
El fragmento es `section1`, y normalmente se usa para desplazar automáticamente el navegador a un elemento con un identificador (`id`) correspondiente dentro del DOM.

## ¿Para qué sirve?
Los `fragments` se usan para:

* Navegar a secciones específicas de una página. En aplicaciones de una sola página (SPA), es común tener vistas largas divididas en secciones, como documentación o páginas de producto, donde cada sección tiene un identificador único.

* Proporcionar una experiencia de usuario mejorada: Permite al usuario compartir enlaces directos a partes específicas de una página.

* Mejorar la navegación interna: Los `fragments` ayudan a manejar desplazamientos automáticos basados en el identificador de elementos HTML en una página.

## ¿Qué resuelve?
* Navegación sin recarga de página: En lugar de cargar una nueva vista o página completa, Angular puede manejar los `fragments` para desplazar la vista actual directamente a una sección específica.

* Mejora de la experiencia del usuario: Permite una navegación fluida hacia elementos específicos de una página, especialmente en vistas largas.

* Compatibilidad con estándares web: Los `fragments` son compatibles con la semántica HTML y pueden ser interpretados por navegadores y herramientas externas.

## ¿Cómo lo resuelve?
Angular utiliza el servicio de enrutamiento para gestionar los `fragments`:

* Definiendo `fragments` en el Router: El enrutador de Angular permite incluir `fragments` en las rutas generadas.

* Desplazando automáticamente la vista: Cuando un fragment está presente en la URL, Angular se encarga de desplazarse al elemento correspondiente, siempre que el identificador exista en el DOM.

* Accediendo y manipulando `fragments` dinámicamente: Angular proporciona el servicio Router para programar navegación basada en `fragments`.

## Uso básico de fragments en Angular
* **Configuración de la ruta**, No necesitas realizar configuraciones especiales para `fragments`; estos se manejan como parte de las URL. Sin embargo, el desplazamiento automático necesita estar habilitado.

**Archivo `app-routing.module.ts`**:
```ts
import { NgModule } from '@angular/core';
import { RouterModule, Routes } from '@angular/router';
import { HomeComponent } from './home/home.component';

const routes: Routes = [
  { path: 'home', component: HomeComponent }
];

@NgModule({
  imports: [RouterModule.forRoot(routes, { anchorScrolling: 'enabled' })],
  exports: [RouterModule]
})
export class AppRoutingModule {}
```
En este caso:
  * La opción `{ anchorScrolling: 'enabled' }` habilita el desplazamiento automático basado en `fragments`.

* **Configuración del HTML**, En el componente de destino, define elementos con atributos id que coincidan con los `fragments`.
```html
<div id="section1">
  <h2>Section 1</h2>
  <p>This is the first section.</p>
</div>

<div id="section2">
  <h2>Section 2</h2>
  <p>This is the second section.</p>
</div>

<a routerLink="/home" fragment="section1">Go to Section 1</a>
<a routerLink="/home" fragment="section2">Go to Section 2</a>
```

* **Navegación programática con `fragments`**, Puedes navegar a fragments usando el servicio Router en TypeScript.
```ts
import { Component } from '@angular/core';
import { Router } from '@angular/router';

@Component({
  selector: 'app-home',
  template: `
    <button (click)="goToSection('section1')">Go to Section 1</button>
    <button (click)="goToSection('section2')">Go to Section 2</button>
  `
})
export class HomeComponent {
  constructor(private router: Router) {}

  goToSection(section: string): void {
    this.router.navigate(['/home'], { fragment: section });
  }
}
```

### Acceso al fragment actual
Puedes acceder al fragmento actual desde `ActivatedRoute`.
```ts
import { Component, OnInit } from '@angular/core';
import { ActivatedRoute } from '@angular/router';

@Component({
  selector: 'app-home',
  template: `<p>Current fragment: {{ currentFragment }}</p>`
})
export class HomeComponent implements OnInit {
  currentFragment: string | null = null;

  constructor(private route: ActivatedRoute) {}

  ngOnInit(): void {
    this.route.fragment.subscribe(fragment => {
      this.currentFragment = fragment;
    });
  }
}
```

## Buenas prácticas
* Define identificadores únicos: Asegúrate de que los elementos HTML tengan atributos id únicos para evitar conflictos.

* Usa fragments solo en vistas largas: Los fragments son útiles principalmente en páginas extensas o documentos que necesitan navegación interna.

* Habilita el desplazamiento automático: Configura `{ anchorScrolling: 'enabled' }` en el RouterModule para mejorar la experiencia del usuario.

  * **Desplazamiento personalizado**, Si necesitas personalizar el desplazamiento, Angular ofrece la opción scrollOffset:

  ```ts
  @NgModule({
    imports: [RouterModule.forRoot(routes, { 
      anchorScrolling: 'enabled', 
      scrollOffset: [0, 64] // Offset de 64 píxeles
    })],
    exports: [RouterModule]
  })
  export class AppRoutingModule {}
  ```
