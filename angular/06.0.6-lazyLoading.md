# Lazy Loading
El Lazy Loading (carga diferida) en Angular es una técnica para cargar módulos o partes de la aplicación bajo demanda, es decir, solo cuando son necesarios, en lugar de cargarlos durante el inicio de la aplicación. Esto se implementa principalmente en las rutas para optimizar el rendimiento y mejorar la experiencia del usuario.

## ¿Para qué sirve?
La carga diferida sirve para:

* Mejorar el tiempo de carga inicial: Al evitar cargar toda la aplicación de una sola vez.

* Optimizar el rendimiento: Reduce el tamaño del paquete JavaScript cargado al inicio.

* Organizar mejor la aplicación: Ayuda a dividir el código en módulos más pequeños y específicos.

## ¿Qué resuelve?
* Carga lenta inicial: Las aplicaciones grandes pueden tardar mucho en cargar si todos los módulos se cargan de forma anticipada (Eager Loading).

* Uso innecesario de recursos: Cargar módulos que no serán usados inmediatamente desperdicia memoria y recursos.

* Escalabilidad: Hace que las aplicaciones sean más manejables al separar las funcionalidades en módulos independientes.

## ¿Cómo lo resuelve?
Angular resuelve esto mediante la configuración de rutas con la función `loadChildren`. Esta función permite especificar un módulo que se cargará de forma diferida solo cuando la ruta correspondiente sea accedida.

## Ejemplo Básico
Supongamos una aplicación con un módulo de administración que no se necesita cargar inmediatamente.

**Estructura de la Aplicación**
* **`app.module.ts`**

* **`admin.module.ts`**

* **`admin.component.ts`**

**Paso 1: Crear el Módulo Diferido**, El módulo de administración `AdminModule`:
```ts
import { NgModule } from '@angular/core';
import { CommonModule } from '@angular/common';
import { RouterModule, Routes } from '@angular/router';
import { AdminComponent } from './admin.component';

const routes: Routes = [
  { path: '', component: AdminComponent },
];

@NgModule({
  declarations: [AdminComponent],
  imports: [CommonModule, RouterModule.forChild(routes)],
})
export class AdminModule {}
```
**Paso 2: Configurar Lazy Loading en las Rutas**, En el módulo principal, define la carga diferida con `loadChildren`.
```ts
import { NgModule } from '@angular/core';
import { RouterModule, Routes } from '@angular/router';

const routes: Routes = [
  {
    path: 'admin',
    loadChildren: () =>
      import('./admin/admin.module').then((m) => m.AdminModule),
  },
];

@NgModule({
  imports: [RouterModule.forRoot(routes)],
  exports: [RouterModule],
})
export class AppRoutingModule {}
```
**Aquí**:
  * La ruta admin utiliza `loadChildren` para cargar el módulo `AdminModule` solo cuando se acceda a `http://localhost:4200/admin`.

**Paso 3: Uso del Módulo de Administración**, El componente principal del módulo cargado diferido:
```ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-admin',
  template: `<h1>Admin Panel</h1>`,
})
export class AdminComponent {}
```
Cuando el usuario navega a `/admin`, el módulo AdminModule se carga dinámicamente.

## Flujo de Lazy Loading
* Inicio de la aplicación: Solo se cargan los módulos necesarios para las rutas iniciales.

* Navegación a una ruta con lazy loading: Angular detecta que la ruta requiere un módulo diferido.

* Carga dinámica: Angular solicita y carga el módulo necesario desde el servidor.

* Renderizado: Una vez cargado, el módulo renderiza el componente correspondiente.
