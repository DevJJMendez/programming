# `ngDoCheck`
El hook ngDoCheck es una función del ciclo de vida de los componentes de Angular que permite detectar y responder a cambios personalizados en el componente o en sus datos. Este hook se ejecuta durante cada ciclo de detección de cambios que Angular realiza en el componente.

Es parte de la detección de cambios personalizada, lo que significa que puedes usarlo para manejar situaciones en las que la detección de cambios estándar (**`ngOnChanges`**) de Angular no es suficiente.

## ¿Para qué sirve?
* Monitorear cambios personalizados que no son detectados automáticamente por Angular (por ejemplo, modificaciones directas en objetos o arreglos).

* Implementar lógica personalizada para reaccionar a cambios que Angular no detecta mediante los enfoques habituales.

* Detectar modificaciones más allá de las propiedades vinculadas con `@Input()` o del cambio del estado interno del componente.

## ¿Qué resuelve?
`ngDoCheck` resuelve casos como:

* Modificaciones de objetos por referencia: Angular no detecta cambios en propiedades de objetos o arreglos si se alteran directamente sin modificar la referencia.

* Control avanzado del ciclo de vida: Cuando necesitas ejecutar lógica específica durante el ciclo de detección de cambios.

* Optimización personalizada: Si deseas optimizar el comportamiento de detección de cambios en un componente específico.

## ¿Cómo lo resuelve?
`ngDoCheck` permite a los desarrolladores intervenir en el ciclo de detección de cambios de Angular para implementar comprobaciones adicionales o responder a situaciones complejas. Puedes comparar manualmente estados anteriores y actuales de los datos y reaccionar a cambios de manera más precisa.

## Ejemplo básico de `ngDoCheck`
```ts
import { Component, DoCheck } from '@angular/core';

@Component({
  selector: 'app-do-check-example',
  template: `
    <h3>Lista de tareas</h3>
    <ul>
      <li *ngFor="let tarea of tareas">{{ tarea }}</li>
    </ul>
    <button (click)="agregarTarea()">Agregar tarea</button>
  `,
})
export class DoCheckExampleComponent implements DoCheck {
  tareas: string[] = ['Tarea 1', 'Tarea 2'];

  // Variable para guardar el estado anterior
  private tareasPrevias: string[] = [];

  agregarTarea() {
    this.tareas.push(`Tarea ${this.tareas.length + 1}`);
  }

  ngDoCheck(): void {
    // Compara si hay diferencias entre el estado anterior y el actual
    if (this.tareasPrevias.length !== this.tareas.length) {
      console.log('Se detectó un cambio en la lista de tareas.');
      this.tareasPrevias = [...this.tareas]; // Actualiza el estado previo
    }
  }
}
```
**En este ejemplo:**
* Angular no detecta automáticamente los cambios en la longitud del array tareas porque no se está actualizando directamente su referencia.

* `ngDoCheck` monitorea manualmente el cambio en la longitud de la lista para reaccionar a los cambios.

## ¿Cómo funciona `ngDoCheck`?
* Angular ejecuta ngDoCheck después de evaluar los bindings de datos en el componente.

* No reemplaza la detección de cambios estándar de Angular, sino que la complementa con lógica personalizada.

* Puedes usarlo para implementar tu propia lógica de detección o validación de cambios.

## Casos de uso de ngDoCheck
1. **Detección personalizada de cambios en objetos o arreglos**, Si un objeto cambia sus propiedades pero no su referencia, Angular no detectará ese cambio. Con ngDoCheck, puedes implementar una comparación profunda.

```ts
import { Component, DoCheck } from '@angular/core';

@Component({
  selector: 'app-do-check-object',
  template: `<p>{{ datos.nombre }}</p>
             <button (click)="cambiarNombre()">Cambiar nombre</button>`,
})
export class DoCheckObjectComponent implements DoCheck {
  datos = { nombre: 'Angular' };

  cambiarNombre() {
    this.datos.nombre = 'Angular 16';
  }

  ngDoCheck(): void {
    console.log('ngDoCheck ejecutado. Datos:', this.datos);
  }
}
```
En este ejemplo, aunque cambie el valor de nombre, Angular no detectará automáticamente el cambio en el objeto datos.

2. **Optimización del rendimiento**, Puedes usar `ngDoCheck` para reducir la cantidad de operaciones realizadas durante la detección de cambios. Por ejemplo:
```ts
import { Component, DoCheck } from '@angular/core';

@Component({
  selector: 'app-performance-check',
  template: `
    <p>{{ valor }}</p>
    <button (click)="incrementar()">Incrementar</button>
  `,
})
export class PerformanceCheckComponent implements DoCheck {
  valor = 0;

  incrementar() {
    this.valor++;
  }

  ngDoCheck(): void {
    if (this.valor % 2 === 0) {
      console.log('El valor es par:', this.valor);
    }
  }
}
```

3. **Optimización de Detección de Cambios**: **ngDoCheck** es útil cuando se necesita optimizar la forma en que Angular realiza la detección de cambios, especialmente si **ngOnChanges** no cubre completamente tus necesidades.

4. **Complemento a ngOnChanges**: Si **ngOnChanges** no se activa por un cambio en una propiedad, **ngDoCheck** puede actuar como un complemento para cubrir esos casos.
