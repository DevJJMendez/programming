# Navegación Programática
La navegación programática es la capacidad de controlar la navegación entre rutas de una aplicación Angular utilizando código, en lugar de depender exclusivamente de enlaces declarativos como `routerLink`. Se logra utilizando el servicio `Router` proporcionado por Angular.

## ¿Para qué sirve?
Sirve para manejar navegaciones complejas que no pueden resolverse con enlaces estáticos, como:

* Redirigir a los usuarios después de realizar una acción (inicio de sesión, creación de un registro, etc.).

* Navegar a una ruta basada en lógica condicional (autenticación, parámetros dinámicos, etc.).

* Cambiar la ruta como parte de la respuesta a un evento.

## ¿Qué resuelve?
* Flexibilidad en la navegación: Permite cambiar rutas en tiempo de ejecución basándose en lógica del negocio.

* Interacción dinámica: Navegación basada en entradas del usuario, estados de la aplicación o eventos específicos.

* Control total: Brinda más control sobre cómo y cuándo ocurre la navegación.

## ¿Cómo lo resuelve?
Angular proporciona el servicio `Router`, que expone métodos como:

* **`navigate`**: Permite navegar a una ruta específica.

* **`navigateByUrl`**: Navega directamente a una URL.

## Métodos Clave del Router
* **Método `navigate`**, Usa un arreglo para especificar la ruta destino. Permite incluir parámetros dinámicos o **query params**.
```ts
this.router.navigate(['/ruta-destino', id], { queryParams: { key: 'value' } });
```

* **Método `navigateByUrl`**, Usa una cadena como URL para navegar directamente.
```ts
this.router.navigateByUrl('/ruta-destino');
```

## Ejemplo Básico
* **Redirigir al realizar una acción**, Supongamos que después de un inicio de sesión exitoso, deseas redirigir al usuario al **`dashboard`**.
```ts
import { Router } from '@angular/router';
import { Component } from '@angular/core';

@Component({
  selector: 'app-login',
  template: `
    <button (click)="login()">Iniciar Sesión</button>
  `,
})
export class LoginComponent {
  constructor(private router: Router) {}

  login() {
    // Lógica de autenticación
    const loginExitoso = true;

    if (loginExitoso) {
      this.router.navigate(['/dashboard']);
    }
  }
}
```

## Navegación con parámetros
Si necesitas navegar a una ruta que recibe un parámetro dinámico.
```ts
this.router.navigate(['/user', userId]);
```
Ruta configurada:
```ts
const routes: Routes = [
  { path: 'user/:id', component: UserComponent },
];
```
En `UserComponent`, se puede leer el parámetro utilizando `ActivatedRoute`:
```ts
import { ActivatedRoute } from '@angular/router';

@Component({
  selector: 'app-user',
  template: `<p>Usuario: {{ userId }}</p>`,
})
export class UserComponent {
  userId!: string;

  constructor(private route: ActivatedRoute) {
    this.userId = this.route.snapshot.paramMap.get('id')!;
  }
}
```

## Navegación con Query Params
Puedes añadir parámetros de consulta a la navegación.
```ts
this.router.navigate(['/search'], { queryParams: { term: 'angular' } });
```
En el componente de destino, puedes leer los query params:
```ts
import { ActivatedRoute } from '@angular/router';

@Component({
  selector: 'app-search',
  template: `<p>Búsqueda: {{ term }}</p>`,
})
export class SearchComponent {
  term!: string;

  constructor(private route: ActivatedRoute) {
    this.route.queryParamMap.subscribe((params) => {
      this.term = params.get('term')!;
    });
  }
}
```

## Navegación Condicional
```ts
if (isLoggedIn) {
  this.router.navigate(['/dashboard']);
} else {
  this.router.navigate(['/login']);
}
```

## Configuración Adicional
**`RelativeTo` (Rutas Relativas)**, Usa la propiedad relativeTo para navegar desde una ruta actual relativa en lugar de una absoluta.

## Buenas Prácticas
* Centralizar la lógica de navegación: Evita mezclar la navegación con lógica de componentes. Usa servicios si es necesario.

* Manejo de errores: Implementa manejo de errores para rutas inexistentes o fallos de redirección.

* Usa guards cuando sea necesario: Protege las rutas críticas.

* Evita hardcoding: Usa constantes o configuraciones para definir rutas clave.
