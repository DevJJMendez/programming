# `FormBuilder.control()`
El método FormBuilder.control() es una función proporcionada por el servicio FormBuilder en Angular que se utiliza para crear una instancia de FormControl, representando un único control en un formulario reactivo.

Un FormControl es la unidad básica en los formularios reactivos y se utiliza para manejar datos de entrada, estados y validaciones de un campo individual.

## ¿Para qué sirve FormBuilder.control()?
* Crear un control de formulario independiente o dentro de un grupo (FormGroup) o un arreglo (FormArray).

* Asignar un valor inicial y validadores a un control específico.

* Gestionar el estado y las validaciones de un campo de entrada de manera reactiva.

## ¿Qué problemas resuelve FormBuilder.control()?
* Inicialización tediosa: Antes de FormBuilder.control(), instanciar controles requería utilizar directamente el constructor de FormControl, lo que podía volverse repetitivo y aumentar la complejidad en formularios más grandes.

* Centralización de configuración: Facilita la centralización de configuración al usar el servicio FormBuilder para gestionar todos los aspectos del formulario.

* Reutilización y flexibilidad: Permite crear controles individuales de manera dinámica, reutilizándolos según sea necesario en diferentes partes de la aplicación.

## ¿Cómo lo resuelve?
* Sintaxis simplificada: Encapsula la lógica de inicialización en un método simple y directo.

* Declaración concisa: Permite especificar el valor inicial, validadores sincrónicos y asincrónicos directamente.

* Compatibilidad: Se integra perfectamente en FormGroup o FormArray, facilitando su uso en formularios complejos.

## Sintaxis de FormBuilder.control()
```ts
const control = this.fb.control(
  initialValue,            // Valor inicial
  validators,              // Validadores sincrónicos
  asyncValidators          // Validadores asincrónicos (opcional)
);
```

## Ejemplo básico de uso
* Creando un control independiente
```ts
import { Component } from '@angular/core';
import { FormBuilder, FormControl, Validators } from '@angular/forms';

@Component({
  selector: 'app-control-example',
  templateUrl: './control-example.component.html',
})
export class ControlExampleComponent {
  myControl: FormControl;

  constructor(private fb: FormBuilder) {
    this.myControl = this.fb.control('', [Validators.required, Validators.minLength(3)]);
  }

  submit() {
    console.log(this.myControl.value); // Devuelve el valor actual del control
  }
}
```
```html
<form (ngSubmit)="submit()">
  <label for="name">Name:</label>
  <input id="name" [formControl]="myControl" />
  <div *ngIf="myControl.errors?.['required']">Este campo es obligatorio.</div>
  <div *ngIf="myControl.errors?.['minlength']">Debe tener al menos 3 caracteres.</div>

  <button type="submit" [disabled]="myControl.invalid">Enviar</button>
</form>
```

## Usando FormBuilder.control() en un grupo
```ts
import { Component } from '@angular/core';
import { FormBuilder, FormGroup, Validators } from '@angular/forms';

@Component({
  selector: 'app-group-example',
  templateUrl: './group-example.component.html',
})
export class GroupExampleComponent {
  myForm: FormGroup;

  constructor(private fb: FormBuilder) {
    this.myForm = this.fb.group({
      username: this.fb.control('', [Validators.required]),
      email: this.fb.control('', [Validators.required, Validators.email]),
    });
  }

  submit() {
    console.log(this.myForm.value);
  }
}
```
```html
<form [formGroup]="myForm" (ngSubmit)="submit()">
  <label for="username">Username:</label>
  <input id="username" formControlName="username" />
  <div *ngIf="myForm.get('username')?.errors?.['required']">Requerido.</div>

  <label for="email">Email:</label>
  <input id="email" formControlName="email" />
  <div *ngIf="myForm.get('email')?.errors?.['email']">Email inválido.</div>

  <button type="submit" [disabled]="myForm.invalid">Enviar</button>
</form>
```
