# Interpolación de Datos
La interpolación en Angular es una técnica de data binding unidireccional que permite mostrar valores dinámicos en la interfaz de usuario (UI). Se usa para incrustar expresiones de JavaScript dentro de las plantillas HTML, encerrándolas entre doble llaves `{{ expresión }}`.

La interpolación está diseñada para tomar datos de la lógica del componente y renderizarlos en la vista de manera declarativa.

## ¿Para qué sirve?
* Mostrar datos dinámicos provenientes de propiedades o métodos del componente.

* Actualizar automáticamente la vista cuando los valores del componente cambian.

* Simplificar la lógica de renderizado, al permitir incrustar expresiones directamente en el HTML sin manipular el DOM manualmente.

## ¿Qué problemas resuelve?
* Renderizado de contenido dinámico: Evita tener que generar contenido HTML manualmente o manipular el DOM directamente.

* Sincronización de datos en tiempo real: Actualiza automáticamente la vista cuando los datos cambian en el componente.

* Legibilidad y mantenibilidad: Facilita la escritura de plantillas al usar un enfoque declarativo.

## ¿Cómo lo resuelve?
Angular utiliza su mecanismo de Change Detection para:

* Evaluar las expresiones dentro de las llaves dobles `{{ }}` en cada ciclo de detección de cambios.

* Actualizar el contenido renderizado en el DOM si el valor de la expresión cambia.

Esto lo hace de manera eficiente, asegurándose de que los datos del componente siempre estén sincronizados con la UI.

## Ejemplo
`app.component.ts`
```ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-root',
  template: `<h1>{{ titulo }}</h1><p>{{ mensaje }}</p>`
})
export class AppComponent {
  titulo: string = 'Bienvenido a Angular';
  mensaje: string = 'Este texto es generado dinámicamente';
}
```

### Uso de expresiones en interpolación
Puedes usar expresiones de JavaScript para manipular los datos directamente en la interpolación.

Ejemplo:
```html
<p>La suma es: {{ 10 + 20 }}</p>
<p>Mayúsculas: {{ mensaje.toUpperCase() }}</p>
```
### Reglas para la interpolación
1. Solo expresiones válidas de JavaScript:

   * Puedes realizar operaciones aritméticas, acceder a propiedades, llamar métodos, etc.

     * Ejemplo válido: `{{ usuario.nombre }}`, `{{ precio * cantidad }}`

     * Ejemplo inválido: `{{ let x = 10 }}` (declaraciones no permitidas).

2. Acceso seguro a propiedades:

   * Si existe la posibilidad de que una propiedad sea `undefined` o `null`, usa el operador de navegación segura `?.`.

     * Ejemplo: `{{ usuario?.nombre }}`.

3. Evita lógica compleja en las plantillas: Mueve cálculos o lógica avanzada al componente para mantener la plantilla limpia.

## Limitaciones de la interpolación
* No puede modificar el DOM: La interpolación solo puede mostrar datos. Para cambiar atributos del DOM, usa Property Binding `[propiedad]`.

* No puede manejar eventos: Para responder a eventos del usuario, usa Event Binding `(evento)`.

* Cuidado con métodos en la plantilla: Llamar métodos dentro de `{{ }}` puede ser costoso en términos de rendimiento si los métodos realizan operaciones complejas.
