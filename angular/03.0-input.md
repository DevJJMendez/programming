# `@Input`
Es un decorador proporcionado por Angular que permite a un **componente hijo** recibir datos desde un **componente padre**. Este decorador se utiliza en las propiedades de una clase de componente para marcar que dichas propiedades pueden ser inicializadas por un valor pasado desde el padre.

## ¿Para qué sirve?
`@Input` se utiliza para establecer un canal de comunicación `unidireccional` desde el componente padre hacia el componente hijo.

* **Propósito principal**:

  * Permitir que un componente hijo sea más dinámico y reutilizable al aceptar datos configurados por el padre.

* **Ejemplo de uso**:

  * En una lista de productos, el componente padre puede enviar información específica (nombre, precio, etc.) a un componente hijo que representa cada producto.

## ¿Qué resuelve?
El decorador @Input resuelve los siguientes problemas:

* **Inflexibilidad de componentes hijos**: Sin `@Input`, los componentes hijos no podrían recibir información dinámica y serían menos reutilizables.

* **Falta de modularidad**: Sin comunicación clara entre padre e hijo, la lógica de los datos quedaría mezclada en un único componente, dificultando la separación de responsabilidades.

* **Duplicación de código**: Permite reutilizar componentes hijos con diferentes datos sin necesidad de escribir código adicional.

## ¿Cómo lo resuelve?
`@Input` permite pasar valores de manera declarativa desde el HTML del componente padre al hijo. Esto se logra mediante **`property binding`**, donde se utiliza el selector del hijo y se pasa un valor.

## Funcionamiento
1. Definición de la propiedad `@Input` en el hijo: En el componente hijo, se utiliza el decorador `@Input` para definir una propiedad que recibirá los datos del padre.

```ts
import { Component, Input } from '@angular/core';

@Component({
  selector: 'app-hijo',
  template: `<p>El dato recibido es: {{ data }}</p>`,
})
export class HijoComponent {
  @Input() data!: string; // Recibe un valor desde el componente padre
}
```

2. **Paso de datos desde el padre**: En el componente padre, se utiliza el **selector del hijo** y se pasa un valor mediante el binding de propiedades `[property]="value"`.

```html
<app-hijo [data]="'Mensaje desde el padre'"></app-hijo>
```
Esto enlaza el valor `'Mensaje desde el padre'` con la propiedad data del componente hijo.

3. **Datos dinámicos**: El valor pasado al hijo puede ser una variable del componente padre, lo que permite dinamismo.

```ts
export class PadreComponent {
  mensaje = 'Hola, hijo!';
}
```
```html
<app-hijo [data]="mensaje"></app-hijo>
```

## Características de @Input
* **Unidireccional**: Los datos fluyen del padre al hijo, pero no al revés. Si el valor cambia en el padre, el hijo recibe el cambio automáticamente.

* **Reutilizable**: El hijo puede ser utilizado en múltiples lugares con diferentes valores.

* **Tipo de dato flexible**: La propiedad decorada con @Input puede ser de cualquier tipo: primitivo, objeto, arreglo, etc.

* **Compatibilidad con alias**: Puedes definir un alias para la propiedad, útil si el nombre en el padre difiere del usado en el hijo.

```ts
@Input('padreData') data!: string;
```
```html
<app-hijo [padreData]="'Texto con alias'"></app-hijo>
```

## Buenas Prácticas
* **Tipar las propiedades**: Usa tipos específicos para las propiedades decoradas con @Input.
```ts
@Input() data!: string;
```

* **Evitar lógica compleja**: No realices cálculos o transformaciones dentro de la propiedad decorada.

* **Documentar las propiedades**: Describe en comentarios qué datos espera recibir el hijo.

* **Usar valores predeterminados**: Configura valores iniciales para evitar errores si el padre no proporciona datos.
```ts
@Input() data: string = 'Valor predeterminado';
```

* **Alias para nombres legibles**: Usa alias si el nombre de la propiedad no es intuitivo.

## Manipulación de Datos en la Lógica del Componente Hijo
Además de la visualización, puedes manipular o transformar los datos dentro de la lógica del componente hijo. Puedes usar esos datos para realizar cálculos, tomar decisiones, o modificar otras variables del componente.

Ejemplo:
Supón que el componente hijo recibe un número y lo multiplica para mostrar el resultado en su template.

Componente Hijo:
```ts
import { Component, Input } from '@angular/core';

@Component({
  selector: 'app-hijo',
  template: `
    <p>El número recibido es: {{ data }}</p>
    <p>El número multiplicado por 2 es: {{ doubledData }}</p>
  `
})
export class HijoComponent {
  @Input() data!: number; // Recibe el número desde el padre

  get doubledData(): number {
    return this.data * 2; // Manipula el dato recibido
  }
}
```
Componente Padre:
```ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-padre',
  template: `<app-hijo [data]="numero"></app-hijo>`
})
export class PadreComponent {
  numero = 5; // Enviando un número al hijo
}
```

## Cambios Reactivos: Utilización en Funciones y Observables
Una vez que un componente hijo recibe los datos a través de @Input, es posible utilizar esa información en funciones reactivas, como las funciones de cambio, o incluso dentro de un Observable o Subject si estás manejando estados reactivos.

Ejemplo con ngOnChanges para reaccionar ante cambios:
Si deseas realizar algo cada vez que el valor de @Input cambie, puedes implementar el ciclo de vida ngOnChanges.

Componente Hijo:
```ts
import { Component, Input, SimpleChanges, OnChanges } from '@angular/core';

@Component({
  selector: 'app-hijo',
  template: `<p>El dato recibido es: {{ data }}</p>`
})
export class HijoComponent implements OnChanges {
  @Input() data!: string;

  ngOnChanges(changes: SimpleChanges): void {
    if (changes['data']) {
      console.log('El valor de "data" ha cambiado:', changes['data'].currentValue);
    }
  }
}
```
Componente Padre:
```ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-padre',
  template: `<app-hijo [data]="mensaje"></app-hijo>
             <button (click)="cambiarMensaje()">Cambiar mensaje</button>`
})
export class PadreComponent {
  mensaje = 'Hola desde el padre!';

  cambiarMensaje(): void {
    this.mensaje = 'Nuevo mensaje desde el padre!'; // Cambia el mensaje
  }
}
```
Cada vez que el valor de data cambie en el padre, el método ngOnChanges del hijo se ejecutará, permitiéndote realizar alguna acción o lógica.

Resultado
```bash
El dato recibido es: Hola desde el padre!
(Al presionar el botón)
El dato recibido es: Nuevo mensaje desde el padre!
```

## Uso en Formatos de Datos Complejos (Objetos, Arreglos)
No solo puedes pasar valores simples (como números o cadenas), sino que también puedes pasar objetos o arreglos. Puedes utilizar estos datos complejos para acceder a sus propiedades y manipularlos.

Ejemplo con un objeto:
Supón que el componente padre pasa un objeto con datos sobre un producto al componente hijo.

Componente Hijo:
```ts
import { Component, Input } from '@angular/core';

@Component({
  selector: 'app-hijo',
  template: `
    <p>Producto: {{ product.name }}</p>
    <p>Precio: ${{ product.price }}</p>
  `
})
export class HijoComponent {
  @Input() product!: { name: string, price: number }; // Recibe un objeto
}
```
Componente Padre:
```ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-padre',
  template: `<app-hijo [product]="producto"></app-hijo>`
})
export class PadreComponent {
  producto = { name: 'Zapato', price: 45 }; // Objeto de producto
}
```
Resultado en el navegador:
```ts
Producto: Zapato
Precio: $45
```

## Condicionales o Lógica de Presentación Basada en @Input
Puedes usar los datos recibidos en el componente hijo para decidir qué mostrar en el template o realizar alguna lógica de presentación. Esto es útil cuando quieres mostrar diferentes vistas o componentes dependiendo de los datos que recibas.

Ejemplo de lógica condicional:
Imagina que un componente recibe un valor que indica si un producto está en oferta o no.

Componente Hijo:
```ts
import { Component, Input } from '@angular/core';

@Component({
  selector: 'app-hijo',
  template: `
    <p>{{ productName }}</p>
    <div *ngIf="isOnSale">¡Este producto está en oferta!</div>
    <div *ngIf="!isOnSale">Este producto no está en oferta.</div>
  `
})
export class HijoComponent {
  @Input() productName!: string;
  @Input() isOnSale!: boolean; // Recibe información sobre si está en oferta
}
```
Componente Padre:
```ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-padre',
  template: `<app-hijo [productName]="producto.name" [isOnSale]="producto.onSale"></app-hijo>`
})
export class PadreComponent {
  producto = { name: 'Pantalón', onSale: true }; // Información del producto
}
```
Resultado en el navegador:
```ts
Pantalón
¡Este producto está en oferta!
```
