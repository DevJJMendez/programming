# `FormBuilder.group()`
Es una función del servicio FormBuilder en Angular que se utiliza para crear una instancia de FormGroup, la cual representa un formulario reactivo con una colección de controles (campos de entrada), junto con su estado, valor y validaciones asociadas.

## ¿Para qué sirve FormBuilder.group()?
* Definir la estructura y configuración de un formulario reactivo.

* Configurar los controles de un formulario (campos) de manera rápida y legible.

* Asociar validadores a cada control del formulario, ya sean sincrónicos o asincrónicos.

* Organizar los datos de los formularios en estructuras jerárquicas utilizando grupos anidados.

## ¿Qué problemas resuelve FormBuilder.group()?
* Complejidad en la inicialización manual de controles: Crear instancias de FormControl y FormGroup de manera manual puede volverse tedioso y propenso a errores, especialmente en formularios grandes.

* Legibilidad del código: Proporciona una sintaxis más limpia y concisa para crear formularios, mejorando la comprensión y el mantenimiento.

* Configuración centralizada: Permite definir el valor inicial, los validadores y las estructuras anidadas de los formularios en un solo lugar.

## ¿Cómo resuelve FormBuilder.group() estos problemas?
* Simplifica la creación de controles al encapsular la lógica dentro del método group.

* Proporciona una forma declarativa para configurar valores iniciales y validadores en una sola línea.

* Admite grupos de controles anidados para manejar estructuras complejas.

* Ofrece una API clara e intuitiva que reduce errores de configuración.

## Sintaxis de FormBuilder.group()
```ts
formGroupInstance = this.fb.group({
  controlName: ['initialValue', [Validators]],
  nestedGroup: this.fb.group({
    nestedControl: ['nestedValue', [Validators]],
  }),
});
```

## Uso práctico de FormBuilder.group()
* Formulario básico
```ts
import { Component } from '@angular/core';
import { FormBuilder, FormGroup, Validators } from '@angular/forms';

@Component({
  selector: 'app-basic-form',
  templateUrl: './basic-form.component.html',
})
export class BasicFormComponent {
  myForm: FormGroup;

  constructor(private fb: FormBuilder) {
    this.myForm = this.fb.group({
      username: ['', Validators.required], // Campo con validador requerido
      email: ['', [Validators.required, Validators.email]], // Múltiples validadores
      password: ['', [Validators.required, Validators.minLength(8)]],
    });
  }

  onSubmit() {
    console.log(this.myForm.value); // Devuelve un objeto con los valores de los controles
  }
}
```
```html
<form [formGroup]="myForm" (ngSubmit)="onSubmit()">
  <label for="username">Username:</label>
  <input id="username" formControlName="username" />
  <div *ngIf="myForm.get('username')?.errors?.['required']">Este campo es obligatorio.</div>

  <label for="email">Email:</label>
  <input id="email" formControlName="email" />
  <div *ngIf="myForm.get('email')?.errors?.['email']">Debe ser un email válido.</div>

  <label for="password">Password:</label>
  <input id="password" type="password" formControlName="password" />
  <div *ngIf="myForm.get('password')?.errors?.['minlength']">
    Debe tener al menos 8 caracteres.
  </div>

  <button type="submit" [disabled]="myForm.invalid">Enviar</button>
</form>
```

* Formulario con grupos anidados
```ts
import { Component } from '@angular/core';
import { FormBuilder, FormGroup, Validators } from '@angular/forms';

@Component({
  selector: 'app-nested-form',
  templateUrl: './nested-form.component.html',
})
export class NestedFormComponent {
  myForm: FormGroup;

  constructor(private fb: FormBuilder) {
    this.myForm = this.fb.group({
      personalInfo: this.fb.group({
        firstName: ['', Validators.required],
        lastName: ['', Validators.required],
      }),
      contactInfo: this.fb.group({
        email: ['', [Validators.required, Validators.email]],
        phone: ['', Validators.required],
      }),
    });
  }

  onSubmit() {
    console.log(this.myForm.value); // Estructura jerárquica de valores
  }
}
```
```html
<form [formGroup]="myForm" (ngSubmit)="onSubmit()">
  <div formGroupName="personalInfo">
    <label for="firstName">First Name:</label>
    <input id="firstName" formControlName="firstName" />
    <div *ngIf="myForm.get('personalInfo.firstName')?.errors?.['required']">Requerido.</div>

    <label for="lastName">Last Name:</label>
    <input id="lastName" formControlName="lastName" />
    <div *ngIf="myForm.get('personalInfo.lastName')?.errors?.['required']">Requerido.</div>
  </div>

  <div formGroupName="contactInfo">
    <label for="email">Email:</label>
    <input id="email" formControlName="email" />
    <div *ngIf="myForm.get('contactInfo.email')?.errors?.['email']">Email inválido.</div>

    <label for="phone">Phone:</label>
    <input id="phone" formControlName="phone" />
  </div>

  <button type="submit" [disabled]="myForm.invalid">Enviar</button>
</form>
```

## Ventajas de usar FormBuilder.group()
* Eficiencia: Menos código repetitivo.

* Claridad: Estructuras de formulario más fáciles de leer.

* Flexibilidad: Manejo de grupos y validadores personalizados.

* Escalabilidad: Ideal para formularios pequeños y grandes con controles dinámicos.

## Buenas prácticas al usar FormBuilder.group()
* Usa validadores reutilizables para no repetir lógica.

* Divide formularios grandes en grupos anidados para modularidad.

* Utiliza getters para acceder fácilmente a controles y grupos.

* Centraliza la definición del formulario en el constructor o método inicializador.
