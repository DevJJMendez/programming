# Event Binding
El Event Binding (enlace de eventos) es una característica de Angular que permite conectar eventos del DOM (como clics, cambios, entradas de teclado, etc.) con métodos o expresiones en la lógica del componente. Este enlace utiliza la sintaxis `()` para escuchar eventos y ejecutar una función del componente cuando se produce el evento.

## ¿Para qué sirve?
* Responder a interacciones del usuario: Permite ejecutar lógica personalizada en el componente cuando el usuario realiza acciones como hacer clic en un botón, escribir en un campo de texto, o desplazarse por una página.

* Sincronizar eventos del DOM con la lógica del componente: Facilita que el componente reaccione dinámicamente a los eventos generados en la plantilla.

* Vincular eventos DOM con métodos del componente: Simplifica el manejo de la interacción usuario-componente.

## ¿Qué resuelve?
Angular, a diferencia de manipular directamente el DOM con librerías como jQuery, utiliza el Event Binding para:

* Mantener el código limpio y desacoplado del DOM.

* Facilitar la interacción entre la vista (HTML) y el modelo (TS).

* Prevenir la manipulación insegura del DOM, manteniendo las buenas prácticas de seguridad (como proteger contra ataques XSS).

## ¿Cómo lo resuelve?
Event Binding utiliza la siguiente sintaxis para vincular un evento del DOM a un método del componente:

```html
<button (eventoDOM)="metodoComponente()">Texto</button>
```
  * `(eventoDOM)`: El evento del DOM que quieres escuchar (como **`click`**, **`input`**, **`change`**).

  * `metodoComponente()`: El método o expresión del componente que se ejecutará cuando ocurra el evento.

## Ejemplo básico
* Componente (TypeScript):
```ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-ejemplo',
  template: `
    <button (click)="saludar()">Hacer clic</button>
  `
})
export class EjemploComponent {
  saludar() {
    console.log('¡Hola desde Event Binding!');
  }
}
```
**Explicación**:
  * `(click)="saludar()"`: Cuando el usuario haga clic en el botón, se ejecutará el método `saludar()` del componente.

  * `Resultado`: Aparecerá el mensaje "¡Hola desde Event Binding!" en la consola del navegador.

## Tipos de eventos compatibles
Puedes vincular cualquier evento estándar del DOM con el Event Binding, como:

* Eventos de mouse: **`click`**, **`dblclick`**, **`mousedown`**, **`mouseup`**, **`mouseenter`**, **`mouseleave`**, etc.

* Eventos de teclado: **`keydown`**, **`keyup`**, **`keypress`**.

* Eventos de entrada: **`input`**, **`change`**, **`focus`**, **`blur`**.

* Eventos de formulario: **`submit`**, **`reset`**.

* Eventos personalizados: Emitidos desde componentes hijos con `@Output`.

## Event Binding con parámetros
Puedes pasar parámetros desde la plantilla al método del componente.

Ejemplo:
```html
<button (click)="saludar('Usuario')">Saludar</button>
```
```ts
saludar(nombre: string) {
  console.log(`¡Hola, ${nombre}!`);
}
```
Resultado: Al hacer clic, el mensaje en la consola será "¡Hola, Usuario!".

## Event Binding con expresiones
Además de llamar métodos, puedes usar expresiones simples directamente en el Event Binding.

Ejemplo:
```html
<button (click)="contador = contador + 1">Incrementar</button>
<p>{{ contador }}</p>
```
```ts
contador: number = 0;
```
