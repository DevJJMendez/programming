# `ngOnChanges`
El hook ngOnChanges es un método del ciclo de vida de un componente en Angular que se ejecuta cada vez que cambian los valores de las propiedades de entrada `@Input()` del componente. Este hook pertenece a la interfaz **`OnChanges`**, que puedes implementar opcionalmente en tus componentes para aprovechar esta funcionalidad.

## ¿Para qué sirve?
El hook ngOnChanges sirve para:

* Detectar cambios en las propiedades decoradas con `@Input()`.

* Ejecutar lógica en respuesta a dichos cambios.

* Mantener sincronizada la lógica interna del componente con los valores que recibe de su componente padre.

## ¿Qué resuelve?
* **Sincronización de datos**: Permite reaccionar de manera inmediata a los cambios en los valores de las propiedades de entrada.

* **Ejecutar lógica condicional**: Facilita la ejecución de lógica específica en función de los cambios detectados.

* **Evitar errores**: Previene problemas de desincronización entre el componente padre y el hijo, especialmente en sistemas complejos con enlaces de datos dinámicos.

## ¿Cómo lo resuelve?
Angular detecta automáticamente los cambios en las propiedades decoradas con `@Input()` y llama al método `ngOnChanges`, pasando como argumento un objeto de tipo `SimpleChanges`. Este objeto contiene información sobre las propiedades que cambiaron, sus valores anteriores y nuevos.

## Sintaxis de ngOnChanges
Para usar este hook, debes implementar la interfaz `OnChanges` en tu componente.

```ts
import { Component, Input, OnChanges, SimpleChanges } from '@angular/core';

@Component({
  selector: 'app-example',
  template: `<p>Valor recibido: {{ value }}</p>`,
})
export class ExampleComponent implements OnChanges {
  @Input() value: string = '';

  ngOnChanges(changes: SimpleChanges): void {
    console.log('Cambios detectados:', changes);
  }
}
```
## Argumento: SimpleChanges
El parámetro `changes` es de tipo `SimpleChanges`, un objeto que contiene detalles sobre las propiedades que cambiaron.

**Estructura de `SimpleChanges`**:
* **Clave**: El nombre de la propiedad de entrada que cambió.

* **Valor**: Un objeto de tipo `SimpleChange` con las siguientes propiedades:
  * `previousValue`: El valor anterior de la propiedad.

  * `currentValue`: El valor actual de la propiedad.

  * `firstChange`: Un booleano que indica si es la primera vez que la propiedad cambia.

```ts
ngOnChanges(changes: SimpleChanges): void {
  for (const propName in changes) {
    const change = changes[propName];
    console.log(`Propiedad: ${propName}`);
    console.log(`Valor anterior: ${change.previousValue}`);
    console.log(`Valor actual: ${change.currentValue}`);
    console.log(`¿Primer cambio?: ${change.firstChange}`);
  }
}
```
## Casos de uso
* **Sincronizar datos dinámicos**: Ideal para ajustar la lógica interna del componente según cambios en las propiedades recibidas.

* **Inicializar valores derivados**: Permite calcular o transformar datos basados en los valores de las propiedades entrantes.

* **Ejecutar efectos secundarios**: Por ejemplo, llamar a un servicio o actualizar una vista en respuesta a cambios.

* **Depuración y monitoreo**: Útil para rastrear cambios en tiempo de desarrollo o depuración.

# `SimpleChanges`
Es una clase proporcionada por Angular que se utiliza como el parámetro del hook del ciclo de vida `ngOnChanges`. Este objeto contiene información detallada sobre los cambios que ocurrieron en las propiedades de entrada `@Input()` de un componente.

Cada propiedad decorada con `@Input()` que cambia genera un registro dentro del objeto `SimpleChanges`, facilitando el acceso a los valores actuales, anteriores y si es el primer cambio de dicha propiedad.

## ¿Para qué sirve?
* **Rastrear cambios en propiedades de entrada**: Permite saber qué valores de propiedades han cambiado y cómo.

* **Facilitar el manejo de cambios específicos**: Proporciona información suficiente para ejecutar lógica condicional dependiendo del cambio.

* **Depurar**: Facilita la inspección de cambios en las propiedades de entrada para monitorear el flujo de datos entre componentes.

##  ¿Qué resuelve?
SimpleChanges resuelve los siguientes problemas:

* **Detección de cambios precisos**: Permite identificar qué propiedades cambiaron y cómo afectaron al componente.

* **Ejecución de lógica basada en cambios específicos**: Ayuda a ejecutar diferentes acciones según el tipo de cambio en una propiedad.

* **Sincronización de datos entre componentes**: Garantiza que un componente hijo pueda reaccionar a actualizaciones realizadas desde el componente padre.

##  ¿Cómo lo resuelve?
Angular genera automáticamente un objeto SimpleChanges cuando detecta cambios en las propiedades decoradas con `@Input()`. Este objeto se pasa al método ngOnChanges, proporcionando detalles específicos para cada propiedad que cambió.

Cada propiedad dentro de `SimpleChanges` es de tipo `SimpleChange`, y contiene:

* **`previousValue`**
  * Contiene el valor anterior de la propiedad antes del cambio.

  * Si es la primera vez que la propiedad cambia, será `undefined`.

* **`currentValue`**: El nuevo valor asignado a la propiedad.

* **`firstChange`**: Un booleano que indica si es la primera vez que la propiedad cambia.

* `isFirstChange()`: Un método que devuelve `true` si es la primera vez que la propiedad cambia.

##  Estructura de SimpleChanges
El objeto tiene la siguiente estructura:

```ts
{
  [propertyName: string]: SimpleChange;
}
```
**Donde**:
* `propertyName` es el nombre de la propiedad que cambió.

* El valor es un objeto de tipo `SimpleChange`.

## Casos de uso
1. **Comparación de valores actuales y anteriores**: Puedes comparar los valores actuales y anteriores para determinar qué lógica ejecutar:

```ts
ngOnChanges(changes: SimpleChanges): void {
  if (changes['value']) {
    const { previousValue, currentValue, firstChange } = changes['value'];
    if (firstChange) {
      console.log('Propiedad inicializada:', currentValue);
    } else {
      console.log(`Cambio detectado. Anterior: ${previousValue}, Actual: ${currentValue}`);
    }
  }
}
```

2. **Validación de datos**: Puedes usar `SimpleChanges` para validar nuevos valores antes de procesarlos:

```ts
ngOnChanges(changes: SimpleChanges): void {
  if (changes['value']) {
    const newValue = changes['value'].currentValue;
    if (typeof newValue === 'string' && newValue.length > 0) {
      console.log('Valor válido:', newValue);
    } else {
      console.error('Valor inválido');
    }
  }
}
```

3. **Optimización del comportamiento del componente**: Puedes evitar realizar cálculos innecesarios si el cambio no es relevante:

```ts
ngOnChanges(changes: SimpleChanges): void {
  if (changes['value'] && changes['value'].previousValue !== changes['value'].currentValue) {
    console.log('Procesando cambio...');
    this.performAction(changes['value'].currentValue);
  }
}

performAction(newValue: string): void {
  console.log('Acción realizada con:', newValue);
}
```

## Limitaciones
* **Solo detecta cambios en propiedades `@Input()`**: No funciona con variables locales o propiedades que no sean de entrada.

* **No detecta cambios anidados**: Si un objeto `@Input()` cambia una propiedad interna, SimpleChanges no lo detectará automáticamente.
  * Solución: Usa `ngDoCheck` para realizar detección de cambios personalizada.
