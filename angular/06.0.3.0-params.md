# `params`
`params` es una propiedad de la clase `ActivatedRoute` que contiene los parámetros de ruta actuales, definidos en la configuración de rutas de Angular. Estos parámetros son dinámicos y se utilizan para pasar datos en la URL.

Por ejemplo, en la ruta `/products/:id`, `:id` es un parámetro de ruta, y el valor que toma (por ejemplo, **123**) estará disponible en `params`.

## ¿Para qué sirve?
`params` se utiliza para:

* Acceder a valores dinámicos en la URL, como identificadores o datos que definen el estado de un componente.

* Vincular la URL con la lógica del componente, permitiendo que los valores de los parámetros afecten la visualización o comportamiento del componente.

* Implementar navegación dinámica, como cargar detalles de un producto basado en su **ID**.

## ¿Qué resuelve?
params resuelve el problema de cómo pasar y recibir datos dinámicos a través de la URL, una práctica común en aplicaciones SPA (Single Page Application).

**Problemas resueltos:**
* **Identificación de recursos dinámicos**: Permite identificar elementos específicos (productos, usuarios, etc.) basados en su ID.

* **Sincronización de estado con la URL**: Facilita que el estado de la aplicación sea representado en la URL, mejorando la experiencia de usuario.

* **Navegación modular**: Habilita la navegación basada en parámetros, mejorando la reutilización de componentes.

## ¿Cómo lo resuelve?
params se implementa como un **`observable`** en `ActivatedRoute`. Esto permite:

* **Escuchar cambios dinámicos en los parámetros de la ruta**: Si los parámetros cambian mientras el componente está activo, puedes reaccionar automáticamente.

* **Obtener valores directamente al cargar la ruta**: También puedes acceder a los parámetros estáticos con `snapshot`.

## Accediendo a params
* **Acceso a través de suscripción (para cambios dinámicos)**
```ts
import { Component, OnInit } from '@angular/core';
import { ActivatedRoute } from '@angular/router';

@Component({
  selector: 'app-product-detail',
  template: `
    <h1>Product ID: {{ productId }}</h1>
  `
})
export class ProductDetailComponent implements OnInit {
  productId: string | null = null;

  constructor(private route: ActivatedRoute) {}

  ngOnInit(): void {
    // Escucha de cambios en los parámetros
    this.route.params.subscribe(params => {
      this.productId = params['id'];
    });
  }
}
```

* **Acceso directo con Snapshot (solo para valores estáticos)**
```ts
ngOnInit(): void {
  this.productId = this.route.snapshot.params['id'];
}
```

### Configuración de rutas con parámetros
Para usar `params`, necesitas definir los parámetros en la configuración de rutas. Ejemplo:
```ts
const routes: Routes = [
  { path: 'products/:id', component: ProductDetailComponent },
];
```
* `:id` es un parámetro dinámico.

* Cualquier valor en la URL después de `/products/` se mapeará al parámetro `id`.
