# `FormGroup`
Es una clase de Angular utilizada en Reactive Forms para agrupar controles de formulario individuales (`FormControl`) o incluso otros grupos de controles (`FormGroup`). Representa una colección de controles de formulario que comparten un mismo estado y validaciones.

Un FormGroup permite gestionar el estado de un grupo de controles, como su valor, validaciones, estado de error, tocado/no tocado, y más.

## ¿Para qué sirve FormGroup?
* Agrupar controles relacionados: Organiza controles de formulario que tienen un propósito común, como datos de un usuario (nombre, correo, teléfono).

* Gestionar el estado colectivo del grupo: Proporciona un único punto para manejar el estado y las validaciones de todos los controles dentro del grupo.

* Facilitar validaciones a nivel de grupo: Permite definir validaciones que involucren múltiples controles, como comparar contraseñas (`password` y `confirmPassword`).

* Sincronizar datos con el modelo: Permite mapear y actualizar fácilmente estructuras de datos complejas.

## ¿Qué resuelve FormGroup?
* Gestión complicada de controles individuales: Si trabajas con muchos controles, manejarlos uno por uno es tedioso.

* Validaciones dependientes entre campos: Por ejemplo, validar que dos campos sean iguales (como contraseñas).

* Sincronización inconsistente: Sin una estructura, mantener los datos del formulario sincronizados con el modelo es más propenso a errores.

* Acceso al estado global: Necesitas saber si un formulario completo es válido, ha sido modificado o enviado.

## ¿Cómo lo resuelve FormGroup?
* Agrupación lógica: Crea una jerarquía de controles que facilita su manipulación como unidad.

* Validaciones centralizadas: Define validaciones que involucran múltiples campos en un solo lugar.

* Gestión simplificada del estado: Proporciona propiedades como `valid`, `invalid`, `dirty`, `pristine` a nivel de grupo.

* Integración con RxJS: Se puede observar los cambios en el valor o estado del grupo completo.

## Componentes clave de FormGroup
### Propiedades principales:
* **`value`**: Devuelve los valores actuales de todos los controles como un objeto.

* **`valid`**: Indica si todos los controles del grupo son válidos.

* **`invalid`**: Indica si algún control del grupo es inválido.

* **`dirty`**: Indica si algún control ha sido modificado.

* **`pristine`**: Indica si ningún control ha sido modificado.

* **`touched`**: Indica si algún control ha sido enfocado o interactuado.

### Métodos clave:
* **`get(controlName)`**: Obtiene un control específico por su nombre.

* **`setValue(value)`**: Establece valores para todos los controles del grupo.

* **`patchValue(value)`**: Actualiza solo algunos valores sin afectar el resto.

* **`reset(value?)`**: Restablece el estado del formulario, opcionalmente con valores iniciales.

## Configuración inicial
Para usar FormGroup, necesitas importar las clases necesarias de Angular:
```ts
import { FormGroup, FormControl, Validators } from '@angular/forms';
```

## Ejemplo básico
Definiendo un formulario con FormGroup
```ts
import { Component } from '@angular/core';
import { FormGroup, FormControl, Validators } from '@angular/forms';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
})
export class AppComponent {
  userForm: FormGroup;

  constructor() {
    this.userForm = new FormGroup({
      name: new FormControl('', [Validators.required, Validators.minLength(3)]),
      email: new FormControl('', [Validators.required, Validators.email]),
      age: new FormControl('', [Validators.required, Validators.min(18)]),
    });
  }

  onSubmit() {
    if (this.userForm.valid) {
      console.log('Formulario válido:', this.userForm.value);
    } else {
      console.log('Formulario inválido:', this.userForm.errors);
    }
  }
}
```
```html
<form [formGroup]="userForm" (ngSubmit)="onSubmit()">
  <label for="name">Nombre:</label>
  <input id="name" formControlName="name" />
  <div *ngIf="userForm.get('name')?.invalid && userForm.get('name')?.touched">
    El nombre es obligatorio y debe tener al menos 3 caracteres.
  </div>

  <label for="email">Correo:</label>
  <input id="email" formControlName="email" />
  <div *ngIf="userForm.get('email')?.invalid && userForm.get('email')?.touched">
    Introduce un correo válido.
  </div>

  <label for="age">Edad:</label>
  <input id="age" formControlName="age" type="number" />
  <div *ngIf="userForm.get('age')?.invalid && userForm.get('age')?.touched">
    La edad debe ser mayor o igual a 18.
  </div>

  <button type="submit" [disabled]="userForm.invalid">Enviar</button>
</form>
```

## Validaciones a nivel de grupo
Puedes definir validaciones que afecten a múltiples campos dentro del grupo.

Ejemplo:
Comparar contraseñas (password y confirmPassword):
```ts
import { ValidatorFn, AbstractControl } from '@angular/forms';

const passwordMatchValidator: ValidatorFn = (group: AbstractControl) => {
  const password = group.get('password')?.value;
  const confirmPassword = group.get('confirmPassword')?.value;
  return password === confirmPassword ? null : { passwordMismatch: true };
};

this.userForm = new FormGroup(
  {
    password: new FormControl('', Validators.required),
    confirmPassword: new FormControl('', Validators.required),
  },
  { validators: passwordMatchValidator }
);
```

## Ventajas de FormGroup
* Escalabilidad: Ideal para formularios con múltiples campos y jerarquías.

* Validaciones avanzadas: Facilita la creación de validaciones complejas.

* Acceso centralizado: Permite manejar el estado y las validaciones de forma global.

* Reutilización: Puedes reutilizar grupos de controles en diferentes partes de la aplicación.
