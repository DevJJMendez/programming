# `data`
En Angular, data es una propiedad de las rutas definida en el módulo de enrutamiento (`RouterModule`). Se utiliza para asociar información estática o metadatos a una ruta específica, los cuales luego pueden ser accedidos por los componentes que manejan esas rutas.

Estos metadatos son simplemente un objeto que contiene **claves y valores** que pueden ser leídos a través de `ActivatedRoute`.

## ¿Para qué sirve?
El atributo data permite:

* Proveer información estática a las rutas. Por ejemplo, títulos de páginas, permisos necesarios, o cualquier otro dato que un componente o guardia pueda necesitar.

* Simplificar la configuración de rutas. Evita que se necesiten servicios adicionales o constantes externas para manejar valores que son específicos de una ruta.

* Centralizar configuraciones específicas de las rutas.

## ¿Qué resuelve?
* Reduce la dependencia de servicios para datos estáticos: Al definir datos estáticos directamente en la configuración de rutas, se evita el uso de servicios solo para pasar información básica.

* Mejora la cohesión: Cada ruta puede tener su propia configuración asociada, haciendo que sea más fácil de entender y mantener.

* Facilita la personalización del comportamiento de componentes: Por ejemplo, personalizar el título de un componente basado en el dato estático definido en la ruta.

## ¿Cómo lo resuelve?
* Definiendo datos en la configuración de rutas: Los datos se especifican en la propiedad data de cada objeto de ruta.

* Accediendo a los datos con ActivatedRoute: Los datos están disponibles a través de la propiedad data del **observable** de `ActivatedRoute`, o directamente desde el `snapshot`.

## Configuración de data en una ruta
Ejemplo de configuración de rutas
```ts
import { NgModule } from '@angular/core';
import { RouterModule, Routes } from '@angular/router';
import { HomeComponent } from './home/home.component';
import { AboutComponent } from './about/about.component';

const routes: Routes = [
  {
    path: '',
    component: HomeComponent,
    data: { title: 'Home Page', requiresLogin: false }
  },
  {
    path: 'about',
    component: AboutComponent,
    data: { title: 'About Us', requiresLogin: true }
  }
];

@NgModule({
  imports: [RouterModule.forRoot(routes)],
})
export class AppRoutingModule {}
```
**En este ejemplo:**
  * La ruta raíz tiene metadatos como `title: 'Home Page'` y `requiresLogin: false`.

  * La ruta `/about` tiene `title: 'About Us'` y `requiresLogin: true`.

### Accediendo a los datos en el componente
Puedes acceder a los datos de las rutas usando la clase `ActivatedRoute`.

* **Acceso usando el `observable data`**
```ts
import { Component, OnInit } from '@angular/core';
import { ActivatedRoute } from '@angular/router';

@Component({
  selector: 'app-about',
  template: `
    <h1>{{ title }}</h1>
    <p>Requires Login: {{ requiresLogin }}</p>
  `
})
export class AboutComponent implements OnInit {
  title: string | null = null;
  requiresLogin: boolean = false;

  constructor(private route: ActivatedRoute) {}

  ngOnInit(): void {
    this.route.data.subscribe(data => {
      this.title = data['title'];
      this.requiresLogin = data['requiresLogin'];
    });
  }
}
```

* **Acceso usando el `snapshot`**, Si los datos no cambian mientras el componente está activo, puedes usar el `snapshot`:
```ts
ngOnInit(): void {
  const data = this.route.snapshot.data;
  this.title = data['title'];
  this.requiresLogin = data['requiresLogin'];
}
```

### Usos comunes de data
* Definir títulos de página:
```ts
data: { title: 'Contact Us' }
```

* Proveer roles o permisos requeridos:
```ts
data: { roles: ['admin', 'editor'] }
```

* Definir configuraciones específicas de vista:
```ts
data: { layout: 'fullscreen' }
``` 

* Configurar breadcrumbs (migas de pan):
```ts
data: { breadcrumb: 'Dashboard' }
```

### data con Guards
Puedes usar data para pasar información a los guardias de ruta, como roles o permisos necesarios para acceder a la ruta.
```ts
{
  path: 'admin',
  component: AdminComponent,
  canActivate: [AuthGuard],
  data: { roles: ['admin'] }
}
```

## Buenas prácticas
* Usar datos solo para valores estáticos: Si los datos cambian dinámicamente, utiliza un servicio en su lugar.

* Evitar sobrecargar la configuración de rutas: No abuses de data para almacenar información compleja. Mantén los datos simples y específicos a la ruta.

* Documenta los datos usados en cada ruta: Esto facilita el mantenimiento y asegura que los desarrolladores sepan qué datos esperar.
