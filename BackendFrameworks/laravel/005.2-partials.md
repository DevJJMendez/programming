### Directiva `@include`

La directiva **@include** se usa para incluir una vista Blade dentro de otra vista. Esto es útil para fragmentar tu código en componentes reutilizables, como cabeceras, pies de página, barras de navegación, etc.

### Partials

Partials son fragmentos de vistas Blade que puedes incluir en otras vistas. Se usan típicamente para incluir secciones de HTML que se repiten en múltiples lugares de tu aplicación, como **headers**, **footers**,**navbars**, etc.

### Ejemplo Completo

1. **Definir un Partial**:
```js
<!-- resources/views/partials/navbar.blade.php -->
<nav>
    <!-- Navbar content -->
</nav>
```
2. **Incluir un Partial en una Vista**:
```php
<!-- resources/views/layouts/app.blade.php -->
<!DOCTYPE html>
<html>
<head>
    <title>My App - @yield('title')</title>
</head>
<body>
    <header>
        @include('partials.navbar')
    </header>

    <footer>
        @include('partials.footer')
    </footer>
</body>
</html>
```
### Enviar Información

Enviar datos a partials en Blade es una técnica útil para personalizar y reutilizar fragmentos de vistas en diferentes contextos. Aunque los partials son más simples y directos, puedes pasar datos a ellos para hacerlos más dinámicos y reutilizables.

**Enviar Datos a Partials**

- **Definiendo un Partial**
  
Primero, crea un partial que pueda recibir datos:
```php
<!-- resources/views/partials/alert.blade.php -->
<div class="alert alert-{{ $type }}">
    {{ $message }}
</div>
```
En este ejemplo, el partial `alert.blade.php` espera dos variables: `$type` y `$message`.

- **Incluir el Partial y Pasar Datos**

Cuando incluyes el partial en una vista, puedes pasarle los datos como un array asociativo:
```php
<!-- resources/views/home.blade.php -->
@extends('layouts.app')

@section('content')
    <h1>Welcome to the Home Page</h1>
    @include('partials.alert', ['type' => 'success', 'message' => 'Operation successful!'])
@endsection
```

### Diferencias y Cuándo Usar Cada Uno
- **Partials**:
  - **Simplicidad**: Partials son más simples y directos. Úsalos cuando solo necesitas fragmentar tu HTML sin lógica asociada.
  - **Casos de Uso Comunes**: Cabeceras, pies de página, barras de navegación, y pequeñas secciones de HTML que se repiten.

- **Components**:
  - **Encapsulación**: Components encapsulan tanto la lógica como la presentación. Son ideales cuando necesitas reutilizar código con comportamiento específico.
  - **Flexibilidad**: Los componentes pueden ser class-based, permitiendo añadir métodos y lógica más compleja.
- **Casos de Uso Comunes**: Formularios, alertas, tarjetas, modales, y cualquier otro elemento UI que tenga lógica asociada.
