### Query Builder
El Query Builder de Laravel proporciona una interfaz fluida y conveniente para construir y ejecutar consultas de bases de datos SQL. Es compatible con varios sistemas de bases de datos, incluyendo MySQL, PostgreSQL, SQLite y SQL Server. Utiliza una sintaxis expresiva que facilita la construcción de consultas complejas de manera sencilla y legible.

### Características del Query Builder
Interfaz fluida: Permite encadenar métodos para construir consultas de manera intuitiva.
Compatibilidad: Soporta múltiples bases de datos.
Seguridad: Utiliza binding de parámetros para prevenir inyecciones SQL.
Versatilidad: Soporta consultas **SELECT**, **INSERT**, **UPDATE**, **DELETE**, y muchas otras operaciones SQL.

### Ejemplos de Uso

1. **SELECT Básico**
```php
$users = DB::table('users')->get();
```
Esto retorna todos los registros de la tabla users.

2. **WHERE Clauses**
```php
$users = DB::table('users')->where('votes', '>', 100)->get();
```
Este ejemplo obtiene todos los usuarios con más de 100 votos.

3. **OR Clauses**
```php
$users = DB::table('users')
            ->where('votes', '>', 100)
            ->orWhere('name', 'John')
            ->get();
```
Obtiene todos los usuarios con más de 100 votos o con el nombre 'John'.

4. **Select Específico**
```php
$users = DB::table('users')->select('name', 'email')->get();
```
Selecciona solo los campos **name** y **email** de la tabla **users**.

5. **Uso de `Join`**
```php
$users = DB::table('users')
            ->join('contacts', 'users.id', '=', 'contacts.user_id')
            ->select('users.*', 'contacts.phone')
            ->get();
```
Realiza una consulta con un **join** entre las tablas **users** y **contacts**.

6. **Agrupamiento y Agregaciones**
```php
$users = DB::table('users')
            ->groupBy('status')
            ->having('status', '>', 1)
            ->select(DB::raw('count(*) as user_count, status'))
            ->get();
```
Agrupa los usuarios por el campo status y obtiene el conteo de usuarios para cada estado.

7. **Insertar Datos**
```php
DB::table('users')->insert([
    'name' => 'John',
    'email' => 'john@example.com',
    'votes' => 0
]);
```
Inserta un nuevo registro en la tabla **users**.

8. **Actualizar Datos**
```php
DB::table('users')
    ->where('id', 1)
    ->update(['votes' => 1]);
```
Actualiza el campo **votes** del usuario con **id** 1 a 1.

9. **Eliminar Datos**
```php
DB::table('users')
    ->where('votes', '<', 100)
    ->delete();
```
Elimina todos los usuarios con menos de 100 votos.

### Encadenamiento de Consultas
Una de las ventajas del Query Builder de Laravel es la capacidad de encadenar métodos para construir consultas complejas.
```php
$users = DB::table('users')
            ->where('status', 'active')
            ->orderBy('name', 'asc')
            ->take(10)
            ->get();
```
Esta consulta obtiene los primeros 10 usuarios activos ordenados por nombre en orden ascendente.

### Paginar Resultados
El Query Builder también soporta paginación sencilla.
```php
$users = DB::table('users')->paginate(15);
```
Obtiene 15 usuarios por página.
