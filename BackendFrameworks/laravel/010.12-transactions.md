### Transactions
Las transacciones en Laravel son una característica poderosa que te permite realizar múltiples operaciones de base de datos de forma atómica, asegurando que todas las operaciones se completen con éxito antes de confirmar los cambios. Si alguna de las operaciones falla, puedes deshacer (**rollback**) todas las operaciones realizadas durante la transacción, manteniendo la integridad de los datos.

### Uso de Transacciones en Laravel
Laravel proporciona métodos sencillos para manejar transacciones a través de su componente de base de datos. Los dos métodos principales son **`DB::transaction`** y **`DB::beginTransaction`**, **`DB::commit`**, y **`DB::rollBack`**.

#### DB::transaction
El método más común para manejar transacciones es **DB::transaction**. Este método toma un `closure` que recibe el código de las operaciones que deseas ejecutar dentro de la transacción.
```php
use Illuminate\Support\Facades\DB;

DB::transaction(function () {
    DB::table('users')->update(['votes' => 1]);

    DB::table('posts')->delete();
});
```
En este ejemplo, ambas operaciones (actualización y eliminación) se ejecutarán dentro de una transacción. Si alguna de las operaciones falla, todas las operaciones realizadas dentro de la transacción se revertirán automáticamente.

#### `DB::beginTransaction`, `DB::commit`, `DB::rollBack`
Si necesitas más control sobre el manejo de la transacción, puedes usar los métodos **DB::beginTransaction**, **DB::commit**, y **DB::rollBack**.
```php
use Illuminate\Support\Facades\DB;

try {
    DB::beginTransaction();

    DB::table('users')->update(['votes' => 1]);

    DB::table('posts')->delete();

    DB::commit();
} catch (\Exception $e) {
    DB::rollBack();
    // Manejar la excepción
}
```
En este ejemplo, inicias la transacción con `DB::beginTransaction`, realizas las operaciones y, si todas tienen éxito, confirmas los cambios con `DB::commit`. Si ocurre una excepción, deshaces los cambios con `DB::rollBack`.

### Anidamiento de Transacciones
Laravel también soporta el anidamiento de transacciones. Si una transacción interna falla, se revertirán todas las transacciones anidadas.
```php
use Illuminate\Support\Facades\DB;

DB::transaction(function () {
    DB::table('users')->update(['votes' => 1]);

    DB::transaction(function () {
        DB::table('posts')->delete();
    });
});
```
En este ejemplo, si cualquiera de las transacciones falla, se revertirán todas las operaciones realizadas.

### Bloqueo de Filas
En algunos casos, es posible que necesites bloquear filas durante una transacción para prevenir que otros procesos modifiquen los datos. Puedes usar `DB::raw` con los métodos `select` para lograr esto.
```php
use Illuminate\Support\Facades\DB;

DB::transaction(function () {
    $users = DB::table('users')->where('votes', '>', 100)->lockForUpdate()->get();

    // Procesar usuarios
});
```
En este ejemplo, las filas seleccionadas estarán bloqueadas hasta que la transacción se complete.

### Uso de Transacciones con Eloquent
Puedes usar transacciones con Eloquent de la misma manera que con el **Query Builder**.
```php
use Illuminate\Support\Facades\DB;

DB::transaction(function () {
    $user = User::find(1);
    $user->votes = 1;
    $user->save();

    $post = Post::find(1);
    $post->delete();
});
```

## Consideraciones de Rendimiento
El uso de transacciones puede afectar el rendimiento de tu aplicación si no se utiliza adecuadamente. Es importante:

- Mantener las transacciones lo más cortas posible.
- Evitar operaciones largas o intensivas dentro de una transacción.
- Asegurarse de manejar adecuadamente las excepciones y errores.
