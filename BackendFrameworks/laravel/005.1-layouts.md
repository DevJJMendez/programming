### Layouts

En Laravel, los layouts (diseños o plantillas base) son una característica del motor de plantillas **Blade** que permite definir una estructura común para varias vistas. Esto facilita la consistencia del diseño y reduce la repetición de código.

### Layout Base
Un layout base es una plantilla que contiene la estructura HTML común para varias vistas. Se define utilizando la sintaxis de Blade.

### Directiva `@extends`

La directiva `@extends` en **Blade** se utiliza para indicar que una vista específica extiende o hereda un layout base. Esto es fundamental para mantener una estructura consistente y reutilizable en las vistas de tu aplicación Laravel. Usando `@extends`, puedes definir un diseño base común y luego crear vistas que completen las secciones definidas en ese diseño.

**Sintaxis y Uso Básico de `@extends`**

La directiva `@extends` se coloca al principio de una vista y toma como argumento el nombre de la vista de layout que se está extendiendo. Por convención, los layouts se colocan en la carpeta `resources/views/layouts`.

### Inyeccion de Contenido con `@yield()` ó `@section()`

1. **`@yield`**: se utiliza en un **layout** para definir un espacio donde **se inyectará el contenido** de una sección desde una vista que extiende ese layout. Se define en el layout y crea un espacio reservado para una sección que será completada por el contenido de una **vista hija**. Básicamente, actúa como un marcador de posición.

2. **`@section`**: se utiliza en vistas que extienden un layout para definir el contenido que debe ser insertado en los lugares marcados por `@yield`.

### Ejemplo Completo

- **layout base**
```php
<!-- resources/views/layouts/app.blade.php -->
<!DOCTYPE html>
<html>
<head>
    <title>My App - @yield('title')</title>
</head>
<body>
<div class='container'>
    @yield('content')
</div>
<main class="container">
        @yield('content')
    </main>
</body>
</html>
```

- **Vista Hija**
```php
<!-- resources/views/home.blade.php -->
@extends('layouts.app')

@section('title', 'Home')

@section('content')
    <h1>Welcome to the Home Page</h1>
    <p>This is the content of the home page.</p>
@endsection
```
