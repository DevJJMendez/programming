**Directiva `@push()`**

La directiva `@push` en Laravel Blade es una herramienta poderosa para gestionar la inclusión de **scripts**, **estilos** y otros elementos en tu aplicación de una manera flexible y modular.

`@push` te permite agregar contenido a una pila de secciones (**stack**) que puedes definir en cualquier parte de tu plantilla principal. Esto es especialmente útil cuando quieres agregar **scripts** o estilos **desde vistas secundarias sin modificar la estructura base de tu plantilla.**

**Estructura Básica de `@push`**
```php
@push('scripts')
    <script src="/example.js"></script>
@endpush
```
- `@push('scripts')`: Empuja el contenido hacia una sección de pila llamada scripts.
- `<script src="/example.js"></script>`: El contenido que estás empujando a la pila. En este caso, estás agregando un script.
- `@endpush`: Marca el final del contenido que estás empujando a la pila.

**¿CÓMO FUNCIONA @push**
1. **Definición de la Pila:**
En tu plantilla base, defines la sección de pila utilizando `@stack`:
```php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    @stack('styles') <!-- Aquí se insertan los estilos -->
</head>
<body>
    @yield('content')
    @stack('scripts') <!-- Aquí se insertan los scripts -->
</body>
</html>
```
2. **Agregando Contenido a la Pila:**
En tus vistas, puedes agregar contenido a la pila usando `@push`:
```php
@push('scripts')
    <script src="/example.js"></script>
@endpush
```
Esto empuja el contenido hacia la pila **scripts**.
3. **Renderización del Contenido:**
El contenido en la pila scripts se renderiza en el lugar donde has colocado `@stack('scripts')` en tu plantilla base.

**EJEMPLO COMPLETO**

Supongamos que tienes una plantilla base y varias vistas. Aquí tienes un ejemplo de cómo puedes usar `@push` y `@stack`:

**Archivo de Plantilla Base (`resources/views/layouts/app.blade.php`)**
```php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>@yield('title', 'Default Title')</title>
    @stack('styles') <!-- Aquí se insertan los estilos -->
</head>
<body>
    @yield('content')
    @stack('scripts') <!-- Aquí se insertan los scripts -->
</body>
</html>
```
**Vista que Usa la Plantilla Base (`resources/views/home.blade.php`)**
```php
@extends('layouts.app')

@section('title', 'Home Page')

@push('styles')
    <link rel="stylesheet" href="/home.css">
@endpush

@section('content')
    <h1>Welcome to the Home Page</h1>
@endsection
```
**Vista que Agrega Scripts (`resources/views/home.blade.php`)**
```php
@extends('layouts.app')

@section('title', 'Home Page')

@push('styles')
    <link rel="stylesheet" href="/home.css">
@endpush

@section('content')
    <h1>Welcome to the Home Page</h1>
@endsection

@push('scripts')
    <script src="/home.js"></script>
@endpush
```
### Casos de Uso Comunes para `@push`

1. **Incluir Scripts o Estilos Específicos en Páginas:** Agregar scripts o estilos específicos para **ciertas vistas sin modificar la plantilla base**.
2. **Extender Funcionalidades de Vistas Secundarias:** Añadir funcionalidades adicionales desde vistas secundarias.
3. **Condicionales Basados en Contexto:** Incluir contenido condicional basado en el contexto.
```php
@push('scripts')
    @if($someCondition)
        <script src="/conditional-script.js"></script>
    @endif
@endpush
```
