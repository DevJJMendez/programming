### manyToMany
se utiliza cuando un modelo puede tener múltiples instancias de otro modelo y viceversa. Por ejemplo, un `User` puede estar inscrito en múltiples `Group`, y un `Group` puede tener múltiples `User` registrados.

### Estructura de la Relación `Many-to-Many`
Para implementar una relación **muchos a muchos**, necesitas **tres tablas** en tu base de datos:

1. La tabla del primer modelo.
2. La tabla del segundo modelo.
3. Una **tabla pivote** intermedia que **almacena las claves foráneas** de ambos modelos.
   - **Nomenclatura para crear esta**:
      - se nombran con los nombres de las dos tablas separado con un guion bajo.
      - se nombran en **orden alfabetico**.
      - se crea la migracion **sin un modelo**.
      - ejemplo:
    ```bash
    php artisan make:migration create_group_user_table
    ```
### Migraciones

`User`
```php
Schema::create('users', function (Blueprint $table) {
            $table->unsignedBigInteger('user_id', true);
        });
```
`Group`
```php
Schema::create('groups', function (Blueprint $table) {
            $table->unsignedBigInteger('group_id', true);
        });
```
`group_user`
```php
Schema::create('group_user', function (Blueprint $table) {
            $table->unsignedBigInteger('group_user_id', true);

            $table->unsignedBigInteger('group_id');
            $table->foreign('group_id')->references('group_id')->on('groups')
                ->onDelete('cascade')
                ->onUpdate('cascade');
            
            $table->unsignedBigInteger('user_id');
            $table->foreign('user_id')->references('user_id')->on('groups')
                ->onDelete('cascade')
                ->onUpdate('cascade');
        });
```
### Parámetros que Recibe `belongsToMany()`
1. `$related`: El modelo relacionado.
```php
public function courses()
{
    return $this->belongsToMany(Course::class);
}
```
2. `$table` (opcional): El nombre de la tabla pivote. Si no se proporciona, Eloquent asume el nombre de la tabla pivote como una combinación de los nombres de los modelos en orden alfabético, por ejemplo, `group_user`.
```php
public function courses()
{
    return $this->belongsToMany(Course::class, 'group_user');
}
```
3. `$foreignPivotKey` (opcional): La clave foránea del modelo actual en la tabla pivote.
```php
public function courses()
{
    return $this->belongsToMany(Course::class, 'course_student', 'user_id');
}
```
4. `$relatedPivotKey` (opcional): La clave foránea del modelo relacionado en la tabla pivote.
```php
public function courses()
{
    return $this->belongsToMany(Course::class, 'course_student', 'student_id', 'course_id');
}
```
5. `$parentKey` (opcional): La clave principal del modelo actual.

6. `$relatedKey` (opcional): La clave principal del modelo relacionado.

### Modelos

`User`
```php
class User extends Authenticatable
{
    public function groups()
    {
        return $this->belongsToMany(Group::class, 'group_user', 'user_id', 'group_id', 'user_id', 'group_id');
    }
}
```
`Group`
```php
class Group extends Model
{
    public function users()
        {
            return $this->belongsToMany(User::class, 'group_user', 'group_id', 'user_id', 'group_id', 'user_id');
        }
}
```
