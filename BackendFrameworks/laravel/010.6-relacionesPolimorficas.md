## Morphs
Las relaciones polimórficas en Laravel permiten que **un modelo pertenezca a más de un modelo** en una única asociación. Esto es útil cuando se necesita que **diferentes tipos de modelos compartan una relación.**

## Relaciones Polimórficas Uno a Uno
Supongamos que tienes una tabla `photos` que puede pertenecer a tanto `users` como a `products`.

### Estructura de Tablas

`photos`
| id  | imageable_id | imageable_type | url |
| --- | ------------ | -------------- | --- |

`users`
| id  | name | email |
| --- | ---- | ----- |

`products`
| id  | name | description |
| --- | ---- | ----------- |

## Modelos
`Photo`
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Photo extends Model
{
    public function imageable()
    {
        return $this->morphTo();
    }
}
```
`User`
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class User extends Model
{
    public function photos()
    {
        return $this->morphMany(Photo::class, 'imageable');
    }
}
```
`Product`
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Product extends Model
{
    public function photos()
    {
        return $this->morphMany(Photo::class, 'imageable');
    }
}
```
Los registros se verian de la siguiente forma:
`photos`
| id  | imageable_id | imageable_type | url |
| 1 | user_photo.jpg | -------------- | --- |
| 2 | ------------ | -------------- | --- |
### Uso de la relación

**Asignar una `Photo` a un `User`**
```php
$user = User::find(1);
$photo = new Photo(['url' => 'profile.jpg']);
$user->photos()->save($photo);
```
**Asignar una `Photo` a un `Product`**
```php
$product = Product::find(1);
$photo = new Photo(['url' => 'product.jpg']);
$product->photos()->save($photo);
```
**Obtener el Modelo asociado a una `Photo`**
```php
$photo = Photo::find(1);
$imageable = $photo->imageable; // Puede ser un User o un Product
```
De esta forma se verian los registros:
| id  | imageable_id | imageable_type | url |
| --- | ------------ | -------------- | --- |

## Relación Polimórfica Uno a Muchos
Las relaciones polimórficas uno a muchos son similares, pero se utilizan para relaciones donde un modelo puede tener muchos otros modelos.

### Estructura de Tablas
comments (id, commentable_id, commentable_type, body)
posts (id, title, body)
videos (id, title, url)

## Modelos

`Comment`
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Comment extends Model
{
    public function commentable()
    {
        return $this->morphTo();
    }
}
```
`Post`
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Post extends Model
{
    public function comments()
    {
        return $this->morphMany(Comment::class, 'commentable');
    }
}
```
`Video`
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Video extends Model
{
    public function comments()
    {
        return $this->morphMany(Comment::class, 'commentable');
    }
}
```
## Relaciones Polimórficas Muchos a Muchos
Las relaciones polimórficas muchos a muchos permiten que un modelo pertenezca a varios otros modelos, y que esos otros modelos también pertenezcan a varios otros modelos.

**Estructura de Tablas**
tags (id, name)
taggables (tag_id, taggable_id, taggable_type)
posts (id, title, body)
videos (id, title, url)

**Modelos**
`Tag`
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Tag extends Model
{
    public function posts()
    {
        return $this->morphedByMany(Post::class, 'taggable');
    }

    public function videos()
    {
        return $this->morphedByMany(Video::class, 'taggable');
    }
}
```
`Post`
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Video extends Model
{
    public function tags()
    {
        return $this->morphToMany(Tag::class, 'taggable');
    }
}
```
`Video`
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Video extends Model
{
    public function tags()
    {
        return $this->morphToMany(Tag::class, 'taggable');
    }
}
```
