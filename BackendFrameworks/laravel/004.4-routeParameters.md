### Parametros de Ruta

Los parámetros de ruta en Laravel permiten capturar valores de la URL y pasarlos a los controladores o closures que manejan las rutas. Son esenciales para construir rutas dinámicas y responder a peticiones basadas en valores específicos dentro de la URL.

**Tipos de Parámetros de Ruta**

- Parámetros Requeridos
- Parámetros Opcionales

1. **Parámetros Requeridos**: Un parámetro de ruta requerido debe estar presente en la URL para que la ruta coincida. Los parámetros requeridos se definen encerrando el nombre del parámetro entre llaves `{}`.

**Ejemplo**
```php
Route::get('/user/{id}', function ($id) {
    return 'User '.$id;
});
```
- En este ejemplo, la ruta responderá a URLs como `/user/1`, `/user/42`, etc. El valor de `{id}` se pasará a la función como `$id`.

2. **Parámetros Opcionales**: Los parámetros opcionales se definen agregando un signo de interrogación `?` después del nombre del parámetro dentro de las llaves. Debes proporcionar un valor por defecto para el parámetro en el controlador o closure.
```php
Route::get('/user/{name?}', function ($name = 'Guest') {
    return 'Hello '.$name;
});
```
- Esta ruta responderá tanto a `/user` como a `/user/John`. Si el parámetro `{name}` no se proporciona, el valor por defecto será **'Guest'**.

### Restricciones de Parámetros (Route Constraints)
Laravel permite restringir los valores que los parámetros pueden aceptar utilizando expresiones regulares. Esto se logra con el método `where`.

**Ejemplo**
```php
Route::get('/user/{id}', function ($id) {
    return 'User '.$id;
})->where('id', '[0-9]+');
```
- Esta ruta solo coincidirá si el parámetro `{id}` **es un número**.

### Parámetros de Ruta Múltiples
Puedes definir múltiples parámetros en una ruta. Deben ser capturados y pasados en el mismo orden en que están definidos.

**Ejemplo**
```php
Route::get('/posts/{post}/comments/{comment}', function ($postId, $commentId) {
    return 'Post '.$postId.' Comment '.$commentId;
});
```
- Esta ruta responderá a URLs como `/posts/1/comments/5`.

### Nombrar Parámetros de Ruta
Nombrar rutas es útil para generar URLs o redireccionar a rutas específicas mediante sus nombres. Puedes definir nombres de rutas usando el método `name`.

**Ejemplo**
```php
Route::get('/user/{id}', [UserController::class, 'show'])->name('user.show');
```

### Parámetros de Ruta y Controladores
En aplicaciones más complejas, es común usar controladores en lugar de closures para manejar rutas. Los parámetros de ruta se pasan automáticamente a los métodos del controlador.

**Ejemplo**
```php
Route::get('/user/{id}', [UserController::class, 'show']);
```

En el controlador:
```php
class UserController extends Controller
{
    public function show($id)
    {
        return 'User '.$id;
    }
}
```

### Dependencias de Parámetros en Controladores

Si un método de controlador tiene parámetros adicionales además de los parámetros de ruta, Laravel los resolverá automáticamente mediante inyección de dependencias.

**Ejemplo**
```php
Route::get('/user/{id}', [UserController::class, 'show']);
```
En el controlador:
```php
class UserController extends Controller
{
    public function show(Request $request, $id)
    {
        $name = $request->input('name');
        return 'User '.$id.' Name '.$name;
    }
}
```
- En este ejemplo, el objeto **Request** será inyectado automáticamente antes del parámetro de ruta `$id`.

### Parámetros Globales
Si necesitas aplicar restricciones globales a parámetros de ruta en toda la aplicación, puedes hacerlo en el método boot de tu `App\Providers\RouteServiceProvider`.
```php
public function boot()
{
    Route::pattern('id', '[0-9]+');
}
```
- Con esta configuración, todas las rutas que contengan un parámetro {id} se validarán contra la expresión regular `[0-9]+`.
