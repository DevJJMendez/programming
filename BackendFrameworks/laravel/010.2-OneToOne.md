# Relaciones
las relaciones son un aspecto fundamental para modelar y gestionar la interacción entre distintos conjuntos de datos en una aplicación.

### One to One
La relación uno a uno (one-to-one) en Eloquent se utiliza cuando **cada registro** de un modelo está asociado con **un solo registro** de otro modelo. Un ejemplo típico podría ser un **usuario** que tiene un **perfil**, donde cada usuario **tiene un perfil único** y viceversa.

**Modelos y Migraciones**
- `User.php`
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class User extends Model
{
    public function profile()
    {
        return $this->hasOne(Profile::class);
    }
}
public function up(): void
    {
        Schema::create('users', function (Blueprint $table) {
            $table->unsignedBigInteger('user_id', true);
        });
    }
```
- `Profile.php`
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Profile extends Model
{
    public function user()
    {
        return $this->belongsTo(User::class);
    }
}
public function up(): void
    {
        Schema::create('profiles', function (Blueprint $table) {
            $table->unsignedBigInteger('profile_id', true);
            $table->unsignedBigInteger('user_id');
            $table->foreign('user_id')->references('user_id')->on('users')->onDelete('cascade')->onUpdate('cascade');
        });
    }
```
### Método `belongsTo()`
define una relación de tipo "**pertenece a**" entre dos modelos.

**Párametros**
1. `$related`: Este parámetro especifica el modelo al que esta relación pertenece. Debe ser el nombre completo de la clase del modelo relacionado.
    ```php
    public function user()
    {
        return $this->belongsTo(User::class);
    }
    ```
2. `$foreignKey (opcional)`: Este parámetro define la clave foránea en el modelo actual que establece la relación con el modelo relacionado. Si no se proporciona, Eloquent intenta determinar el nombre de la clave foránea basándose en el nombre del método de la relación y el sufijo `_id`. 
    ```php
    public function user()
    {
        return $this->belongsTo(User::class, 'user_id');
    }
    ```
    **Si la clave foránea es user_id, no es necesario especificarla si sigue la convención de nombres de Eloquent.**

3. `$ownerKey (opcional)`: Este parámetro especifica la clave primaria en el modelo relacionado. Si no se proporciona, Eloquent asume que la clave primaria es `id`.
    ```php
    public function user()
    {
        return $this->belongsTo(User::class, 'user_id', 'user_id');
    }
    ```
    **En este ejemplo, id es la clave primaria del modelo User. Si el modelo relacionado tiene una clave primaria diferente, puedes especificarla aquí.**

1. `$relation (opcional)`: Este parámetro permite definir un nombre personalizado para la relación. Esto es útil si deseas definir varias relaciones en el mismo modelo que apunten al mismo modelo relacionado, pero con diferentes claves.
    ```php
    public function manager()
    {
        return $this->belongsTo(User::class, 'manager_id', 'user_id', 'manager');
    }

    public function supervisor()
    {
        return $this->belongsTo(User::class, 'supervisor_id', 'user_id', 'supervisor');
    }
    ```
**EJEMPLO COMPLETO**
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Profile extends Model
{
    public function user()
    {
        return $this->belongsTo(User::class, 'user_id', 'user_id', 'user');
    }
}
```

### Método `hasOne()`
define una relación uno a uno en Eloquent, en la que un modelo **tiene una** única instancia de otro modelo.

**Párametros**
1. `$related`: Este parámetro es el modelo relacionado al que estás haciendo referencia. Debe ser el nombre completo de la clase del modelo relacionado.
    ```php
    public function profile()
    {
        return $this->hasOne(Profile::class);
    }
    ```

2. `$foreignKey (opcional)`: Este parámetro define la clave foránea en el modelo relacionado que establece la relación con el modelo principal. Si no se especifica, Eloquent asume que el nombre de la clave foránea sigue la convención **`model_name_id`**, en este caso, `user_id`.
    ```php
    public function profile()
    {
        return $this->hasOne(Profile::class, 'user_id');
    }
    ```
    **En este ejemplo, `user_id` es la clave foránea en la tabla `profiles` que se utiliza para referirse al `User`.**

3. `$localKey (opcional)`: Este parámetro especifica la clave local en el modelo principal que se usa para establecer la relación. Si no se proporciona, Eloquent asume que la clave local es `id`.
    ```php
    public function profile()
    {
        return $this->hasOne(Profile::class, 'user_id', 'user_id');
    }
    ```
    **Aquí, `id` es la clave primaria en el modelo `User`, y `user_id` es la clave foránea en el modelo `Profile`.**

**EJEMPLO COMPLETO**
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class User extends Model
{
    public function profile()
    {
        return $this->hasOne(Profile::class, 'user_id', 'user_id');
    }
}
```
