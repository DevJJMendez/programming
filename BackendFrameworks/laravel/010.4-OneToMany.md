### One to Many
se utiliza cuando un modelo **puede tener múltiples** instancias de otro modelo, por ejemplo: **un `Level` puede tener muchos `User`**.

**Modelos y Migraciones**

`User`
```php
class User extends Authenticatable
{
    public function level()
    {
        return $this->belongsTo(Profile::class, 'level_id', 'level_id');
    }
}
// Migración
Schema::create('users', function (Blueprint $table) {
            $table->unsignedBigInteger('user_id', true);

            $table->unsignedBigInteger('level_id')
                ->nullable();

            $table->foreign('level_id')
                ->references('level_id')
                ->on('levels')
                ->onDelete('set null')
                ->onUpdate('cascade');
        });
```
```php
class level extends Model
{
    public function users()
    {
        return $this->hasMany(User::class, 'level_id', 'level_id');
    }
}
```
