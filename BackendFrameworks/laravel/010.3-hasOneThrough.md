### has-one-through
se utiliza para definir una relación indirecta de **uno a uno a través de un tercer modelo**. Esto es útil cuando deseas acceder a un modelo secundario a través de un modelo intermediario.

Esta relación se lee de la siguiente forma: **uno a través de**

### Definición de la Relación `has-one-through`
se utiliza cuando tienes tres modelos en una relación, y quieres acceder a un registro del tercer modelo desde el primer modelo a través del segundo modelo.

### Parámetros que Recibe `hasOneThrough()`
1. `$related`: El modelo final al que se está accediendo. En este caso, `Location::class`.

2. `$through`: El modelo intermediario a través del cual se realiza la relación. En este caso, `Profile::class`.

3. `$firstKey`: La clave foránea en el modelo intermediario. En este caso, `user_id` en el modelo `Profile`.

4. `$secondKey`: La clave foránea en el modelo final. En este caso, profile_id en el modelo `Location`.

5. `$localKey` (opcional): La clave local en el modelo principal. Si no se especifica, Eloquent asume `id`.

6. `$secondLocalKey` (opcional): La clave local en el modelo intermediario. Si no se especifica, Eloquent asume `id`.

### Ejemplo
Un `User` tiene a través de `Profile` una `Location`

`User`
```php
class User extends Authenticatable
{
    public function location()
    {
        return $this->hasOneThrough(Location::class, Profile::class, 'user_id', 'profile_id', 'user_id', 'profile_id');
    }
}
```
`Profile`
```php
class Profile extends Model
{
    public function user(): BelongsTo
    {
        return $this->belongsTo(User::class, 'user_id', 'user_id');
    }
    public function location()
    {
        return $this->hasOne(Location::class, 'profile_id', 'profile_id');
    }
}
```
`Location`
```php
class Location extends Model
{
    public function profile()
    {
        return $this->belongsTo(Profile::class, 'profile_id', 'profile_id');
    }
}

// Migración
Schema::create('locations', function (Blueprint $table) {
            $table->unsignedTinyInteger('location_id', true);
            $table->unsignedBigInteger('profile_id');
            $table->foreign('profile_id')
                ->references('profile_id')
                ->on('profiles')
                ->onUpdate('cascade')
                ->onDelete('cascade');
        });
```
