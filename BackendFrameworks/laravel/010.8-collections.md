### Collections
Las Eloquent Collections en Laravel son extensiones de las colecciones estándar de Laravel (Collections) y ofrecen una forma poderosa y fluida de manipular y trabajar con conjuntos de resultados de Eloquent. Las colecciones de Eloquent se basan en la clase `Illuminate\Database\Eloquent\Collection`, que extiende la clase base `Illuminate\Support\Collection`.

### Características de las Eloquent Collections
- **Acceso a Modelos Eloquent**: Las Eloquent Collections están diseñadas específicamente para trabajar con instancias de modelos Eloquent.
  
- **Métodos de Manipulación de Colecciones**: Ofrecen una amplia variedad de métodos para manipular los conjuntos de resultados, como filtrado, agrupamiento, transformación y más.

- **Métodos Personalizados de Eloquent**: Puedes usar métodos personalizados definidos en tu modelo en las colecciones.

### Creación de Eloquent Collections
Las Eloquent Collections se crean automáticamente cuando obtienes resultados de Eloquent usando métodos como `get`, `all`, o cuando navegas relaciones.

**Ejemplo**
```php
$users = User::where('active', 1)->get();
```
Aquí, $users es una instancia de `Illuminate\Database\Eloquent\Collection`.

### Métodos Comunes en Eloquent Collections
Las Eloquent Collections heredan todos los métodos de las colecciones estándar de Laravel y añaden algunos métodos específicos para trabajar con modelos Eloquent.

- **Métodos Heredados de Collection**
`filter`
`map`
`each`
`pluck`
`first`
`last`
`groupBy`

- **Métodos Específicos de Eloquent Collections**
- `load`: Carga ansiosamente relaciones adicionales.
- `loadMissing`: Carga relaciones que no han sido cargadas previamente.
- `fresh`: Obtiene una nueva instancia del modelo desde la base de datos.
- `modelKeys`: Obtiene las claves primarias de los modelos en la colección.
- `save`: Guarda todos los modelos en la colección.
- `push`: Añade un nuevo modelo a la colección y lo guarda en la base de datos.
- `contains`: Verifica si un modelo existe en la colección.

### Ejemplos

- **Filtrado**
```php
$activeUsers = $users->filter(function ($user) {
    return $user->isActive();
});
```

- **Transformación**
```php
$userNames = $users->map(function ($user) {
    return $user->name;
});
```

- **Iteración**
```php
$users->each(function ($user) {
    // Realiza alguna operación en cada usuario
    $user->notify(new WelcomeNotification());
});
```

- **Cargar Relaciones**
```php
$users = User::with('posts')->get();
$users->load('comments');
```

- **Agrupamiento**
```php
$groupedByRole = $users->groupBy('role');
```

### Trabajar con Métodos Personalizados
Si defines métodos personalizados en tu modelo Eloquent, puedes usarlos en las colecciones.

**Ejemplo**
```php
class User extends Model
{
    public function isActive()
    {
        return $this->active == 1;
    }
}
```
**Uso**
```php
$activeUsers = $users->filter(function ($user) {
    return $user->isActive();
});
```
