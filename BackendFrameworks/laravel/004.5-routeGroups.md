### Grupos de Rutas
Los Route Groups en Laravel permiten agrupar rutas que comparten atributos comunes, como middleware, nombres de prefijo, espacios de nombres de controlador, entre otros. Esto ayuda a mantener tu archivo de rutas (`web.php` o `api.php`) organizado y **DRY (Don't Repeat Yourself)**.

### Ventajas de los Route Groups
- **Reducción de Redundancia**: Permiten definir atributos comunes una sola vez para múltiples rutas.
- **Organización**: Mantienen el archivo de rutas más limpio y legible.
- **Gestión Centralizada**: Facilitan la administración de middleware, prefijos, y otros atributos.

### Tipos de Atributos en Route Groups
- **Middleware**
- **Prefijos URI**
- **Espacios de Nombres de Controlador**
- **Nombres de Rutas**
- **Subdominios**

1. **Middleware**: Agrupar rutas con middleware común.
```php
Route::middleware(['auth'])->group(function () {
    Route::get('/dashboard', function () {
        // Solo accesible para usuarios autenticados
    });

    Route::get('/profile', function () {
        // Solo accesible para usuarios autenticados
    });
});
```
2. **Prefijos URI**: Agregar un prefijo a todas las rutas del grupo.
```php
Route::prefix('admin')->group(function () {
    Route::get('/users', function () {
        // URL: /admin/users
    });

    Route::get('/settings', function () {
        // URL: /admin/settings
    });
});
```
3. **Espacios de Nombres de Controlador**: Asignar un espacio de nombres a los controladores en el grupo.
```php
Route::namespace('Admin')->group(function () {
    Route::get('/dashboard', 'DashboardController@index');
    Route::get('/users', 'UserController@index');
});
```
4. **Nombres de Rutas**: Agregar un prefijo a los nombres de las rutas.
```php
Route::name('admin.')->group(function () {
    Route::get('/dashboard', 'AdminController@dashboard')->name('dashboard');
    // Route assigned name "admin.dashboard"...
    Route::get('/users', 'AdminController@users')->name('users');
    // Route assigned name "admin.users"...
});
```
5. **Subdominios**: Definir rutas que respondan a subdominios específicos.
```php
Route::domain('{account}.myapp.com')->group(function () {
    Route::get('user/{id}', function ($account, $id) {
        // Manejar la solicitud del subdominio
    });
});
```

### Combinar Atributos en Route Groups
Puedes combinar varios atributos en un solo grupo de rutas.

**Ejemplo**
```php
Route::middleware(['auth'])->prefix('admin')->namespace('Admin')->name('admin.')->group(function () {
    Route::get('/dashboard', 'DashboardController@index')->name('dashboard');
    Route::get('/users', 'UserController@index')->name('users');
    Route::get('/settings', 'SettingsController@index')->name('settings');
});
```
En este ejemplo:

- Todas las rutas requieren el `middleware auth`.
- Todas las rutas tienen el prefijo `admin` en su URI.
- Todas las rutas utilizan el espacio de nombres `Admin` para los controladores.
- Todas las rutas tienen un prefijo de nombre `admin`..

### Uso de Route Groups con Parámetros
Puedes definir parámetros dentro de un grupo de rutas y Laravel los resolverá adecuadamente.

**Ejemplo**
```php
Route::prefix('admin')->group(function () {
    Route::get('users/{id}', function ($id) {
        return 'User ID: '.$id;
    });

    Route::get('posts/{post}', function ($post) {
        return 'Post: '.$post;
    });
});
```

### Anidar Route Groups
Los grupos de rutas pueden ser anidados para aplicar múltiples niveles de atributos.

**Ejemplo**
```php
Route::middleware(['auth'])->group(function () {
    Route::prefix('admin')->group(function () {
        Route::get('/dashboard', 'Admin\DashboardController@index');
        Route::get('/users', 'Admin\UserController@index');
    });

    Route::prefix('user')->group(function () {
        Route::get('/profile', 'UserProfileController@show');
        Route::get('/settings', 'UserSettingsController@index');
    });
});
```
