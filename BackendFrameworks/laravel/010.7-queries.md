### Consultas
En Laravel, las consultas usando Eloquent se encadenan mediante métodos que permiten construir consultas de manera fluida y expresiva. La cadena de métodos en Eloquent sigue una jerarquía y un orden lógico que facilita la creación de consultas complejas. 

Eloquent ofrece métodos encadenables para realizar consultas a la base de datos de manera legible y simple. Los métodos como `where()`, `orderBy()`, `groupBy()`, entre otros, permiten construir consultas SQL de manera fluida.

### Encadenamiento de Consultas en Eloquent
El encadenamiento de métodos en Eloquent se realiza al llamar varios métodos en una sola línea de código. Cada método devuelve una instancia del constructor de consultas, lo que permite encadenar más métodos.

**Ejemplo**
```php
$users = User::where('active', 1)
             ->where('age', '>', 18)
             ->orderBy('name', 'asc')
             ->get();
```
En este ejemplo, estamos encadenando los métodos `where`, `orderBy` y `get` para construir y ejecutar una consulta que obtiene **todos los usuarios activos mayores de 18 años ordenados por nombre de forma ascendente.**

### Orden y Jerarquía en la Encadenación de Métodos
El orden y la jerarquía de los métodos en Eloquent son importantes para asegurar que las consultas se construyan y ejecuten correctamente. Aquí hay un desglose típico del orden y jerarquía:

1. **Selección de Columnas**
* `select`
* `distinct`

2. **Cláusulas de Condición**
* `where`
* `orWhere`
* `whereIn`
* `whereNotIn`
* `whereNull`
* `whereNotNull`
* `whereBetween`
* `whereDate`
* `whereMonth`
* `whereYear`

3. **Relaciones**
* `with` (carga ansiosa de relaciones)
* `has`
* `whereHas`

4. **Agrupación y Ordenamiento**
* `groupBy`
* `having`
* `orderBy`
* `latest`
* `oldest`

5. **Limitación y Desplazamiento**
* `skip`
* `take`
* `limit`
* `offset`

6. **Ejecución de la Consulta**
* `get`
* `first`
* `pluck`
* `count`
* `exists`

### Ejemplos

1. **Consulta Compleja**
```php
$users = User::select('name', 'email')
             ->where('active', 1)
             ->where('age', '>', 18)
             ->with('posts')
             ->groupBy('name')
             ->having('age', '>', 30)
             ->orderBy('name', 'asc')
             ->skip(10)
             ->take(5)
             ->get();
```
2. **Carga Ansiosa de Relaciones**
```php
$posts = Post::with(['comments' => function ($query) {
                $query->where('approved', 1);
            }])
            ->where('published', 1)
            ->orderBy('created_at', 'desc')
            ->get();
```

### Detalles y Características Adicionales

1. **Selección de Columnas:**
* `select`: Selecciona columnas específicas para devolver.
* `distinct`: Devuelve resultados únicos.

2. **Cláusulas de Condición:**
* `where`: Filtra registros según la condición dada.
* `orWhere`: Añade una cláusula OR a la consulta.

3. **Relaciones:**
* `with`: Carga relaciones ansiosamente para evitar el problema de n+1 consultas.
* `has` y `whereHas`: Filtra resultados basados en la existencia de relaciones.

4. **Agrupación y Ordenamiento:**
* `groupBy`: Agrupa resultados.
* `having`: Filtra grupos de resultados.
* `orderBy`: Ordena los resultados.
* `latest` y `oldest`: Métodos de conveniencia para ordenar por fecha.

5. **Limitación y Desplazamiento:**
* `skip`: Desplaza el número de registros.
* `take`: Limita el número de registros devueltos.

6. **Ejecución de la Consulta:**
* `get`: Ejecuta la consulta y obtiene los resultados.
* `first`: Obtiene el primer registro.
* `pluck`: Extrae un valor específico de los resultados.
* `count`: Cuenta el número de registros que coinciden con la consulta.
* `exists`: Verifica si algún registro coincide con la consulta.

### Operadores Logicos y Relacionales

1. **Operadores Logicos**

- `WHERE` con `AND`: Puedes encadenar varios métodos `where` para aplicar múltiples condiciones con el operador lógico "`AND`":
```php
$users = User::where('age', '>', 18)->where('status', 'active')->get();
```
Esto recuperará usuarios con una edad superior a 18 años y con estado activo.

- `WHERE` con `OR`: Usa `orWhere` para aplicar condiciones con el operador "`OR`":
```php
$users = User::where('role', 'admin')->orWhere('role', 'superadmin')->get();
```
Esto recuperará usuarios que tengan el rol de "admin" o "superadmin".

2. **Operadores Relacionales**

- **Operador igual (=)**:
```php
$users = User::where('age', '=', 25)->get();
```

- **Operador mayor que (>), menor que (<), mayor o igual que (>=), menor o igual que (<=):**
```php
$users = User::where('age', '>', 30)->get();
$users = User::where('age', '<', 40)->get();
$users = User::where('age', '>=', 25)->get();
$users = User::where('age', '<=', 35)->get();
```

- **Operador diferente (!= o <>):**
```php
$users = User::where('age', '!=', 30)->get();
$users = User::where('age', '<>', 30)->get();
```

- **Operador `Like`**

El operador like en Eloquent se utiliza para realizar consultas que buscan patrones dentro de una columna de la base de datos. Esto es especialmente útil cuando deseas buscar valores que contengan una cadena específica.

- **Búsqueda por coincidencia parcial:**

```php
$users = User::where('name', 'like', '%John%')->get();
```

En este ejemplo, la consulta recuperará todos los registros de la tabla de usuarios donde el campo '`name`' contenga la cadena "**John**" en cualquier parte del nombre. El `%` antes y después de "John" indica que puede haber cualquier cantidad de caracteres antes y después de la cadena "John".

- **Búsqueda por coincidencia exacta:**
```php
$users = User::where('email', 'like', 'john@example.com')->get();
```

En este caso, la consulta recuperará todos los registros donde el campo 'email' coincida exactamente con "john@example.com".

- **Búsqueda con comodines específicos:**

  - `%son%`: Encuentra valores que contengan "son" en cualquier lugar

  - `a%`: Encuentra valores que comiencen con "a".

  - `%a`: Encuentra valores que terminen con "a".

  - Comodín de coincidencia única: Representa un único carácter en una cadena. Por ejemplo: h_t: Encuentra valores como "hat", "hot", etc., donde el segundo carácter es cualquier letra.
