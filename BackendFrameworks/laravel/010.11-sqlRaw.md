### SQL Raw
El uso de expresiones SQL raw (crudas) en Laravel proporciona una manera de ejecutar consultas SQL directamente sin pasar por el **Query Builder** o **Eloquent**. Esto puede ser útil en situaciones donde necesitas ejecutar consultas muy específicas, complejas o optimizadas que no son fácilmente manejables mediante las abstracciones de Laravel.

### Casos de Uso de SQL Raw
- Consultas complejas que no pueden ser fácilmente expresadas con el Query Builder.
- Operaciones específicas de la base de datos que no están soportadas por el Query Builder.
- Optimización de rendimiento mediante consultas manuales.

### Ejemplos de Uso

**Uso Básico de `DB::raw`**

Puedes utilizar **DB::raw** para incluir expresiones SQL en tus consultas, El método `DB::table()` se utiliza para interactuar con una tabla específica de la base de datos utilizando consultas SQL directas.

```php
$users = DB::table('users')
            ->select(DB::raw('count(*) as user_count, status'))
            ->groupBy('status')
            ->get();
```
En este ejemplo, **DB::raw** se usa para contar el número de usuarios y agruparlos por estado.

- **Consultas `Select Raw`**: Puedes utilizar `selectRaw` para incluir expresiones en la cláusula `SELECT`.
```php
$users = DB::table('users')
            ->selectRaw('name, email, count(*) as total')
            ->groupBy('name', 'email')
            ->get();
```

- **Consultas `Where Raw`**: Puedes usar `whereRaw` para incluir condiciones complejas en la cláusula `WHERE`.
```php
$users = DB::table('users')
            ->whereRaw('age > ? and votes >= ?', [25, 100])
            ->get();
```

- **Consultas `Having Raw`**: `havingRaw` permite incluir condiciones en la cláusula `HAVING`.
```php
$users = DB::table('users')
            ->select('status', DB::raw('count(*) as user_count'))
            ->groupBy('status')
            ->havingRaw('user_count > 1')
            ->get();
```

- **Insertar Datos**: Puedes usar `DB::insert` para ejecutar consultas de inserción.
```php
DB::insert('insert into users (id, name, email) values (?, ?, ?)', [1, 'John', 'john@example.com']);

$inserted = DB::table('users')->insert([
    'name' => 'John Doe',
    'email' => 'john@example.com',
]);
```
El símbolo `?` se utiliza como marcador de posición en consultas SQL para indicar un valor que será sustituido por un parámetro real cuando la consulta se ejecute. Estos marcadores se corresponden con los valores proporcionados en un array que se pasa como segundo argumento al método de ejecución de la consulta.

**Seguridad y Bindings de Parámetros**: Para prevenir ataques de inyección SQL, Laravel utiliza bindings de parámetros. Siempre debes usar bindings de parámetros en lugar de concatenar valores directamente en tus consultas SQL raw. Estos se utilizan para reemplazar los marcadores de posición (`?`) en la consulta con los valores reales, lo que ayuda a prevenir la inyección de SQL.

- **Actualizar Datos con Raw**: Puedes usar `DB::update` para ejecutar consultas de actualización.
```php
DB::update('update users set votes = 100 where name = ?', ['John']);

$updated = DB::table('users')
            ->where('id', 1)
            ->update(['name' => 'Jane Doe']);
```

- **Eliminar Datos con Raw**: Puedes usar `DB::delete` para ejecutar consultas de eliminación.
```php
DB::delete('delete from users where votes < 100');

$deleted = DB::table('users')
            ->where('id', 1)
            ->delete();
```

### Ejecución de Consultas Arbitrarias
Puedes ejecutar cualquier consulta arbitraria usando DB::statement.
```php
DB::statement('drop table users');
```

### Consideraciones

Si bien `DB::raw()` ofrece flexibilidad al insertar expresiones SQL directas en consultas, es importante usarlo con precaución. La inyección de SQL es un riesgo potencial si los valores dinámicos no están debidamente asegurados. Por lo tanto, es recomendable utilizar `DB::raw()` solo cuando sea estrictamente necesario y asegurarse de sanitizar o validar los valores pasados a estas expresiones para evitar posibles ataques de inyección de SQL.
