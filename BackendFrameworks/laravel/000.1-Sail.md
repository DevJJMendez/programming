# Crear app laravel usando Sail

- Ubuntu: si se esta usando Docker Desktop debemos usar el siguiente comando:

  ```bash
  docker context use default
  ```

- Crear:

  - instalar la ultima version de Laravel y **TODOS LOS SERVICIOS QUE OFRECE SAIL**:

    ```bash
    curl -s https://laravel.build/example-app | bash
    ```

  - Elegir version y servicios:

    ```bash
    curl -s https://laravel.build/my-app?with=mysql,redis,version_number | bash
    ```

  - Ejemplo:

    ```bash
    curl -s https://laravel.build/my-app?with=mysql,redis,10 | bash
    ```

## Iniciar Sail

- comando:

  ```bash
  ./vendor/bin/sail up
  ```

  El comando `./vendor/bin/sail up` se utiliza para iniciar el entorno de desarrollo de Laravel Sail. Este comando es una envoltura que se ejecuta en Docker Compose para levantar los servicios definidos en el archivo docker-compose.yml que se encuentra en la raíz de tu proyecto de Laravel.

  - ## ¿Qué hace exactamente?

    - **Ejecuta Docker Compose**:

      - El comando utiliza Docker Compose para levantar los contenedores Docker definidos en docker-compose.yml.

      - Inicia los servicios definidos en el archivo, creando y ejecutando los contenedores necesarios para cada servicio.

    - **Descarga imágenes Docker**:

      - Si alguna de las imágenes Docker definidas en docker-compose.yml aún no está descargada, Docker Compose la descargará automáticamente del registro de Docker.

    - **Crea y ejecuta contenedores**:

      - Una vez que todas las imágenes Docker están disponibles, Docker Compose crea y ejecuta los contenedores Docker según las configuraciones definidas en `docker-compose.yml`.
      - Los contenedores incluyen servicios como bases de datos (MySQL, PostgreSQL), caché (Redis, Memcached), servidores web (Nginx), etc.

    - **Configura redes y volúmenes**:

      - Docker Compose configura redes y volúmenes según lo definido en docker-compose.yml.
      - Esto permite que los servicios se comuniquen entre sí y almacenen datos de forma persistente.

    - **Inicia tu aplicación**:

      - Una vez que todos los servicios están en funcionamiento, tu aplicación de Laravel estará lista para usar y podrás acceder a ella en http://localhost o en la dirección que hayas configurado.

    - **Consejos adicionales**:

      ```yaml
      ./vendor/bin/sail up -d
      ```

      Puedes usar la opción -d para ejecutar los servicios en modo "detached" (desacoplado), lo que significa que los contenedores se ejecutarán en segundo plano sin bloquear la terminal.

## Detener Sail

```yaml
./vendor/bin/sail down
```

- Este comando hará lo siguiente:

  - Detendrá y eliminará todos los contenedores Docker que están en ejecución para los servicios definidos en tu archivo docker-compose.yml.
  - Liberará los puertos y recursos que estaban siendo utilizados por los contenedores.
  - Los volúmenes de datos persistentes permanecerán intactos, por lo que los datos almacenados por los servicios seguirán estando disponibles cuando vuelvas a iniciar el entorno.

## docker-compose.yml

El archivo docker-compose.yml es el archivo de configuración central para Docker Compose, que es utilizado por Laravel Sail para definir los servicios y contenedores necesarios para ejecutar tu aplicación de Laravel. El archivo docker-compose.yml se encuentra en la raíz de tu proyecto de Laravel y define cómo se deben ejecutar los contenedores de Docker para tu aplicación.

- Services:

  La sección services es donde defines los contenedores de Docker que se ejecutarán.
  Cada servicio se define con un nombre, seguido de las configuraciones específicas para ese servicio.
  Por ejemplo, un servicio de base de datos MySQL puede definirse así:

  ```yaml
  services:
    mysql:
      image: "mysql:8.0"
      ports:
        - "3306:3306"
      environment:
        MYSQL_ROOT_PASSWORD: secret
        MYSQL_DATABASE: laravel
      volumes:
        - "sailmysql:/var/lib/mysql"
  ```

- Networks:

  Los servicios pueden estar conectados a redes Docker.
  Por lo general, Sail configura automáticamente las redes necesarias para tus servicios.

- Volumes:

  Los volúmenes permiten persistir datos entre los reinicios de los contenedores.
  Puedes definir volúmenes para servicios como bases de datos o almacenamiento de archivos.

## Servicios

Para agregar o modificar servicios, edita el archivo docker-compose.yml y define los servicios que necesitas, especificando sus imágenes Docker, puertos y configuraciones necesarias. Después de realizar cambios en este archivo, recuerda reiniciar el entorno de Sail para aplicar los cambios.

- Definir un nuevo servicio:

  - En la sección services, agrega una nueva entrada para el servicio que deseas agregar.
  - Define el nombre del servicio, la imagen Docker que deseas usar, puertos, variables de entorno, volúmenes, etc.
  - Por ejemplo, para agregar un servicio de Redis:

    ```yaml
    services:
    redis:
    image: "redis:6-alpine"
    ports:
      - "6379:6379"
    ```

- Guardar los cambios:

  - Guarda los cambios en el archivo docker-compose.yml.

- Reiniciar Sail:

  - Reinicia el entorno de Sail para aplicar los cambios:

  ```bash
  ./vendor/bin/sail down
  ./vendor/bin/sail up
  ```

## Algunos servicios que proporciona Laravel Sail

- `MySQL`:

  Base de datos MySQL para el almacenamiento de datos de tu aplicación.

- `PostgreSQL`:

  Una base de datos alternativa a MySQL, ideal si prefieres usar PostgreSQL para el almacenamiento de datos.

- `Redis`:

  Servicio de almacenamiento en memoria caché que puede usarse para mejorar el rendimiento de tu aplicación.

- `MeiliSearch`:

  Un motor de búsqueda que puede integrarse con tu aplicación para ofrecer funcionalidades de búsqueda rápida.

- `MailHog`:

  Una herramienta para capturar y visualizar correos electrónicos enviados desde tu aplicación. Útil para probar funcionalidades relacionadas con el envío de correos electrónicos.

- `Memcached`:

  Otro servicio de almacenamiento en memoria caché que puede ser una alternativa a Redis.

- `MinIO`:

  Un servicio de almacenamiento de objetos que puede usarse como alternativa a servicios de almacenamiento en la nube.

- `Nginx`:

  Servidor web Nginx que puede actuar como proxy inverso para tu aplicación Laravel.

- `Selenium`:

  Un servicio de pruebas de automatización de navegadores, útil para realizar pruebas de integración y de extremo a extremo.
