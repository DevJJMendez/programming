### CSRF
El token CSRF (Cross-Site Request Forgery) es una medida de seguridad crítica en las aplicaciones web para protegerse contra ataques que intentan realizar acciones no autorizadas en nombre de un usuario autenticado. Laravel proporciona una serie de herramientas y directivas para gestionar el token CSRF de manera efectiva.

### ¿Qué es el Token CSRF?
El token CSRF es una cadena secreta generada por el servidor y enviada al cliente en cada solicitud. Este token se incluye en los formularios de la aplicación y se verifica en cada solicitud entrante para asegurar que la solicitud proviene de una fuente legítima y no de un atacante.

###¿Cómo Funciona el Token CSRF?

1. **Generación del Token**: Laravel genera un token CSRF único para cada sesión de usuario. Este token se guarda en la sesión del usuario y se incluye en cada formulario HTML enviado al cliente.

2. **Inclusión en Formularios**: El token CSRF se incluye en los formularios HTML a través de un campo oculto o una directiva Blade.

3. **Verificación del Token**: Cuando el usuario envía un formulario, el token CSRF se envía con la solicitud. Laravel verifica el token en la solicitud comparándolo con el token almacenado en la sesión del usuario.

4. **Prevención de Ataques**: Si el token en la solicitud no coincide con el token en la sesión, Laravel rechaza la solicitud, previniendo un posible ataque CSRF.

### Inclusión del Token CSRF en Formularios
Laravel ofrece una directiva Blade para incluir automáticamente el token CSRF en formularios HTML:
```php
<form method="POST" action="/example">
    @csrf
    <!-- Campos del formulario -->
</form>
```
- Directiva `@csrf`: Esta directiva inserta un campo oculto con el token CSRF en el formulario. Esto es esencial para proteger las solicitudes **POST**, **PUT**, **PATCH**, **DELETE**.
