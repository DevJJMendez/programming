# Ejemplo de file storage

Creamos nuestro modelo, su respectiva migracion y su request.

El campo donde se guardara el archivo solamente contendra la ubicacion de este, ya que si guardamos directamente el archivo podria darle un mayor peso a nuestra base de datos.

```php
public function up()
    {
        Schema::create('infos', function (Blueprint $table) {
            $table->id();
            $table->string('name')->nullable();
            $table->string('file_url')->nullable();
            $table->timestamps();
        });
    }
```

En el controlador haremos lo siguiente:

```php
public function store(InfoRequest $request)
    {
        // le dara un nombre unico al archivo
        $fileName = time() . '.' . $request->file('file_url')->getClientOriginalExtension();
        // lo almacenara en el directorio public/images
        $request->file('file_url')->move(public_path('images'), $fileName);

        $info = new Info;
        $info->name = $request->name;
        $info->file_url = $fileName;
        $info->save();

        return redirect()->route('index');
    }
```

En la vista:

```php
@forelse ($infos as $info)
    <ul class="list-group">
        <li class="list-group-item">{{ $info->name }}</li>
        <li class="list-group-item">{{ $info->file_url }} <img src="{{asset('images/' . $info->file_url )}}" alt="">
        </li>
        @empty
        <li class="list-group-item">No data found</li>
        @endforelse
    </ul>
```

Si queremos guardarlo en el directorio publico:

```php
// para guardarla en el directorio publico
$request->file('file_url')->storeAs('public/images', $fileName);
```

Para mostrarlo en la vista debemos crear un link simbolico:

```bash
php artisan storage:link
```

