# Atributo OLD

En Laravel, el atributo old se utiliza para recuperar el valor anterior (anterior a la recarga de la página) de un campo de formulario después de una redirección. Esto es útil, por ejemplo, al mostrar mensajes de error después de un intento fallido de envío de formulario.

Cuando validas un formulario y hay errores, Laravel redirecciona de nuevo a la página y, al mismo tiempo, almacena los valores ingresados por el usuario para que puedan ser utilizados nuevamente en el formulario.

Ejemplo en una vista de Blade:

```php
<input type="text" name="username" value="{{ old('username') }}">
```

En este ejemplo, si el usuario ingresó un nombre de usuario, pero hubo errores en el formulario y Laravel redirigió de vuelta a la vista, old('username') recuperará el valor anterior del campo username para que no tenga que volver a ingresar toda la información.

# Custom Validation Rules

Las "Custom Validation Rules" (Reglas de Validación Personalizadas) en el contexto de los frameworks de desarrollo web, como Laravel, se refieren a reglas de validación que tú defines para validar datos de entrada en formularios o en otros contextos donde se necesite asegurar que ciertos criterios se cumplan.

En Laravel, las reglas de validación personalizadas te permiten definir tus propias reglas de validación además de las que ofrece por defecto el framework. Esto es útil cuando necesitas validar campos de manera específica para tu aplicación.

Para crearlas podemos usar el comando:

```bash
php artisan make:rule NameRule
```

Esto creara una carpeta en el directorio `app\Rules`

```php
namespace App\Rules;

use Illuminate\Contracts\Validation\Rule;

class CustomRule implements Rule
{
    public function passes($attribute, $value)
    {
        // Lógica de validación personalizada
        return $value == 'mi_valor_esperado';
    }

    public function message()
    {
        return 'El campo :attribute debe ser igual a "mi_valor_esperado".';
    }
}
```

- Usar la Regla Personalizada en las Validaciones:

Ahora puedes usar tu regla personalizada en las reglas de validación de tus controladores o solicitudes.

```php
use App\Rules\CustomRule;

$validatedData = $request->validate([
    'mi_campo' => ['required', new CustomRule],
]);
```

- Controlador:

```php
namespace App\Http\Controllers;

use App\Rules\CustomRule;
use Illuminate\Http\Request;

class MiControlador extends Controller
{
    public function validar(Request $request)
    {
        $request->validate([
            'mi_campo' => ['required', new CustomRule],
        ]);

        // El código continúa aquí si la validación es exitosa
    }
}
```
