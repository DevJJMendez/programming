# File Storage

el almacenamiento de archivos es una tarea común en muchas aplicaciones web. Laravel proporciona una API poderosa y simple para manejar el almacenamiento y la gestión de archivos en varios sistemas de archivos, incluyendo sistemas de archivos locales, Amazon S3, Rackspace Cloud Storage y otros.

---

## Configuracion del almacenamiento de archivos en Laravel

- Configuración del archivo .env:

En el archivo .env, puedes configurar el driver de almacenamiento que deseas utilizar, así como las credenciales necesarias. Por ejemplo:

```php
FILESYSTEM_DRIVER=local
```

Otros drivers comunes son s3 para Amazon S3 o rackspace para Rackspace Cloud Storage. Debes proporcionar las credenciales correspondientes para cada driver en el archivo `.env`.

- Configuración en `config/filesystems.php`:

El archivo `config/filesystems.php` contiene la configuración para los sistemas de archivos definidos en tu aplicación. Puedes establecer las configuraciones para los distintos drivers aquí.

## Uso del almacenamiento de archivos en Laravel

- Manipulación de archivos:

Laravel proporciona una API simple y expresiva para trabajar con archivos. Puedes usar métodos como `Storage::put()`,` Storage::get()`, `Storage::delete()`, entre otros, para manipular archivos.

```php
// Ejemplo de almacenamiento de un archivo en un directorio específico
use Illuminate\Support\Facades\Storage;

// Almacenar un archivo
Storage::put('directorio/archivo.txt', 'Contenido del archivo');

// Obtener el contenido de un archivo
$contenido = Storage::get('directorio/archivo.txt');

// Eliminar un archivo
Storage::delete('directorio/archivo.txt');
```

- Trabajar con sistemas de archivos remotos:

Si estás utilizando un servicio de almacenamiento remoto como Amazon S3 o Rackspace Cloud Storage, Laravel ofrece métodos para interactuar con estos sistemas de archivos de manera similar a cómo trabajas con el almacenamiento local.

- Manipulación de archivos en formularios:

Para manejar la carga de archivos desde formularios, Laravel proporciona facilidades como el método `store()` en las instancias de UploadedFile.

- Creación de enlaces simbólicos:

Laravel permite crear enlaces simbólicos a directorios almacenados utilizando el método `storage::link()`.
