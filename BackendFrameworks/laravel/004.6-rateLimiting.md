### Rate Limiting

El Rate Limiting (limitación de tasa) es una técnica utilizada para controlar la cantidad de solicitudes que un cliente puede hacer a un servidor dentro de un período de tiempo específico. Laravel proporciona soporte robusto para la limitación de tasa, lo que es especialmente útil para proteger tu aplicación de abusos, ataques **DDoS** y garantizar una distribución justa de los recursos.

### Conceptos Básicos del Rate Limiting en Laravel
- **Throttle Middleware**: Middleware de limitación de tasa incluido en Laravel.
- **Configuración**: Puedes definir las reglas de limitación de tasa en el archivo de configuración `App\Providers\RouteServiceProvider`
- **Custom Rate Limiting**: Definición de reglas personalizadas de limitación de tasa.

### Throttle Middleware
Laravel incluye un middleware de limitación de tasa llamado ThrottleRequests, que se puede aplicar a rutas o grupos de rutas.

**Uso Básico del Middleware de Limitación de Tasa**: Puedes aplicar el middleware throttle a una ruta específica o a un grupo de rutas. La sintaxis básica es throttle:`{maxAttempts},{decayMinutes}.`

**Ejemplo**
```php
Route::middleware('throttle:10,1')->group(function () {
    Route::get('/profile', function () {
        // Solo se permiten 10 solicitudes por minuto
    });

    Route::get('/settings', function () {
        // Solo se permiten 10 solicitudes por minuto
    });
});
```
En este ejemplo, se permiten hasta 10 solicitudes por minuto para las rutas dentro del grupo.

### Definir Limites Personalizados

Puedes definir reglas de limitación de tasa personalizadas utilizando el método `for` en el `RateLimiter`.
```php
// app/Providers/RouteServiceProvider.php

use Illuminate\Cache\RateLimiting\Limit;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\RateLimiter;

public function boot()
{
    $this->configureRateLimiting();

    $this->routes(function () {
        // Definición de rutas
    });
}

protected function configureRateLimiting()
{
    RateLimiter::for('api', function (Request $request) {
        return Limit::perMinute(60);
    });

    RateLimiter::for('uploads', function (Request $request) {
        return Limit::perMinute(10)->by($request->user()->id ?: $request->ip());
    });
}
```
En este ejemplo, hemos definido dos limitadores de tasa: uno para la API y otro para cargas de archivos, limitando a 10 solicitudes por minuto por usuario o por IP.

### Límites Dinámicos Basados en Condiciones
Puedes definir límites de tasa dinámicos basados en diversas condiciones, como roles de usuario, IPs específicas, etc.

**Ejemplo**
```php
RateLimiter::for('api', function (Request $request) {
    if ($request->user() && $request->user()->isAdmin()) {
        return Limit::none(); // Sin limitación para administradores
    }

    return Limit::perMinute(60);
});
```
