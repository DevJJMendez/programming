### Scopes

En Laravel, los scopes son una manera de encapsular condiciones de **consulta comunes** que se **reutilizan en múltiples lugares**. Los scopes permiten definir consultas en los modelos de manera modular y reutilizable, haciendo que el código sea más limpio y manejable.

### Tipos de Scopes en Laravel
- **Global Scopes**
- **Local Scopes**

### Local Scopes
Los **Local Scopes** permiten definir métodos en tu modelo que pueden ser usados como parte de las consultas de Eloquent. Son particularmente útiles para agregar condiciones de manera fluida y reutilizable.

**Definiendo un Local Scope**

1. **Definir el Scope**: En el modelo, define un método que comience con **scope**, seguido por el nombre del **scope**. Este método debe aceptar un `Builder` como el primer parámetro y luego los parámetros de consulta adicionales.
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;

class User extends Model
{
    /**
     * Scope a query to only include active users.
     *
     * @param  \Illuminate\Database\Eloquent\Builder  $query
     * @return \Illuminate\Database\Eloquent\Builder
     */
    public function scopeActive(Builder $query)
    {
        return $query->where('active', 1);
    }

    /**
     * Scope a query to only include users of a given type.
     *
     * @param  \Illuminate\Database\Eloquent\Builder  $query
     * @param  string  $type
     * @return \Illuminate\Database\Eloquent\Builder
     */
    public function scopeOfType(Builder $query, $type)
    {
        return $query->where('type', $type);
    }
}
```
2. **Usar el Scope**: Cuando uses el **scope**, omite el prefijo `scope` y llama al método directamente en la consulta.
```php
$activeUsers = App\Models\User::active()->get();

$adminUsers = App\Models\User::ofType('admin')->get();

$users = User::active()->orderBy('created_at')->get();
```

### Global Scopes
Los Global Scopes permiten definir condiciones de consulta que se aplican automáticamente a **todas las consultas de un modelo**. Son útiles para agregar restricciones globales a un modelo, como filtrar registros eliminados (soft deletes) o restringir acceso a datos específicos.

**Definiendo un Global Scope**

1. **Crear un Scope**: Crea una clase que implemente la interfaz `Illuminate\Database\Eloquent\Scope`.
    ```php
    namespace App\Scopes;

    use Illuminate\Database\Eloquent\Builder;
    use Illuminate\Database\Eloquent\Model;
    use Illuminate\Database\Eloquent\Scope;

    class ActiveScope implements Scope
    {
        public function apply(Builder $builder, Model $model)
        {
            $builder->where('active', 1);
        }
    }
    ```
- Tambien se puede usar un comando **Artisan**
  ```bash
  php artisan make:scope ActiveScope
  ``` 
1. **Aplicar el Scope a un Modelo**:

- En el modelo, utiliza el método booted para aplicar el scope.
  ```php
  namespace App\Models;

  use Illuminate\Database\Eloquent\Model;
  use App\Scopes\ActiveScope;

  class User extends Model
  {
      /**
       * The "booted" method of the model.
       *
       * @return void
       */
      protected static function booted()
      {
          static::addGlobalScope(new ActiveScope);
      }
  }
  ```
- Tambien podemos usar el atributo `ScopedBy`
  ```php
  namespace App\Models;
  
  use App\Models\Scopes\ActiveScope;
  use Illuminate\Database\Eloquent\Attributes\ScopedBy;
  
  #[ScopedBy([ActiveScope::class])]
  class User extends Model
  {
      //
  }
  ```
3. **Usar el Modelo con Global Scope**: Las consultas al modelo aplicarán automáticamente el global scope.
  ```php
  $users = App\Models\User::all(); // Solo usuarios activos
  ```
4. **Eliminar un Global Scope en una Consulta Específica**: Usa el método `withoutGlobalScope`.
```php
$allUsers = App\Models\User::withoutGlobalScope(ActiveScope::class)->get(); // Todos los usuarios, sin filtrar por 'active'

// Remove all of the global scopes...
User::withoutGlobalScopes()->get();
 
// Remove some of the global scopes...
User::withoutGlobalScopes([
    FirstScope::class, SecondScope::class
])->get();
```

### Scope Anónimos

Los Scopes Anónimos te permiten definir una lógica de consulta dentro de una función de cierre (closure) directamente en la llamada de consulta. Son útiles para situaciones en las que necesitas una lógica de consulta que no se reutiliza lo suficiente como para justificar la creación de un método de scope separado en el modelo.

```php
namespace App\Models;
 
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;
 
class User extends Model
{
    /**
     * The "booted" method of the model.
     */
    protected static function booted(): void
    {
        static::addGlobalScope('ancient', function (Builder $builder) {
            $builder->where('created_at', '<', now()->subYears(2000));
        });
    }
}
```

### Scope Dinamicos

Los Scopes Dinámicos en Laravel son una extensión de los scopes tradicionales que permiten definir condiciones de consulta reutilizables con parámetros que pueden variar cada vez que se llaman. Son especialmente útiles para casos en los que necesitas aplicar una lógica de consulta común pero con diferentes valores de parámetros.

**Ejemplo Básico de un Scope Dinámico**

Supongamos que tienes un modelo `User` y deseas filtrar usuarios por su **tipo** y **estado** **activo**:
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;

class User extends Model
{
    /**
     * Scope a query to only include users of a given type and active status.
     *
     * @param  \Illuminate\Database\Eloquent\Builder  $query
     * @param  string  $type
     * @param  bool  $active
     * @return \Illuminate\Database\Eloquent\Builder
     */
    public function scopeOfTypeAndActive(Builder $query, $type, $active = true)
    {
        return $query->where('type', $type)
                     ->where('active', $active);
    }
}
```
**Usando el Scope Dinámico**

Cuando uses el scope dinámico, llama al método del scope con los parámetros necesarios:
```php
// Filtrar usuarios de tipo 'admin' que están activos
$activeAdmins = User::ofTypeAndActive('admin')->get();

// Filtrar usuarios de tipo 'subscriber' que no están activos
$inactiveSubscribers = User::ofTypeAndActive('subscriber', false)->get();
```
