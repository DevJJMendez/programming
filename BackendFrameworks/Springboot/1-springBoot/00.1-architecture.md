## Layered Architecture

Spring Boot sigue una arquitectura en capas que ayuda a separar las preocupaciones y facilita el desarrollo, mantenimiento y escalabilidad de aplicaciones. Las principales capas en esta arquitectura son: **Presentation Layer**, **Business Layer**, **Persistence Layer** y **Database Layer**. 

![Layered Architecure Example](assets/layeredArchitecture.png)

### Presentation Layer (Capa de Presentación)

La capa de presentación es responsable de la interacción con el usuario. Es la capa donde se manejan las **solicitudes y respuestas HTTP** en aplicaciones web, y se presentan datos al usuario final.

* **Componentes**:

  * **Controladores** (`@Controller`, `@RestController`): Manejan las peticiones HTTP entrantes, invocan los servicios apropiados y retornan respuestas. Utilizan anotaciones como `@RequestMapping`, `@GetMapping`, `@PostMapping`, etc.

  * **Vistas (si se usa MVC)**: Plantillas que generan HTML dinámico (`Thymeleaf`, `JSP`, etc.).

* **Ejemplo**

  ```java
  @RestController
  @RequestMapping("/api/users")

  public class UserController {

      @Autowired
      private UserService userService;

      @GetMapping("/{id}")
      public ResponseEntity<User> getUserById(@PathVariable Long id) {
          User user = userService.getUserById(id);
          return ResponseEntity.ok(user);
      }

      @PostMapping
      public ResponseEntity<User> createUser(@RequestBody User user) {
          User createdUser = userService.createUser(user);
          return ResponseEntity.status(HttpStatus.CREATED).body(createdUser);
      }
  }
  ```

### Business Layer (Capa de Negocios)

La capa de negocios contiene la lógica de la aplicación. Es donde se implementan las reglas de negocio y se maneja la lógica principal de la aplicación.

* **Componentes**:

  * **Servicios (`@Service`)**: Contienen métodos que encapsulan la lógica de negocio. Los servicios son invocados por los controladores y pueden llamar a los repositorios para acceder a los datos.

* **Ejemplo**

  ```java
  @Service
  public class UserService {

      @Autowired
      private UserRepository userRepository;

      public User getUserById(Long id) {
          return userRepository.findById(id)
                  .orElseThrow(() -> new ResourceNotFoundException("User not found"));
      }

      public User createUser(User user) {
          return userRepository.save(user);
      }
  }
  ```

###  Persistence Layer (Capa de Persistencia)

La capa de persistencia es responsable de la interacción con la base de datos. Maneja las operaciones **CRUD** y la gestión de datos persistentes.

* **Componentes**
  
  *** Repositorios (`@Repository`)**: Interfaces o clases que interactúan directamente con la base de datos utilizando **JPA**, **Hibernate**, u otros frameworks de persistencia.

* **Ejemplo**

```java
@Repository
public interface UserRepository extends JpaRepository<User, Long> {}
```

### Database Layer (Capa de Base de Datos)

La capa de base de datos es la capa física que contiene los datos. Esta capa incluye la base de datos en sí misma y las estructuras de datos (tablas, índices, etc.).

* **Componentes**

  *  **Base de datos**: Sistema de gestión de bases de datos (DBMS) como **MySQL**, **PostgreSQL**, **Oracle**, etc.
  
  * **Esquema de base de datos**: Definición de las tablas y relaciones en la base de datos.
