### HttpServletRequest

Es una interfaz en Java que forma parte de la especificación de Servlets, dentro del paquete `javax.servlet.http`. Esta interfaz define un objeto que encapsula toda la información de una solicitud HTTP que un cliente hace a un servidor. Es una pieza clave en el desarrollo de aplicaciones web en Java, ya que permite a los desarrolladores acceder a los detalles de la solicitud entrante, como los **parámetros**, **encabezados**, **cookies**, y otros datos relevantes.

### Principales Métodos de `HttpServletRequest`

1. `String getMethod()`

   - Devuelve el método HTTP de la solicitud (por ejemplo, **GET**, **POST**, **PUT**, **DELETE**).

     ```java
     String method = request.getMethod(); // "GET"
     ```

2. `String getRequestURI()`

   - Devuelve la parte de la URL de la solicitud que sigue al nombre del contexto de la aplicación.

     ```java
     String uri = request.getRequestURI(); // "/mi-app/recurso"
     ```

3. `String getContextPath()`

   - Devuelve el nombre del contexto de la aplicación web.

     ```java
     String contextPath = request.getContextPath(); // "/mi-app"
     ```

4. `String getServletPath()`

   - Devuelve la ruta específica del servlet que está gestionando la solicitud.

     ```java
     String servletPath = request.getServletPath(); // "/recurso"
     ```

5. `String getQueryString()`

   - Devuelve la cadena de consulta de la solicitud (la parte de la URL que sigue al `?`).

     ```java
     String queryString = request.getQueryString(); // "param1=valor1&param2=valor2"
     ```

6. `String getParameter(String name)`

   - Devuelve el valor de un parámetro de la solicitud (por ejemplo, parámetros de formularios enviados en una solicitud **GET** o **POST**).

7. `Map<String, String[]> getParameterMap()`

   - Devuelve un Map de todos los parámetros de la solicitud, donde la clave es el nombre del parámetro y el valor es un array de String con los valores del parámetro.

     ```java
     Map<String, String[]> params = request.getParameterMap();
     ```

8. `Enumeration<String> getParameterNames()`

   - Devuelve un **Enumeration** de los nombres de todos los parámetros de la solicitud.

     ```java
     Enumeration<String> paramNames = request.getParameterNames();
     ```

9. `String[] getParameterValues(String name)`

   - Devuelve un array de String con todos los valores de un parámetro que puede tener múltiples valores.

     ```java
     String[] values = request.getParameterValues("checkbox"); // ["valor1", "valor2"]
     ```

10. `HttpSession getSession()`

    - Devuelve el objeto HttpSession asociado con la solicitud, creando una nueva sesión si no existe.

      ```java
      HttpSession session = request.getSession();
      ```

11. `Cookie[] getCookies()`

    - Devuelve un array de Cookie que contiene todas las cookies enviadas por el cliente en la solicitud.

      ```java
      Cookie[] cookies = request.getCookies();
      ```

12. `String getHeader(String name)`

    - Devuelve el valor de un encabezado específico de la solicitud HTTP.

      ```java
      String userAgent = request.getHeader("User-Agent");
      ```

13. `Enumeration<String> getHeaderNames()`

    - Devuelve un Enumeration de todos los nombres de los encabezados de la solicitud HTTP.

      ```java
      Enumeration<String> headerNames = request.getHeaderNames();
      ```

14. `InputStream getInputStream()`

    - Devuelve un **InputStream** que puede ser usado para leer el cuerpo de la solicitud. Es comúnmente utilizado en solicitudes **POST** que envían datos en el cuerpo.

      ```java
      InputStream inputStream = request.getInputStream();
      ```

15. `String getRemoteAddr()`

    - Devuelve la dirección IP del cliente que hizo la solicitud.

      ```java
      String ip = request.getRemoteAddr(); // "192.168.1.100"
      ```

## HttpServletResponse

Es una interfaz en Java que forma parte de la especificación de Servlets, dentro del paquete javax.servlet.http. Esta interfaz define un objeto que representa la respuesta HTTP que un servidor envía al cliente. Al trabajar con HttpServletResponse, los desarrolladores pueden controlar cómo el servidor responde a las solicitudes HTTP, incluyendo la configuración de encabezados, el envío de cookies, la redirección a otras URL y la escritura del cuerpo de la respuesta.

### Principales Métodos de `HttpServletResponse`

1. `void setStatus(int sc)`

   - Establece el código de estado de la respuesta HTTP.

   - **Parámetro**:

     - `sc`: El código de estado HTTP (por ejemplo, `HttpServletResponse.SC_OK para 200, HttpServletResponse.SC_NOT_FOUND para 404`).

     ```java
     response.setStatus(HttpServletResponse.SC_OK);
     ```

2. `void setHeader(String name, String value)`

   - Establece un encabezado HTTP con un nombre y valor específicos. Si el encabezado ya existe, sobrescribe su valor.

   - **Parámetros**:

     - `name`: El nombre del encabezado.

     - `value`: El valor del encabezado.

     ```java
     response.setHeader("Content-Type", "application/json");
     ```

3. `void addHeader(String name, String value)`

   - Añade un valor a un encabezado HTTP, sin sobrescribir valores anteriores.

   - **Parámetros**:

     - `name`: El nombre del encabezado.

     - `value`: El valor adicional del encabezado.

     ```java
     response.addHeader("Set-Cookie", "sessionId=abc123");
     ```

4. `void sendRedirect(String location)`

   - Envía una redirección a la URL especificada. Esto instruye al cliente (generalmente un navegador) a hacer una nueva solicitud a la URL dada.

   - **Parámetro**:

     - `location`: La URL a la que se redirigirá la solicitud.

     ```java
     response.sendRedirect("/login");
     ```

5. `void setContentType(String type)`

   - Establece el tipo de contenido de la respuesta. Esto es importante para que el cliente sepa cómo interpretar el cuerpo de la respuesta (por ejemplo, HTML, JSON, texto plano, etc.).

   - **Parámetro**:

     - `type`: El tipo de contenido (por ejemplo, `text/html`, `application/json`).

     ```java
     response.setContentType("text/html");
     ```

6. `void setCharacterEncoding(String charset)`

   - Establece la codificación de caracteres de la respuesta. Esto es importante para asegurar que el texto en la respuesta sea interpretado correctamente por el cliente.

   - **Parámetro**:

     - `charset`: La codificación de caracteres (por ejemplo, UTF-8).

     ```java
     response.setCharacterEncoding("UTF-8");
     ```

7. `PrintWriter getWriter()`

   - Devuelve un **PrintWriter** para enviar datos de texto al cliente. Es comúnmente usado para escribir HTML o texto plano en la respuesta.

   ```java
   PrintWriter out = response.getWriter();
   out.println("<h1>Hola, Mundo!</h1>");
   ```

8. `ServletOutputStream getOutputStream()`

   - Devuelve un **ServletOutputStream** para enviar datos binarios al cliente, como imágenes o archivos. No se puede usar junto con `getWriter()`.

   ```java
   ServletOutputStream out = response.getOutputStream();
   out.write(bytes);
   ```

9. `void setContentLength(int len)`

   - Establece la longitud del contenido de la respuesta en bytes. Esto es opcional ya que el servidor puede calcularlo automáticamente, pero puede ser útil en ciertos casos.

   - **Parámetro**:

     - `len`: El tamaño del contenido en bytes.

   ```java
   response.setContentLength(1000);
   ```

10. `void setBufferSize(int size)`

    - Establece el tamaño del buffer de la respuesta. El buffer se usa para almacenar temporalmente los datos de la respuesta antes de ser enviados al cliente.

      - **Parámetro**:
      - `size`: El tamaño del buffer en bytes.

      ```java
      response.setBufferSize(8192);
      ```

11. `void flushBuffer()`

    - Fuerza el vaciado del buffer de salida, enviando los datos acumulados al cliente.

      ```java
      response.flushBuffer();
      ```

12. `boolean isCommitted()`

    - Indica si la respuesta ya ha sido enviada al cliente. Una vez que la respuesta es "committed" (comprometida), no se pueden hacer más modificaciones.

      ```java
      if (response.isCommitted()) {
         // No se pueden hacer más cambios en la respuesta
      }
      ```

13. `void addCookie(Cookie cookie)`

    - Añade una cookie a la respuesta, que será enviada al cliente.

    - **Parámetro**:

      - `cookie`: El objeto Cookie a ser añadido a la respuesta.

      ```java
      Cookie cookie = new Cookie("sessionId", "abc123");
      response.addCookie(cookie);
      ```
