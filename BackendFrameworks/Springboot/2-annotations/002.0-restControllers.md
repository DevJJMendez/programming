## Rest Annotations
Estas anotaciones son una forma más específica y concisa de mapear solicitudes HTTP a métodos de controlador en comparación con `@RequestMapping`.

## `@GetMapping`
Mapea solicitudes HTTP GET a métodos específicos del controlador. Se utiliza para obtener recursos.

**Parámetros**
* `value`: Ruta(s) de la solicitud.

* `path`: Alias de value.

* `params`: Parámetros de solicitud que deben estar presentes.

* `headers`: Encabezados de solicitud que deben estar presentes.

* `consumes`: Tipo de contenido que el método puede consumir.

* `produces`: Tipo de contenido que el método puede producir.

**Ejemplo**
```java
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class MyController {
    @GetMapping(value = "/hello", produces = "application/json")
    public String sayHello() {
        return "Hello, World!";
    }
}
```

## `@PostMapping`
Mapea solicitudes HTTP POST a métodos específicos del controlador. Se utiliza para crear nuevos recursos.

**Parámetros**
* `value`: Ruta(s) de la solicitud.

* `path`: Alias de value.

* `params`: Parámetros de solicitud que deben estar presentes.

* `headers`: Encabezados de solicitud que deben estar presentes.

* `consumes`: Tipo de contenido que el método puede consumir.

* `produces`: Tipo de contenido que el método puede producir.

**Ejemplo**
```java
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class MyController {
    @PostMapping(value = "/create", consumes = "application/json", produces = "application/json")
    public String createResource(@RequestBody Resource resource) {
        // lógica para crear el recurso
        return "Resource created";
    }
}
```

## `@PutMapping`
Mapea solicitudes HTTP PUT a métodos específicos del controlador. Se utiliza para actualizar recursos completos.

**Parámetros**
* `value`: Ruta(s) de la solicitud.

* `path`: Alias de value.

* `params`: Parámetros de solicitud que deben estar presentes.

* `headers`: Encabezados de solicitud que deben estar presentes.

* `consumes`: Tipo de contenido que el método puede consumir.

* `produces`: Tipo de contenido que el método puede producir.

**Ejemplo**
```java
import org.springframework.web.bind.annotation.PutMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class MyController {
    @PutMapping(value = "/update/{id}", consumes = "application/json", produces = "application/json")
    public String updateResource(@PathVariable("id") Long id, @RequestBody Resource resource) {
        // lógica para actualizar el recurso
        return "Resource updated";
    }
}
```

## `@DeleteMapping`
Mapea solicitudes HTTP DELETE a métodos específicos del controlador. Se utiliza para eliminar recursos.

**Parámetros**
* `value`: Ruta(s) de la solicitud.

* `path`: Alias de value.

* `params`: Parámetros de solicitud que deben estar presentes.

* `headers`: Encabezados de solicitud que deben estar presentes.

* `consumes`: Tipo de contenido que el método puede consumir.

* `produces`: Tipo de contenido que el método puede producir.


**Ejemplo**
```java
import org.springframework.web.bind.annotation.DeleteMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class MyController {
    @DeleteMapping(value = "/delete/{id}", produces = "application/json")
    public String deleteResource(@PathVariable("id") Long id) {
        // lógica para eliminar el recurso
        return "Resource deleted";
    }
}
```

## `@PatchMapping`
Mapea solicitudes HTTP PATCH a métodos específicos del controlador. Se utiliza para realizar actualizaciones parciales de recursos.

**Parámetros**
* `value`: Ruta(s) de la solicitud.

* `path`: Alias de value.

* `params`: Parámetros de solicitud que deben estar presentes.

* `headers`: Encabezados de solicitud que deben estar presentes.

* `consumes`: Tipo de contenido que el método puede consumir.

* `produces`: Tipo de contenido que el método puede producir.

**Ejemplo**
```java
import org.springframework.web.bind.annotation.PatchMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class MyController {
    @PatchMapping(value = "/updatePartial/{id}", consumes = "application/json", produces = "application/json")
    public String updatePartialResource(@PathVariable("id") Long id, @RequestBody Map<String, Object> updates) {
        // lógica para actualizar parcialmente el recurso
        return "Resource partially updated";
    }
}
```

## `@RestController`
Combina las anotaciones `@Controller` y `@ResponseBody`. 

Se utiliza para simplificar la creación de controladores RESTful, indicando que el controlador maneja directamente el cuerpo de la respuesta HTTP (generalmente en formato JSON o XML).

**Ejemplo**
```java
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class MyRestController {
    @GetMapping("/data")
    public Data getData() {
        return new Data("Example data");
    }
}
```

## `@RequestAttribute`
Vincula un atributo de solicitud (establecido en algún filtro o interceptor) a un parámetro de método en un controlador. 

Extrae atributos de la solicitud HTTP que fueron establecidos previamente en el ciclo de vida de la solicitud.

**Parámetros**
* `value`: Nombre del atributo de solicitud.

* `required`: Indica si el atributo es obligatorio (por defecto es true).

**Ejemplo**
```java
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestAttribute;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class MyController {
    @GetMapping("/showAttribute")
    public String showAttribute(@RequestAttribute("myAttribute") String myAttribute) {
        return "Attribute value: " + myAttribute;
    }
}
```
