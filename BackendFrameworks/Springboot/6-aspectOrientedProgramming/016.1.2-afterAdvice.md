## @After Advice
El `@After` advice en Aspect-Oriented Programming (AOP) es un tipo de **advice** que se ejecuta después de que un método objetivo (el join point) ha terminado su ejecución. A diferencia del **`@Before` advice**, que se ejecuta antes del método, el @After advice se asegura de que se ejecute una vez que el método ha finalizado, independientemente de si el método terminó de manera exitosa o si lanzó una excepción.

### Tipos de @After Advice
En AOP, existen varios tipos de @After advice, dependiendo de cuándo exactamente se debe ejecutar el código:

1. `@After` (general):

   * Se ejecuta después de la ejecución del método, sin importar si el método terminó correctamente o lanzó una excepción.

   * **Uso**: Es útil para tareas que siempre deben realizarse después de la ejecución de un método, como liberar recursos o cerrar conexiones.

      ```java
      @After("execution(* com.example.service.UserService.createUser(..))")
      public void logAfterMethod(JoinPoint joinPoint) {
          System.out.println("Método terminado: " + joinPoint.getSignature().getName());
      }
      ```
      Este advice se ejecutará después de que createUser haya sido invocado, sin importar si tuvo éxito o lanzó una excepción.

2. `@AfterReturning`:

   * Se ejecuta solo si el método objetivo completa su ejecución normalmente, es decir, no lanza ninguna excepción.

   * **Uso**: Útil para ejecutar lógica basada en el valor de retorno del método, como el logging del resultado o la ejecución de un código dependiente de la salida.

      ```java
      @AfterReturning(pointcut = "execution(* com.example.service.UserService.findUser(..))", returning = "result")
      public void logAfterReturning(JoinPoint joinPoint, Object result) {
          System.out.println("Método " + joinPoint.getSignature().getName() + " retornó: " + result);
      }
      ```
      Este advice solo se ejecutará si `findUser` termina exitosamente, y te permitirá acceder al valor retornado por el método.

3. `@AfterThrowing`:

   * Se ejecuta solo si el método objetivo lanza una excepción.

   * **Uso**: Es útil para manejar errores, hacer logging de excepciones, o lanzar alertas cuando algo falla.

      ```java
      @AfterThrowing(pointcut = "execution(* com.example.service.UserService.createUser(..))", throwing = "error")
      public void logAfterThrowing(JoinPoint joinPoint, Throwable error) {
          System.out.println("Método " + joinPoint.getSignature().getName() + " lanzó una excepción: " + error);
      }
      ```
      Este advice se ejecutará únicamente si `createUser` lanza una excepción, permitiendo capturar y manejar el error.
