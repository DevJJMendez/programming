# `@Entity`
Es una anotación de JPA que marca una clase Java como una entidad, es decir, una representación de una tabla de base de datos. La clase anotada con @Entity se convierte en un modelo de datos que JPA utilizará para generar y gestionar la tabla y las filas en la base de datos correspondiente.

Esta anotación debe estar presente en todas las clases que representan una entidad de negocio y que requieren ser persistidas en una base de datos.

## Parámetros de @Entity
La anotación @Entity tiene un solo parámetro opcional:

* **`name`**: Define el nombre de la entidad, el cual JPA usará para identificar a esta clase en las consultas JPQL (Java Persistence Query Language). Si no se define, JPA usará el nombre de la clase como nombre de la entidad por defecto.

```java
@Entity(name = "EmpleadoEntity")
public class Empleado {
    // ...
}
```

En este ejemplo, EmpleadoEntity sería el nombre usado en consultas JPQL, en lugar de Empleado.

## ¿Para qué sirve @Entity?
La anotación @Entity sirve para establecer que una clase Java representa una tabla en la base de datos. Esto permite que JPA gestione la persistencia de instancias de la clase, realizando las operaciones CRUD (Crear, Leer, Actualizar, Eliminar) sin necesidad de escribir consultas SQL explícitas.

**Integración de JPQL**, Al definir el nombre de la entidad con @Entity, se facilita la creación de consultas en JPQL, que es un lenguaje de consulta orientado a objetos basado en SQL, simplificando la recuperación de datos.
