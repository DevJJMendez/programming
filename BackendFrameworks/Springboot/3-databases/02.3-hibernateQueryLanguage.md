# Hibernate Query Language
Hibernate Query Language (HQL) es un lenguaje de consulta orientado a objetos y específico de Hibernate que se utiliza para realizar consultas sobre las entidades mapeadas en una base de datos. HQL es similar a SQL pero está diseñado para trabajar con entidades de Java en lugar de con tablas directamente. Su sintaxis está muy inspirada en SQL, pero permite escribir consultas que se enfocan en los objetos y sus relaciones, en lugar de las estructuras de tablas.

## ¿Qué es HQL?
HQL es un lenguaje de consulta desarrollado por Hibernate, que permite ejecutar operaciones de búsqueda, modificación y eliminación de datos utilizando un enfoque orientado a objetos. HQL es parte de la API de Hibernate y se convierte internamente a SQL para interactuar con la base de datos, por lo que funciona de manera eficiente con diversas bases de datos sin necesidad de escribir consultas SQL específicas de cada motor.

## ¿Para qué sirve?
HQL sirve para:

* **Consultar objetos persistentes**: Permite realizar consultas sobre entidades mapeadas en lugar de trabajar directamente con las tablas de la base de datos.

* **Realizar operaciones CRUD**: HQL facilita la creación, lectura, actualización y eliminación de entidades en la base de datos.

* **Consultas complejas y optimización**: HQL permite expresar consultas complejas, incluyendo filtrados, ordenamientos, agrupamientos, y soporte para relaciones entre entidades.

## ¿Qué problemas resuelve?
HQL resuelve los siguientes problemas en el manejo de bases de datos:

* **Portabilidad**: Al abstraer las consultas SQL específicas del motor, HQL permite escribir consultas independientes del tipo de base de datos.

* **Compatibilidad con la orientación a objetos**: HQL permite trabajar directamente con las propiedades y relaciones de las clases en Java, alineándose mejor con el paradigma orientado a objetos.

* **Facilita el uso de relaciones**: Permite definir y consultar fácilmente las relaciones entre entidades sin tener que preocuparse por las claves foráneas o el JOIN entre tablas.

## ¿Cómo resuelve estos problemas?
* **Mapeo automático**: HQL convierte automáticamente las consultas en SQL entendible para la base de datos subyacente, gracias al mapeo que Hibernate realiza entre clases Java y tablas.

* **Abstracción de SQL**: Al trabajar con HQL, el desarrollador se enfoca en clases y propiedades en lugar de columnas y tablas.

* **Sintaxis orientada a objetos**: HQL permite usar métodos y expresiones similares a los de Java, aprovechando directamente el mapeo de Hibernate para simplificar el trabajo con entidades.

## Principales Características de HQL
* **Consulta sobre Entidades**: Trabaja con entidades (clases mapeadas) en lugar de tablas, usando sus nombres de clase y propiedades.

* **Relaciones**: Soporta consultas basadas en las relaciones entre entidades, respetando las anotaciones @OneToOne, @OneToMany, etc.

* **Funciones de Agregación**: HQL permite el uso de funciones de agregación (SUM, AVG, COUNT, MIN, MAX) y la cláusula GROUP BY.

* **Alias**: Permite el uso de alias para facilitar la legibilidad y simplificación de consultas.
Filtros y Condiciones: HQL soporta operaciones de filtrado y condiciones con las clásicas cláusulas WHERE, ORDER BY, HAVING.

## Sintaxís Básica de HQL

* **Selección Básica**

    ```java
    String hql = "FROM Empleado";
    List<Empleado> empleados = session.createQuery(hql, Empleado.class).list();
    ```
    En este ejemplo, la consulta selecciona todas las instancias de la entidad `Empleado`. Observa que no se utiliza `SELECT *` como en SQL, sino que simplemente se especifica la clase.

* **Uso de Alias**

      ```java
      String hql = "FROM Empleado e WHERE e.departamento.nombre = :nombre";
      List<Empleado> empleados = session.createQuery(hql)
                                        .setParameter("nombre", "IT")
                                        .list();
      ```
      Aquí, `e` es un alias para la entidad `Empleado`, lo que permite referenciarla de manera más concisa en la consulta.

* **Selección de Propiedades Específicas**

      ```java
      String hql = "SELECT e.nombre, e.salario FROM Empleado e";
      List<Object[]> resultados = session.createQuery(hql).list();
      ```
      En este caso, la consulta selecciona solo los campos nombre y salario de Empleado. Los resultados se devuelven como una lista de arrays de objetos (Object[]), donde cada array contiene los valores de las propiedades seleccionadas.

* **Consultas con Condiciones (WHERE)**

      ```java
      String hql = "FROM Empleado e WHERE e.salario > :salario";
      List<Empleado> empleados = session.createQuery(hql)
                                        .setParameter("salario", 50000)
                                        .list();
      ```
      Esta consulta selecciona todos los empleados cuyo salario es mayor a 50,000.

* **Consultas con Ordenación (ORDER BY)**

      ```java
      String hql = "FROM Empleado e ORDER BY e.nombre ASC";
      List<Empleado> empleados = session.createQuery(hql).list();
      ```
      Esta consulta selecciona todos los empleados y los ordena alfabéticamente por nombre.

* **Consultas con Unión (JOIN)**: HQL soporta varios tipos de uniones (joins), que son muy útiles para realizar consultas sobre relaciones entre entidades.

      ```java
      String hql = "SELECT e FROM Empleado e INNER JOIN e.departamento d WHERE d.nombre = :nombre";
      List<Empleado> empleados = session.createQuery(hql)
                                        .setParameter("nombre", "IT")
                                        .list();
      ```
      Esta consulta selecciona todos los empleados que pertenecen al departamento "IT".

      **Left Join**
      ```java
      String hql = "SELECT e FROM Empleado e LEFT JOIN e.departamento d";
      List<Empleado> empleados = session.createQuery(hql).list();
      ```
      En este caso, la consulta selecciona todos los empleados y sus departamentos, incluyendo aquellos empleados que no tienen un departamento asociado (NULL).

* **Subconsultas**: HQL también permite la utilización de subconsultas:

      ```java
      String hql = "FROM Empleado e WHERE e.salario > (SELECT AVG(e2.salario) FROM Empleado e2)";
      List<Empleado> empleados = session.createQuery(hql).list();
      ```
      Esta consulta selecciona a todos los empleados cuyo salario es superior al salario promedio de todos los empleados.

* **Agregaciones y Funciones de Grupo**: HQL soporta funciones de agregación como `COUNT`, `SUM`, `AVG`, `MAX`, y `MIN`:

      ```java
      String hql = "SELECT AVG(e.salario) FROM Empleado e";
      Double salarioPromedio = session.createQuery(hql, Double.class).uniqueResult();
      ```
      Esta consulta obtiene el salario promedio de todos los empleados.
