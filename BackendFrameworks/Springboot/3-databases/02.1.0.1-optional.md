# `optional`
En Hibernate y JPA, el parámetro optional en las anotaciones de relaciones como `@OneToOne` y `@ManyToOne` se utiliza para indicar si la relación es opcional o requerida. Este parámetro permite controlar si el valor de la relación puede ser nulo en la base de datos o si es obligatorio.

## ¿Qué es el parámetro optional?
Es un atributo de las anotaciones de relaciones que recibe un valor booleano (true o false), y define la obligatoriedad de la relación:

* `optional = true`: La relación es opcional, por lo que el valor de la referencia puede ser `null`.

* `optional = false`: La relación es obligatoria, lo que implica que siempre debe haber una referencia asociada y no puede ser `null`.

## ¿Para qué sirve optional?
El parámetro optional permite controlar la cardinalidad de la relación y sus restricciones en el esquema de la base de datos. Cuando estableces optional = false, la relación se define como no opcional, lo cual asegura la integridad referencial entre las entidades.

## Ejemplo de uso
Imaginemos dos entidades: Persona y Pasaporte.

Si queremos asegurar que cada Persona tenga un Pasaporte obligatorio, podemos usar optional = false en la relación @OneToOne.
```java
@Entity
public class Persona {
    @Id
    private Long id;

    @OneToOne(optional = false) // Pasaporte es obligatorio
    @JoinColumn(name = "pasaporte_id")
    private Pasaporte pasaporte;

    // Getters y setters
}

@Entity
public class Pasaporte {
    @Id
    private Long id;

    @OneToOne(mappedBy = "pasaporte")
    private Persona persona;

    // Getters y setters
}
```
En este caso:

* Con `optional = false`, Hibernate y JPA esperan que siempre haya un Pasaporte asociado a cada Persona.

* En la base de datos, esto generalmente se traducirá en una restricción de integridad que impide que la columna pasaporte_id sea NULL.

Por el contrario, si configuramos `optional = true`, entonces la relación Pasaporte para Persona es opcional, permitiendo que la columna pasaporte_id pueda ser NULL.
