# `ResultSet`
ResultSet es una interfaz en JDBC (Java Database Connectivity) que representa el conjunto de resultados de una consulta SQL realizada a la base de datos. Se utiliza para navegar y procesar los datos obtenidos, proporcionando métodos para acceder a cada columna de las filas de resultado de forma estructurada y eficiente.

## ¿Qué es ResultSet?
ResultSet es una estructura que almacena los datos devueltos por una consulta SQL ejecutada mediante métodos como executeQuery() de Statement o PreparedStatement. Actúa como un cursor bidireccional que permite iterar y acceder a cada fila y columna devuelta en el conjunto de resultados.

## ¿Para qué sirve ResultSet?
* **Almacenar resultados de consulta**: Guarda los datos devueltos de la base de datos, permitiendo que la aplicación procese o muestre la información.

* **Navegar por los datos**: Ofrece métodos para moverse entre las filas y acceder a los valores en cada columna de las filas.

* **Manipulación de datos**: Permite obtener información y aplicar lógica de negocio en la aplicación a partir de los datos de la base.

##  ¿Qué resuelve ResultSet?
* **Acceso organizado a los datos**: Resuelve la necesidad de acceder a datos en un formato estructurado, simplificando la obtención de valores columna por columna.

* **Iteración sobre filas de datos**: Permite manejar múltiples filas de resultados de forma ordenada y eficiente.

* **Abstracción de la consulta**: Oculta los detalles de la consulta SQL y facilita la recuperación de datos en un formato comprensible y manipulable en Java.

## ¿Cómo resuelve ResultSet el acceso y procesamiento de datos?
* **Proporciona métodos de navegación**: Ofrece métodos como next(), previous(), first(), y last() para moverse por las filas de resultados.

* **Métodos para obtener valores**: Usa métodos como getInt(), getString(), getDouble(), etc., para extraer el valor de cada columna según el tipo de datos.

* **Capacidad de actualización y desplazamiento**: En configuraciones avanzadas, permite desplazarse en ambas direcciones (hacia adelante y atrás) y actualizar los datos directamente desde el ResultSet.

## Métodos principales de ResultSet
* Navegación:

  * `next()`: Avanza a la siguiente fila.

  * `previous()`: Retrocede a la fila anterior (en ResultSet desplazable).

  * `first()` y `last()`: Mueve a la primera o última fila respectivamente.

  * `beforeFirst()` y `afterLast()`: Posiciona el cursor antes de la primera fila o después de la última.

* Acceso a datos:

  * `getInt(columnLabel)`, `getString(columnLabel)`, `getDate(columnLabel)`, etc., para acceder a valores de columna.

  * `getObject(columnIndex)` o `getObject(columnLabel)`: Método genérico que permite obtener cualquier tipo de valor.

* Información sobre el ResultSet:

  * `wasNull()`: Permite verificar si el último valor leído fue NULL.

  * `getMetaData()`: Devuelve los metadatos de la consulta (como nombre de columnas y tipos de datos).

## Buenas prácticas al usar ResultSet
* Cerrar el ResultSet y otros recursos: Es fundamental para evitar fugas de memoria y mantener una conexión eficiente con la base de datos.

* Validar el contenido: Antes de acceder a un valor en el ResultSet, verifica si el cursor apunta a una fila válida.

* Uso de metadatos: Al manipular consultas dinámicas, getMetaData() proporciona detalles útiles sobre el conjunto de resultados.

## Casos de uso y limitaciones
* Ideal para consultas de solo lectura: ResultSet es óptimo para ejecutar consultas SELECT donde se desea procesar o mostrar datos.

* Actualización directa: No es ideal para todas las aplicaciones. Aunque puede actualizar registros en algunas configuraciones, el acceso a nivel de fila puede volverse ineficiente en grandes volúmenes de datos.
