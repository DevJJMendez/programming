# Java Persistence Query Language
Java Persistence Query Language (JPQL) es el lenguaje de consultas utilizado en la Java Persistence API (JPA) que permite realizar consultas a las entidades mapeadas en una base de datos de una manera orientada a objetos. JPQL se basa en el modelo de entidades definido por JPA, y sus consultas se escriben en términos de entidades y sus relaciones, en lugar de tablas y columnas como en SQL.

## ¿Qué es JPQL?
JPQL (Java Persistence Query Language) es un lenguaje de consultas orientado a objetos que forma parte de JPA. A diferencia de SQL, JPQL trabaja sobre clases y objetos en lugar de tablas y columnas. Esto significa que JPQL utiliza nombres de entidades, atributos y relaciones en lugar de nombres de tablas y campos de bases de datos.

## ¿Para qué sirve JPQL?
JPQL es utilizado para:

* **Consultar datos almacenados en una base de datos**: Realizar búsquedas de información almacenada de acuerdo a criterios definidos.

* **Actualizar o eliminar datos**: Ejecutar operaciones de modificación o eliminación sobre las entidades persistidas.

* **Realizar operaciones complejas con facilidad**: Permite el uso de expresiones condicionales y funciones de agregación, como SUM, AVG, COUNT, MAX, y MIN.

## ¿Qué resuelve JPQL?
* **Complejidad en la interacción con bases de datos**: Al abstraer las operaciones de consulta en un lenguaje orientado a objetos, JPQL simplifica la lógica para trabajar con datos persistentes en Java.

* **Compatibilidad multiplataforma**: JPQL es independiente del proveedor de bases de datos, lo que permite realizar consultas que funcionan de manera uniforme en diferentes sistemas de bases de datos.

## ¿Cómo lo resuelve JPQL?
JPQL permite definir consultas de manera intuitiva a través de sentencias similares a SQL, pero basadas en entidades y sus relaciones. Para ejecutar una consulta, se utiliza el `EntityManager` y el resultado es transformado en instancias de las entidades o en tipos de datos específicos si se usan valores agregados.

## Elementos Clave de JPQL
En JPQL, existen algunos elementos y características importantes:

* **Cláusula `SELECT`**: Selecciona las entidades o propiedades de entidades.

* **Cláusula `WHERE`**: Define condiciones para filtrar los datos.

* **Cláusula `ORDER BY`**: Ordena el resultado de la consulta.

* **Funciones de Agregación**: Como `COUNT`, `SUM`, `AVG`, `MAX`, `MIN`.

* **Expresiones de Asociación**: Permiten consultar entidades relacionadas usando relaciones (e.g., `JOIN`).

## Ejemplo de Consulta en JPQL
Imaginemos una entidad llamada Producto:
```java
@Entity
public class Producto {
    
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String nombre;
    private double precio;

    // Getters y Setters
}
```
**Ejemplo de Consulta Básica**
```java
String jpql = "SELECT p FROM Producto p WHERE p.precio > :precioMinimo";
TypedQuery<Producto> query = entityManager.createQuery(jpql, Producto.class);
query.setParameter("precioMinimo", 100.0);
List<Producto> productos = query.getResultList();
```
**En esta consulta:**
* Se seleccionan todos los productos cuyo precio es mayor a 100.

* `entityManager` ejecuta la consulta y devuelve los resultados como una lista de objetos Producto.

**Ejemplo de Consulta con Ordenación y Agregación**
```java
String jpql = "SELECT AVG(p.precio) FROM Producto p WHERE p.precio > :precioMinimo";
TypedQuery<Double> query = entityManager.createQuery(jpql, Double.class);
query.setParameter("precioMinimo", 100.0);
Double precioPromedio = query.getSingleResult();
```
**En esta consulta:**
* Calcula el precio promedio de productos cuyo precio es mayor a 100.

* Devuelve el resultado como un valor `Double`.

## Características Adicionales de JPQL
* **Consultas Nativas**: JPQL permite ejecutar consultas SQL nativas si se necesita mayor control o se usan funciones específicas del proveedor de la base de datos.

* **Consultas Dinámicas y Estáticas**: JPQL permite definir consultas en tiempo de ejecución o mediante `@NamedQuery` en las anotaciones de las entidades, optimizando el rendimiento.

## Ventajas de JPQL
* **Abstracción de la base de datos**: Al no depender de SQL, permite que el mismo código funcione en distintas bases de datos.

* **Facilidad de uso en entornos orientados a objetos**: Las consultas son más legibles y se integran mejor en aplicaciones Java al trabajar directamente sobre las entidades.
