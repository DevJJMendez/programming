# Conections Pools
Los pools de conexiones (connection pools) son una técnica utilizada para gestionar y reutilizar conexiones de base de datos de manera eficiente en aplicaciones. En lugar de abrir y cerrar una nueva conexión cada vez que se necesita interactuar con la base de datos, un pool de conexiones mantiene un conjunto de conexiones abiertas y disponibles para ser reutilizadas. Esto mejora significativamente el rendimiento y la escalabilidad de la aplicación.

## Ventajas de los Pools de Conexiones

1. **Rendimiento Mejorado**: Abrir y cerrar conexiones es una operación costosa en términos de tiempo y recursos. Reutilizar conexiones reduce esta sobrecarga.

2. **Escalabilidad**: Permite manejar un mayor número de solicitudes concurrentes al evitar el costo de crear nuevas conexiones repetidamente.

3. **Gestión de Recursos**: Los pools de conexiones gestionan eficientemente las conexiones disponibles, liberando conexiones inactivas y creando nuevas cuando sea necesario.

4. **Configuración Centralizada**: La configuración de las conexiones (como el tiempo de espera y el tamaño del pool) se puede gestionar de manera centralizada.

## Cómo Funciona un Pool de Conexiones

1. **Inicialización**: Al inicio de la aplicación, el pool crea un conjunto inicial de conexiones abiertas a la base de datos.

2. **Asignación**: Cuando una aplicación necesita una conexión, solicita una del pool. Si hay una conexión disponible, se asigna inmediatamente.

3. **Reutilización**: Después de que la aplicación termina de usar la conexión, esta no se cierra, sino que se devuelve al pool para ser reutilizada.

4. **Creación de Nuevas Conexiones**: Si todas las conexiones en el pool están en uso y se necesita una nueva, el pool puede crear una nueva conexión (hasta un límite configurado).

5. **Liberación de Conexiones**: Con el tiempo, las conexiones inactivas pueden ser cerradas para liberar recursos.

## Implementación de un Pool de Conexiones en Java
Una de las bibliotecas más populares para manejar pools de conexiones en Java es **HikariCP**.

**Paso 1: Agregar Dependencia**

En **Maven**, añade la dependencia de HikariCP en tu `pom.xml`:

```xml
<dependency>
    <groupId>com.zaxxer</groupId>
    <artifactId>HikariCP</artifactId>
    <version>5.0.1</version> <!-- Verifica la última versión disponible -->
</dependency>
```

**Paso 2: Configurar HikariCP**
```java
import com.zaxxer.hikari.HikariConfig;
import com.zaxxer.hikari.HikariDataSource;

import java.sql.Connection;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;

public class HikariCPDemo {
    public static void main(String[] args) {
        // Configuración de HikariCP
        HikariConfig config = new HikariConfig();
        config.setJdbcUrl("jdbc:mysql://localhost:3306/mydatabase");
        config.setUsername("root");
        config.setPassword("password");
        config.setMaximumPoolSize(10); // Número máximo de conexiones en el pool
        config.setMinimumIdle(5); // Número mínimo de conexiones inactivas en el pool
        config.setConnectionTimeout(30000); // Tiempo de espera para obtener una conexión

        // Crear el pool de conexiones
        HikariDataSource dataSource = new HikariDataSource(config);

        // Usar el pool de conexiones
        try (Connection connection = dataSource.getConnection()) {
            String sql = "SELECT * FROM users";
            try (PreparedStatement preparedStatement = connection.prepareStatement(sql);
                 ResultSet resultSet = preparedStatement.executeQuery()) {
                
                while (resultSet.next()) {
                    int id = resultSet.getInt("id");
                    String name = resultSet.getString("name");
                    String email = resultSet.getString("email");

                    System.out.println("ID: " + id + ", Name: " + name + ", Email: " + email);
                }
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }

        // Cerrar el pool de conexiones al finalizar
        dataSource.close();
    }
}
```
## Parámetros Comunes de Configuración en HikariCP


* `setJdbcUrl(String jdbcUrl)`: Establece la URL JDBC de la base de datos.

* `setUsername(String username)`: Establece el nombre de usuario para la conexión.

* `setPassword(String password)`: Establece la contraseña para la conexión.

* `setMaximumPoolSize(int maxPoolSize)`: Establece el número máximo de conexiones en el pool.

* `setMinimumIdle(int minIdle)`: Establece el número mínimo de conexiones inactivas en el pool.

* `setConnectionTimeout(long connectionTimeout)`: Establece el tiempo máximo de espera para obtener una conexión del pool.

* `setIdleTimeout(long idleTimeout)`: Establece el tiempo máximo que una conexión puede estar inactiva antes de ser eliminada del pool.

* `setMaxLifetime(long maxLifetime)`: Establece el tiempo máximo de vida de una conexión en el pool.

### Buenas Prácticas

1. **Configuración Adecuada**: Ajusta los parámetros del pool de conexiones según las necesidades de tu aplicación y el rendimiento de tu base de datos.

2. **Cerrar Conexiones**: Asegúrate de siempre cerrar las conexiones después de usarlas para devolverlas al pool.

3. **Monitoreo**: Implementa monitoreo y alertas para detectar posibles problemas de rendimiento o fugas de conexiones.
