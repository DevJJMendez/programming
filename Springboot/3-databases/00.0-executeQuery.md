# `ExecuteQuery`
El método executeQuery es una función de PreparedStatement y Statement en JDBC que permite ejecutar sentencias SQL que devuelven un conjunto de resultados (como las consultas SELECT). Es fundamental para obtener y procesar datos desde la base de datos en aplicaciones Java.

## ¿Qué es executeQuery?
executeQuery es un método específico de JDBC que ejecuta una consulta SQL de tipo SELECT y devuelve un objeto ResultSet. Este objeto representa el conjunto de resultados devuelto por la consulta y permite navegar y manipular los datos de la tabla en una base de datos.

## ¿Para qué sirve executeQuery?
* **Recuperar datos**: Se utiliza para extraer datos de una base de datos mediante consultas SELECT.

* **Navegar y procesar datos**: Permite iterar sobre los datos obtenidos y trabajar con ellos en la aplicación.

* **Acceso seguro a la base de datos**: Al usarse con PreparedStatement, ayuda a evitar inyecciones SQL.

## ¿Qué resuelve executeQuery?
* **Conexión y extracción de datos**: Permite interactuar con una base de datos para extraer datos de manera eficiente y estructurada.

* **Navegación por el conjunto de resultados**: Proporciona una forma ordenada y segura de acceder a cada registro en la tabla.

* **Integración con aplicaciones**: Con executeQuery, puedes traer datos desde la base de datos y procesarlos en tu aplicación, lo cual es esencial para aplicaciones dinámicas que dependen de datos en tiempo real.

##  ¿Cómo resuelve executeQuery la consulta y recuperación de datos?
* **Ejecución de la consulta**: Cuando se llama a executeQuery, se envía la sentencia SQL a la base de datos, que devuelve el ResultSet con los datos solicitados.

* **Uso de ResultSet**: Una vez que la base de datos devuelve el ResultSet, puedes iterar sobre sus filas y columnas para manipular los datos en Java.

## Ejemplo de uso básico de executeQuery
Imaginemos que queremos obtener datos de una tabla llamada empleados. Este ejemplo usa executeQuery para ejecutar una consulta SELECT y recorrer los resultados:

```java
String sql = "SELECT id, nombre, salario FROM empleados WHERE salario > ?";
try (PreparedStatement pstmt = connection.prepareStatement(sql)) {
    pstmt.setDouble(1, 3000.0); // Definir el salario mínimo

    ResultSet rs = pstmt.executeQuery(); // Ejecuta la consulta y devuelve el ResultSet
    while (rs.next()) { // Iterar sobre cada fila en el ResultSet
        int id = rs.getInt("id");
        String nombre = rs.getString("nombre");
        double salario = rs.getDouble("salario");
        
        System.out.println("ID: " + id + ", Nombre: " + nombre + ", Salario: " + salario);
    }
} catch (SQLException e) {
    e.printStackTrace();
}
```

## Métodos comunes de ResultSet para trabajar con executeQuery
Para trabajar eficientemente con los datos en ResultSet, se utilizan métodos específicos que corresponden al tipo de datos en cada columna:

* `next()`: Avanza el cursor a la siguiente fila. Es el método más común para iterar sobre los resultados.

* `getInt(columnLabel)`: Obtiene un valor int de la columna especificada.

* `getString(columnLabel)`: Obtiene un valor String de la columna.

* `getDouble(columnLabel)`: Obtiene un valor double.

* `getDate(columnLabel)`: Recupera valores de fecha.

## Buenas prácticas al usar executeQuery
* **Cerrar recursos**: Asegúrate de cerrar el ResultSet y otros recursos para evitar fugas de memoria.


* **Evitar consultas complejas dentro del bucle**: Coloca consultas pesadas fuera del bucle o usa parámetros para optimizar el rendimiento.

* **Verificar que el ResultSet no esté vacío**: Usa rs.next() de manera adecuada y maneja casos en los que no se devuelven resultados.

## Casos de uso y limitaciones
* **Ideal para consultas SELECT**: executeQuery está optimizado para operaciones de solo lectura.

* **No para operaciones de modificación**: No se recomienda usar executeQuery para INSERT, UPDATE o DELETE, ya que están mejor gestionados con executeUpdate.
