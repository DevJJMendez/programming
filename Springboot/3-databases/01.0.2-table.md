# `@Table`
@Table es una anotación de JPA que define detalles adicionales sobre el mapeo de una entidad a una tabla en la base de datos. Mientras que @Entity indica que una clase representa una tabla, @Table permite definir el nombre exacto de esa tabla y proporciona opciones adicionales para la configuración de las restricciones y el esquema.

Se coloca en la clase de la entidad, inmediatamente antes o después de la anotación @Entity, para complementar la configuración de mapeo.

## Parámetros de @Table
La anotación @Table incluye varios parámetros opcionales:

* **`name`**: Define el nombre de la tabla en la base de datos con la que la entidad se va a mapear. Si no se especifica, JPA utilizará el nombre de la clase como nombre de la tabla por defecto.

* **`catalog`**: Especifica el catálogo de la base de datos al que pertenece la tabla.

* **`schema`**: Indica el esquema de la base de datos donde se encuentra la tabla.

* **`uniqueConstraints`**: Establece restricciones de unicidad en columnas o combinaciones de columnas, lo que es útil para evitar duplicados en datos críticos.

* **`indexes`**: Define índices adicionales para columnas específicas, mejorando el rendimiento en consultas frecuentes.

**Ejemplo**
```java
@Entity
@Table(name = "empleados", schema = "empresa", uniqueConstraints = @UniqueConstraint(columnNames = "email"))
public class Empleado {
    // ...
}
```

## ¿para que sirve?
La anotación @Table permite configurar los detalles específicos del mapeo de una clase a una tabla de base de datos. Esto es útil cuando se necesita que el nombre de la tabla sea distinto al nombre de la clase, o cuando se requiere trabajar con un esquema o catálogo específico en la base de datos.

Además, al definir restricciones de unicidad o índices, @Table ayuda a mejorar la integridad de los datos y el rendimiento de las consultas, respectivamente.
