# `@ManyToOne`
La anotación `@ManyToOne` en **JPA/Hibernate** define una relación entre dos entidades en la que **muchas instancias** de una entidad están asociadas con **una sola instancia** de otra entidad. Esto es útil en casos donde, por ejemplo, muchos pedidos pertenecen a un cliente o varios empleados pertenecen a un departamento.

## Qué es?
`@ManyToOne` es una anotación de **JPA** que define una relación de **muchos-a-uno** entre dos entidades. Es decir, varios registros de una entidad están relacionados con un único registro de otra entidad. En Hibernate, esto se representa mediante una clave foránea que apunta a la entidad con la que se está asociando.

## Parámetros de la Anotación
La anotación `@ManyToOne` ofrece varios parámetros para personalizar su comportamiento. Los principales son:

* **`fetch`**: Define el tipo de carga (eager o lazy). Por defecto, es FetchType.EAGER.

  * `FetchType.LAZY`: La relación se carga bajo demanda, mejorando la eficiencia en algunos casos.

  * `FetchType.EAGER`: La relación se carga inmediatamente junto con la entidad principal.

  * `optional`: Indica si la relación es opcional (por defecto es true). Si se establece en false, significa que la entidad asociada no puede ser nula.

* **`cascade`**: Define qué operaciones en cascada (persistir, eliminar, actualizar, etc.) se deben aplicar a la entidad relacionada.

## ¿Para qué sirve?
`@ManyToOne` se usa para mapear una relación en la que varias entidades están asociadas a una sola entidad. Esta anotación permite establecer estas relaciones y gestionarlas en el contexto de **JPA** o **Hibernate**, haciendo que el código sea más intuitivo y reduciendo el esfuerzo de realizar consultas complejas manualmente.

**Ejemplo:**

* En un sistema de gestión de pedidos, `Pedido` puede tener una relación de **`@ManyToOne`** con `Cliente`, donde **muchos pedidos pertenecen a un solo cliente**.

## ¿Qué resuelve?
Esta anotación resuelve la necesidad de estructurar y gestionar relaciones entre entidades de forma eficiente y robusta en aplicaciones empresariales. Al tener un mapeo claro de las relaciones, JPA/Hibernate puede manejar las interacciones entre las entidades de forma transparente, lo que facilita:

* La consistencia de los datos en la base de datos.

* La simplificación de consultas complejas, ya que Hibernate se encarga de enlazar las relaciones.

* El manejo de operaciones en cascada y la carga diferida o temprana de datos según sea necesario.

## ¿Cómo lo resuelve?
**Hibernate/JPA** utiliza **`@ManyToOne`** para generar la estructura de la base de datos que permita la relación, estableciendo una clave foránea en la tabla de la entidad que representa el lado "muchos" de la relación.

## Ejemplo en Código
Imaginemos que tenemos dos entidades: Pedido y Cliente, donde cada Pedido pertenece a un Cliente.

```java
@Entity
public class Pedido {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @ManyToOne(fetch = FetchType.LAZY, optional = false)
    @JoinColumn(name = "cliente_id") // Clave foránea en la tabla de pedidos
    private Cliente cliente;

    // Getters y setters
}
@Entity
public class Cliente {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @OneToMany(mappedBy = "cliente") // "cliente" es el nombre del campo en Pedido
    private List<Pedido> pedidos;

    // Getters y setters
}
```
En este ejemplo:

* La anotación `@ManyToOne` se usa en el campo cliente dentro de la clase Pedido.

* `@JoinColumn(name = "cliente_id")` especifica el nombre de la columna en la tabla Pedido que almacena la clave foránea.

## Representación en una base de datos
```sql
CREATE TABLE Cliente (
    id BIGINT PRIMARY KEY,
    nombre VARCHAR(100),
    email VARCHAR(100)
);

CREATE TABLE Pedido (
    id BIGINT PRIMARY KEY,
    fecha DATE,
    cliente_id BIGINT,
    FOREIGN KEY (cliente_id) REFERENCES Cliente(id)
);
```
