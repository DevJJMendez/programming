# `@Column`
Es una anotación que se coloca en los campos de una clase de entidad para definir el mapeo entre una propiedad de Java y una columna en la tabla de la base de datos correspondiente. Permite personalizar atributos como el nombre de la columna, la longitud, la nulidad, entre otros.

## ¿Qué parámetros recibe @Column?
La anotación @Column puede recibir varios parámetros, entre los que se incluyen:

* `name`: Especifica el nombre de la columna en la tabla. Si no se proporciona, se usará el nombre del atributo como nombre de columna por defecto.

* `nullable`: Indica si la columna puede contener valores nulos. Por defecto es true, lo que significa que se permite que la columna sea nula.

* `unique`: Indica si el valor de la columna debe ser único en la tabla. Por defecto es false.

* `length`: Define la longitud de la columna, utilizado principalmente para tipos de datos como String. Por defecto es 255.

* `precision`: Especifica la precisión de la columna, utilizado para números decimales. Especifica la cantidad total de dígitos.

* `scale`: Define cuántos dígitos se pueden usar después del punto decimal para números decimales.

* `columnDefinition`: Permite definir la columna en SQL, útil para tipos de datos específicos de la base de datos.

* `insertable`: Indica si el valor de la columna puede ser insertado. Por defecto es true.

* `updatable`: Indica si el valor de la columna puede ser actualizado. Por defecto es true.

**Ejemplo**
```java
@Entity
public class Usuario {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(name = "nombre_usuario", nullable = false, length = 50, unique = true)
    private String nombre;

    @Column(name = "email", nullable = false, unique = true)
    private String email;

    // Constructor, getters y setters
}
```
En este ejemplo, la propiedad nombre está mapeada a la columna nombre_usuario, que no permite valores nulos, tiene una longitud máxima de 50 caracteres y debe ser única en la tabla.

## ¿Para qué sirve @Column?
La anotación @Column sirve para proporcionar un control más granular sobre cómo se mapean las propiedades de la entidad a las columnas de la base de datos. Permite definir características específicas de la columna que pueden ser importantes para la integridad y eficiencia de la base de datos.

## ¿Qué problemas resuelve @Column?
* **Control sobre la estructura de la base de datos**: Permite especificar nombres de columna diferentes a los nombres de atributo, así como definir restricciones y características de las columnas.

* **Integridad de los datos**: Al establecer restricciones como nullable y unique, ayuda a asegurar que los datos almacenados cumplan con ciertas reglas de validación.

* **Flexibilidad**: Facilita el mapeo de tipos de datos y permite ajustar el comportamiento de las columnas según las necesidades de la aplicación.
