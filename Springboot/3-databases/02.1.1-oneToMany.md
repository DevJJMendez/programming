# `@OneToMany`
La anotación `@OneToMany` en Hibernate y JPA define una relación **uno a muchos** entre dos entidades, es decir, establece que **una entidad puede estar relacionada con múltiples instancias de otra entidad**. Esta anotación se utiliza comúnmente para modelar situaciones en las que una entidad principal contiene una colección de entidades relacionadas, como el caso de una entidad `Cliente` que puede tener múltiples `Pedidos`.

## ¿Qué es la anotación `@OneToMany`?
`@OneToMany` es una anotación que define una relación en la que:

* Una instancia de una entidad se asocia con varias instancias de otra entidad.

* La entidad en el lado "uno" se define como la propietaria de la relación, aunque el lado "muchos" contiene la clave foránea (foreign key) que conecta las dos tablas en la base de datos.

**Ejemplo básico:**
```java
@Entity
public class Cliente {
    @Id
    private Long id;

    @OneToMany(mappedBy = "cliente") // "cliente" es el nombre del campo en Pedido
    private List<Pedido> pedidos;

    // Getters y setters
}

@Entity
public class Pedido {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String descripcion;

    @ManyToOne
    @JoinColumn(name = "cliente_id")
    private Cliente cliente;

    // Getters y Setters
}
```

## ¿Para qué sirve?
La anotación `@OneToMany` permite manejar una lista o colección de entidades relacionadas, facilitando la navegación y la gestión de datos relacionados de manera estructurada. Con esta relación, se pueden realizar operaciones en cascada, acceso sencillo a los datos asociados y mantenimiento de la consistencia.

## ¿Qué resuelve?
`@OneToMany` resuelve el problema de modelar relaciones donde una entidad principal necesita agrupar o relacionarse con varias instancias de otra entidad:

* **Navegación**: Permite navegar fácilmente desde una entidad principal a una colección de entidades relacionadas.

* **Gestión en cascada**: Facilita operaciones en cascada como persistencia y eliminación, de manera que se puede guardar o eliminar una entidad principal junto con todas las entidades relacionadas.

* **Integridad de datos**: Mantiene la relación en la base de datos y asegura que los datos estén sincronizados y consistentemente relacionados.

## ¿Cómo lo resuelve?
Hibernate y JPA resuelven esta relación mediante el uso de claves foráneas en la tabla de la entidad secundaria (en el ejemplo, la tabla `Pedido`). Para manejar esta relación, Hibernate mapea la colección de elementos de la entidad primaria con la tabla correspondiente en la base de datos.

## Parámetros de @OneToMany
1. **`mappedBy`**: Define la propiedad de la otra entidad que se encarga de la relación. Especifica que el lado inverso de la relación está en la entidad `Pedido` y que la propiedad `cliente` es la que almacena la referencia hacia `Cliente`. Este parámetro debe definirse en el lado no propietario de la relación.

```java
@OneToMany(mappedBy = "cliente")
private List<Pedido> pedidos;
```

2. **`cascade`**: Indica las operaciones en cascada que deben aplicarse a las entidades relacionadas. Puede usar valores como:

   * `CascadeType.PERSIST`: Persiste todas las entidades relacionadas cuando se guarda la entidad principal.

   * `CascadeType.REMOVE`: Elimina todas las entidades relacionadas cuando se elimina la entidad principal.

   * `CascadeType.ALL`: Aplica todas las operaciones en cascada.

```java
@OneToMany(mappedBy = "cliente", cascade = CascadeType.ALL)
private List<Pedido> pedidos;
```

3. **`fetch`**: Controla el comportamiento de carga de las entidades relacionadas. Los valores son:

   * `FetchType.LAZY`: Carga diferida (por defecto), es decir, la colección se carga solo cuando se accede a ella.

   * `FetchType.EAGER`: Carga todas las entidades relacionadas inmediatamente al cargar la entidad principal.

```java
@OneToMany(mappedBy = "cliente", fetch = FetchType.LAZY)
private List<Pedido> pedidos;
```

3. `orphanRemoval`: Cuando es `true`, elimina las entidades "huérfanas" que ya no están asociadas a la entidad principal.

```java
@OneToMany(mappedBy = "cliente", orphanRemoval = true)
private List<Pedido> pedidos;
```

## Representación en una base de datos
```sql
CREATE TABLE cliente (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(255) NOT NULL
    -- Otros campos del cliente
);

CREATE TABLE pedido (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    cliente_id BIGINT,
    fecha_pedido DATE,
    -- Otros campos del pedido
    CONSTRAINT fk_cliente
        FOREIGN KEY (cliente_id) REFERENCES cliente(id)
);
```
