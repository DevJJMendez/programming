# EntityClass
La Entity Class en JPA es una clase de Java que representa una entidad o una tabla en la base de datos, donde cada instancia de la clase corresponde a una fila en la tabla. Esta clase es fundamental en JPA, ya que permite definir y gestionar los datos de la base de datos en un formato orientado a objetos.

## Qué es una Entity Class en JPA?
Una Entity Class es una clase en Java que está anotada con `@Entity`, lo que le indica a JPA que esta clase debe ser tratada como una entidad de base de datos. Esta clase representa la estructura de una tabla y contiene atributos que representan las columnas de la tabla en la base de datos.

Para ser una entidad válida, la clase debe cumplir ciertos requisitos:

* Tener la anotación `@Entity`.

* Incluir una clave primaria (Primary Key) anotada con `@Id`.

* Contar con un constructor sin argumentos (JPA lo requiere para poder crear instancias de la entidad).

## ¿Para qué sirve una Entity Class?
Las Entity Classes permiten mapear los datos entre objetos Java y tablas de bases de datos relacionales, eliminando la necesidad de escribir consultas SQL manuales. Esta capa de abstracción hace que el código sea más orientado a objetos y permite que el desarrollo se enfoque más en la lógica del negocio en lugar de detalles de la base de datos.

## ¿Qué problemas resuelve la Entity Class?
La Entity Class resuelve varios problemas relacionados con la gestión de datos en aplicaciones empresariales:

* **Desacoplamiento**: Permite trabajar con datos sin necesidad de que la lógica de la aplicación dependa de consultas SQL o de la estructura específica de la base de datos.

* **Abstracción de SQL**: Los desarrolladores pueden manipular datos en forma de objetos, lo cual hace que el código sea más legible y mantenible.

* **Automatización de operaciones CRUD**: Simplifica las operaciones de Crear, Leer, Actualizar y Eliminar al ser gestionadas automáticamente por JPA.

* **Gestión de relaciones**: La Entity Class permite representar relaciones entre diferentes tablas (como `OneToMany`, `ManyToOne`, etc.), permitiendo modelar asociaciones complejas en la base de datos de una manera natural.

## ¿Cómo resuelve la Entity Class estos problemas?
JPA gestiona las Entity Classes mediante anotaciones, el EntityManager y el mapeo de atributos. Estos componentes trabajan en conjunto para simplificar la gestión de datos:

* **Anotaciones**: Anotaciones como `@Entity`, `@Id`, `@Table`, `@Column`, y otras ayudan a definir cómo JPA debe mapear la clase y sus atributos a la tabla correspondiente en la base de datos.

* **Gestión de relaciones**: Mediante anotaciones como `@OneToMany`, `@ManyToOne`, `@ManyToMany` y `@OneToOne`, se pueden definir relaciones complejas entre entidades.

* **Persistencia automática**: JPA utiliza el EntityManager para gestionar el ciclo de vida de las instancias de las Entity Classes, permitiendo a los desarrolladores persistir objetos en la base de datos de manera eficiente sin preocuparse por escribir consultas SQL explícitas.

## Componentes principales de una Entity Class
A continuación, se detalla la estructura y componentes básicos de una Entity Class.

```java
import javax.persistence.Entity;
import javax.persistence.Table;
import javax.persistence.Id;
import javax.persistence.GeneratedValue;
import javax.persistence.GenerationType;
import javax.persistence.Column;

`@Entity`
`@Table`(name = "empleados")
public class Empleado {
    `@Id`
    @GeneratedValue(strategy = GenerationType.IDENTITY) // Define el tipo de generación de clave primaria
    private Long id;

    `@Column`(name = "nombre", nullable = false) // Mapea el atributo a una columna en la tabla
    private String nombre;

    `@Column`(name = "edad")
    private int edad;

    // Constructor sin argumentos
    public Empleado() {}

    // Getters y setters
    public Long getId() {
        return id;
    }

    public void setId(Long id) {
        this.id = id;
    }

    public String getNombre() {
        return nombre;
    }

    public void setNombre(String nombre) {
        this.nombre = nombre;
    }

    public int getEdad() {
        return edad;
    }

    public void setEdad(int edad) {
        this.edad = edad;
    }
}
```
**Explicación de las anotaciones clave**

* ``@Entity``: Marca la clase como una entidad que JPA gestionará y persistirá en la base de datos.

* ``@Table``: Especifica el nombre de la tabla en la base de datos a la que la entidad está mapeada.

* ``@Id``: Marca un campo como clave primaria de la tabla.

* `@GeneratedValue`: Define la estrategia para la generación de claves primarias (`AUTO`, `IDENTITY`, `SEQUENCE`, `TABLE`).

* ``@Column``: Especifica el nombre y propiedades de la columna en la base de datos correspondiente a un campo.
