# `@ManyToMany`
La anotación `@ManyToMany` en **JPA e Hibernate** define una relación en la cual **una entidad puede estar asociada con muchas instancias de otra entidad, y viceversa**. Esto es útil para modelar relaciones donde ambas entidades tienen múltiples ocurrencias conectadas entre sí, como la relación entre Estudiante y Curso, donde un estudiante puede estar en múltiples cursos, y un curso puede tener múltiples estudiantes.

## ¿Qué es @ManyToMany?
Es una anotación que indica una relación de muchos a muchos entre dos entidades. En el contexto de una base de datos, esta relación se representa mediante una tabla de unión (join table) que actúa como intermediario, evitando la duplicación de datos y manteniendo la integridad de la relación.

¿Para qué sirve?
Sirve para simplificar la gestión de relaciones muchos a muchos sin tener que crear la lógica para manejar una tabla de relación adicional manualmente. Hibernate o JPA se encarga de manejar esta relación, permitiendo que las entidades interactúen de forma transparente sin necesidad de que el desarrollador escriba SQL adicional para la relación de unión.

¿Qué resuelve?
Resuelve la complejidad de implementar relaciones de muchos a muchos en una base de datos relacional, donde normalmente no es posible hacerlo directamente. Facilita la navegación y manipulación de datos relacionados en ambas direcciones (de una entidad a otra y viceversa), y es especialmente útil en aplicaciones de gestión de datos donde es común tener relaciones cruzadas.

¿Cómo lo resuelve?
@ManyToMany crea una tabla de unión para almacenar las claves primarias de ambas entidades en columnas separadas. Esta tabla de unión actúa como una lista de pares que unen las dos entidades, permitiendo que cada registro de la entidad A esté asociado con varios registros de la entidad B, y viceversa.

## Ejemplo
Supongamos una relación de muchos a muchos entre Estudiante y Curso:

```java
@Entity
public class Estudiante {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    private String nombre;

    @ManyToMany
    @JoinTable(
        name = "estudiante_curso", // Nombre de la tabla de unión
        joinColumns = @JoinColumn(name = "estudiante_id"), // Columna de clave foránea de Estudiante
        inverseJoinColumns = @JoinColumn(name = "curso_id") // Columna de clave foránea de Curso
    )
    private List<Curso> cursos = new ArrayList<>();

    // Getters y Setters
}

@Entity
public class Curso {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    private String nombre;

    @ManyToMany(mappedBy = "cursos") // Especifica que esta es la parte inversa de la relación
    private List<Estudiante> estudiantes = new ArrayList<>();

    // Getters y Setters
}
```

## Parámetros de @ManyToMany
mappedBy: Se usa en la entidad inversa para indicar que esta relación está mapeada por el atributo de la otra entidad.
cascade: Permite definir el comportamiento de cascada de la relación, como CascadeType.PERSIST o CascadeType.MERGE.
fetch: Controla el tipo de carga de la relación, ya sea FetchType.LAZY (por defecto) o FetchType.EAGER.

## Tabla de Unión en Base de Datos
La tabla de unión se crea automáticamente con el nombre estudiante_curso (especificado en @JoinTable), y contiene dos columnas: estudiante_id y curso_id, ambas actuando como claves foráneas a las tablas Estudiante y Curso.

```sql
CREATE TABLE estudiante (
    id BIGINT PRIMARY KEY,
    nombre VARCHAR(100)
);

CREATE TABLE curso (
    id BIGINT PRIMARY KEY,
    nombre VARCHAR(100)
);

CREATE TABLE estudiante_curso (
    estudiante_id BIGINT,
    curso_id BIGINT,
    PRIMARY KEY (estudiante_id, curso_id),
    FOREIGN KEY (estudiante_id) REFERENCES estudiante(id),
    FOREIGN KEY (curso_id) REFERENCES curso(id)
);
```

## Ejemplo de Uso en Código
Para agregar un curso a un estudiante:

```java
Estudiante estudiante = new Estudiante();
Curso curso = new Curso();

estudiante.getCursos().add(curso);
curso.getEstudiantes().add(estudiante);

entityManager.persist(estudiante);
entityManager.persist(curso);
```
