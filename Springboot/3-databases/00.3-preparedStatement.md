# `PreparedStatement`
Es una interfaz en JDBC que permite la ejecución de sentencias SQL precompiladas, las cuales pueden contener parámetros para su reutilización. Su uso incrementa la seguridad y eficiencia en la interacción con bases de datos, especialmente en aplicaciones con consultas SQL dinámicas que se ejecutan con regularidad.

## ¿Qué es PreparedStatement?
PreparedStatement es una subclase de Statement que permite ejecutar consultas SQL precompiladas con parámetros. A diferencia de Statement, PreparedStatement utiliza marcadores de posición `?` en lugar de valores específicos, lo que hace que el código sea más limpio y seguro, además de mejorar el rendimiento en consultas repetitivas.

## ¿Para qué sirve PreparedStatement?
PreparedStatement es ideal para:

* Ejecutar consultas parametrizadas.

* Evitar ataques de inyección SQL.

* Optimizar el rendimiento en consultas repetitivas o con datos variables.

* Reducir la sobrecarga del servidor de base de datos al permitir la precompilación de las consultas.

En general, PreparedStatement es una solución robusta para consultas dinámicas y repetitivas donde se requiere seguridad y eficiencia.

## ¿Qué resuelve PreparedStatement?
* **Inyección SQL**: Al utilizar parámetros en lugar de concatenación de strings, se eliminan las vulnerabilidades relacionadas con la inyección de código SQL.

* **Eficiencia en consultas repetidas**: Al precompilar la consulta SQL, la base de datos guarda el plan de ejecución, lo cual reduce el tiempo de procesamiento para consultas repetitivas.

* **Legibilidad y mantenimiento**: PreparedStatement permite separar la lógica de la consulta y los datos específicos, facilitando la lectura y el mantenimiento del código.

Sin PreparedStatement, las consultas parametrizadas serían más complejas y propensas a errores, además de ser menos seguras.

## ¿Cómo lo resuelve PreparedStatement?
PreparedStatement logra resolver los problemas anteriores mediante:

* **Marcadores de posición `?`**: Permiten incluir valores específicos sin necesidad de concatenar strings directamente en la consulta.

* **Precompilación**: Al crear un PreparedStatement, la consulta es precompilada por el servidor de base de datos, lo que acelera el procesamiento de consultas repetitivas.

* **Parámetros**: Los valores se asignan usando métodos como setString, setInt, setDouble, etc., que sustituyen los marcadores de posición con valores específicos antes de ejecutar la consulta.

## Principales métodos de `PreparedStatement`
1. **Creación y uso básico**: Para crear un `PreparedStatement`, debes especificar la consulta SQL con parámetros marcados con `?` en lugar de valores concretos:

```java
String sql = "SELECT * FROM usuarios WHERE nombre = ? AND edad = ?";
PreparedStatement preparedStatement = connection.prepareStatement(sql);
```

## Métodos para asignar valores a los parámetros
Estos métodos permiten definir valores específicos para cada parámetro `?` en la consulta. Algunos de los métodos más comunes incluyen:

* `setInt(int parameterIndex, int value)`: Asigna un valor entero al parámetro de la consulta.

```java
preparedStatement.setInt(1, 25);  // Asigna el valor 25 al primer parámetro (edad)
```

* `setString(int parameterIndex, String value)`: Asigna un valor de tipo String al parámetro.
```java
preparedStatement.setString(2, "Carlos");  // Asigna "Carlos" al segundo parámetro (nombre)
```

* `setDouble(int parameterIndex, double value)`: Asigna un valor double al parámetro.
```java
preparedStatement.setDouble(1, 199.99); // Ideal para valores como precios
```

* `setDate(int parameterIndex, java.sql.Date date)`: Asigna un valor de tipo fecha.
```java
preparedStatement.setDate(3, Date.valueOf("2024-10-29")); // Para manejar fechas
```

* `setBoolean(int parameterIndex, boolean value)`: Asigna un valor booleano.
```java
preparedStatement.setBoolean(4, true);
```

## Ejemplo de uso completo de PreparedStatement
Imaginemos que necesitamos insertar datos en una tabla usuarios en la base de datos.

```java
String sql = "INSERT INTO usuarios (nombre, edad, email, fecha_registro) VALUES (?, ?, ?, ?)";
try (PreparedStatement pstmt = connection.prepareStatement(sql)) {
    pstmt.setString(1, "Carlos");
    pstmt.setInt(2, 25);
    pstmt.setString(3, "carlos@ejemplo.com");
    pstmt.setDate(4, Date.valueOf("2024-10-29"));

    int rowsInserted = pstmt.executeUpdate();
    System.out.println("Filas insertadas: " + rowsInserted);
} catch (SQLException e) {
    e.printStackTrace();
}
```
