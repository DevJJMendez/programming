# `@Id`
Es una anotación de JPA que marca un atributo en una clase de entidad como el identificador único de la entidad. La clave primaria es fundamental en las bases de datos, ya que permite diferenciar cada registro y establecer relaciones entre tablas.

**Ejemplo**
```java
@Entity
public class Empleado {

    @Id
    private Long id;

    // otros atributos, constructores, getters y setters
}
```
En este ejemplo, el campo id es el identificador único de la entidad Empleado.

## ¿Para qué sirve `@Id`?
Sirve para definir el atributo que actuará como clave primaria en una entidad. Esto permite que cada instancia de la entidad esté vinculada a un registro único en la base de datos, permitiendo las operaciones CRUD y las relaciones entre entidades.
