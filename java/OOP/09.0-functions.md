# Funciones
En programación, una función es un bloque de código que realiza una tarea específica. Se puede considerar como una "subrutina" que toma algunas entradas (parámetros), realiza algún procesamiento y puede devolver una salida (resultado). Las funciones permiten organizar y reutilizar el código para evitar la repetición y hacer que los programas sean más mantenibles y modulares.

## ¿Para Qué Sirven las Funciones?
1. **Reutilización de Código**: Las funciones permiten encapsular una lógica que se puede usar múltiples veces en diferentes partes del programa. Esto evita la duplicación de código y hace que el sistema sea más fácil de mantener.

2. **Modularidad**: Las funciones ayudan a dividir un programa grande en partes más pequeñas y manejables. Cada función tiene una responsabilidad clara, lo que hace que el código sea más legible y fácil de depurar.

3. **Abstracción**: Al encapsular la lógica en una función, se ocultan los detalles de implementación. Los usuarios de la función solo necesitan saber qué hace, no cómo lo hace, lo que simplifica el uso del código.

## ¿Qué Problemas Resuelven las Funciones?
1. **Evitar la Duplicación de Código**: Si tienes una misma operación que se repite en varias partes de tu programa, encapsular esa operación en una función significa que solo necesitas cambiar el código en un lugar si hay que hacer modificaciones, en lugar de buscar y actualizar múltiples fragmentos.

2. **Mantenimiento y Legibilidad**: Los programas grandes y complejos se vuelven más fáciles de gestionar cuando se dividen en funciones pequeñas. Esto mejora la mantenibilidad, ya que cada función tiene una tarea clara y concisa.

3. **Estructura y Organización del Código**: Al usar funciones, el código se vuelve más estructurado. En lugar de tener todo el flujo de un programa en un solo bloque, puedes dividirlo en secciones lógicas que realizan tareas específicas, haciéndolo más entendible.

## ¿Cómo Resuelven Estos Problemas?
1. **Dividiendo el Código en Bloques Lógicos y Reutilizables**: Las funciones encapsulan una tarea o proceso específico. Por ejemplo, si necesitas calcular el promedio de una lista de números, puedes escribir una función `calcularPromedio()` y llamarla en cualquier lugar donde necesites esa operación.

2. **Encapsulando Detalles Complejos**: Si una operación es compleja, puedes escribir una función que maneje esa complejidad y solo proporcionar los resultados que otros fragmentos del código necesitan. Esto hace que el resto del código sea más limpio y fácil de entender.

**Ejemplo**
```java
public class Utilidades {
    // Función para calcular el cuadrado de un número
    public static int cuadrado(int numero) {
        return numero * numero;
    }

    // Función para verificar si un número es par
    public static boolean esPar(int numero) {
        return numero % 2 == 0;
    }

    // Función para convertir grados Celsius a Fahrenheit
    public static double convertirCelsiusAFahrenheit(double celsius) {
        return (celsius * 9 / 5) + 32;
    }
}
```
**Uso de las funciones**
```java
public class Main {
    public static void main(String[] args) {
        int resultado = Utilidades.cuadrado(5);
        System.out.println("Cuadrado de 5: " + resultado); // Cuadrado de 5: 25

        boolean esNumeroPar = Utilidades.esPar(10);
        System.out.println("¿10 es par?: " + esNumeroPar); // ¿10 es par?: true

        double fahrenheit = Utilidades.convertirCelsiusAFahrenheit(30);
        System.out.println("30 grados Celsius en Fahrenheit: " + fahrenheit); // 86.0
    }
}
```

## Diferencias Entre Funciones y Métodos
Aunque las funciones y los métodos son muy similares y a menudo se usan indistintamente, hay algunas diferencias clave, especialmente en lenguajes como Java:

1. **Contexto de Uso**:

   * **Funciones**: En lenguajes como Python, C o JavaScript, una función es simplemente un bloque de código que realiza una operación. No tiene que estar asociada a una clase y se puede definir y usar de manera independiente.

   * **Métodos**: En lenguajes orientados a objetos como Java, los métodos son funciones que están asociadas a una clase. Deben pertenecer a una clase y a menudo interactúan con los atributos de una instancia de esa clase.

2. **Vinculación con Objetos**:

   * Los métodos están ligados a un objeto específico (en el caso de métodos de instancia) o a la clase (en el caso de métodos estáticos). Esto significa que los métodos tienen acceso a los atributos de la clase y pueden manipular el estado del objeto.

   * Las funciones no están asociadas a un objeto en particular y no tienen acceso directo a atributos específicos.

3. **Propósito**:

   * Los métodos definen comportamientos de un objeto, mientras que las funciones suelen representar operaciones independientes que no dependen del estado de un objeto.
