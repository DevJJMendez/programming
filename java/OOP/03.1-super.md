# `super()`
El método super() es una llamada especial en Java utilizada dentro de un constructor para invocar el constructor de la clase padre (superclase).

## ¿Para qué sirve?
* Permite reutilizar la lógica de inicialización de la superclase.

* Evita la duplicación de código en los constructores de las subclases.

* Garantiza que los atributos de la clase padre sean correctamente inicializados antes de que la subclase agregue su propia lógica.

## ¿Cuál es su estructura?
```java
super(); // Llama al constructor sin parámetros de la superclase
super(argumentos); // Llama a un constructor específico de la superclase
```
**Importante**:
* La llamada a super() debe ser la primera instrucción dentro de un constructor de la subclase.

* Si no se especifica super(), Java lo invoca implícitamente si la superclase tiene un constructor sin parámetros.

## ¿Qué resuelve?
* La inicialización correcta de los atributos de la superclase antes de agregar atributos específicos de la subclase.

* Evita la repetición de código en los constructores.

* Facilita la reutilización de código en jerarquías de herencia.

## ¿Cómo lo resuelve?
**Ejemplo básico**: Llamando al constructor de la superclase
```java
class Empleado {
    String nombre;
    
    // Constructor de la superclase
    public Empleado(String nombre) {
        this.nombre = nombre;
    }
}

class Gerente extends Empleado {
    String departamento;
    
    // Constructor de la subclase que usa super()
    public Gerente(String nombre, String departamento) {
        super(nombre); // Llama al constructor de Empleado
        this.departamento = departamento;
    }
}
```
Explicación:
* Gerente hereda de Empleado.

* super(nombre) llama al constructor de Empleado para inicializar nombre.

* Luego, departamento se inicializa en la subclase.

## Ejemplo más avanzado: Clases con múltiples constructores
```java
class Usuario {
    String username;
    String email;

    // Constructor con 1 parámetro
    public Usuario(String username) {
        this.username = username;
    }

    // Constructor con 2 parámetros
    public Usuario(String username, String email) {
        this(username); // Llamada a otro constructor de la misma clase
        this.email = email;
    }
}

class Cliente extends Usuario {
    int puntosFidelidad;

    public Cliente(String username, String email, int puntosFidelidad) {
        super(username, email); // Llamada a constructor de Usuario
        this.puntosFidelidad = puntosFidelidad;
    }
}
```
* Usuario tiene dos constructores.

* Cliente usa super(username, email) para inicializar los atributos heredados de Usuario.

* Cliente agrega puntosFidelidad como nuevo atributo.

## Ejemplo con múltiples niveles de herencia
```java
class Persona {
    String nombre;

    public Persona(String nombre) {
        this.nombre = nombre;
    }
}

class Empleado extends Persona {
    double salario;

    public Empleado(String nombre, double salario) {
        super(nombre); // Llama al constructor de Persona
        this.salario = salario;
    }
}

class Manager extends Empleado {
    int equipo;

    public Manager(String nombre, double salario, int equipo) {
        super(nombre, salario); // Llama al constructor de Empleado
        this.equipo = equipo;
    }
}
```
* Manager llama a super(nombre, salario) de Empleado.

* Empleado a su vez llama a super(nombre) de Persona.

* Así, toda la jerarquía se inicializa correctamente

## Ejemplo con super para llamar métodos de la superclase
```java
class Persona {
    public void mostrarInfo() {
        System.out.println("Soy una persona");
    }
}

class Estudiante extends Persona {
    public void mostrarInfo() {
        super.mostrarInfo(); // Llama al método de la superclase
        System.out.println("Soy un estudiante");
    }
}

public class Main {
    public static void main(String[] args) {
        Estudiante e = new Estudiante();
        e.mostrarInfo();
    }
}
```
Salida:
```bash
Soy una persona  
Soy un estudiante  
```
* super.mostrarInfo(); llama al método mostrarInfo() de Persona antes de ejecutar el de Estudiante.

* Esto permite extender el comportamiento del método sin sobrescribir completamente la lógica original.
