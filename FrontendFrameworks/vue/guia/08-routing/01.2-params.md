## Parámetros en Rutas

Los parámetros en rutas permiten crear rutas dinámicas que pueden aceptar valores variables. Los parámetros se definen usando `:` seguido del nombre del parámetro en la ruta.
```typescript
import { createRouter, createWebHistory } from 'vue-router';
import User from '../views/User.vue';
import Post from '../views/Post.vue';

const routes = [
  {
    path: '/user/:id',
    name: 'User',
    component: User,
    props: true
  },
  {
    path: '/post/:postId',
    name: 'Post',
    component: Post,
    props: true
  }
];

const router = createRouter({
  history: createWebHistory(process.env.BASE_URL),
  routes
});

export default router;
```
En este ejemplo, las rutas `/user/:id` y `/post/:postId` aceptan parámetros dinámicos id y postId respectivamente.

- **En los componentes**
```typescript
<template>
  <div>
    <h1>User</h1>
    <p>User ID: {{ id }}</p>
  </div>
</template>

<script>
export default {
  name: 'User',
  props: ['id']
};
</script>

<template>
  <div>
    <h1>Post</h1>
    <p>Post ID: {{ postId }}</p>
  </div>
</template>

<script>
export default {
  name: 'Post',
  props: ['postId']
};
</script>
```
## Parámetros de Ruta Anidados

Las rutas pueden tener parámetros anidados, lo que permite crear rutas más complejas.

```typescript
import { createRouter, createWebHistory } from 'vue-router';
import User from '../views/User.vue';
import UserProfile from '../views/UserProfile.vue';
import UserPosts from '../views/UserPosts.vue';

const routes = [
  {
    path: '/user/:id',
    name: 'User',
    component: User,
    children: [
      {
        path: 'profile',
        name: 'UserProfile',
        component: UserProfile
      },
      {
        path: 'posts',
        name: 'UserPosts',
        component: UserPosts
      }
    ]
  }
];

const router = createRouter({
  history: createWebHistory(process.env.BASE_URL),
  routes
});

export default router;
```

- **En el componente**
```typescript
<template>
  <div>
    <h1>User</h1>
    <p>User ID: {{ $route.params.id }}</p>
    <router-link :to="`/user/${$route.params.id}/profile`">Profile</router-link>
    <router-link :to="`/user/${$route.params.id}/posts`">Posts</router-link>
    <router-view></router-view>
  </div>
</template>

<script>
export default {
  name: 'User'
};
</script>
```

En este ejemplo, la ruta `/user/:id` tiene rutas hijas `/user/:id/profile` y `/user/:id/posts`, lo que permite una navegación más compleja dentro de un mismo usuario.

## Buenas Práctica

En ciertas situaciones, utilizar `:to` con el nombre de la ruta directamente en `<router-link>` puede no ser la mejor práctica. Esto generalmente se refiere a la preferencia de mantener las rutas **desacopladas del enlace** y aprovechar más las ventajas que **Vue Router** ofrece. 

## Consideraciones

- **Legibilidad**: Directamente poner el nombre de la ruta puede hacer que el código sea menos legible, especialmente si la lógica para determinar la ruta es compleja.

- **Desacoplamiento**: Utilizar directamente los nombres de las rutas puede acoplar fuertemente los componentes de presentación con las rutas definidas, lo que puede dificultar la reutilización y el mantenimiento.

- **Flexibilidad**: En algunos casos, puede ser más flexible generar el destino del enlace mediante una función o computed property, especialmente cuando los enlaces dependen de datos dinámicos.

## Utilizar un `Object` para Definir Rutas

Es una buena práctica utilizar un objeto en lugar de una cadena de texto cuando defines la ruta. Esto hace que el código sea más explícito y manejable.

**Ejemplo**:
```typescript
<template>
  <div>
    <!-- Enlace utilizando objeto -->
    <router-link :to="{ name: 'User', params: { id: userId } }">Go to User</router-link>
  </div>
</template>

<script>
export default {
  data() {
    return {
      userId: 123
    };
  }
};
</script>
```

- **Computed Properties para Generar Rutas**

Utilizar computed properties para generar el objeto de ruta puede mejorar la legibilidad y permitir una lógica más compleja.

**Ejemplo**:
```typescript
<template>
  <div>
    <!-- Enlace utilizando computed property -->
    <router-link :to="userLink">Go to User</router-link>
  </div>
</template>

<script>
export default {
  data() {
    return {
      userId: 123
    };
  },
  computed: {
    userLink() {
      return {
        name: 'User',
        params: { id: this.userId }
      };
    }
  }
};
</script>
```
