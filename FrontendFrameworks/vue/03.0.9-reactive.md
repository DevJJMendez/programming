# reactive()
reactive() es una función de la Composition API en Vue 3 que permite crear objetos reactivos. Convierte un objeto JavaScript normal en un proxy reactivo, lo que significa que Vue puede rastrear los cambios realizados en sus propiedades y actualizar automáticamente las vistas que dependen de él.

Es una herramienta clave para manejar estados más complejos, como objetos y arrays.

## ¿Para qué sirve?
Crear estados reactivos complejos:

Es ideal para manejar estructuras de datos como objetos con múltiples propiedades o arrays.
Sincronizar datos con la vista:

Cualquier cambio en las propiedades del objeto reactivo será detectado automáticamente por Vue, actualizando las partes relevantes del DOM.
Proporcionar reactividad profunda:

Todas las propiedades del objeto (incluidas las anidadas) son rastreadas de manera reactiva.

## ¿Qué resuelve?
Manejo de estructuras de datos complejas:

Permite gestionar objetos con múltiples propiedades y arrays de forma reactiva, algo que sería más complicado de lograr con ref().
Reactividad automática:

Resuelve el problema de actualizar manualmente las vistas cuando cambian los datos.
Reactividad profunda:

Vue rastrea automáticamente los cambios en propiedades anidadas del objeto, lo que reduce la necesidad de realizar un seguimiento manual.
Simplificación del código:

Hace que el manejo de estados sea más intuitivo y menos propenso a errores.

## ¿Cómo lo resuelve?
Transformando el objeto en un proxy reactivo:

Vue utiliza un proxy para interceptar accesos y modificaciones a las propiedades del objeto.
Integración con el sistema de reactividad de Vue:

El objeto reactivo se conecta automáticamente al sistema de reactividad de Vue, lo que permite que las vistas se actualicen sin intervención manual.
Reactividad profunda:

Todas las propiedades del objeto, incluidas las propiedades anidadas, se rastrean automáticamente.

## Estructura básica de reactive()
```ts
import { reactive } from 'vue';

const state = reactive({
  contador: 0,
  usuario: {
    nombre: 'Juan',
    edad: 25,
  },
});

// Acceder y modificar propiedades
console.log(state.contador); // 0
state.contador++;
console.log(state.contador); // 1

state.usuario.nombre = 'María';
console.log(state.usuario.nombre); // María
```

## ¿Cómo se usa reactive()?
1. Uso básico con objetos
```ts
<script setup lang="ts">
import { reactive } from 'vue';

const state = reactive({
  contador: 0,
  mensaje: 'Hola, Vue 3',
});

const incrementar = () => {
  state.contador++;
};
</script>

<template>
  <div>
    <p>{{ state.mensaje }}</p>
    <p>Contador: {{ state.contador }}</p>
    <button @click="incrementar">Incrementar</button>
  </div>
</template>
```

2. Uso con arrays
reactive() también funciona perfectamente con arrays y los hace reactivos.
```ts
<script setup lang="ts">
import { reactive } from 'vue';

const frutas = reactive(['manzana', 'pera', 'plátano']);

const agregarFruta = () => {
  frutas.push('fresa');
};
</script>

<template>
  <div>
    <p>Frutas: {{ frutas.join(', ') }}</p>
    <button @click="agregarFruta">Agregar Fruta</button>
  </div>
</template>
```

3. Uso con propiedades anidadas
La reactividad también aplica a propiedades dentro de objetos anidados.
```ts
<script setup lang="ts">
import { reactive } from 'vue';

const state = reactive({
  usuario: {
    nombre: 'Juan',
    edad: 30,
  },
});

const cambiarNombre = () => {
  state.usuario.nombre = 'Ana';
};
</script>

<template>
  <div>
    <p>Nombre: {{ state.usuario.nombre }}</p>
    <p>Edad: {{ state.usuario.edad }}</p>
    <button @click="cambiarNombre">Cambiar Nombre</button>
  </div>
</template>
```

## Limitaciones de reactive()
Acceso a primitivas individuales:

Aunque puedes envolver primitivas en un objeto, es menos conveniente que usar ref() para este caso.
Referencias al DOM:

No se puede usar reactive() para referenciar elementos del DOM. Para esto, utiliza ref().
