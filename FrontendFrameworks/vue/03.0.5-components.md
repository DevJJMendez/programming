# `components{}`
En Vue.js, el objeto components dentro de la Option API se utiliza para registrar componentes hijos que serán utilizados dentro del componente actual. Este registro permite que los componentes hijos puedan ser utilizados en la plantilla del componente padre.

## ¿Qué es components()?
El components es una opción en la Option API de Vue.js que:

* Permite registrar componentes locales.

* Define qué componentes hijos estarán disponibles en la plantilla del componente donde se declara.

Es una clave dentro del objeto que define un componente y no un método propiamente dicho.

## ¿Cuál es su estructura?
La estructura básica de la opción components es un objeto donde cada clave representa el nombre del componente que se usará en la plantilla, y el valor es la referencia al componente hijo importado.

**Ejemplo básico:**
```ts
export default {
  components: {
    NombreComponente: ComponenteImportado,
  },
};
```

**Estructura más compleja:**
Si tienes varios componentes hijos, puedes registrarlos todos en el mismo objeto:
```ts
import Header from './Header.vue';
import Footer from './Footer.vue';

export default {
  components: {
    Header,
    Footer,
  },
};
```

## ¿Para qué sirve?
La opción components sirve para:

* **Registrar componentes locales**: Esto permite usar un componente hijo únicamente dentro del componente actual.

* **Facilitar la modularidad**: Al usar components, los componentes se vuelven reutilizables, lo que permite crear aplicaciones más organizadas y mantenibles.

* **Evitar colisiones de nombres**: Al registrar los componentes localmente, se evita que estén disponibles globalmente, reduciendo el riesgo de conflictos de nombres.

## ¿Qué resuelve?
* **Modularidad y reutilización**: Permite dividir la interfaz de usuario en pequeños componentes reutilizables, mejorando la organización y escalabilidad del código.

* **Control del alcance**: Restringe el uso de componentes a un ámbito local en lugar de registrarlos globalmente, lo que evita problemas de acoplamiento.

* **Mejor rendimiento**: Al registrar componentes localmente, se cargan y utilizan solo cuando son necesarios, optimizando el rendimiento.

## ¿Cómo lo resuelve?
* **Registro local**: Se importan los componentes hijos y se agregan a la opción components en el componente padre.

* **Uso en la plantilla**: Después de registrar los componentes, se pueden utilizar directamente en el HTML de la plantilla.

## Ejemplo
**Componente padre:**
```ts
<template>
  <div>
    <Header />
    <main>
      <p>Contenido principal del componente padre.</p>
    </main>
    <Footer />
  </div>
</template>

<script>
import Header from './Header.vue';
import Footer from './Footer.vue';

export default {
  components: {
    Header, // Registro del componente hijo Header
    Footer, // Registro del componente hijo Footer
  },
};
</script>
```

**Componente hijo (`Header.vue`):**
```ts
<template>
  <header>
    <h1>Este es el encabezado</h1>
  </header>
</template>

<script>
export default {
  name: 'Header',
};
</script>
```
**Componente hijo (`Footer.vue`):**
```ts
<template>
  <footer>
    <p>Este es el pie de página</p>
  </footer>
</template>

<script>
export default {
  name: 'Footer',
};
</script>
```

## ¿Cuándo usar components?
* **Al trabajar con componentes locales**: Si un componente solo se utiliza dentro de otro componente específico, regístralo localmente con components.

* **Para dividir aplicaciones grandes**: En aplicaciones complejas, dividir la lógica en varios componentes mejora la escalabilidad y mantenibilidad.

* **Si no deseas registrar componentes globalmente**: Usar registros locales permite evitar el sobrecargado del registro global.

## Diferencia entre componentes locales y globales
* **Componentes globales**: Se registran en un archivo principal como `main.js` y están disponibles en toda la aplicación.
```ts
import Vue from 'vue';
import Header from './Header.vue';

Vue.component('Header', Header); // Registro global
```

* **Componentes locales**: Se registran en un componente específico dentro de la opción `components`.
```ts
import Header from './Header.vue';

export default {
  components: {
    Header,
  },
};
```
