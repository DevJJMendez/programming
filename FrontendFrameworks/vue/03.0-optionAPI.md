# Option API
Es un enfoque de programación en Vue.js en el cual defines los distintos aspectos de un componente utilizando opciones claramente separadas en un objeto de configuración. Estas opciones incluyen datos **(`data`), métodos (`methods`), propiedades computadas (`computed`)**, y más, cada una dentro de su propia sección en el componente.

Es el enfoque tradicional en Vue (antes de Vue 3) para organizar el código y estructurar un componente.

## ¿Cuál es su estructura?
La estructura básica de un componente utilizando la Option API es un objeto que contiene diferentes propiedades y funciones que configuran el comportamiento del componente.
```ts
<template>
  <div>
    <h1>{{ title }}</h1>
    <p>{{ message }}</p>
    <button @click="updateMessage">Actualizar Mensaje</button>
  </div>
</template>

<script>
export default {
  name: "MyComponent", // Nombre del componente (opcional)
  
  // Datos reactivos
  data() {
    return {
      title: "Hola desde Option API",
      message: "Este es un mensaje inicial",
    };
  },

  // Propiedades computadas
  computed: {
    reversedMessage() {
      return this.message.split("").reverse().join("");
    },
  },

  // Métodos
  methods: {
    updateMessage() {
      this.message = "El mensaje ha sido actualizado.";
    },
  },

  // Ciclos de vida
  mounted() {
    console.log("El componente ha sido montado.");
  },
};
</script>

<style scoped>
/* Estilos específicos del componente */
h1 {
  color: blue;
}
</style>
```

## ¿Para qué sirve?
La Option API permite definir de manera estructurada:

* **Datos reactivos**: Variables que actualizan automáticamente el DOM cuando cambian.

* **Propiedades computadas**: Valores derivados que dependen de los datos reactivos.

* **Métodos**: Funciones que implementan la lógica del componente.

* **Ciclo de vida**: Métodos especiales que se ejecutan en diferentes momentos del ciclo de vida del componente (montaje, actualización, destrucción, etc.).

* **Propiedades y eventos**: Manejo de comunicación entre componentes (`props` y `events`).

## ¿Qué resuelve?
La Option API facilita la organización y separación de responsabilidades dentro de un componente:

* **Estructura clara y legible**: Cada funcionalidad (datos, métodos, computadas, etc.) se encuentra en una sección bien definida.

* **Mantenimiento**: Es más fácil identificar dónde se encuentra cada lógica dentro de un componente.

* **Adopción rápida**: Es intuitiva y fácil de aprender, especialmente para principiantes.

## ¿Cómo lo resuelve?
La Option API resuelve estos problemas al proporcionar una estructura estandarizada en la cual cada aspecto del componente se define en una opción específica del objeto:


* **Datos Reactivos**: Se definen dentro de la opción data, donde cada propiedad del objeto es reactiva y puede actualizar el DOM automáticamente.

* **Propiedades Computadas**: Las propiedades computadas se colocan en la opción computed y se recalculan automáticamente cuando los datos de los que dependen cambian.

* **Métodos**: Las funciones que ejecutan lógica se colocan en la opción methods para separar las acciones de los datos.

* **Ciclo de Vida**: Métodos como `mounted` y `beforeDestroy` facilitan la ejecución de código en momentos clave del ciclo de vida del componente.
