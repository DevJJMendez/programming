# `filters()`
El método filters() en la Option API de Vue.js era una forma de definir filtros personalizados para formatear o transformar datos antes de mostrarlos en la interfaz. Estos filtros se podían usar directamente en las plantillas dentro de las expresiones interpoladas o en las directivas.

**Nota importante**: A partir de Vue 3, **los filtros fueron eliminados** debido a que no eran esenciales y podían reemplazarse fácilmente con métodos, funciones computed o incluso funciones de utilidades externas.

## ¿Cuál era su estructura?
Los filtros se definían en la opción filters dentro del objeto del componente. Cada filtro era una función que recibía un valor como argumento y devolvía el valor transformado.

```ts
export default {
  filters: {
    capitalize(value) {
      if (!value) return '';
      return value.charAt(0).toUpperCase() + value.slice(1);
    },
    currency(value) {
      return `$${parseFloat(value).toFixed(2)}`;
    },
  },
};
```

## ¿Para qué servía?
* **Transformación de datos**: Los filtros servían para formatear datos o realizar transformaciones simples antes de mostrarlos en la interfaz.

* **Reutilización de lógica**: Permitían evitar la duplicación de lógica para formatear datos al centralizar esta funcionalidad en un solo lugar.

* **Legibilidad en las plantillas**: Hacían las plantillas más limpias y legibles, ya que encapsulaban la lógica de transformación en un filtro.

## ¿Qué resolvía?
* **Formato repetitivo de datos**: En lugar de repetir lógica para formatear valores como fechas, monedas, o cadenas, se podía utilizar un filtro para estandarizar el formato.

* **Simplificación de las plantillas**: Reducían el uso de métodos o lógica compleja en las plantillas, haciendo que el código fuera más limpio.

## ¿Cómo lo resolvía?
* **Aplicación sencilla en plantillas**: Los filtros se utilizaban directamente en las plantillas de Vue mediante un pipe `|`.
```html
<p>{{ message | capitalize }}</p>
<p>{{ price | currency }}</p>
```

* **Encapsulación de lógica**: Cada filtro era una función que contenía la lógica de transformación, lo que lo hacía fácil de reutilizar en todo el componente.

## Ejemplo práctico:
**Componente con filtros:**
```ts
export default {
  filters: {
    capitalize(value) {
      if (!value) return '';
      return value.charAt(0).toUpperCase() + value.slice(1);
    },
    currency(value) {
      if (typeof value !== 'number') return value;
      return `$${value.toFixed(2)}`;
    },
  },
};
```
**Plantilla que usa los filtros:**
```html
<template>
  <div>
    <p>{{ 'hello world' | capitalize }}</p> <!-- Resultado: "Hello world" -->
    <p>{{ 1234.56 | currency }}</p> <!-- Resultado: "$1234.56" -->
  </div>
</template>
```

## ¿Por qué fueron eliminados en Vue 3?
* **Simplicidad**: Los filtros no eran esenciales, ya que podían ser reemplazados fácilmente con métodos o propiedades computadas.

* **Consistencia**: Al usar métodos o funciones computed, toda la lógica de transformación de datos se gestiona de manera uniforme.

* **Evitar acoplamiento**: Los filtros podían crear un fuerte acoplamiento con Vue, mientras que las utilidades externas (como bibliotecas de formateo) son más independientes y reutilizables.

## Alternativas a los filtros en Vue 3
Aunque los filtros ya no están disponibles en Vue 3, puedes lograr el mismo resultado utilizando métodos, funciones computed o utilidades externas.

1. **Usar métodos**:
```ts
export default {
  methods: {
    capitalize(value) {
      if (!value) return '';
      return value.charAt(0).toUpperCase() + value.slice(1);
    },
    currency(value) {
      if (typeof value !== 'number') return value;
      return `$${value.toFixed(2)}`;
    },
  },
};
```
```html
<p>{{ capitalize('hello world') }}</p> <!-- Resultado: "Hello world" -->
<p>{{ currency(1234.56) }}</p> <!-- Resultado: "$1234.56" -->
```

2. **Usar propiedades computadas**:
```ts
export default {
  data() {
    return {
      message: 'hello world',
      price: 1234.56,
    };
  },
  computed: {
    capitalizedMessage() {
      return this.message.charAt(0).toUpperCase() + this.message.slice(1);
    },
    formattedPrice() {
      return `$${this.price.toFixed(2)}`;
    },
  },
};
```
```html
<p>{{ capitalizedMessage }}</p> <!-- Resultado: "Hello world" -->
<p>{{ formattedPrice }}</p> <!-- Resultado: "$1234.56" -->
```
