# Computed Properties
Las propiedades computadas son valores derivados automáticamente de otras propiedades reactivas en un componente de Vue.js. Estas propiedades se definen dentro de la opción computed en la Option API y actúan como métodos que se memorizan (caching) para evitar cálculos innecesarios.

Son muy útiles para manejar lógica relacionada con la transformación o combinación de datos sin repetir cálculos o tener que implementar lógica redundante en múltiples lugares.

## ¿Para qué sirven?
* **Cálculos basados en datos reactivos**: Derivan valores dinámicos a partir de otras propiedades reactivas de manera eficiente.

* **Simplificación del template**: Evitan incluir lógica compleja en el template, mejorando la legibilidad del código.

* **Organización del código**: Centralizan la lógica de transformación o combinación de datos en un solo lugar.

* **Mejor rendimiento**: Usan memorización para recalcular el valor solo cuando sus dependencias cambian, optimizando los procesos de renderizado.

## ¿Qué resuelven?
* **Cálculos repetitivos**: Evitan la necesidad de recalcular valores derivados manualmente en diferentes partes del código.

* **Código desordenado en el template**: Eliminan lógica innecesaria en las vistas, lo que mejora la organización y legibilidad.

* **Recalcular datos innecesariamente**: A diferencia de los métodos, las propiedades computadas no se ejecutan cada vez que el componente se vuelve a renderizar. Solo se ejecutan cuando alguna de sus dependencias cambia.

## ¿Cómo lo resuelven?
* **Reactividad automática**: Vue.js rastrea automáticamente las dependencias dentro de la propiedad computada. Si alguna de ellas cambia, la propiedad computada se recalcula.

* **Memorización (`Caching`)**: Las propiedades computadas almacenan su último valor calculado y solo se actualizan si las dependencias cambian.

* **Integración con el ciclo de vida**: Las propiedades computadas están diseñadas para trabajar perfectamente con el sistema de reactividad de Vue.js, garantizando que los valores estén siempre sincronizados con los datos subyacentes.

# `computed()`
Es una característica dentro de la **Option API** de Vue.js que se utiliza para declarar propiedades computadas.

## Estructura básica
```ts
computed: {
  propiedadComputada() {
    // Retorna un valor derivado de otros datos reactivos
    return /* cálculo basado en this.algo */;
  }
}

<template>
  <div>
    <p>Nombre completo: {{ fullName }}</p>
  </div>
</template>

<script>
export default {
  data() {
    return {
      firstName: "Juan",
      lastName: "Pérez",
    };
  },
  computed: {
    fullName() {
      return `${this.firstName} ${this.lastName}`;
    },
  },
};
</script>
```
## Ejemplo práctico
Propiedad computada para datos derivados:
```ts
<template>
  <div>
    <p>Precio total (con IVA): {{ totalPrice }}</p>
  </div>
</template>

<script>
export default {
  data() {
    return {
      price: 100,
      tax: 0.15,
    };
  },
  computed: {
    totalPrice() {
      return this.price + this.price * this.tax;
    },
  },
};
</script>
```

## Propiedades computadas vs Métodos
Aunque puedes lograr cálculos similares usando métodos, las propiedades computadas tienen ventajas clave:

1. **Propiedades computadas**:
   * Están memorizadas.

   * Se vuelven a calcular solo cuando cambian las dependencias.

2. **Métodos**:
   * No están memorizados.

   * Se ejecutan cada vez que se llaman, incluso si las dependencias no cambian.

# Propiedades computadas con `get` y `set`
Las propiedades computadas pueden ser de solo lectura (por defecto) o de lectura y escritura utilizando `get` y `set`.

```ts
<template>
  <div>
    <p>Nombre completo: {{ fullName }}</p>
    <input v-model="fullName" />
  </div>
</template>

<script>
export default {
  data() {
    return {
      firstName: "Juan",
      lastName: "Pérez",
    };
  },
  computed: {
    fullName: {
      get() {
        return `${this.firstName} ${this.lastName}`;
      },
      set(value) {
        const names = value.split(" ");
        this.firstName = names[0];
        this.lastName = names[1] || "";
      },
    },
  },
};
</script>
```

## Cuándo usar propiedades computadas
* **Para cálculos derivados**: Si necesitas mostrar información calculada basada en los datos reactivos.

* **Cuando el rendimiento es importante**: Evita cálculos innecesarios mediante la memorización de valores.

* **En combinación con `watch`**: Usa propiedades computadas para cálculos y watchers para lógica reactiva (como llamadas a APIs).
