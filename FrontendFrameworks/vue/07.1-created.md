# `create`
created es uno de los ciclos de vida de un componente en Vue.js. Es el segundo hook que se ejecuta después de beforeCreate y se dispara inmediatamente después de que el componente ha sido inicializado. En este punto, el sistema de reactividad ya está configurado, lo que significa que puedes acceder y manipular las propiedades de data, computed, y los métodos definidos en el componente.

1. ¿Qué es el hook created?
El hook created es una función del ciclo de vida que se ejecuta cuando:

El componente ha sido creado.
El sistema de reactividad de Vue ya está configurado.
Las propiedades de data, methods, computed, y props ya están disponibles y funcionales.
Sin embargo, en este punto, el DOM del componente aún no está accesible. Esto significa que no puedes interactuar con el DOM o realizar tareas relacionadas con elementos visuales. Para eso, usarías el hook mounted.

2. Estructura del hook created
La estructura básica de un componente con el hook created es la siguiente:
```ts
<template>
  <div>
    <h1>{{ message }}</h1>
  </div>
</template>

<script>
export default {
  data() {
    return {
      message: '¡Hola desde Vue.js!'
    };
  },
  created() {
    console.log('El componente ha sido creado.');
    console.log('Mensaje inicial:', this.message); // Se puede acceder a `data`
  }
};
</script>
```
En este ejemplo:

La función created se define como parte de las opciones del componente.
Se ejecuta después de inicializar las propiedades de data.
Puedes interactuar con this.message porque la reactividad ya está configurada.

## ¿Para qué sirve el hook created?
El hook created tiene varios usos principales:

Inicialización de datos reactivos:

Puedes cargar datos desde una API o realizar cálculos iniciales para poblar el estado del componente.
Configuración de lógica reactiva:

Es un buen lugar para configurar eventos, observadores, o suscribirse a servicios externos.
Depuración temprana:

Ideal para verificar el estado inicial del componente o realizar pruebas de funcionalidad básica.
Acceso a propiedades reactivas:

A diferencia de beforeCreate, en created ya puedes trabajar con data, methods, y computed.

## ¿Qué resuelve el hook created?
El hook created resuelve las necesidades de inicialización temprana de un componente. En particular:

Cargar datos desde un servidor:

Si necesitas obtener datos antes de que el componente se renderice, este es el lugar adecuado.
Preparar el estado inicial del componente:

Puedes establecer valores iniciales dinámicos o preconfigurar lógica basada en datos reactivos.
Establecer suscripciones:

Conectar el componente a eventos o servicios externos (como WebSockets).

## ¿Cómo lo resuelve?
El hook created resuelve estas necesidades de la siguiente manera:

Se ejecuta después de que Vue ha inicializado el sistema de reactividad.
Permite acceder y manipular las propiedades de data, computed, y methods.
Es lo suficientemente temprano como para garantizar que cualquier inicialización o lógica sea completada antes de la renderización del componente.
Ejemplo: Cargar datos desde una API
```ts
<template>
  <div>
    <h1>Usuarios</h1>
    <ul>
      <li v-for="user in users" :key="user.id">{{ user.name }}</li>
    </ul>
  </div>
</template>

<script>
export default {
  data() {
    return {
      users: []
    };
  },
  created() {
    console.log('Cargando datos...');
    fetch('https://jsonplaceholder.typicode.com/users')
      .then(response => response.json())
      .then(data => {
        this.users = data; // Actualiza los datos reactivos
        console.log('Datos cargados:', this.users);
      });
  }
};
</script>
```
En este ejemplo:
* El hook created se utiliza para cargar datos desde una API antes de que el componente sea renderizado.

* Los datos se almacenan en la propiedad reactiva users, lo que asegura que el componente los renderice automáticamente una vez obtenidos.

## Características importantes del hook created
Acceso al sistema de reactividad:

A diferencia de beforeCreate, en este hook ya puedes trabajar con propiedades de data, methods, props, y computed.
El DOM aún no está disponible:

No puedes usar this.$el ni manipular elementos del DOM. Para ello, utiliza el hook mounted.
Ideal para tareas de inicialización no visual:

Es el lugar perfecto para preparar el estado, cargar datos, o configurar servicios.
Es síncrono, pero puede contener lógica asíncrona:

Puedes usar promesas (then) o async/await dentro de este hook.

## Limitaciones del hook created
* No acceso al DOM: Si necesitas manipular elementos del DOM, espera a que el componente esté montado (mounted).

* No es adecuado para tareas relacionadas con la interfaz de usuario: Cualquier lógica que dependa de elementos visuales debe ejecutarse después del montaje.

## Caso de uso del hook created
Ejemplo 1: Configuración inicial de datos
```ts
export default {
  data() {
    return {
      count: 0
    };
  },
  created() {
    console.log('Inicializando contador...');
    this.count = Math.random() * 100; // Asignación inicial basada en lógica
  }
};
```

Ejemplo 2: Suscripción a eventos
```ts
export default {
  created() {
    console.log('Suscribiéndose a eventos...');
    window.addEventListener('resize', this.handleResize);
  },
  methods: {
    handleResize() {
      console.log('El tamaño de la ventana ha cambiado.');
    }
  }
};
```

Ejemplo 3: Carga inicial de configuraciones
```ts
export default {
  data() {
    return {
      settings: null
    };
  },
  created() {
    console.log('Cargando configuraciones...');
    this.settings = JSON.parse(localStorage.getItem('appSettings')) || {};
  }
};
```
