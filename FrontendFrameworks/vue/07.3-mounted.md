# `mounted`
El hook mounted es uno de los más utilizados en el ciclo de vida de un componente en Vue.js. Se ejecuta una vez que el componente ha sido montado en el DOM real, lo que significa que puedes interactuar directamente con los elementos del DOM.

¿Qué es el hook mounted?
El hook mounted es un método del ciclo de vida que:

Se ejecuta después de que el DOM real ha sido actualizado con los datos del componente.
Es el primer momento en el que puedes acceder al elemento raíz del componente a través de this.$el.
Este hook es ideal para realizar tareas relacionadas con la interacción del DOM, como agregar eventos, inicializar bibliotecas de terceros o realizar operaciones que dependen de que el DOM esté presente.

Estructura del hook mounted
La estructura básica del hook mounted es la siguiente:
```ts
<template>
  <div>
    <h1 ref="header">¡Hola, Vue.js!</h1>
  </div>
</template>

<script>
export default {
  data() {
    return {
      message: 'Componente montado'
    };
  },
  mounted() {
    console.log('El hook mounted se ha ejecutado');
    console.log('El componente está montado en el DOM real');
    console.log(this.$refs.header); // Acceso al elemento DOM
  }
};
</script>
```
En este ejemplo:
* El mensaje "El hook mounted se ha ejecutado" se mostrará en la consola cuando el componente esté completamente montado.

* Se accede al elemento DOM `<h1>` utilizando la referencia `this.$refs.header`.

## ¿Para qué sirve el hook mounted?
El hook mounted sirve para:

Acceder al DOM real:

Puedes manipular o interactuar con el DOM directamente.
Ejemplo: Aplicar estilos dinámicos o manipular elementos HTML.
Inicializar bibliotecas de terceros:

Es el lugar adecuado para inicializar librerías que dependen del DOM, como gráficos (Chart.js), carruseles (Swiper.js), entre otros.
Realizar llamadas a API o servicios externos:

Si necesitas cargar datos desde un servidor y mostrarlos inmediatamente en el componente, puedes hacerlo aquí.
Añadir listeners personalizados:

Puedes configurar eventos relacionados con el DOM o el navegador.

## ¿Qué resuelve el hook mounted?
El hook mounted resuelve la necesidad de interactuar con el DOM real o realizar tareas que requieren que el componente esté completamente visible para el usuario.

Esto incluye:

Manipulación del DOM con datos ya renderizados.
Configuración de bibliotecas o herramientas que necesitan acceso al DOM.
Realizar acciones que dependen de la visualización del componente.
5. ¿Cómo lo resuelve?
El hook mounted lo resuelve ejecutando código después de que el DOM real ha sido actualizado con el contenido del componente. En este punto:

El sistema de reactividad de Vue está completamente funcional.
Los datos están sincronizados con el DOM.
Puedes interactuar con los elementos del DOM utilizando this.$refs o el propio DOM API.

## Ejemplo práctico del hook mounted
Ejemplo 1: Manipulación del DOM
```ts
<template>
  <div>
    <h1 ref="title">Texto inicial</h1>
  </div>
</template>

<script>
export default {
  mounted() {
    // Cambiar el texto de un elemento DOM usando $refs
    this.$refs.title.textContent = 'Texto actualizado desde el hook mounted';
  }
};
</script>
```
Aquí, el texto inicial del <h1> se cambia después de que el componente está montado.

Ejemplo 2: Inicialización de una biblioteca de terceros
```ts
<template>
  <canvas ref="chart"></canvas>
</template>

<script>
import Chart from 'chart.js/auto';

export default {
  mounted() {
    const ctx = this.$refs.chart.getContext('2d');
    new Chart(ctx, {
      type: 'bar',
      data: {
        labels: ['Enero', 'Febrero', 'Marzo'],
        datasets: [{
          label: 'Ventas',
          data: [10, 20, 30],
          backgroundColor: ['red', 'blue', 'green']
        }]
      }
    });
  }
};
</script>
```
En este ejemplo, se utiliza el hook mounted para inicializar un gráfico utilizando Chart.js.

Ejemplo 3: Llamada a una API
```ts
<template>
  <div>
    <p v-if="data">Datos cargados: {{ data }}</p>
    <p v-else>Cargando datos...</p>
  </div>
</template>

<script>
export default {
  data() {
    return {
      data: null
    };
  },
  mounted() {
    // Realizar una llamada a una API
    fetch('https://jsonplaceholder.typicode.com/todos/1')
      .then(response => response.json())
      .then(json => {
        this.data = json.title; // Actualizar los datos después de montado
      });
  }
};
</script>
```
En este ejemplo, se realiza una llamada a una API para cargar datos y mostrarlos en el componente después de montarlo.

## Consideraciones y buenas prácticas
Ventajas del hook mounted:
Acceso directo al DOM real:

Ideal para manipular el DOM o inicializar herramientas que dependan de él.
Sincronización de datos con el DOM:

El DOM está actualizado con los datos del componente.
Llamadas API seguras:

Puedes estar seguro de que los datos cargados se mostrarán correctamente.
Buenas prácticas:
Evitar lógica compleja:

Mantén el código del hook limpio y enfocado en tareas específicas. Mueve la lógica compleja a métodos.
Evitar abusar del DOM manualmente:

Usa la reactividad de Vue para evitar manipulaciones innecesarias.
Desmontar listeners o recursos al desmontar el componente:

Si agregas eventos o recursos en mounted, asegúrate de limpiarlos en el hook beforeUnmount o unmounted.
