# `$emit`
`$emit()` es un método integrado en Vue.js que se utiliza para emitir eventos personalizados desde un componente hijo hacia su componente padre. Este método permite al hijo comunicar información o notificar al padre sobre eventos específicos.

## ¿Cuál es su estructura?
La estructura básica de $emit() es la siguiente:
```ts
this.$emit('nombreDelEvento', payloadOpcional);
```
* nombreDelEvento: El nombre del evento personalizado que el padre escuchará.

* payloadOpcional: (Opcional) Los datos que se envían al padre junto con el evento.

## ¿Para qué sirve?
El método $emit() sirve para:

Comunicar de hijo a padre:
Notifica al componente padre que ocurrió un evento en el hijo.

Enviar datos al padre:
Puede incluir un "payload" con información adicional relevante, como datos que el hijo desea compartir con el padre.

Desacoplar la lógica de componentes:
Permite que el componente hijo sea reutilizable sin depender de la lógica específica del componente padre.

## ¿Qué resuelve?
Flujo de datos hacia arriba:
Las Props permiten que los datos fluyan del padre al hijo. $emit() resuelve la necesidad de enviar datos en la dirección opuesta, es decir, del hijo al padre.

Separación de responsabilidades:
Ayuda a mantener el código modular y desacoplado, permitiendo que los componentes trabajen de forma independiente.

## ¿Cómo lo resuelve?
Emitir eventos desde el hijo:
El hijo utiliza $emit() para disparar eventos personalizados.

El padre escucha el evento:
El componente padre utiliza la directiva @ o v-on para escuchar el evento emitido por el hijo y realizar alguna acción.

Transferencia de datos:
$emit() puede incluir datos adicionales que el padre recibe como argumento en el manejador del evento.

## Ejemplo básico
Hijo: Emite un evento con $emit()
```ts
<template>
  <button @click="enviarMensaje">Enviar mensaje</button>
</template>

<script>
export default {
  methods: {
    enviarMensaje() {
      // Emitir un evento llamado 'mensajeEnviado' con un payload
      this.$emit('mensajeEnviado', 'Hola desde el hijo');
    }
  }
};
</script>
```
Padre: Escucha el evento emitido
```ts
<template>
  <div>
    <Hijo @mensajeEnviado="manejarMensaje" />
    <p>{{ mensaje }}</p>
  </div>
</template>

<script>
import Hijo from './Hijo.vue';

export default {
  components: { Hijo },
  data() {
    return {
      mensaje: ''
    };
  },
  methods: {
    manejarMensaje(payload) {
      this.mensaje = payload; // Recibir el mensaje emitido por el hijo
    }
  }
};
</script>
```
Resultado:
Cuando se hace clic en el botón del hijo, el evento mensajeEnviado se emite con el mensaje "Hola desde el hijo", que el padre escucha y maneja, actualizando el mensaje en pantalla.

## Ejemplo avanzado: Comunicación con datos dinámicos
Hijo:
```ts
<template>
  <button @click="seleccionarItem">Seleccionar</button>
</template>

<script>
export default {
  props: ['item'],
  methods: {
    seleccionarItem() {
      // Emitir un evento 'itemSeleccionado' con el objeto 'item' como payload
      this.$emit('itemSeleccionado', this.item);
    }
  }
};
</script>
```
Padre:
```ts
<template>
  <Hijo
    v-for="item in lista"
    :key="item.id"
    :item="item"
    @itemSeleccionado="manejarSeleccion"
  />
  <p>Elemento seleccionado: {{ seleccionado?.nombre || 'Ninguno' }}</p>
</template>

<script>
import Hijo from './Hijo.vue';

export default {
  components: { Hijo },
  data() {
    return {
      lista: [
        { id: 1, nombre: 'Elemento 1' },
        { id: 2, nombre: 'Elemento 2' },
        { id: 3, nombre: 'Elemento 3' }
      ],
      seleccionado: null
    };
  },
  methods: {
    manejarSeleccion(item) {
      this.seleccionado = item; // Guardar el elemento seleccionado
    }
  }
};
</script>
```
Resultado:
Cuando se selecciona un elemento, el hijo emite el evento con el elemento seleccionado, y el padre actualiza la variable seleccionado.

## Buenas prácticas al usar $emit()
Nombres de eventos descriptivos:
Usa nombres claros y legibles, como @actualizarUsuario o @enviarFormulario.

Definición explícita de eventos (Vue 3):
En Vue 3, utiliza defineEmits() para declarar los eventos que el componente emitirá. Esto mejora la claridad y ayuda con el tipado en TypeScript.
```ts
defineEmits(['eventoNombre', 'otroEvento']);
```

Evitar nombres genéricos:
En lugar de nombres como @click o @evento, usa nombres más específicos para evitar conflictos.

Mantén los datos enviados simples:
Solo envía datos relevantes como payload para mantener la claridad.

Desacopla la lógica del hijo:
Evita que el hijo llame métodos directamente del padre; usa $emit() para que el padre decida qué hacer.

## Limitaciones y consideraciones
Solo para comunicación directa (hijo → padre):
Si necesitas comunicarte con un abuelo, hermano o componente no relacionado, necesitarás otras estrategias como event buses (deprecated) o gestión de estado global (Vuex o Pinia).

Complejidad en aplicaciones grandes:
En aplicaciones grandes, el uso excesivo de $emit() puede volverse difícil de gestionar. Para flujos complejos, considera utilizar una solución centralizada como Vuex o Pinia.
