# props
Son un mecanismo para pasar datos desde un componente padre a un componente hijo. Los props permiten que los componentes sean reutilizables y configurables, ya que el componente hijo puede recibir diferentes datos y comportarse de manera distinta en función de esos datos.

## ¿Qué son los props?
* Los props son propiedades que se utilizan para enviar datos desde un componente padre hacia un componente hijo.

* Representan una forma de comunicación unidireccional, es decir, los datos fluyen únicamente del componente padre al hijo.

* Los props se pueden considerar como argumentos que un componente hijo recibe para personalizar su comportamiento.

## ¿Cuál es su estructura?
Los props se declaran en la sección `props` de un componente en la Option API. Pueden ser definidos como:

* Un array con los nombres de las propiedades.

* Un objeto que especifica el tipo, valor predeterminado, y validaciones.

**Ejemplo básico (definición como array):**
```ts
export default {
  props: ['titulo', 'mensaje'],
};
```

**Ejemplo avanzado (definición como objeto):**
```ts
export default {
  props: {
    titulo: {
      type: String,          // Tipo esperado
      required: true,        // Es obligatorio
    },
    mensaje: {
      type: String,
      default: 'Hola mundo', // Valor predeterminado
    },
    conteo: {
      type: Number,
      validator: (valor) => valor >= 0, // Validación personalizada
    },
  },
};
```

## ¿Para qué sirven?
Los props permiten a los componentes:

* Recibir datos desde su padre para personalizarse o tomar decisiones.

* Facilitar la reutilización de componentes al poder configurarlos dinámicamente desde el exterior.

* Separar responsabilidades: los componentes hijos no necesitan conocer los detalles de dónde provienen los datos.

## ¿Qué resuelven?
Los props resuelven varios problemas comunes en el desarrollo de componentes, como:

* **Comunicación unidireccional**: Garantizan que los datos fluyan en una única dirección (de padre a hijo), lo que simplifica el seguimiento de cambios en el estado.

* **Personalización de componentes reutilizables**: Permiten que un componente se comporte de manera diferente en función de los valores que reciba.

* **Separación de lógica**: Evitan que los componentes hijos dependan directamente del estado o lógica del componente padre.

## ¿Cómo lo resuelven?
* Los props funcionan declarando en el hijo qué propiedades espera recibir y utilizando estos datos dentro de su lógica o plantilla.

* Los datos se pasan desde el padre al usar atributos en la plantilla:

**Ejemplo Padre -> Hijo**

**Componente hijo:**
```ts
export default {
  props: ['titulo', 'mensaje'],
  template: `
    <div>
      <h1>{{ titulo }}</h1>
      <p>{{ mensaje }}</p>
    </div>
  `,
};
```
**Componente padre:**
```ts
<template>
  <MiComponente titulo="Bienvenido" mensaje="Este es un mensaje personalizado" />
</template>

<script>
import MiComponente from './MiComponente.vue';

export default {
  components: { MiComponente },
};
</script>
```

## Validaciones en los props
Vue.js permite definir tipos, valores predeterminados y validaciones personalizadas para las propiedades.

Tipos comunes:

* **`String`**: Cadena de texto.

* **`Number`**: Número.

* **`Boolean`**: Valor booleano (`true`/`false`).

* **`Array`**: Lista de elementos.

* **`Object`**: Objeto con claves y valores.

* **`Function`**: Función.

* **`Date`**: Fecha.
```ts
export default {
  props: {
    titulo: {
      type: String,
      required: true,
    },
    edad: {
      type: Number,
      default: 18,
      validator: (valor) => valor >= 0, // Debe ser mayor o igual a 0
    },
  },
};
```

## Buenas prácticas al usar props:
1. **Declara siempre los tipos de las propiedades**: Esto ayuda a detectar errores y mejorar la legibilidad del código.
```ts
props: {
  titulo: { type: String, required: true },
}
```

2. **Define valores predeterminados**: Asegúrate de que las propiedades opcionales tengan valores por defecto.
```ts
props: {
  items: { type: Array, default: () => [] },
}
```

3. **No modifiques directamente las propiedades en el hijo**: Las props son de solo lectura. Si necesitas modificarlas, usa una copia local o un valor derivado en `data()`.
```ts
props: ['titulo'],
data() {
  return {
    tituloLocal: this.titulo, // Copia local de la prop
  };
},
```

4. **Usa validaciones personalizadas**: Esto permite que las propiedades cumplan con condiciones específicas.
```ts
props: {
  edad: {
    type: Number,
    validator: (valor) => valor >= 0 && valor <= 120,
  },
}
```

## Errores comunes:
* **No declarar los props**: Si no declaras un prop en el componente hijo, Vue no lo detectará y mostrará un warning.

* **Modificar directamente los props**: Esto rompe el flujo unidireccional de datos y genera errores.

* **No usar el tipo correcto**: Si el padre pasa un tipo diferente al esperado, Vue mostrará un warning (pero no un error).
