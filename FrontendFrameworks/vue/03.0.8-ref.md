# `ref()`
ref() es una función proporcionada por la Composition API en Vue 3 que se utiliza para crear variables reactivas. Es una de las herramientas principales para manejar reactividad en Vue.

Cuando usas ref(), Vue envuelve el valor en un objeto reactivo que puede ser rastreado y actualizado automáticamente en el DOM siempre que cambie.

## ¿Para qué sirve?
ref() sirve para:

Definir estados reactivos simples:

Es útil para manejar variables individuales (primitivas como números, cadenas, booleanos) o valores complejos (objetos y arrays).
Actualizar el DOM automáticamente:

Las variables creadas con ref() se sincronizan automáticamente con la vista, por lo que cuando cambian, el DOM se actualiza de manera reactiva.
Crear referencias a valores dinámicos:

También puede ser usado para manejar referencias a elementos del DOM cuando se combina con el atributo ref en el template.

## ¿Qué resuelve?
Reactividad simple:

Facilita la creación de estados reactivos sin necesidad de usar la opción data como en la Option API.
Control claro sobre valores reactivos:

Ofrece más flexibilidad al trabajar con valores reactivos en comparación con métodos no reactivos o variables normales.
Compatibilidad con primitivas:

Hace que las primitivas como números y cadenas sean reactivas, algo que no era directamente posible en Vue 2.
Desacoplamiento de la lógica del componente:

Permite gestionar reactividad y lógica fuera de la estructura rígida de Vue 2, habilitando una mejor modularidad.
¿Cómo lo resuelve?
Encapsulando el valor dentro de un objeto reactivo:

Vue convierte la variable en un objeto que rastrea automáticamente los cambios y notifica al sistema de reactividad.
Proporcionando una propiedad .value:

Accedes y modificas el valor reactivo mediante la propiedad .value.
Integrándose con el DOM:

Las variables definidas con ref() se sincronizan automáticamente con el template y actualizan el DOM cuando cambian.

## Estructura básica de ref()
```ts
import { ref } from 'vue';

const contador = ref(0); // Crear un estado reactivo
console.log(contador.value); // Acceder al valor inicial (0)

contador.value++; // Actualizar el valor reactivo
console.log(contador.value); // Acceder al nuevo valor (1)
```

## ¿Cómo se usa ref()?
1. Uso básico con tipos primitivos
ref() se usa comúnmente para números, cadenas, booleanos o valores primitivos.
```ts
<script setup lang="ts">
import { ref } from 'vue';

const mensaje = ref('Hola, Vue 3');
const contador = ref(0);

const incrementar = () => {
  contador.value++;
};
</script>

<template>
  <div>
    <p>{{ mensaje }}</p>
    <p>Contador: {{ contador }}</p>
    <button @click="incrementar">Incrementar</button>
  </div>
</template>
```

2. Uso con objetos y arrays
Aunque reactive() es más común para objetos y arrays, ref() también funciona.
```ts
<script setup lang="ts">
import { ref } from 'vue';

const usuario = ref({
  nombre: 'Juan',
  edad: 30,
});

const frutas = ref(['manzana', 'pera', 'plátano']);

const agregarFruta = () => {
  frutas.value.push('fresa');
};
</script>

<template>
  <div>
    <p>Usuario: {{ usuario.nombre }}, Edad: {{ usuario.edad }}</p>
    <p>Frutas: {{ frutas }}</p>
    <button @click="agregarFruta">Agregar Fruta</button>
  </div>
</template>
```
Nota: Cuando trabajas con objetos y arrays, las modificaciones internas en las propiedades de los objetos o elementos del array siguen siendo reactivas.

3. Uso con referencias al DOM
Puedes usar ref() para referenciar elementos HTML directamente.
```ts
<script setup lang="ts">
import { ref, onMounted } from 'vue';

const inputRef = ref<HTMLInputElement | null>(null);

onMounted(() => {
  if (inputRef.value) {
    inputRef.value.focus(); // Establecer foco en el input
  }
});
</script>

<template>
  <input ref="inputRef" placeholder="Enfocado automáticamente" />
</template>
```
