# composables
Los composables son funciones reutilizables en Vue 3 que encapsulan lógica reactiva, estados y efectos secundarios. Están diseñados para trabajar con la Composition API y permiten organizar, compartir y reutilizar código reactivo en una aplicación.

El término "composable" proviene del concepto de composición en programación, que se refiere a la práctica de construir funcionalidades complejas a partir de piezas más pequeñas y reutilizables.

## ¿Cuáles son los composables?
1. Composables nativos de Vue 3
Vue proporciona composables integrados para manejar estados, reactividad y efectos secundarios. Algunos ejemplos comunes son:

* **`ref()`**: Crear variables reactivas.

* **`reactive()`**: Crear objetos reactivamente.

* **`computed()`**: Propiedades computadas.

* **`watch()`**: Observar cambios en variables específicas.

* **`watchEffect()`**: Efectos secundarios reactivos automáticos.

* **`onMounted()`**: Ejecutar código cuando el componente se monta.

* **`onUnmounted()`**: Ejecutar código cuando el componente se desmonta.

* **`provide()`** y **`inject()`**: Compartir estado entre componentes.

2. Composables personalizados: Puedes crear tus propios composables para encapsular lógica de negocio o funcionalidad específica.

**Ejemplo**
```ts
import { ref } from 'vue';

export function useContador() {
  const contador = ref(0);

  const incrementar = () => {
    contador.value++;
  };

  const decrementar = () => {
    contador.value--;
  };

  return { contador, incrementar, decrementar };
}
```

3. **Librerías de terceros**: Muchas librerías ofrecen composables predefinidos para funcionalidades específicas como manejo de formularios, autenticación, o acceso a APIs (por ejemplo, `VueUse`).

## ¿Para qué sirven los composables?
* Reutilización de lógica: Permiten encapsular y compartir lógica entre componentes sin duplicarla.

* Organización del código: Ayudan a separar la lógica de negocio o estado compartido en módulos independientes, mejorando la mantenibilidad.

* Mejorar la legibilidad: Reducen la complejidad de los componentes al mover lógica específica a funciones reutilizables.

* Composición: Facilitan la creación de funcionalidades complejas combinando múltiples composables pequeños.

## ¿Qué resuelven?
* El problema de la duplicación de lógica: En Vue 2, la lógica compartida solía depender de mixins, que tienen limitaciones como colisiones de nombres y dificultades de depuración. Los composables eliminan estas desventajas.

* Dificultad para organizar componentes grandes: En Vue 2, componentes con mucha lógica podían volverse difíciles de entender y mantener. Los composables permiten dividir esa lógica en funciones independientes.

* Reutilización ineficiente: Anteriormente, compartir estado entre componentes requería patrones complejos como Vuex. Con los composables, es posible manejar estados compartidos de manera más simple.

## ¿Cómo lo resuelven?
* Encapsulando lógica en funciones: Los composables encapsulan lógica en funciones que pueden ser importadas y utilizadas en múltiples componentes.

* Uso de la Composition API: Gracias a la Composition API, los composables permiten trabajar directamente con las herramientas reactivas (ref, reactive, etc.) y funciones del ciclo de vida (onMounted, onUnmounted, etc.).

* Independencia: Los composables son independientes del componente, lo que los hace más fáciles de testear y reutilizar.
