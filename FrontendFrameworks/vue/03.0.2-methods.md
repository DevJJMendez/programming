# `methods()`
En Vue.js, methods es una opción dentro de la Option API que permite definir funciones o métodos que se pueden invocar desde el template del componente o desde otras partes del mismo componente. Estos métodos no se memorizan (a diferencia de las propiedades computadas) y se ejecutan cada vez que se llaman.

## ¿Cuál es su estructura?
La opción methods es un objeto donde defines funciones como pares clave-valor. El nombre de la clave es el nombre del método y el valor es la función correspondiente.

```ts
methods: {
  nombreDelMetodo() {
    // lógica del método
  }
}
```

## ¿Para qué sirve?
* **Definir lógica específica**: Permite encapsular lógica que puede ser reutilizada en diferentes partes del componente.

* **Responder a eventos**: Se usa principalmente para manejar eventos del DOM, como clics o entradas de texto.

* **Manipular datos**: Modifica las propiedades del data del componente o realiza tareas relacionadas con ellas.

* **Realizar acciones complejas**: Se utiliza para ejecutar lógica que no encaja bien en propiedades computadas, como invocar APIs o manipular directamente el DOM.

## ¿Qué resuelve?
* **Centralización de lógica**: Permite agrupar funciones relacionadas con el comportamiento del componente en un solo lugar.

* **Manejo de eventos**: Resuelve la necesidad de responder dinámicamente a acciones del usuario (como clics, entradas, etc.).

* **Evitar lógica redundante en templates**: Simplifica los templates al encapsular lógica en métodos reutilizables.

* **Interacción directa con datos o estados**: Proporciona un lugar para implementar lógica que afecta los datos reactivos del componente.

## ¿Cómo lo resuelve?
* **Acceso a datos y propiedades del componente**: Los métodos tienen acceso directo a las propiedades del objeto data, props y otras opciones del componente mediante this.

* **Vinculación de eventos**: Se pueden asociar métodos a eventos del DOM en el template usando directivas como `v-on` o su alias `@`.

* **Flexibilidad y simplicidad**: No tienen limitaciones como las propiedades computadas; puedes incluir lógica compleja y realizar tareas como llamadas a APIs o cálculos no derivados.

## Ejemplo básico
```ts
<template>
  <div>
    <button @click="saludar">Saludar</button>
  </div>
</template>

<script>
export default {
  data() {
    return {
      nombre: "Juan",
    };
  },
  methods: {
    saludar() {
      alert(`Hola, ${this.nombre}!`);
    },
  },
};
</script>
```
En este ejemplo:
* El método saludar se ejecuta cuando el usuario hace clic en el botón.

* Usa `this.nombre` para acceder a los datos del componente.

## Ventajas de methods
* **Reutilización de lógica**: Permite definir lógica que puede llamarse desde múltiples lugares (template o dentro de otros métodos).

* **Acceso al estado reactivo**: Los métodos pueden leer y modificar las propiedades del componente sin restricciones.

* **Compatibilidad con eventos del DOM**: Perfecto para manejar interacciones del usuario.

* **Integración con el sistema reactivo de Vue**: Los cambios realizados en los datos dentro de un método actualizan automáticamente la interfaz.
