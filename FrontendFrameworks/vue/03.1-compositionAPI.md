# Composition API
La Composition API es una forma avanzada y flexible de definir la lógica de un componente en Vue 3. Introduce un enfoque basado en funciones, permitiendo organizar y reutilizar mejor la lógica en componentes complejos, en lugar de depender de las opciones predefinidas (como data(), methods(), computed()) de la Option API.

Es especialmente útil cuando necesitas crear componentes grandes y reutilizar la lógica entre ellos, y es completamente compatible con TypeScript.

## ¿Cuál es su estructura?
La Composition API utiliza funciones como `setup()` para definir la lógica del componente. Dentro de `setup()`, puedes declarar variables reactivas, usar funciones computadas, observar cambios, y acceder a propiedades y eventos del componente.

**Estructura básica:**
```ts
<script lang="ts">
import { defineComponent, ref, computed } from 'vue';

export default defineComponent({
  name: 'MiComponente',
  setup() {
    // Variables reactivas
    const contador = ref(0);

    // Propiedad computada
    const mensaje = computed(() => `El contador es: ${contador.value}`);

    // Métodos
    const incrementar = () => {
      contador.value++;
    };

    // Devuelve todo lo que quieres exponer en la plantilla
    return {
      contador,
      mensaje,
      incrementar,
    };
  },
});
</script>

<template>
  <div>
    <p>{{ mensaje }}</p>
    <button @click="incrementar">Incrementar</button>
  </div>
</template>
```

## ¿Para qué sirve?
* **Organización de la lógica del componente**: Permite agrupar lógicas relacionadas en lugar de dividirlas en secciones como data, methods, y computed.

* **Reutilización de código**: Facilita la creación de composables (funciones reutilizables) que encapsulan y comparten lógica entre componentes.

* **Compatibilidad con TypeScript**: Ofrece una mejor integración con TypeScript, haciendo más seguro y predecible el desarrollo.

* **Escalabilidad**: Maneja mejor componentes grandes y complejos, reduciendo la confusión al trabajar con muchas opciones.

## ¿Qué resuelve?
* **Fragmentación de la lógica**: En la Option API, la lógica relacionada podía estar dispersa entre varias secciones (data, methods, computed), dificultando su mantenimiento.

* **Reutilización limitada**: La lógica reutilizable en la Option API dependía de patrones como mixins o componentes base, que podían ser difíciles de manejar en proyectos grandes.

* **Falta de tipado robusto**: La Option API tenía un soporte limitado para TypeScript, lo que hacía que la inferencia de tipos fuera menos eficiente.

## ¿Cómo lo resuelve?
* **Centralización de la lógica**: La lógica relacionada se agrupa dentro de funciones o bloques en el método `setup()`, haciéndola más fácil de leer y entender.

* **Creación de composables reutilizables**: Las funciones reutilizables permiten encapsular la lógica y compartirla entre múltiples componentes.

* **Soporte completo para TypeScript**: Con **Composition API**, puedes usar tipos, interfaces y clases directamente, aprovechando al máximo el sistema de tipos de TypeScript.

## Pilares clave de la Composition API
1. **El método `setup()`**:
   * Es el punto de entrada para la lógica de la **Composition API**.

   * Se ejecuta antes del ciclo de vida del componente.

   * Recibe como argumentos el contexto del componente, que incluye propiedades como `props`, `attrs`, `slots` y `emit`.

```ts
setup(props, { emit }) {
  const mensaje = ref('Hola, mundo');
  const actualizarMensaje = () => emit('mensaje-actualizado', mensaje.value);

  return { mensaje, actualizarMensaje };
}
```

2. **Reactividad con `ref()` y `reactive()`**:
   * `ref()`: Crea una variable reactiva que contiene un valor primitivo o un objeto.

   * `reactive()`: Convierte un objeto en reactivo, ideal para estructuras complejas.

3. **Propiedades computadas con `computed()`**: Encapsulan la lógica derivada basada en variables reactivas.
```ts
const mensaje = computed(() => `El contador es: ${contador.value}`);
```

4. **Efectos secundarios con `watch()` y `watchEffect()`**:
   * `watch()`: Observa variables reactivas y ejecuta una función cuando cambian.

   * `watchEffect()`: Ejecuta una función automáticamente cada vez que una variable reactiva utilizada dentro de ella cambia.

5. **Composables reutilizables**:
   * Las composables son funciones que encapsulan lógica reutilizable.

   * Se utilizan para compartir lógica entre componentes de forma eficiente.
```ts
// useContador.ts
import { ref } from 'vue';

export function useContador() {
  const contador = ref(0);
  const incrementar = () => contador.value++;
  return { contador, incrementar };
}
```
**Uso**
```ts
import { useContador } from './useContador';

export default defineComponent({
  setup() {
    const { contador, incrementar } = useContador();
    return { contador, incrementar };
  },
});
```

## Ventajas de la Composition API
* **Flexibilidad**:
  * Permite una mejor separación de preocupaciones.

  * Fácil de usar con cualquier patrón de diseño.

* **Reutilización**: Facilita la creación de código más modular y reutilizable.

* **`TypeScript`**: Integra de manera nativa el tipado estático.

* **Escalabilidad**: Ideal para manejar aplicaciones grandes y complejas.
