# `watch()`
Es una herramienta que permite observar cambios en variables reactivas (tanto propiedades declaradas en `data()` como valores computados) y ejecutar una función en respuesta a dichos cambios. Es un sistema de observación explícita de cambios en comparación con las propiedades computadas, que son más adecuadas para cálculos derivados.

## ¿Cuál es su estructura?
El método `watch()` se define en la opción `watch` dentro de un componente en la Option API. Cada propiedad dentro del objeto `watch` especifica:

* La propiedad o variable a observar.

* Una función que se ejecutará cuando el valor de la propiedad cambie.

```ts
watch: {
  propiedad(observada, valorAnterior) {
    // Lógica que se ejecuta cuando "propiedad" cambia
    console.log("Valor actual:", observada);
    console.log("Valor anterior:", valorAnterior);
  },
}
```

## ¿Para qué sirve?
El método `watch()` se utiliza para realizar tareas en respuesta a cambios en una o más propiedades reactivas. Es útil para situaciones en las que necesitas observar un cambio y ejecutar una acción específica, como:

* Llamar a una API cuando un valor cambia.

* Sincronizar datos entre componentes o con un backend.

* Aplicar lógica que no puede calcularse directamente con propiedades computadas.

## ¿Qué resuelve?
* **Reaccionar a cambios específicos**: Permite ejecutar acciones personalizadas en función de los cambios de datos.

* **Seguimiento de cambios no triviales**: Es ideal para observar cambios profundos en objetos anidados o arrays.

* **Diferenciar entre valores nuevos y antiguos**: Ofrece acceso tanto al valor actual como al valor previo de la propiedad.

## ¿Cómo lo resuelve?
* **Detecta automáticamente cambios reactivos**: Utiliza el sistema de reactividad de Vue para monitorear propiedades.

* **Ejecuta una función de `callback`**: Llama a una función definida cada vez que el valor observado cambia.

* **Permite la configuración de opciones avanzadas**: Ofrece opciones como observación profunda (**`deep`**) para detectar cambios en propiedades anidadas y `arrays`.

## Ejemplo básico:
```ts
export default {
  data() {
    return {
      contador: 0,
    };
  },
  watch: {
    contador(nuevoValor, valorAnterior) {
      console.log(`El contador cambió de ${valorAnterior} a ${nuevoValor}`);
    },
  },
};
```
**Explicación:**
* Se observa la propiedad contador.

* Cuando contador cambia, la función de callback imprime el valor anterior y el nuevo valor.

### Ejemplo con múltiples propiedades:
```ts
export default {
  data() {
    return {
      nombre: "",
      edad: 0,
    };
  },
  watch: {
    nombre(nuevoValor) {
      console.log(`El nombre cambió a: ${nuevoValor}`);
    },
    edad(nuevaEdad) {
      if (nuevaEdad > 18) {
        console.log("Eres mayor de edad");
      }
    },
  },
};
```

## Ejemplo con observación profunda (`deep`):
```ts
export default {
  data() {
    return {
      usuario: {
        nombre: "Juan",
        detalles: {
          edad: 25,
        },
      },
    };
  },
  watch: {
    usuario: {
      handler(nuevoValor) {
        console.log("El objeto usuario cambió:", nuevoValor);
      },
      deep: true, // Activa la observación de cambios profundos
    },
  },
};
```
**Explicación:**
* La opción deep permite detectar cambios en propiedades anidadas, como `usuario.detalles.edad`.

* Sin `deep`, los cambios dentro de un objeto no desencadenan la función de callback.

## Ejemplo con arrays:
```ts
export default {
  data() {
    return {
      lista: [1, 2, 3],
    };
  },
  watch: {
    lista: {
      handler(nuevaLista) {
        console.log("La lista cambió:", nuevaLista);
      },
      deep: true, // Necesario para observar cambios dentro del array
    },
  },
};
```
**Nota:** Cambios como agregar, eliminar o modificar elementos en un array también requieren la opción `deep` para ser detectados.

## Opciones avanzadas en `watch`:
1. **`Deep` (profundo)**: Se usa para observar cambios en objetos anidados o arrays.
```ts
watch: {
  miObjeto: {
    handler(nuevoValor) {
      console.log("Objeto actualizado:", nuevoValor);
    },
    deep: true,
  },
},
```

2. **`Immediate` (inmediato)**: Ejecuta la función de callback inmediatamente al inicializar el componente.
```ts
watch: {
  propiedad: {
    handler(nuevoValor) {
      console.log("Cambio detectado:", nuevoValor);
    },
    immediate: true, // Se ejecuta al montar el componente
  },
},
```

## ¿Cuándo usar watch() en lugar de propiedades computadas?
* **Usa `computed` cuando**:
  * Necesitas derivar un nuevo valor a partir de propiedades reactivas.

  * Quieres que Vue haga automáticamente el seguimiento y la actualización.

* **Usa `watch()` cuando**:
  * Necesitas ejecutar lógica o realizar efectos secundarios en respuesta a un cambio (por ejemplo, llamar a una API o modificar valores externos).

  * Necesitas observar un cambio en propiedades anidadas u objetos reactivos complejos.

## Buenas prácticas:
* **Mantén tus `watch` claros y simples**: Evita incluir demasiada lógica dentro del `callback`. Si es necesario, delega la lógica a métodos.

* **Usa propiedades computadas en lugar de `watch` si es posible**: Si solo necesitas transformar datos, computed es más eficiente y fácil de mantener.

* **Combina `deep` e `immediate` con cuidado**: Estas opciones son útiles, pero pueden generar sobrecarga si se observan objetos grandes o anidados.

* **Evita observar demasiadas propiedades**: Observa solo las propiedades esenciales para evitar sobrecargar la reactividad del componente.

# `watchEffect()`
watchEffect() es un método proporcionado por la Composition API de Vue 3. Es una función reactiva que ejecuta automáticamente un efecto o callback cada vez que cualquier variable reactiva dentro de su alcance cambia.

A diferencia de watch(), no necesita que especifiques de manera explícita las dependencias, ya que Vue las rastrea automáticamente.

¿Para qué sirve?
Reaccionar automáticamente a cambios en datos reactivos:

Ideal para ejecutar código cuando cambian los valores de variables o propiedades reactivas.
Efectos secundarios reactivos:

Permite ejecutar lógica como actualizaciones del DOM, registros en la consola, o llamadas a APIs siempre que cambie una variable.
Depuración:

Muy útil para observar el comportamiento y los cambios de las propiedades reactivas mientras desarrollas.
¿Qué resuelve?
Simplificación de efectos reactivos:

No tienes que definir explícitamente qué propiedades observar, ya que Vue detecta automáticamente las dependencias dentro del callback.
Reactividad implícita:

Hace que el código sea más limpio y fácil de mantener al eliminar la necesidad de declarar dependencias manualmente.
Control automático de dependencias:

Resuelve el problema de rastrear manualmente qué variables afectan un efecto específico.

## ¿Cómo lo resuelve?
Rastreo automático de dependencias:

Vue detecta automáticamente qué variables reactivas son usadas dentro del efecto y las asocia al watchEffect().
Reactividad eficiente:

Cada vez que una dependencia cambia, Vue vuelve a ejecutar el efecto de forma optimizada.
Manejo automático de suscripciones:

Vue limpia las suscripciones anteriores antes de ejecutar el efecto nuevamente, evitando problemas de memoria.

## Estructura básica de watchEffect()
```ts
import { reactive, watchEffect } from 'vue';

const state = reactive({
  contador: 0,
});

watchEffect(() => {
  console.log(`El contador es: ${state.contador}`);
});
```

## ¿Cómo se usa watchEffect()?
1. Uso básico
```ts
<script setup lang="ts">
import { reactive, watchEffect } from 'vue';

const state = reactive({
  contador: 0,
});

watchEffect(() => {
  console.log(`El contador cambió a: ${state.contador}`);
});

const incrementar = () => {
  state.contador++;
};
</script>

<template>
  <div>
    <p>Contador: {{ state.contador }}</p>
    <button @click="incrementar">Incrementar</button>
  </div>
</template>
```
Cada vez que state.contador cambia, watchEffect() se ejecuta automáticamente y registra el nuevo valor en la consola.

2. Usando efectos secundarios
```ts
<script setup lang="ts">
import { reactive, watchEffect } from 'vue';

const state = reactive({
  mensaje: 'Hola, Vue 3',
});

watchEffect(() => {
  document.title = state.mensaje;
});

const cambiarTitulo = () => {
  state.mensaje = 'Nuevo título';
};
</script>

<template>
  <div>
    <button @click="cambiarTitulo">Cambiar Título</button>
  </div>
</template>
```
En este ejemplo, el título del documento se actualiza automáticamente cada vez que cambia state.mensaje.

3. Uso con arrays y propiedades anidadas
```ts
<script setup lang="ts">
import { reactive, watchEffect } from 'vue';

const lista = reactive({
  frutas: ['manzana', 'pera', 'plátano'],
});

watchEffect(() => {
  console.log(`Frutas: ${lista.frutas.join(', ')}`);
});

const agregarFruta = () => {
  lista.frutas.push('fresa');
};
</script>

<template>
  <div>
    <button @click="agregarFruta">Agregar Fruta</button>
  </div>
</template>
```
Cada vez que se modifica el array, watchEffect() detecta el cambio y actualiza automáticamente el efecto.

## Cuándo usar watchEffect()
Dependencias simples:

Cuando quieres rastrear automáticamente cualquier variable reactiva dentro de un bloque de código.
Efectos secundarios directos:

Para actualizaciones como cambiar el título del documento o realizar registros en consola.
Evitar código redundante:

Si no quieres especificar manualmente las propiedades que deben ser observadas.

## Ventajas de watchEffect()
Simplicidad:

No requiere declarar explícitamente las dependencias, haciendo que el código sea más conciso.
Automatización:

Detecta automáticamente todas las variables reactivas usadas dentro del efecto.
Sincronización automática:

Vue maneja eficientemente la limpieza de efectos previos antes de ejecutarlos nuevamente.
Versatilidad:

Funciona tanto con primitivas como con objetos y arrays reactivos.
Desventajas de watchEffect()
Menor control:

No es ideal para lógica compleja donde necesitas especificar qué propiedad observar.
Dependencias implícitas:

Puede ser difícil depurar si no sabes exactamente qué variables están causando la ejecución del efecto.

## Ejemplo avanzado: Integración con API
```ts
<script setup lang="ts">
import { reactive, watchEffect } from 'vue';

const state = reactive({
  busqueda: '',
  resultados: [],
});

watchEffect(async () => {
  if (state.busqueda) {
    const respuesta = await fetch(`https://api.example.com?q=${state.busqueda}`);
    state.resultados = await respuesta.json();
  }
});
</script>

<template>
  <div>
    <input v-model="state.busqueda" placeholder="Buscar..." />
    <ul>
      <li v-for="resultado in state.resultados" :key="resultado.id">
        {{ resultado.nombre }}
      </li>
    </ul>
  </div>
</template>
```
Cada vez que el usuario escribe en el campo de búsqueda, watchEffect() ejecuta la lógica para realizar una llamada a la API.
