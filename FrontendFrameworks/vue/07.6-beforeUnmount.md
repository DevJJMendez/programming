# `beforeUnmount`
El hook beforeUnmount es parte del ciclo de vida de un componente en Vue.js 3 y se ejecuta justo antes de que un componente sea destruido.
En este punto, el componente sigue siendo completamente funcional, lo que permite realizar tareas como limpiar recursos, eliminar eventos o detener procesos.

2. ¿Cuál es su estructura?
El hook beforeUnmount se define dentro de la sección de script del componente.

Estructura básica:
```ts
export default {
  beforeUnmount() {
    console.log('El componente está a punto de desmontarse.');
  }
};
```

Ejemplo en un componente completo:
```ts
<template>
  <div>
    <p>Componente activo</p>
  </div>
</template>

<script>
export default {
  beforeUnmount() {
    console.log('El componente está a punto de ser desmontado.');
  }
};
</script>
```
En este caso, el mensaje en la consola aparecerá justo antes de que el componente se elimine del DOM.

## ¿Para qué sirve el hook beforeUnmount?
El hook beforeUnmount se utiliza para:

Limpiar recursos externos:

Detener procesos en curso como setInterval, setTimeout, o peticiones HTTP.
Eliminar escuchas de eventos:

Desvincular eventos globales como window.addEventListener o eventos personalizados.
Detener servicios o instancias:

Destruir instancias de librerías o servicios utilizados por el componente.
Registrar actividad:

Registrar que el componente será desmontado, útil en aplicaciones con analíticas.
4. ¿Qué resuelve el hook beforeUnmount?
El hook beforeUnmount resuelve:

Fugas de memoria:

Al detener procesos o liberar recursos no necesarios después de que un componente se elimina, se evita que elementos persistentes consuman memoria innecesariamente.
Conflictos de estado:

Si un componente sigue registrando eventos o realizando procesos después de su desmontaje, esto puede causar errores o comportamientos inesperados.
Manejo correcto de integraciones:

Si un componente usa librerías externas, beforeUnmount permite cerrarlas o limpiarlas correctamente antes de que desaparezcan del DOM.
5. ¿Cómo lo resuelve?
beforeUnmount proporciona un punto seguro para realizar tareas justo antes de que Vue elimine el componente del DOM.
El componente sigue funcional, por lo que puedes acceder a datos, métodos o incluso interactuar con el DOM en ese momento.

6. Ejemplo práctico del hook beforeUnmount
Ejemplo 1: Limpiar un intervalo
```ts
<template>
  <div>
    <p>Tiempo: {{ tiempo }}</p>
  </div>
</template>

<script>
export default {
  data() {
    return {
      tiempo: 0,
      intervalo: null
    };
  },
  mounted() {
    this.intervalo = setInterval(() => {
      this.tiempo++;
    }, 1000);
  },
  beforeUnmount() {
    console.log('Limpiando intervalo...');
    clearInterval(this.intervalo);
  }
};
</script>
```
Explicación:

En mounted, se inicia un intervalo que actualiza la variable tiempo.
En beforeUnmount, el intervalo se detiene con clearInterval para evitar que siga ejecutándose una vez que el componente sea desmontado.

## Ejemplo 2: Eliminar un evento global
```ts
<template>
  <div>
    <p>Presiona cualquier tecla para ver el evento en la consola.</p>
  </div>
</template>

<script>
export default {
  methods: {
    manejarTecla(event) {
      console.log('Tecla presionada:', event.key);
    }
  },
  mounted() {
    window.addEventListener('keydown', this.manejarTecla);
  },
  beforeUnmount() {
    console.log('Eliminando evento global...');
    window.removeEventListener('keydown', this.manejarTecla);
  }
};
</script>
```
Explicación:
En mounted, se añade un evento global al objeto window para detectar teclas presionadas.
En beforeUnmount, se elimina ese evento para evitar fugas de memoria.

Ejemplo 3: Detener una instancia de librería externa
Imagina que usas una librería de animaciones como GSAP:
```ts
<template>
  <div ref="caja" class="caja">Animación</div>
</template>

<script>
import { gsap } from "gsap";

export default {
  mounted() {
    this.animacion = gsap.to(this.$refs.caja, { x: 200, repeat: -1, yoyo: true });
  },
  beforeUnmount() {
    console.log('Deteniendo animación...');
    this.animacion.kill(); // Detiene la animación
  }
};
</script>

<style>
.caja {
  width: 100px;
  height: 100px;
  background: red;
}
</style>
```
Explicación:

Se crea una animación en mounted.
En beforeUnmount, la animación se detiene con el método kill() para liberar recursos.

## Buenas prácticas
Siempre libera recursos:

Limpia cualquier recurso externo como intervalos, eventos o instancias de librerías.
Evita cambiar datos reactivos:

Modificar datos en este hook puede no ser necesario, ya que el componente está a punto de desmontarse.
Usa eventos específicos del componente:

Evita agregar demasiados eventos globales, pero si los usas, asegúrate de limpiarlos aquí.
No confíes en que siempre se ejecutará:

En casos extremos, como un error crítico o un cierre abrupto del navegador, este hook puede no ejecutarse. Usa un enfoque robusto para liberar recursos críticos.
