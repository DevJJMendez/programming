# `snapshot`
Un `snapshot` es una instantánea estática del estado actual de una ruta en un momento específico. Es una forma de acceder a información sobre la ruta activa, como parámetros, datos, fragmentos, y más, sin la necesidad de suscribirse a observables.

En Angular, puedes obtener un snapshot utilizando la propiedad `snapshot` de la clase `ActivatedRoute`.

## ¿Para qué sirve?
El snapshot se utiliza principalmente para acceder a:

* Parámetros de ruta (`paramMap` y `params`).

* Parámetros de consulta (`queryParamMap` y `queryParams`).

* Fragmentos de URL (`fragment`).

* Datos asociados a la ruta (`data`).

### Ventajas del Snapshot
Es útil cuando los parámetros de ruta no cambian mientras el componente está activo.
Simplifica el código al evitar la necesidad de manejar observables cuando los datos son estáticos.

## ¿Qué resuelve?
El snapshot resuelve la necesidad de obtener datos de la ruta activa de manera rápida y sincrónica en casos donde:

* No se esperan cambios dinámicos en los parámetros de la ruta mientras el componente está cargado.

* Se desea evitar suscribirse a observables cuando no es necesario.

### Ejemplo de uso típico:
Si necesitas acceder a un parámetro como :id en una ruta y sabes que no cambiará mientras el usuario permanece en el componente, puedes usar el snapshot para simplificar el acceso.

## ¿Cómo lo resuelve?
El snapshot resuelve el problema de acceso sincrónico a los datos de la ruta proporcionando una representación estática del estado actual de la ruta activa a través de la propiedad `ActivatedRoute`.snapshot.

Al hacerlo, evita la necesidad de gestionar observables para datos estáticos o no dinámicos.

## Uso del snapshot en un componente
### Ejemplo básico: acceso a parámetros estáticos
En una configuración de rutas como:
```ts
const routes: Routes = [
  { 
    path: 'products/:id', 
    component: ProductDetailComponent, 
    data: { title: 'Product Details' }
  }
];
```
El componente puede acceder a los datos así:
```ts
import { Component, OnInit } from '@angular/core';
import { ActivatedRoute } from '@angular/router';

@Component({
  selector: 'app-product-detail',
  template: `
    <h1>{{ title }}</h1>
    <p>Product ID: {{ productId }}</p>
  `
})
export class ProductDetailComponent implements OnInit {
  productId: string | null = null;
  title: string | null = null;

  constructor(private route: ActivatedRoute) {}

  ngOnInit(): void {
    // Acceder a parámetros de ruta
    this.productId = this.route.snapshot.paramMap.get('id');

    // Acceder a datos estáticos de la ruta
    this.title = this.route.snapshot.data['title'];
  }
}
```

## Casos donde el snapshot no es suficiente
Aunque el snapshot es conveniente, tiene limitaciones:

1. **No detecta cambios dinámicos**: Si la ruta cambia mientras el componente está activo, el snapshot no se actualiza automáticamente. Ejemplo:

   * Cambio de URL de `/products/1` a `/products/2`.

   * El snapshot seguirá mostrando el **ID 1**.

2. **No sirve para rutas dinámicas**: En estos casos, deberías usar los observables proporcionados por **`ActivatedRoute`**, como `paramMap` o `params`.
