# `ngSubmit`
ngSubmit es una directiva en Angular asociada a formularios que permite capturar el evento de envío de un formulario. Se utiliza para ejecutar una función definida en el componente cuando el usuario intenta enviar un formulario, ya sea presionando el botón de tipo submit o cualquier otro medio que dispare el evento submit.

## ¿Para qué sirve ngSubmit?
Funciones principales:

* Gestionar el envío de datos del formulario: Permite definir qué acción debe realizarse al enviar el formulario, como validar los datos, procesar información o enviar una solicitud al servidor.

* Intervenir en el comportamiento del formulario: Previene el comportamiento por defecto de los formularios HTML (**`action`**) y proporciona control total sobre la lógica de envío.

* Sincronizar el modelo del formulario con la lógica del componente: Garantiza que los datos del formulario estén completamente actualizados antes de procesarlos.

## ¿Qué resuelve ngSubmit?
Problemas comunes:

* Dependencia de eventos nativos: Sin ngSubmit, tendrías que usar directamente el evento submit del DOM, lo que implica más código y reduce la integración con el sistema de formularios de Angular.

* Validaciones personalizadas: ngSubmit te permite centralizar las validaciones y la lógica de envío en una sola función, mejorando la mantenibilidad.

* Interoperabilidad con Angular Forms: Se integra perfectamente con Template-Driven Forms y Reactive Forms, respetando los estados y validaciones del formulario.

## ¿Cómo lo resuelve ngSubmit?
Mecanismo de solución:

* Intercepción del evento submit: ngSubmit actúa como un manejador de eventos que captura el envío del formulario antes de que el navegador ejecute su comportamiento predeterminado.

* Integración con el estado del formulario: Proporciona acceso al estado del formulario (como valid, pristine, etc.) para decidir si proceder con el envío o no.

* Ejecución de lógica personalizada: Dispara la función definida en el componente para manejar el envío del formulario según la lógica de negocio.

## Uso básico
```html
<form #userForm="ngForm" (ngSubmit)="onSubmit(userForm)">
  <label for="name">Nombre:</label>
  <input id="name" name="name" ngModel required />
  
  <label for="email">Correo:</label>
  <input id="email" name="email" ngModel required email />

  <button type="submit" [disabled]="userForm.invalid">Enviar</button>
</form>
```
```ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
})
export class AppComponent {
  onSubmit(form: any) {
    console.log('Datos del formulario:', form.value);
  }
}
```
Explicación:
  * `(ngSubmit)` enlaza el evento de envío del formulario con el método onSubmit.

  * Se pasa como argumento la referencia local del formulario (userForm) para acceder a sus valores y estado.

## Uso con Reactive Forms
```html
<form [formGroup]="userForm" (ngSubmit)="onSubmit()">
  <label for="name">Nombre:</label>
  <input id="name" formControlName="name" required />
  
  <label for="email">Correo:</label>
  <input id="email" formControlName="email" required />

  <button type="submit" [disabled]="userForm.invalid">Enviar</button>
</form>
```
```ts
import { Component } from '@angular/core';
import { FormBuilder, FormGroup, Validators } from '@angular/forms';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
})
export class AppComponent {
  userForm: FormGroup;

  constructor(private fb: FormBuilder) {
    this.userForm = this.fb.group({
      name: ['', Validators.required],
      email: ['', [Validators.required, Validators.email]],
    });
  }

  onSubmit() {
    if (this.userForm.valid) {
      console.log('Datos enviados:', this.userForm.value);
    } else {
      console.log('Formulario no válido');
    }
  }
}
```
Explicación:
  * `(ngSubmit)` se utiliza para disparar el método `onSubmit`.

  * El estado del formulario (`userForm`) se consulta desde el componente.

## Integración con validaciones
Puedes combinar ngSubmit con validaciones personalizadas para manejar errores antes de procesar el envío.

```html
<form #form="ngForm" (ngSubmit)="onSubmit(form)">
  <input name="username" ngModel required #username="ngModel" />
  <div *ngIf="username.invalid && username.touched">
    El nombre de usuario es obligatorio.
  </div>

  <button type="submit" [disabled]="form.invalid">Enviar</button>
</form>
```
