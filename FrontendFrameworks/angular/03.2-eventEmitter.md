# Event Emitter
Es una clase de Angular (disponible en el módulo **`@angular/core`**) que se utiliza para crear y manejar eventos personalizados en un componente. Está diseñado para ser usado en combinación con el decorador `@Output` y permite que un componente hijo emita eventos que otros componentes, como el padre, puedan escuchar y reaccionar.

**En términos simples**:
* Es un mecanismo para emitir eventos en Angular.

* Los eventos pueden incluir datos asociados que son necesarios para que el componente receptor tome decisiones.

## ¿Para qué sirve?
El EventEmitter permite que los componentes de Angular se comuniquen entre sí a través de eventos. Específicamente:

* **Comunicación Hijo -> Padre**: Permite que un componente hijo notifique al componente padre sobre acciones, cambios de estado o cualquier otro evento importante.

* **Desacoplamiento**: Los componentes hijos no necesitan conocer detalles del componente padre, lo que mejora la modularidad y reutilización de los componentes.

* **Transporte de Datos**: El EventEmitter puede enviar datos adjuntos al evento para que el componente receptor los procese.

## ¿Qué resuelve?
EventEmitter resuelve el problema de la comunicación unidireccional del hijo hacia el padre en Angular. Dado que los componentes en Angular están diseñados para ser altamente encapsulados y desacoplados, no es posible que un componente hijo interactúe directamente con las propiedades o métodos del componente padre.

**Problemas resueltos**:
1. **Notificación de eventos desde un hijo a un padre**: Por ejemplo, cuando un usuario hace clic en un botón o selecciona una opción en un componente hijo, el padre puede ser notificado de estas interacciones.

2. **Transferencia de datos en tiempo real**: Permite que un componente hijo envíe datos al padre sin necesidad de un enlace mutuo (binding bidireccional).

3. **Mejora de la reutilización**: Los componentes hijos pueden emitir eventos que el padre puede manejar de diferentes formas según su lógica.

## ¿Cómo lo resuelve?
* **Declarando un `@Output`**: El EventEmitter se declara como una propiedad en el componente hijo y se decora con `@Output`.

* **Emitiendo eventos**: Cuando ocurre una acción específica, el componente hijo utiliza el método `.emit()` del EventEmitter para disparar el evento.

* **Capturando eventos**: El componente padre escucha el evento utilizando la sintaxis de binding de eventos en el template, y maneja el evento con un método correspondiente.

## Cómo usar EventEmitter
1. **Importar y declarar un `EventEmitter`**: El EventEmitter se importa desde el módulo `@angular/core` y se declara como una propiedad decorada con `@Output`.

```ts
import { Component, Output, EventEmitter } from '@angular/core';

@Component({
  selector: 'app-hijo',
  template: `<button (click)="enviarEvento()">Emitir Evento</button>`
})
export class HijoComponent {
  @Output() eventoHijo: EventEmitter<string> = new EventEmitter<string>();

  enviarEvento() {
    this.eventoHijo.emit('¡Mensaje enviado desde el hijo!');
  }
}
```
**En este ejemplo**:
   * `eventoHijo` es una propiedad EventEmitter que emitirá un evento.

   * El método `emit()` envía un evento con un mensaje como dato.

2. **Escuchar el evento en el componente padre**: En el componente padre, usamos la sintaxis de binding de eventos para capturar el evento emitido por el hijo.

```ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-padre',
  template: `
    <app-hijo (eventoHijo)="manejarEvento($event)"></app-hijo>
    <p>{{ mensaje }}</p>
  `
})
export class PadreComponent {
  mensaje: string = '';

  manejarEvento(dato: string) {
    this.mensaje = dato;  // Actualizar mensaje con el dato recibido
  }
}
```
**Aquí**:
   * `(eventoHijo)` escucha el evento emitido desde el hijo.

   * `$event` representa el dato emitido.

   * El método `manejarEvento` procesa el evento y actualiza la propiedad `mensaje`.

## Características clave de EventEmitter
1. **Emitir eventos personalizados**: Puedes emitir cualquier tipo de dato: `string`, `number`, `objects`, `arrays`, etc.

```ts
this.eventoHijo.emit({ id: 1, nombre: 'Angular' });
```

2. **Tipado seguro**: Puedes especificar el tipo de datos que emitirá el evento.

```ts
@Output() eventoHijo: EventEmitter<number> = new EventEmitter<number>();
```

3. **Eventos reactivos**: Se puede utilizar con Observables o técnicas reactivas gracias al diseño basado en **RxJS**.

## Buenas prácticas con EventEmitter
* **Evitar abuso**: Usa EventEmitter solo cuando sea necesario. Si los datos no necesitan viajar al componente padre, considera alternativas.

* **Tipado seguro**: Especifica el tipo de dato que el EventEmitter emitirá para mayor claridad y menos errores.

* **Nombres descriptivos**: Los nombres de las propiedades @Output deben ser intuitivos para reflejar el propósito del evento.

* **Desacoplamiento**: Asegúrate de que el componente hijo no dependa de la implementación del padre, sino que emita eventos genéricos que puedan ser utilizados de diferentes maneras.
