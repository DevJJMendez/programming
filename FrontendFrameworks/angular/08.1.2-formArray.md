# FormArray
FormArray es una clase de Angular que permite gestionar una colección de controles de formulario en un array dinámico. Cada elemento de un FormArray puede ser un FormControl, un FormGroup, o incluso otro FormArray.

Se utiliza para manejar formularios dinámicos en los que el número de controles no es fijo y puede cambiar en tiempo de ejecución, como listas de entradas de usuario.

## ¿Para qué sirve FormArray?
* Crear formularios dinámicos: Permite agregar, eliminar o modificar controles de manera programática.

* Gestionar colecciones de datos: Útil cuando se necesita capturar un número variable de entradas, como una lista de correos electrónicos, direcciones o productos.

* Controlar el estado de múltiples elementos: Ofrece una forma estructurada de manejar los valores y estados de un grupo de controles relacionados.

## ¿Qué resuelve FormArray?
* Entradas dinámicas: Situaciones donde el número de campos no es conocido previamente y puede cambiar durante la interacción del usuario.

* Gestión centralizada: Proporciona un enfoque centralizado para manejar múltiples controles relacionados, en lugar de tener que gestionarlos individualmente.

* Validaciones de grupo: Permite definir validaciones tanto a nivel de cada control como a nivel del array completo.

* Manipulación programática: Facilita la manipulación de controles (agregar, eliminar, resetear) en tiempo de ejecución.

## ¿Cómo lo resuelve FormArray?
FormArray ofrece una estructura ordenada para trabajar con un grupo de controles mediante:

* APIs para manipulación: Métodos como push, removeAt y clear permiten gestionar dinámicamente los elementos del array.

* Observabilidad: Se sincroniza automáticamente con la interfaz, reflejando cambios en tiempo real.

* Validaciones flexibles: Acepta validaciones individuales para cada elemento o para el array completo.

* Compatibilidad con iteraciones: Facilita el renderizado dinámico en la plantilla mediante directivas como *ngFor.

## Componentes clave de FormArray
### Propiedades:
* **`controls`**: Array de controles hijos.

* **`value`**: Un array con los valores actuales de los controles.

* **`valid`**: Indica si todos los controles cumplen con las validaciones.

* **`length`**: Número de controles en el array.

### Métodos importantes:
* **`push(control: AbstractControl)`**: Agrega un nuevo control al array.

* **`removeAt(index: number)`**: Elimina un control en el índice especificado.

* **`clear()`**: Elimina todos los controles del array.

* **`at(index: number)`**: Obtiene el control en el índice especificado.

## Ejemplo básico de FormArray
```ts
import { Component } from '@angular/core';
import { FormArray, FormControl, FormGroup, Validators } from '@angular/forms';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
})
export class AppComponent {
  form: FormGroup;

  constructor() {
    this.form = new FormGroup({
      emails: new FormArray([]),
    });
  }

  get emails() {
    return this.form.get('emails') as FormArray;
  }

  addEmail() {
    const emailControl = new FormControl('', [Validators.required, Validators.email]);
    this.emails.push(emailControl);
  }

  removeEmail(index: number) {
    this.emails.removeAt(index);
  }

  onSubmit() {
    console.log(this.form.value);
  }
}
```
```html
<form [formGroup]="form" (ngSubmit)="onSubmit()">
  <div formArrayName="emails">
    <div *ngFor="let email of emails.controls; let i = index">
      <input [formControlName]="i" placeholder="Email {{ i + 1 }}" />
      <button type="button" (click)="removeEmail(i)">Eliminar</button>
    </div>
  </div>
  <button type="button" (click)="addEmail()">Agregar Email</button>
  <button type="submit" [disabled]="form.invalid">Enviar</button>
</form>
```

## Validaciones en FormArray
Las validaciones se pueden aplicar a nivel de cada control o al array completo.

* Validación a nivel de controles:
```ts
this.emails.push(new FormControl('', [Validators.required, Validators.email]));
```

* Validación a nivel de array:
```ts
this.form = new FormGroup({
  emails: new FormArray([], [Validators.minLength(2)]), // Al menos 2 correos
});
```

## Escuchando cambios en FormArray
Puedes suscribirte a los eventos de cambio de valor o estado.
```ts
this.emails.valueChanges.subscribe((newValues) => {
  console.log('Nuevos valores:', newValues);
});

this.emails.statusChanges.subscribe((newStatus) => {
  console.log('Nuevo estado:', newStatus);
});
```

## Anidación de FormArrays
Los FormArrays pueden contener otros FormArrays o FormGroups, creando estructuras complejas.
```ts
this.form = new FormGroup({
  users: new FormArray([
    new FormGroup({
      name: new FormControl(''),
      phones: new FormArray([
        new FormControl('123456789'),
      ]),
    }),
  ]),
});
```

## Ventajas de FormArray
* Dinámico: Permite agregar y quitar controles en tiempo de ejecución.

* Flexible: Compatible con validaciones, anidación y estructuras complejas.

* Reactividad: Se actualiza automáticamente en la interfaz.

* Control centralizado: Proporciona una API para manipular y validar toda la colección.
