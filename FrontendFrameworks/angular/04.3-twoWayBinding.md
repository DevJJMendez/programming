# Two-Way Binding
Es una técnica que permite sincronizar los datos entre el modelo (en el componente TypeScript) y la vista (HTML) de manera **bidireccional**. Esto significa que cualquier cambio en el modelo actualiza automáticamente la vista, y cualquier cambio en la vista actualiza automáticamente el modelo.

Angular facilita esta sincronización utilizando la directiva especial `ngModel`.

## ¿Para qué sirve?
El Two-Way Binding es útil en situaciones donde necesitas:

* Sincronizar campos de entrada de datos con el modelo subyacente, como formularios o inputs.

* Mantener la consistencia entre el estado de la interfaz de usuario y la lógica de la aplicación.

* Reducir el código necesario para manejar cambios manualmente en ambos sentidos (modelo <-> vista).

## ¿Qué problemas resuelve?
1. Reducción de código boilerplate: Sin Two-Way Binding, necesitarías escribir lógica explícita para:

   * Escuchar los eventos en la vista.

   * Actualizar el modelo con los cambios de la vista.

   * Actualizar la vista cuando el modelo cambia.

2. Sincronización automática: Simplifica la tarea de mantener sincronizados el modelo y la vista, evitando inconsistencias.

3. Facilita formularios interactivos: En aplicaciones con muchos formularios o entradas de datos, el Two-Way Binding minimiza errores y simplifica la implementación.

## ¿Cómo lo resuelve?
Angular resuelve el Two-Way Binding utilizando:

1. **Combination de Property Binding `[ ]` y Event Binding `( )`**: Angular combina ambas técnicas mediante la sintaxis especial `[( )]`, conocida como **banana in a box**.

2. **La directiva `ngModel`**: La directiva de Angular ngModel maneja automáticamente la sincronización entre el modelo y la vista.

3. **Detección de cambios de Angular**: El mecanismo de **Change Detection** de Angular monitorea los cambios en el modelo o la vista y aplica las actualizaciones necesarias.

## Sintaxis de Two-Way Binding
* **Estructura básica**:
```html
<input [(ngModel)]="propiedadDelComponente">
```
  * `[( )]`: Representa una combinación de **Property Binding** y **Event Binding**.
    * `[ ]`: Actualiza el valor del DOM cuando cambia el modelo.

    * `( )`: Escucha eventos del DOM (como `input`) para actualizar el modelo.
