# `ngModel`
ngModel es una directiva proporcionada por Angular que permite implementar el enlace de datos bidireccional **(two-way data binding)** entre el modelo (datos en el componente TypeScript) y la vista (los valores mostrados en el DOM o formulario). Es una de las características clave en **Template-Driven Forms**.

## ¿Para qué sirve ngModel?
* Vincular datos bidireccionalmente: Los cambios realizados en el modelo (en TypeScript) se reflejan automáticamente en la vista (HTML), y viceversa.

* Simplificar la manipulación de formularios: Los valores de los controles de formularios (como input, select, textarea) se pueden sincronizar con las propiedades del modelo del componente sin necesidad de lógica adicional.

* Facilitar validaciones: Angular puede rastrear el estado del control (como **`touched`**, **`dirty`**, **`valid`**, etc.) y validar entradas automáticamente.

## ¿Qué resuelve ngModel?
Problemas resueltos:

* Sincronización manual de datos: Antes de ngModel, era necesario implementar lógica explícita para sincronizar los datos entre el modelo y la vista.

* Gestión del estado de los controles del formulario: ngModel permite obtener fácilmente estados como **`valid`**, **`invalid`**, **`pristine`**, **`dirty`**, etc., sin escribir lógica adicional.

* Reducción de código repetitivo: Evita escribir múltiples manejadores de eventos para actualizar el modelo o la vista.

## ¿Cómo lo resuelve ngModel?
ngModel utiliza el sistema de enlace de datos bidireccional de Angular:

* Enlace hacia la vista: Los datos del modelo se pasan al DOM, actualizando el control asociado.

* Enlace hacia el modelo: Los cambios realizados en el control del formulario actualizan automáticamente la propiedad del modelo en TypeScript.

* Directivas adicionales: ngModel genera automáticamente validaciones y estados, facilitando el manejo del formulario.

Angular detecta cambios usando su mecanismo de detección de cambios, actualizando los datos sincronizados sin intervención manual.

## Uso básico
```html
<input [(ngModel)]="userName" placeholder="Escribe tu nombre" />
<p>Hola, {{ userName }}!</p>
```

```ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
})
export class AppComponent {
  userName = ''; // Modelo vinculado a ngModel
}
```
Flujo:
  * Escribes algo en el input.

  * El valor se sincroniza automáticamente con la variable userName.

  * El valor de userName se muestra dinámicamente en el párrafo.

### Uso en formularios
```html
<form #userForm="ngForm">
  <label for="email">Correo electrónico:</label>
  <input 
    id="email" 
    name="email" 
    [(ngModel)]="user.email" 
    required 
    email 
  />
  <div *ngIf="userForm.controls.email?.invalid && userForm.controls.email?.touched">
    El correo electrónico no es válido.
  </div>

  <button [disabled]="userForm.invalid">Enviar</button>
</form>
```
```ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
})
export class AppComponent {
  user = { email: '' };
}
```
