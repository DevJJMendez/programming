# Cold Observable
Un Cold Observable es un tipo de Observable en RxJS que no comienza a emitir valores hasta que un suscriptor se suscribe a él. Además, cada suscriptor obtiene su propia instancia del flujo de datos, lo que significa que el Observable vuelve a empezar desde el principio para cada suscriptor.

En esencia, un Cold Observable representa una fuente de datos potencial o diferida que no genera valores a menos que se le pida explícitamente.

## ¿Para qué sirven los Cold Observables?
Los Cold Observables son útiles cuando necesitas trabajar con fuentes de datos diferidas o repetibles, tales como:

* Solicitudes HTTP: Cada vez que un suscriptor se suscribe, se realiza una nueva solicitud al servidor.

* Manipulación de arrays o colecciones: Procesar datos estáticos como listas o series de números.

* Flujos independientes para cada suscriptor: Permiten que cada suscriptor reciba una experiencia independiente del flujo de datos, ideal para operaciones que deben ejecutarse desde el principio por cada cliente.

* Flujos no compartidos: Cuando no quieres que múltiples suscriptores compartan el mismo estado del flujo.

## ¿Qué resuelven los Cold Observables?
* Ejecución bajo demanda: Resuelven la necesidad de generar datos solo cuando son requeridos.

* Independencia de suscriptores: Cada suscriptor obtiene su propio flujo, asegurando que no haya conflictos entre diferentes suscriptores.

* Aislamiento de flujo: Los Cold Observables garantizan que cada suscriptor reciba datos desde el principio, lo que es útil para fuentes de datos que deben ser reiniciadas para cada nuevo cliente.

## ¿Cómo lo resuelven?
* Iniciando la emisión al suscribirse: Los Cold Observables no emiten valores automáticamente. El flujo comienza solo cuando alguien se suscribe.

* Reiniciando el flujo para cada suscriptor: Cada suscriptor recibe una experiencia única e independiente, reiniciando el flujo desde el inicio.

* Ejemplo típico: Solicitudes HTTP, donde cada suscriptor realiza una nueva llamada al servidor y no comparte los resultados con otros suscriptores.

### Ejemplo de Cold Observable
```ts
import { Observable } from 'rxjs';

// Crear un Cold Observable
const coldObservable = new Observable<string>(observer => {
  console.log('Iniciando la emisión de datos...');
  observer.next('Dato 1');
  observer.next('Dato 2');
  observer.complete();
});

// Suscribirse al Observable
coldObservable.subscribe(value => console.log('Suscriptor 1 recibió:', value));
coldObservable.subscribe(value => console.log('Suscriptor 2 recibió:', value));
```
salida
```bash
Iniciando la emisión de datos...
Suscriptor 1 recibió: Dato 1
Suscriptor 1 recibió: Dato 2
Iniciando la emisión de datos...
Suscriptor 2 recibió: Dato 1
Suscriptor 2 recibió: Dato 2
```
Cada suscriptor inicia su propio flujo de datos, reiniciando la emisión desde el principio.

## Uso de Cold Observables en Angular
En Angular, los Cold Observables son ampliamente utilizados, especialmente en el manejo de solicitudes HTTP. Un ejemplo típico es el servicio HttpClient, donde cada llamada genera un nuevo Observable que emite los datos de la respuesta.

Ejemplo: Solicitud HTTP con un Cold Observable
```ts
import { HttpClient } from '@angular/common/http';
import { Component } from '@angular/core';

@Component({
  selector: 'app-root',
  template: '<p>Revisa la consola para los resultados</p>',
})
export class AppComponent {
  constructor(private http: HttpClient) {
    const coldObservable = this.http.get('https://jsonplaceholder.typicode.com/posts/1');

    coldObservable.subscribe(data => console.log('Suscriptor 1:', data));
    coldObservable.subscribe(data => console.log('Suscriptor 2:', data));
  }
}
```
salida
```bash
Suscriptor 1: {id: 1, title: '...', ...}
Suscriptor 2: {id: 1, title: '...', ...}
```
En este caso:
  * Cada suscriptor realiza una nueva solicitud al servidor.

  * Los datos no se comparten entre suscriptores, ya que el Observable es Cold.

## Convertir un Cold Observable en Hot Observable
Si necesitas compartir el flujo de datos de un Cold Observable entre múltiples suscriptores, puedes convertirlo en un Hot Observable utilizando un operador como `share`.

```ts
import { HttpClient } from '@angular/common/http';
import { share } from 'rxjs/operators';

@Component({
  selector: 'app-root',
  template: '<p>Revisa la consola para los resultados</p>',
})
export class AppComponent {
  constructor(private http: HttpClient) {
    const coldObservable = this.http.get('https://jsonplaceholder.typicode.com/posts/1').pipe(share());

    coldObservable.subscribe(data => console.log('Suscriptor 1:', data));
    coldObservable.subscribe(data => console.log('Suscriptor 2:', data));
  }
}
```
salida
```bash
Suscriptor 1: {id: 1, title: '...', ...}
Suscriptor 2: {id: 1, title: '...', ...}
```
Ahora ambos suscriptores comparten la misma solicitud HTTP.
