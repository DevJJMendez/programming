# Reactive Forms
Reactive Forms es una de las dos formas principales de manejar formularios en Angular (la otra es Template-Driven Forms). Se basa en un enfoque programático, donde se define y gestiona la estructura y el comportamiento del formulario en el código TypeScript del componente en lugar de depender del HTML.

Los Reactive Forms utilizan una arquitectura basada en la programación reactiva mediante RxJS, lo que permite un control granular, validaciones dinámicas y una mejor escalabilidad en aplicaciones complejas.

## ¿Para qué sirve Reactive Forms?
Reactive Forms se utiliza para:

* Crear formularios dinámicos: Ideal para formularios cuya estructura puede cambiar en tiempo de ejecución.

* Validar formularios de forma robusta: Proporciona un control estricto sobre las validaciones y la lógica de negocio.

* Controlar el estado del formulario: Accede al estado de cada campo del formulario, como touched, dirty, valid, etc.

* Sincronizar datos del formulario: Integra automáticamente los valores ingresados por el usuario con el modelo de datos.

## ¿Qué problemas resuelve?
Problemas comunes:

* Manejo limitado de formularios dinámicos: Con Template-Driven Forms, crear formularios complejos o dinámicos puede ser complicado.

* Falta de control sobre validaciones: Template-Driven Forms depende del HTML, lo que puede ser menos flexible.

* Dificultad para depurar: Reactive Forms tiene una estructura clara en TypeScript, facilitando la depuración.

* Integración limitada con RxJS: Reactive Forms aprovecha RxJS para manejar flujos de datos y eventos de formulario de manera eficiente.

## ¿Cómo lo resuelve?
* Definiendo la estructura del formulario en TypeScript: Usa clases como FormGroup, FormControl y FormArray para modelar formularios.

* Integración nativa con RxJS: Los formularios son reactivos, lo que permite suscribirse a cambios en los valores o estados.

* Validaciones declarativas y dinámicas: Permite definir validaciones directamente en el código y modificarlas en tiempo de ejecución.

* Estados y eventos accesibles: Proporciona métodos y propiedades para interactuar con el estado del formulario.

## Componentes principales de Reactive Forms
* FormGroup:
  * Representa un formulario o una parte del mismo.
  * Agrupa múltiples FormControl o incluso otros FormGroup.

* FormControl: Representa un único campo del formulario, como un input o select.

* FormArray: Representa una lista de controles o grupos, ideal para listas dinámicas.

* Validators: Define validaciones predefinidas o personalizadas.

## Configuración inicial
Para usar Reactive Forms, necesitas importar el módulo `ReactiveFormsModule`:
```ts
import { ReactiveFormsModule } from '@angular/forms';

@NgModule({
  imports: [ReactiveFormsModule],
})
export class AppModule {}
```

## Ejemplo básico
Definir un formulario básico con validaciones
```ts
import { Component } from '@angular/core';
import { FormGroup, FormBuilder, Validators } from '@angular/forms';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
})
export class AppComponent {
  userForm: FormGroup;

  constructor(private fb: FormBuilder) {
    this.userForm = this.fb.group({
      name: ['', [Validators.required, Validators.minLength(3)]],
      email: ['', [Validators.required, Validators.email]],
      age: ['', [Validators.required, Validators.min(18)]],
    });
  }

  onSubmit() {
    if (this.userForm.valid) {
      console.log('Datos enviados:', this.userForm.value);
    } else {
      console.log('Formulario no válido');
    }
  }
}
```
```html
<form [formGroup]="userForm" (ngSubmit)="onSubmit()">
  <label for="name">Nombre:</label>
  <input id="name" formControlName="name" />
  <div *ngIf="userForm.get('name')?.invalid && userForm.get('name')?.touched">
    El nombre es obligatorio y debe tener al menos 3 caracteres.
  </div>

  <label for="email">Correo:</label>
  <input id="email" formControlName="email" />
  <div *ngIf="userForm.get('email')?.invalid && userForm.get('email')?.touched">
    Introduce un correo válido.
  </div>

  <label for="age">Edad:</label>
  <input id="age" formControlName="age" type="number" />
  <div *ngIf="userForm.get('age')?.invalid && userForm.get('age')?.touched">
    La edad debe ser mayor o igual a 18.
  </div>

  <button type="submit" [disabled]="userForm.invalid">Enviar</button>
</form>
```

### Manejo de validaciones dinámicas
Puedes agregar o eliminar validaciones en tiempo de ejecución:
```ts
this.userForm.get('age')?.setValidators([Validators.required, Validators.min(21)]);
this.userForm.get('age')?.updateValueAndValidity();
```

## Manejo de cambios (Reactive Programming)
Suscríbete a los cambios en los valores o estados de los campos del formulario:
```ts
this.userForm.get('name')?.valueChanges.subscribe((value) => {
  console.log('Nuevo valor del campo "name":', value);
});

this.userForm.statusChanges.subscribe((status) => {
  console.log('Estado del formulario:', status);
});
```
