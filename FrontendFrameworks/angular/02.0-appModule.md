# `AppModule`
El `AppModule` es el módulo raíz de una aplicación Angular. Es un archivo TypeScript que actúa como el punto central para definir las configuraciones, componentes, servicios, y otras dependencias necesarias para que la aplicación funcione. Cada aplicación Angular debe tener al menos un módulo raíz, que por convención se llama `AppModule`.

Se encuentra definido en el archivo `app.module.ts`, generalmente ubicado en el directorio `src/app`.

## ¿Para qué sirve?
* **Declarar los componentes principales de la aplicación**: Registra los componentes que se usarán en la aplicación.

* **Configurar los módulos y bibliotecas necesarias**: Importa módulos esenciales como `BrowserModule`, `FormsModule`, o módulos personalizados.

* **Proveer servicios a través del inyector de dependencias**: Registra servicios y provee configuraciones globales para su uso en toda la aplicación.

* Definir el punto de arranque de la aplicación: Especifica cuál será el componente raíz que Angular debe cargar primero.

## ¿Qué resuelve?
El AppModule organiza y estructura el núcleo de la aplicación para:

* **Centralizar la configuración**: Permite definir en un solo lugar los recursos clave de la aplicación.

* **Facilitar la modularidad y escalabilidad**: Angular permite dividir la aplicación en módulos, y el AppModule actúa como la raíz para integrar estos módulos.

* **Iniciar el ciclo de vida de Angular**: Es el punto donde se inicializa la aplicación y se ejecutan los procesos internos de Angular, como la inyección de dependencias y la compilación de componentes.

* **Reducir el acoplamiento**: Al definir las dependencias en un módulo central, se evita la necesidad de cargar recursos manualmente en cada archivo.

## ¿Cómo lo resuelve?
* Usa el decorador `@NgModule`: Este decorador proporciona metadatos que describen cómo debe comportarse el módulo.

* Define declaraciones, importaciones y proveedores: Organiza los recursos de la aplicación en secciones claras como `declarations`, `imports`, `providers`, y `bootstrap`.

* **Integra el componente raíz**: Mediante la propiedad bootstrap, Angular sabe qué componente debe renderizar primero.

## Estructura del AppModule
El decorador `@NgModule` organiza el módulo raíz mediante varias propiedades clave:

```ts
import { NgModule } from '@angular/core';
import { BrowserModule } from '@angular/platform-browser';
import { AppRoutingModule } from './app-routing.module';
import { AppComponent } from './app.component';

@NgModule({
  declarations: [
    AppComponent, // Declaración del componente raíz
  ],
  imports: [
    BrowserModule,     // Módulo necesario para aplicaciones en navegador
    AppRoutingModule,  // Configuración de rutas
  ],
  providers: [],       // Servicios globales
  bootstrap: [AppComponent] // Componente raíz de la aplicación
})
export class AppModule {}
```

### Propiedades del Decorador `@NgModule`
* **`declarations`**: Registra los componentes, directivas y pipes que pertenecen a este módulo.
```ts
declarations: [
  HomeComponent,
  HeaderComponent,
  FooterComponent,
]
```

* **`imports`**: Importa otros módulos que este módulo necesita para funcionar.
```ts
imports: [
  BrowserModule, 
  HttpClientModule, 
  ReactiveFormsModule,
  SharedModule,
]
```

* **`providers`**: Registra servicios disponibles en toda la aplicación mediante el inyector de dependencias.
```ts
providers: [
  AuthService,
  ApiService,
]
```

* `bootstrap`: Especifica el componente raíz que Angular debe inicializar primero.
```ts
bootstrap: [AppComponent]
```
