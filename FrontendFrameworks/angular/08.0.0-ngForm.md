# `ngForm`
ngForm es una directiva en Angular que se aplica automáticamente a los elementos `<form>` en las plantillas cuando se usa el módulo FormsModule. Proporciona una representación y un manejo estructurado de los formularios mediante Template-Driven Forms. Con esta directiva, Angular controla el estado y la validación de un formulario completo.

## ¿Para qué sirve ngForm?
ngForm sirve para:

* Gestionar el estado de un formulario completo: Proporciona acceso al estado y las validaciones del formulario como una unidad (ej., valid, invalid, dirty, pristine).

* Facilitar la manipulación de formularios: Permite interactuar con los datos del formulario desde el componente TypeScript.

* Agrupar controles individuales: Todos los controles hijos (input, select, etc.) dentro de un `<form>` están automáticamente registrados en ngForm.

* Facilitar validaciones y envíos de formularios: Simplifica el manejo de errores y la lógica de envío al proporcionar un acceso centralizado a todos los controles del formulario.

## ¿Qué resuelve ngForm?
* Gestión del estado de un formulario: Sin ngForm, controlar los estados (ej., si el formulario es válido o no) requeriría lógica manual para rastrear cada campo.

* Validaciones declarativas: ngForm permite aplicar validaciones directamente en la plantilla y asociarlas al estado general del formulario.

* Estructura y organización: Facilita el manejo de formularios al agrupar todos los controles bajo una estructura definida y accesible.

* Sincronización de datos: Proporciona un enlace limpio entre el modelo en TypeScript y los valores del formulario.

## ¿Cómo lo resuelve ngForm?
Mecanismo de solución:

* Estado del formulario: ngForm crea automáticamente un objeto de tipo NgForm que contiene el estado y las validaciones del formulario, disponible mediante una referencia local o como un objeto inyectado.

* Registro de controles: Registra automáticamente todos los controles hijos con directivas como ngModel.

* Interfaz amigable: Proporciona métodos como reset() para reiniciar el formulario y un acceso directo al modelo de datos del formulario.

* Validaciones dinámicas: Detecta cambios y actualiza automáticamente el estado (valid, dirty, etc.) del formulario y de sus controles.

## Uso básico
```html
<form #userForm="ngForm">
  <label for="name">Nombre:</label>
  <input id="name" name="name" ngModel required />
  
  <label for="email">Correo:</label>
  <input id="email" name="email" ngModel required email />

  <button [disabled]="userForm.invalid">Enviar</button>
</form>
<p>Estado del formulario: {{ userForm.valid ? 'Válido' : 'Inválido' }}</p>
```
```ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
})
export class AppComponent {}
```
Explicación:
  * La referencia local #userForm expone la instancia NgForm creada por ngForm.

  * Se vincula automáticamente a los controles dentro del formulario.

  * El botón de envío está habilitado/deshabilitado según el estado valid del formulario.

### Envío del formulario
Puedes manejar el evento [`ngSubmit`](08.0.2-ngSubmit.md) para gestionar el envío de datos:
```html
<form #userForm="ngForm" (ngSubmit)="onSubmit(userForm)">
  <label for="name">Nombre:</label>
  <input id="name" name="name" ngModel required />

  <button type="submit" [disabled]="userForm.invalid">Enviar</button>
</form>
```
```ts
onSubmit(form: NgForm) {
  console.log('Datos del formulario:', form.value);
}
```
