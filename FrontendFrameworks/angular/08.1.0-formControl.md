# `FormControl`
FormControl es una clase de Angular que representa un único control de formulario dentro de los formularios reactivos. Cada control maneja su propio estado y validaciones de manera independiente.

Es la unidad básica de los formularios reactivos y se utiliza para manejar entradas individuales como campos de texto, casillas de verificación, botones de selección, entre otros.

## ¿Para qué sirve FormControl?
* Gestionar el estado de un campo: Se ocupa de propiedades como el valor actual, si es válido/inválido, si está sucio/limpio, o si ha sido tocado/no tocado.

* Aplicar validaciones: Permite definir reglas de validación simples (requerido, longitud mínima) o personalizadas.

* Monitorear cambios: Detecta y reacciona ante cambios en el valor o estado del control mediante observables.

* Conectar el modelo de datos: Sincroniza el valor del campo en la vista con el modelo de datos en el componente.

## ¿Qué resuelve FormControl?
Problemas comunes que resuelve:

* Gestión de entradas individuales: Manejar el estado y las validaciones de un campo específico sin depender de toda la estructura del formulario.

* Inconsistencia en validaciones: Facilita la definición de validaciones estándar y personalizadas de manera centralizada.

* Seguimiento del estado del campo: Proporciona un enfoque declarativo para determinar si un campo ha sido modificado, está vacío o contiene errores.

* Reactividad: Habilita la escucha de cambios en tiempo real para realizar acciones dinámicas en la interfaz.

## ¿Cómo lo resuelve FormControl?
Soluciones proporcionadas:

* Estado centralizado: Gestiona el estado del campo mediante propiedades como value, valid, dirty, y más.

* Validaciones flexibles: Permite usar validadores integrados o personalizados con facilidad.

* Observables integrados: Expone eventos de cambio en el valor (valueChanges) y estado (statusChanges), lo que permite reacciones dinámicas.

* Facilidad de integración: Se puede usar de manera independiente o como parte de un FormGroup.

## Componentes clave de FormControl
### Propiedades principales:
* **`value`**: Contiene el valor actual del control.

* **`valid`**: Indica si el control cumple con las validaciones.

* **`invalid`**: Indica si el control tiene errores de validación.

* **`dirty`**: Indica si el control ha sido modificado.

* **`pristine`**: Indica si el control no ha sido modificado.

* **`touched`**: Indica si el control ha sido enfocado o interactuado.

### Métodos importantes:
* **`setValue(value)`**: Establece un nuevo valor en el control.

* **`patchValue(value)`**: Actualiza parcialmente el valor del control.

* **`reset(value?)`**: Restablece el control a su estado inicial.

* **`markAsTouched()`**: Marca el control como tocado.

* **`markAsUntouched()`**: Marca el control como no tocado.

## Configuración inicial
Para usar FormControl, necesitas importar las clases necesarias de Angular:
```ts
import { FormControl, Validators } from '@angular/forms';
```

## Ejemplo básico
Crear un FormControl
```ts
import { Component } from '@angular/core';
import { FormControl, Validators } from '@angular/forms';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
})
export class AppComponent {
  nameControl: FormControl;

  constructor() {
    this.nameControl = new FormControl('', [
      Validators.required,
      Validators.minLength(3),
    ]);
  }

  getErrorMessage() {
    if (this.nameControl.hasError('required')) {
      return 'El nombre es obligatorio.';
    }
    if (this.nameControl.hasError('minlength')) {
      return 'El nombre debe tener al menos 3 caracteres.';
    }
    return '';
  }
}
```
```html
<div>
  <label for="name">Nombre:</label>
  <input id="name" [formControl]="nameControl" />
  <div *ngIf="nameControl.invalid && nameControl.touched">
    {{ getErrorMessage() }}
  </div>
</div>
```

## Monitoreo de cambios
Escucha los cambios de valor:
```ts
this.nameControl.valueChanges.subscribe((newValue) => {
  console.log('Nuevo valor:', newValue);
});
```
Escucha cambios de estado:
```ts
this.nameControl.statusChanges.subscribe((newStatus) => {
  console.log('Nuevo estado:', newStatus);
});
```

## Integración con FormGroup
Los FormControl se utilizan frecuentemente dentro de un FormGroup para manejar formularios más complejos.
```ts
import { FormGroup } from '@angular/forms';

this.form = new FormGroup({
  name: new FormControl('', Validators.required),
  email: new FormControl('', Validators.email),
});
```

## Ventajas de FormControl
* Control granular: Permite manejar cada entrada de manera independiente.

* Validaciones flexibles: Compatible con validadores integrados y personalizados.

* Reactividad: Observa cambios en tiempo real.

* Fácil de integrar: Puede usarse de forma independiente o en combinación con otros formularios.
