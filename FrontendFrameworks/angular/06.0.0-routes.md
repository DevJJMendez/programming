# `Routes`
En Angular, una Route es una configuración que define cómo se debe asociar una URL con un componente específico. Forma parte del sistema de enrutamiento que Angular proporciona para construir aplicaciones SPA (Single Page Applications).

Las rutas se configuran utilizando un arreglo de objetos que describe el mapeo entre las URL y los componentes que se deben renderizar.

## ¿Para qué sirve una Route?
Las Routes sirven para:

* Configurar la navegación de la aplicación: Permiten definir qué componente se debe mostrar para una URL específica.

* Dividir la aplicación en vistas: Cada ruta generalmente representa una vista o sección de la aplicación.

* Manejar parámetros dinámicos: Facilitan pasar información dentro de las URLs (por ejemplo, `user/:id`).

* Cargar módulos y componentes bajo demanda: Permiten implementar carga diferida (**lazy loading**) para optimizar el rendimiento.

## ¿Qué problemas resuelve una Route?
* Gestión manual de vistas: Sin rutas, el desarrollador tendría que escribir lógica personalizada para mostrar/ocultar componentes, lo cual sería tedioso y propenso a errores.

* Navegación inconsistente: Las Routes integran el navegador con la lógica de la aplicación, asegurando que la URL refleje la vista actual.

* Optimización del rendimiento: Con lazy loading, solo se cargan los módulos necesarios cuando se accede a ellos.

* Compatibilidad con navegación de usuario: Permiten usar las funcionalidades estándar del navegador como los botones de "Atrás" y "Adelante".

## Estructura Básica
**Route** tiene varias propiedades que determinan cómo se comporta la ruta.

```ts
{
  path: 'ruta',
  
  component: Componente,   // O bien...
  
  loadChildren: () => import('./ruta.module').then(m => m.RutaModule),
  
  redirectTo: '/otra-ruta',
  
  pathMatch: 'full',
  
  canActivate: [AuthGuard],
  
  data: { title: 'Título de la Página' },
  
  resolve: { datos: Resolver },
  
  children: [
    // Rutas hijas
  ]
}
```
### Propiedades Clave de `Route`

1. `path`:

   * Define la URL que la ruta maneja.

   * **Ejemplo**: `path: 'home'` manejará la URL `/home`.

2. `component`:

   * Especifica el componente que debe renderizarse cuando el usuario navega a esta ruta.

   * **Ejemplo**: `component: HomeComponent` renderizará **HomeComponent** cuando el usuario visite `/home`.

3. `loadChildren`:

   * Carga un módulo de forma diferida (lazy loading). Se usa para cargar módulos hijos solo cuando es necesario.

   * **Ejemplo**: `loadChildren: () => import('./home/home.module').then(m => m.HomeModule)` cargará **HomeModule** cuando se navegue a la ruta correspondiente.

4. `redirectTo`:

   * Redirige la navegación a otra ruta.

   * **Ejemplo**: `redirectTo: '/login'` redirige automáticamente a `/login`.

5. `pathMatch`:

   * Define cómo Angular debe emparejar la ruta. Puede ser '`full`' o '`prefix`'.

   * **Ejemplo**: `pathMatch: 'full'` indica que la ruta debe coincidir completamente con la URL, no solo un prefijo.

6. `canActivate`:

   * Define guardas de ruta (route guards) que deben pasarse antes de activar la ruta.

   * **Ejemplo**: `canActivate: [AuthGuard]` usa el guard **AuthGuard** para determinar si se permite la navegación a esta ruta.

7. `data`:

   * Permite pasar datos adicionales a la ruta, como metadatos, que pueden ser utilizados en el componente.

   * **Ejemplo**: `data: { title: 'Home Page' }` pasa el título "**Home Page**" a la ruta.

8. `resolve`:

   * Define resolvers que se ejecutan antes de cargar el componente, permitiendo pre-cargar datos necesarios.

   * **Ejemplo**: `resolve: { userData: UserResolver }` utiliza **UserResolver** para pre-cargar datos de usuario antes de que se cargue el componente.

9. `children`:

   * Define rutas hijas (sub-rutas) que dependen de la ruta padre.

   * **Ejemplo**: Una ruta padre `/admin` puede tener rutas hijas como `/admin/dashboard` y `/admin/settings`.

### Ejemplo
```ts
const routes: Routes = [
  {
    path: '',
    redirectTo: '/home',
    pathMatch: 'full'
  },
  {
    path: 'home',
    component: HomeComponent,
    data: { title: 'Home' }
  },
  {
    path: 'about',
    component: AboutComponent,
    canActivate: [AuthGuard]
  },
  {
    path: 'admin',
    loadChildren: () => import('./admin/admin.module').then(m => m.AdminModule),
    canActivate: [AdminGuard]
  },
  {
    path: '**',
    component: PageNotFoundComponent
  }
];
```
