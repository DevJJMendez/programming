# `router-outlet`
El **RouterOutlet** es una directiva en Angular que actúa como un marcador de posición para las vistas de componentes asociadas a las rutas definidas en el sistema de enrutamiento. Se utiliza para cargar dinámicamente los componentes correspondientes a las rutas activas en el lugar donde se coloca.

## ¿Qué es el RouterOutlet?
El **RouterOutlet** es un componente/directiva proporcionado por el módulo de enrutamiento de Angular (@angular/router). Sirve como un punto de anclaje donde Angular renderiza dinámicamente los componentes asociados con las rutas activas.

**Declaración**
```html
<router-outlet></router-outlet>
```
Es un contenedor vacío que se llena con el componente correspondiente a la ruta actual.

## ¿Para qué sirve el RouterOutlet?
El **RouterOutlet** permite:

* Renderizar dinámicamente componentes: Según la URL activa, Angular carga el componente correspondiente.

* Soportar rutas anidadas: Permite tener múltiples niveles de navegación dentro de la misma aplicación.

* Facilitar la navegación modular: Proporciona una forma clara de estructurar la interfaz de usuario en aplicaciones SPA (Single Page Application).

* Sincronizar vistas con la URL: Cambiar la URL automáticamente actualiza la vista correspondiente.

## ¿Qué problemas resuelve el RouterOutlet?
* Cambio manual de vistas: Antes del enrutamiento declarativo, era necesario manipular manualmente el DOM para mostrar u ocultar vistas según el estado de la aplicación.

* Confusión en la navegación: En aplicaciones grandes, puede ser difícil manejar múltiples vistas sin un sistema claro de enrutamiento y renderizado.

* Dificultades con rutas anidadas: El **RouterOutlet** permite implementar estructuras jerárquicas de navegación de manera sencilla.

* Sincronización de URL y vista: Sin un sistema de enrutamiento, mantener la URL y las vistas sincronizadas puede ser complicado.

## ¿Cómo resuelve estos problemas?
El **RouterOutlet** trabaja en conjunto con el RouterModule y las rutas configuradas. Cuando la ruta activa cambia, el **RouterOutlet** detecta el cambio y renderiza el componente especificado en la configuración de rutas.

### Configuración básica:
* **Definir rutas**: Se configuran las rutas en el módulo de enrutamiento:
```ts
import { NgModule } from '@angular/core';
import { RouterModule, Routes } from '@angular/router';
import { HomeComponent } from './home/home.component';
import { AboutComponent } from './about/about.component';

const routes: Routes = [
  { path: '', component: HomeComponent }, // Ruta raíz
  { path: 'about', component: AboutComponent } // Ruta "about"
];

@NgModule({
  imports: [RouterModule.forRoot(routes)],
  exports: [RouterModule]
})
export class AppRoutingModule {}
```
* **Insertar el `RouterOutlet`: En el archivo de la plantilla principal (`app.component.html`)**:
```html
<header>
  <nav>
    <a routerLink="/">Inicio</a>
    <a routerLink="/about">Acerca de</a>
  </nav>
</header>
<main>
  <router-outlet></router-outlet>
</main>
```
Aquí, el componente correspondiente a la ruta activa se renderizará dentro del `<router-outlet>`.

### Rutas anidadas con RouterOutlet
El RouterOutlet permite manejar rutas anidadas colocando múltiples contenedores en diferentes niveles.

* **Configuración de rutas anidadas**:
```ts
const routes: Routes = [
  { 
    path: 'dashboard', 
    component: DashboardComponent,
    children: [
      { path: 'stats', component: StatsComponent },
      { path: 'profile', component: ProfileComponent }
    ]
  }
];
```
* **Uso de `RouterOutlet` en rutas anidadas**: En el componente principal de la ruta (`DashboardComponent`):
```html
<h1>Dashboard</h1>
<nav>
  <a routerLink="stats">Estadísticas</a>
  <a routerLink="profile">Perfil</a>
</nav>
<router-outlet></router-outlet>
```
Esto renderiza `StatsComponent` o `ProfileComponent` dentro del `RouterOutlet` secundario según la subruta activa.

### Múltiples RouterOutlets
En aplicaciones complejas, puede ser útil tener múltiples RouterOutlets para diferentes secciones de la interfaz.

* **Configuración**: Definir rutas con `outlet`:
```ts
const routes: Routes = [
  { path: 'home', component: HomeComponent },
  { path: 'login', component: LoginComponent, outlet: 'auth' }
];
```
* Usar múltiples outlets en la plantilla:
```html
<router-outlet></router-outlet> <!-- Outlet principal -->
<router-outlet name="auth"></router-outlet> <!-- Outlet secundario -->
```
La ruta `/login` se renderizará en el outlet nombrado auth, mientras que la ruta activa principal seguirá controlando el outlet estándar.
