# RouterModule
El **RouterModule** es un módulo central en Angular que proporciona la funcionalidad de enrutamiento para las aplicaciones. Este módulo habilita la navegación entre vistas (componentes) dentro de una **SPA (Single Page Application)**, mapeando URLs específicas a componentes específicos.

## ¿Qué es el RouterModule?
El **RouterModule** es un módulo de Angular que contiene las herramientas necesarias para:

Configurar rutas dentro de una aplicación Angular.
Manejar la navegación entre las rutas.
Sincronizar la URL del navegador con las vistas de la aplicación.

El **RouterModule** se importa desde el paquete `@angular/router` y debe configurarse en el módulo raíz o en módulos funcionales según sea necesario.

## ¿Para qué sirve el RouterModule?
El RouterModule sirve para:

* Definir rutas: Asociar rutas específicas a componentes.

* Gestionar navegación: Permite navegar entre componentes mediante enlaces (`routerLink`) o navegación programática (`Router`).

* Parámetros de rutas: Facilita el paso de datos a través de la URL mediante parámetros dinámicos o de consulta.

* Carga diferida: Ayuda a implementar módulos que se cargan bajo demanda para optimizar el rendimiento.

* Control de acceso: Ofrece herramientas como guardias de rutas para restringir o condicionar el acceso.

## ¿Qué problemas resuelve el RouterModule?
* Gestión compleja de navegación: Antes del **RouterModule**, la navegación manual implicaba manipular directamente el DOM, eventos y estados de la URL.

* Recargas completas de páginas: El **RouterModule** evita recargar la página completa al cambiar vistas, ofreciendo una experiencia fluida.

* Falta de estructura en rutas: Permite organizar las rutas de la aplicación de manera jerárquica y modular.

* Rendimiento limitado en grandes aplicaciones: La carga diferida implementada con el RouterModule mejora el rendimiento cargando solo los módulos necesarios.

* Falta de seguridad en la navegación: Con guardias de ruta, se puede proteger el acceso a vistas sensibles.

## ¿Cómo resuelve estos problemas?
### Configuración básica del RouterModule
Se utiliza una configuración de rutas [Routes](06.0.0-routes.md) y se importa el módulo en el sistema de Angular.

```ts
import { NgModule } from '@angular/core';
import { RouterModule, Routes } from '@angular/router';
import { HomeComponent } from './home/home.component';
import { AboutComponent } from './about/about.component';

const routes: Routes = [
  { path: '', component: HomeComponent },  // Ruta raíz
  { path: 'about', component: AboutComponent }, // Ruta /about
  { path: '**', redirectTo: '', pathMatch: 'full' } // Ruta comodín
];

@NgModule({
  imports: [RouterModule.forRoot(routes)], // Configuración del RouterModule
  exports: [RouterModule]                 // Exportación del módulo para uso global
})
export class AppRoutingModule {}
```
