# Shared
El directorio shared es una carpeta en la estructura de un proyecto Angular que contiene recursos compartidos que no dependen directamente de ninguna funcionalidad específica o página, pero que son útiles en múltiples lugares de la aplicación.

Estructura típica del directorio shared:
```plaintext
src/
 └── app/
     ├── shared/
     │    ├── components/
     │    │    ├── navbar/
     │    │    │    ├── navbar.component.ts
     │    │    │    ├── navbar.component.html
     │    │    │    └── navbar.component.scss
     │    │    └── footer/
     │    ├── directives/
     │    │    ├── highlight.directive.ts
     │    ├── pipes/
     │    │    ├── date-format.pipe.ts
     │    ├── models/
     │    │    ├── user.model.ts
     │    └── utils/

```

## ¿Cuáles son las características del directorio shared?
* Reutilización: Contiene elementos diseñados para ser usados en diferentes partes de la aplicación. Por ejemplo, un componente de navbar o una directiva para resaltar texto.

* Neutralidad funcional: No está ligado a ninguna funcionalidad específica o ruta. Se usa en cualquier lugar donde sea necesario.

* Organización por tipo: Dentro de shared, se suelen organizar subcarpetas según el tipo de recurso:

  * **`components`**: Componentes reutilizables como botones, modales, o barras de navegación.

  * **`directives`**: Directivas personalizadas como highlight.

  * **`pipes`**: Pipes como formateadores de fecha o moneda.

  * **`models`**: Interfaces y clases de datos compartidos.

  * **`utils`**: Funciones auxiliares como validadores o formateadores.

* Fácil importación: Los elementos de shared suelen estar declarados en un módulo compartido (SharedModule), lo que simplifica su uso en otros módulos.

## ¿Qué NO es un shared?
* No es una carpeta de funcionalidades específicas: Elementos relacionados únicamente con una página o sección (como pages o features) no deben estar en shared.

* No contiene lógica de negocio específica: Lógica que pertenece a un módulo o servicio específico no debería estar aquí.

* No es obligatorio: Aunque es una convención ampliamente utilizada, no es una regla estricta de Angular.
