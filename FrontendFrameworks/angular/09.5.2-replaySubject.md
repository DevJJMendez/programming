# `ReplaySubject`
Un ReplaySubject es un tipo de Subject en RxJS que:

Almacena un historial de valores emitidos, basado en una cantidad configurada de valores o en un tiempo límite.
Reproduce estos valores almacenados a todos los suscriptores nuevos.

A diferencia de otros Subjects, como BehaviorSubject o Subject, el ReplaySubject puede "reproducir" múltiples valores anteriores a los suscriptores nuevos, según la configuración inicial.

```ts
import { ReplaySubject } from 'rxjs';

const replaySubject = new ReplaySubject<number>(2); // Guarda las 2 últimas emisiones

replaySubject.next(1);
replaySubject.next(2);
replaySubject.next(3);

replaySubject.subscribe(value => console.log('Subscriber 1:', value)); // Recibe 2, 3 inmediatamente

replaySubject.next(4);
```

## ¿Para qué sirve?
El ReplaySubject es ideal cuando necesitas:

* Reproducir un historial de eventos recientes a nuevos suscriptores.

* Garantizar que los suscriptores reciban los valores emitidos antes de su suscripción, sin importar cuándo se suscribieron.

* Compartir múltiples valores pasados y presentes en flujos de datos dinámicos.

## ¿Qué resuelve?
* Problemas con la falta de valores anteriores en Subjects tradicionales: En un Subject básico o un BehaviorSubject, los suscriptores nuevos solo reciben los valores emitidos después de que se suscriben. En cambio, un ReplaySubject puede proporcionar valores emitidos antes de la suscripción.

* Necesidad de compartir un historial de eventos: Por ejemplo, reproducir mensajes recientes de un chat para un usuario que acaba de unirse.

* Acceso a un buffer de datos almacenado: Almacena un número configurable de valores o valores dentro de un tiempo específico.

## ¿Cómo lo resuelve?
* Buffer configurable: Cuando se crea un ReplaySubject, puedes especificar:
  * bufferSize: Número de valores a almacenar y compartir con los nuevos suscriptores.

  * windowTime: Tiempo máximo (en milisegundos) que los valores deben permanecer en el buffer.

```ts
const replaySubject = new ReplaySubject<number>(2, 500); // 2 valores o 500ms
```

* Reproducción automática: A medida que los nuevos suscriptores se conectan, el ReplaySubject reproduce el buffer de valores almacenados antes de emitir cualquier valor nuevo.

* Interoperabilidad: Funciona con las mismas interfaces y operadores que otros observables y subjects, por lo que es fácil de integrar en sistemas existentes.
