# `FormBuilder.array()`
El método FormBuilder.array() es una función proporcionada por el servicio FormBuilder en Angular que se utiliza para crear instancias de FormArray, una estructura que permite manejar un conjunto dinámico de controles de formulario (pueden ser FormControl, FormGroup, u otros FormArray).

Un FormArray es ideal para formularios donde se necesite un número variable de controles, como listas dinámicas de campos.

## ¿Para qué sirve FormBuilder.array()?
* Crear colecciones de controles de formulario que pueden cambiar dinámicamente en tamaño.

* Manejar entradas repetitivas, como una lista de direcciones, números de teléfono, o elementos de una orden.

* Proveer validación a nivel del conjunto o de los elementos individuales dentro del arreglo.

## ¿Qué problemas resuelve FormBuilder.array()?
* Formularios dinámicos: Antes de FormArray, manejar un conjunto dinámico de campos requería soluciones manuales y poco elegantes.

* Gestión eficiente: Proporciona un enfoque estructurado para añadir, eliminar o validar múltiples controles de manera dinámica.

* Integración con plantillas: Facilita la vinculación dinámica de listas de datos a la interfaz gráfica usando la directiva *ngFor de Angular.

## ¿Cómo lo resuelve?
* Estructura dinámica: Permite agregar y quitar controles en tiempo de ejecución.

* Integración reactiva: Cada control dentro del arreglo tiene su propio estado reactivo (valor, validación, etc.).

* Validadores reutilizables: Puedes aplicar validadores tanto a nivel del arreglo como a nivel de sus controles.

## Sintaxis de FormBuilder.array()
```ts
const formArray = this.fb.array(
  controls,        // Lista de controles iniciales (pueden ser FormControl, FormGroup, FormArray)
  validators,      // Validadores sincrónicos (opcional)
  asyncValidators  // Validadores asincrónicos (opcional)
);
```

## Ejemplo básico de uso
* Creando un FormArray independiente
```ts
import { Component } from '@angular/core';
import { FormBuilder, FormArray, Validators } from '@angular/forms';

@Component({
  selector: 'app-form-array-example',
  templateUrl: './form-array-example.component.html',
})
export class FormArrayExampleComponent {
  items: FormArray;

  constructor(private fb: FormBuilder) {
    this.items = this.fb.array([
      this.fb.control('', Validators.required),  // Control inicial
      this.fb.control(''),                       // Otro control
    ]);
  }

  addItem() {
    this.items.push(this.fb.control('', Validators.required)); // Agrega un nuevo control
  }

  removeItem(index: number) {
    this.items.removeAt(index); // Elimina el control en la posición especificada
  }

  submit() {
    console.log(this.items.value); // Devuelve los valores de los controles en el FormArray
  }
}
```
```html
<div *ngFor="let item of items.controls; let i = index">
  <input [formControl]="item" />
  <button (click)="removeItem(i)">Eliminar</button>
</div>
<button (click)="addItem()">Agregar</button>
<button (click)="submit()">Enviar</button>
```

* Usando FormArray dentro de un FormGroup
```ts
import { Component } from '@angular/core';
import { FormBuilder, FormGroup, FormArray, Validators } from '@angular/forms';

@Component({
  selector: 'app-nested-form-array',
  templateUrl: './nested-form-array.component.html',
})
export class NestedFormArrayComponent {
  myForm: FormGroup;

  constructor(private fb: FormBuilder) {
    this.myForm = this.fb.group({
      items: this.fb.array([]), // Inicia con un FormArray vacío
    });
  }

  get items(): FormArray {
    return this.myForm.get('items') as FormArray; // Acceso al FormArray
  }

  addItem() {
    const itemGroup = this.fb.group({
      name: ['', Validators.required],
      quantity: [1, [Validators.required, Validators.min(1)]],
    });
    this.items.push(itemGroup);
  }

  removeItem(index: number) {
    this.items.removeAt(index);
  }

  submit() {
    console.log(this.myForm.value);
  }
}
```
```html
<form [formGroup]="myForm" (ngSubmit)="submit()">
  <div formArrayName="items">
    <div *ngFor="let item of items.controls; let i = index" [formGroupName]="i">
      <input formControlName="name" placeholder="Item name" />
      <input type="number" formControlName="quantity" placeholder="Quantity" />
      <button (click)="removeItem(i)">Eliminar</button>
    </div>
  </div>
  <button (click)="addItem()">Agregar</button>
  <button type="submit" [disabled]="myForm.invalid">Enviar</button>
</form>
```
