# `providedIn`
providedIn es una propiedad del decorador @Injectable en Angular. Se utiliza para definir el ámbito de inyección de dependencias de un servicio, es decir, dónde y cómo estará disponible ese servicio en la aplicación.

Cuando se usa providedIn, Angular determina automáticamente cómo y cuándo debe instanciar un servicio, optimizando el rendimiento y reduciendo la necesidad de configuraciones manuales en los módulos.

## ¿Para qué sirve?
* Controlar el ciclo de vida del servicio: Define si el servicio será un singleton (instancia única) o si tendrá múltiples instancias según su contexto de uso.

* Optimizar la carga de servicios: Angular solo carga el servicio cuando es necesario, mejorando el rendimiento y evitando la carga innecesaria.

* Simplificar la configuración: Elimina la necesidad de registrar servicios manualmente en el arreglo providers de los módulos.

## ¿Qué resuelve?
* Configuración manual en módulos: Antes de providedIn, los servicios debían ser registrados explícitamente en el arreglo providers de un módulo. Esto era propenso a errores y hacía el código menos limpio.

* Control del ámbito del servicio: Sin providedIn, había confusión sobre dónde y cómo compartir servicios entre módulos o componentes.

* Carga innecesaria de servicios: Algunos servicios se cargaban incluso si no eran utilizados, aumentando el peso inicial de la aplicación.

## ¿Cómo lo resuelve?
Angular resuelve estos problemas utilizando providedIn de la siguiente manera:

* Registro automático: providedIn permite que Angular registre automáticamente el servicio en el sistema de inyección de dependencias sin requerir configuraciones manuales.

* Ámbito flexible: Define dónde estará disponible el servicio (a nivel global, de módulo o de componente).

* Ámbito basado en el uso: Angular carga e instancia el servicio solo cuando es necesario (lazy loading).

## Configuración de providedIn
La propiedad providedIn puede configurarse con los siguientes valores:

* **`providedIn: 'root'`**
  * Hace que el servicio esté disponible en toda la aplicación como un singleton.

  * Angular incluye el servicio solo si es utilizado.

  * Ideal para servicios que se comparten en toda la app, como servicios de autenticación o manejo de datos globales.

```ts
import { Injectable } from '@angular/core';

@Injectable({
  providedIn: 'root', // Disponible en toda la aplicación
})
export class MyService {
  constructor() {}
}
```

* **`providedIn: 'any'`**
  * Se crea una nueva instancia del servicio para cada módulo que lo use.

  * Útil para servicios que deben mantener estados independientes por módulo.

```ts
@Injectable({
  providedIn: 'any', // Instancia separada por módulo
})
export class MyModuleService {
  constructor() {}
}
```

* **`providedIn: SomeModule`**
  * Restringe la disponibilidad del servicio a un módulo específico.

  * Ideal para servicios que solo son relevantes dentro de un módulo.

```ts
@Injectable({
  providedIn: MyModule, // Disponible solo dentro de MyModule
})
export class ScopedService {
  constructor() {}
}
```

* Sin `providedIn`, Si no se especifica providedIn, el servicio debe registrarse manualmente en el arreglo providers del módulo donde será utilizado.
```ts
@NgModule({
  providers: [MyService],
})
export class MyModule {}
```

## Ejemplo Práctico
* Servicio Global (`providedIn: 'root'`)
```ts
@Injectable({
  providedIn: 'root',
})
export class AuthService {
  private isAuthenticated = false;

  login() {
    this.isAuthenticated = true;
  }

  logout() {
    this.isAuthenticated = false;
  }

  isLoggedIn(): boolean {
    return this.isAuthenticated;
  }
}
```
**Uso**: Disponible en toda la aplicación sin configuraciones adicionales.

* Servicio con Múltiples Instancias (`providedIn: 'any'`)
```ts
@Injectable({
  providedIn: 'any',
})
export class StateService {
  private state: string[] = [];

  addItem(item: string) {
    this.state.push(item);
  }

  getState(): string[] {
    return this.state;
  }
}
```
**Uso**: Cada módulo que inyecte este servicio obtendrá su propia instancia independiente.

*  **Servicio Específico de un Módulo**
```ts
@Injectable({
  providedIn: MyFeatureModule,
})
export class FeatureService {
  constructor() {}
}
```
**Uso**: Este servicio estará disponible solo en el módulo `MyFeatureModule`.
