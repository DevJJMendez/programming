# `routerLinkActive`
**routerLinkActive** es una directiva de Angular que permite aplicar una o más clases CSS a un elemento HTML cuando la ruta asociada al enlace (routerLink) está activa. Es especialmente útil para resaltar enlaces de navegación cuando el usuario está en la ruta correspondiente.

## ¿Para qué sirve?
* **Resaltar visualmente enlaces activos**: Aplicar estilos (por ejemplo, cambiar color, subrayar) a enlaces de navegación cuando la ruta asociada está activa.

* **Mejorar la experiencia del usuario (UX)**: Ayuda a los usuarios a identificar fácilmente en qué parte de la aplicación se encuentran.

* **Personalización de navegación**: Permite que los desarrolladores definan cómo los enlaces activos se diferencian visualmente de los inactivos.

## ¿Qué problemas resuelve?
* **Falta de retroalimentación visual**: En navegaciones sin **routerLinkActive**, los usuarios no saben claramente qué sección está activa.

* **Complicación de estilos manuales**: Sin esta directiva, habría que gestionar los estilos manualmente mediante programación, lo cual es propenso a errores.

## ¿Cómo lo resuelve?
**routerLinkActive** resuelve estos problemas aplicando automáticamente una o más clases CSS al elemento HTML cuando su ruta está activa, eliminando la necesidad de gestionar manualmente el estado activo de los enlaces.

## Uso básico de routerLinkActive
Ejemplo: Enlaces de navegación
```html
<nav>
  <a routerLink="/home" routerLinkActive="active">Home</a>
  <a routerLink="/about" routerLinkActive="active">About</a>
  <a routerLink="/contact" routerLinkActive="active">Contact</a>
</nav>
```
CSS asociado
```css
.active {
  font-weight: bold;
  color: blue;
}
```
**Comportamiento**
* Cuando el usuario navega a `/home`, el enlace **"Home"** se resalta automáticamente con la clase active.

* Lo mismo ocurre con los enlaces a `/about` y `/contact` según la ruta actual.

## Configuración de coincidencias: routerLinkActiveOptions
De forma predeterminada, routerLinkActive considera activa una ruta si es igual o incluye la ruta actual. Puedes ajustar este comportamiento con routerLinkActiveOptions.

Ejemplo de coincidencia exacta
```html
<a routerLink="/settings" 
   routerLinkActive="active" 
   [routerLinkActiveOptions]="{ exact: true }">Settings</a>
```
  * Por defecto: `/settings` será activa incluso si la ruta actual es `/settings/preferences`.

  * Con `exact: true: /settings` solo será activa si la ruta es exactamente `/settings`.

## Buenas prácticas
* Mantén clases descriptivas: Usa nombres de clases claros como `active-link` o selected para mejorar la mantenibilidad del código.

* Aplica `routerLinkActiveOptions` para precisión: Usa `{ exact: true }` cuando sea necesario evitar que rutas hijas activen el enlace.

* Evita sobrecargar con estilos innecesarios: Define estilos específicos y minimalistas para enlaces activos, como cambios de color o subrayados.

* Combina con aria-current para accesibilidad: Usa la propiedad aria-current en enlaces activos para mejorar la accesibilidad.
