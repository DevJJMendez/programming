## Postman
Es esencialmente un cliente de API que permite a los desarrolladores crear, compartir, **probar** y documentar APIs de forma rápida y sencilla. Es una herramienta todo en uno que simplifica el proceso de trabajar con APIs, ya sea que estés consumiendo una API existente o desarrollando una desde cero.

### Caracteristicas

- **Colecciones**
  
    * Puedes organizar tus solicitudes en colecciones, lo que facilita la gestión y ejecución de diferentes conjuntos de solicitudes relacionadas.

- **Entorno y Variables**
  
    * Postman permite configurar diferentes entornos (por ejemplo, desarrollo, pruebas, producción) y utilizar variables para simplificar la configuración de las solicitudes en diferentes contextos.

- **Automatización de Pruebas** 
  
    * Con Postman, puedes escribir scripts de prueba usando JavaScript para automatizar el proceso de pruebas. Esto es muy útil para ejecutar pruebas unitarias, de integración o funcionales de forma automatizada.

- **Documentación**
  
    * Puedes generar documentación fácilmente para tus APIs, lo que es útil para compartir con otros desarrolladores o para tu propia referencia.

- **Colaboración**
  
    * Postman ofrece capacidades de colaboración que permiten a los equipos trabajar juntos en el desarrollo y prueba de APIs.
