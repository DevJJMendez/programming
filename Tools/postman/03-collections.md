## Colecciones
Son conjuntos de solicitudes que permiten organizar y ejecutar de manera eficiente las pruebas de API.

Son 'contenedores' que puede almacenar un conjunto de solicitudes, variables, scripts y documentación relacionada con una API específica o un conjunto de funcionalidades.

Las colecciones permiten organizar las solicitudes de una API en grupos lógicos, lo que facilita la gestión y ejecución de pruebas.

## Características y Funcionalidades:

- **Solicitudes**
  
    * Las colecciones pueden contener varias solicitudes, como GET, POST, PUT, DELETE, etc., para diferentes rutas y recursos de una API.

- **Variables**
  
    * Se pueden definir variables en una colección y usarlas en todas las solicitudes de la colección. Esto permite la reutilización y la flexibilidad en las pruebas.

- **Scripts**
  
    * Los scripts en Postman (usando JavaScript) se pueden asociar a las solicitudes en una colección para automatizar tareas o realizar pruebas avanzadas.

- **Ambientes (Environments)**
  
    * Postman permite crear ambientes (environments) que contienen conjuntos de variables. Las colecciones pueden utilizar estos ambientes para ajustar automáticamente las variables según el entorno (como desarrollo, prueba, producción).

- **Documentación**
    
    * Las colecciones pueden incluir descripciones y comentarios que sirven como documentación para los usuarios, explicando el propósito de las solicitudes y cómo utilizarlas.
