# Configuración

- **Directorio `/var/www`** acá creamos los directorios donde tengamos el codigo de desarrollo web 
  ```bash
  cd /var/www
  ```

- **Directorio de configuracion**
  ```bash
  cd /etc/apache2/sites-available
  ```

- **Ejemplo**:

  - En el directorio `/var/www` crearemos un directorio `/var/www/test`
  - En el directorio `/etc/apache2/sites-available` crearemos el archivo de configuracion para enlazarlo con el directorio `/var/www/test`.

  - Estructura del archivo:
  ```conf
  <VirtualHost *:80>
    ServerName www.prueba.com
    ServerAlias prueba.com
    ServerAdmin yourEmail@gmail.com
    DocumentRoot /var/www/test
    <Directory /var/www/test>
          Options Indexes FollowSymLinks
          AllowOverride All
          Require all granted
    </Directory>
    ErrorLog ${APACHE_LOG_DIR}/error.log
    CustomLog ${APACHE_LOG_DIR}/access.log combined
  </VirtualHost>
  ```
- Ahora debemos habilitar los sitios en el directorio , esto se hace `/etc/apache2/sites-enabled`, esto lo podemos hacer con el comando:
  ```bash
  sudo a2ensite test.conf
  ```
- Ahora debemos reiniciar el servidor:
  ```bash
  sudo systemctl reload apache2

  sudo systemctl restart apache2
  ```
- Por ultimo, configuramos los Host Locales en el directorio `/etc/hosts`:
  - con el comando `ip a` para obtener informacion de la interfaz red.

    Esta sera la que necesitaremos: 
    ```bash
    2: enp6s0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc fq_codel state UP group default qlen 1000
    link/ether f0:2f:74:2e:f6:ea brd ff:ff:ff:ff:ff:ff
    inet 192.168.1.146/24 brd 192.168.1.255 scope global dynamic noprefixroute enp6s0
       valid_lft 603125sec preferred_lft 603125sec
    inet6 fe80::21c1:f271:6db0:ed39/64 scope link noprefixroute 
       valid_lft forever preferred_lft forever
    ```
