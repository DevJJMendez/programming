## Permisos

Usando el comando `ls -l` veremos lo siguiente:

  ```bash
  drwxr-xr-x 2 root root 4096 abr 20 09:20 html
  ```
- **d**: Indica que es un **directorio**. Si en lugar de d hubiera sido un `-`, significaría que es un archivo regular.

- `rwxr-xr-x`: Estos son los permisos del directorio. Se dividen en tres conjuntos de tres caracteres cada uno. El primer conjunto corresponde al propietario del **archivo/directorio**, el segundo conjunto corresponde al grupo al que pertenece el **archivo/directorio**, y el tercer conjunto corresponde a otros usuarios.
  - `r`: Indica permiso de lectura. El propietario, el grupo y otros usuarios tienen permiso de leer el contenido del directorio.
  - `w`: Indica permiso de escritura. El propietario, el grupo y otros usuarios no tienen permiso de escritura en el directorio.
  - `x`: Indica permiso de ejecución. El propietario, el grupo y otros usuarios tienen permiso de ejecución en el directorio.
- `2`: Este número indica la cantidad de enlaces duros al archivo o directorio.
- `root`: El primer root indica el nombre del usuario propietario del archivo/directorio.
- `root`: El segundo root indica el nombre del grupo al que pertenece el archivo/directorio.
- `4096`: Indica el tamaño del directorio en bytes.
- `abr` 20 09:20: Indica la fecha y hora de la última modificación del directorio.
- `html`: Es el nombre del directorio.

## Asignar permisos:
  ```bash
  sudo chown -R www-data:www-data /var/www

  sudo chmod -R 755 /var/www
  
  sudo find /var/www -type f -exec chmod 644 {} \;
  ```
