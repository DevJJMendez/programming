# Apache - Apache HTTP Server

Es un servidor web de código abierto ampliamente utilizado en todo el mundo. Fue creado originalmente en 1995 y es uno de los servidores web más antiguos y populares disponibles. Es mantenido y desarrollado por la Apache Software Foundation.

## Características Principales de Apache:

- Código Abierto: Apache es un software de código abierto, lo que significa que su código fuente está disponible para que cualquiera lo estudie, modifique y distribuya de acuerdo con las licencias de software libre.

- Multiplataforma: Está disponible para una variedad de sistemas operativos, incluyendo Linux, Windows, macOS y otros Unix-like systems.

- Módulos: Apache es altamente modular y extensible. Puede ser personalizado a través de módulos que añaden funcionalidades específicas, como manejo de PHP, SSL, autenticación, compresión, etc.

- Configuración Flexible: Su configuración se realiza mediante archivos de configuración de texto plano, como el famoso httpd.conf. Esto permite una configuración altamente personalizada y detallada.

- Soporte para múltiples protocolos: Apache puede manejar varios protocolos de red, incluyendo HTTP/1.1, HTTP/2, y SSL/TLS para conexiones seguras.

- Soporte para múltiples lenguajes: Puede trabajar con una variedad de lenguajes de programación y tecnologías, como PHP, Python, Perl, Ruby, entre otros.

- Estabilidad y Desempeño: Apache es conocido por su estabilidad y buen rendimiento. Puede manejar cargas pesadas de tráfico y servir páginas estáticas y dinámicas de manera eficiente.

## Funcionamiento de Apache:

- Petición y Respuesta: Cuando un cliente, como un navegador web, hace una solicitud a un servidor Apache, este recibe la solicitud.

- Módulos: Apache utiliza módulos para procesar la solicitud. Por ejemplo, si la solicitud es para un archivo HTML, se utiliza el módulo mod_mime. Si es para un script PHP, se usa el módulo mod_php.

- Respuesta: Después de procesar la solicitud, Apache envía una respuesta al cliente. Esta respuesta puede ser una página web, un archivo descargable, o cualquier otro tipo de contenido solicitado
