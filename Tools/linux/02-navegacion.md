* **`cd nombreDirectorio`**: Se utiliza para cambiar el directorio actual en el que estás trabajando. Es una herramienta fundamental para navegar por el sistema de archivos y acceder a diferentes ubicaciones dentro de él.

```bash
cd Documents
```

* **`cd //`**: Cambia al directorio especificado por su ruta absoluta

```bash
cd Documents/Projects/laravel
```

* `cd ..`: Cambia al directorio padre del directorio actual.

```bash
cd ..
```

* `cd ~`: Cambia al directorio de inicio del usuario actual.

```bash
cd ~
```
