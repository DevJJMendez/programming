# Diseño de bases de datos
El diseño de bases de datos es el proceso de definir la estructura y organización de una base de datos para satisfacer las necesidades de almacenamiento, gestión y recuperación de información de manera eficiente y efectiva. Implica la creación de un modelo conceptual, lógico y físico de la base de datos, considerando aspectos como la estructura de los datos, las relaciones entre las entidades, las restricciones de integridad y las estrategias de acceso y manipulación de la información.

El diseño de bases de datos es fundamental para el desarrollo de sistemas de información, ya que proporciona una estructura coherente y optimizada para almacenar y gestionar datos de manera consistente y segura. Algunas de las principales funciones y beneficios del diseño de bases de datos son:

* **Organización de la información**: Permite organizar los datos de manera estructurada, facilitando su almacenamiento, consulta y actualización.

* **Integridad de los datos**: Permite establecer reglas y restricciones para garantizar la integridad y la consistencia de los datos almacenados en la base de datos.

* **Eficiencia en el acceso**: Permite diseñar índices, vistas y consultas optimizadas para acceder y recuperar la información de manera rápida y eficiente.

* **Escalabilidad**: Facilita la capacidad de ampliar y modificar la base de datos según las necesidades del sistema y el crecimiento de la información.

* **Seguridad**: Permite establecer mecanismos de seguridad y control de acceso para proteger la información confidencial y garantizar su privacidad.

## Pasos para Modelar Datos
* Identificar las entidades del sistema

* Identificar los atributos de las entidades

* Identificar las llaves primarias y foráneas

* Asignar una nomenclatura adecuada a las entidades y sus atributos

* Identificar las entidades pivotes del sistema

* Identificar los catalogos del sistema

* Identificar los tipos de relaciones del sistema

* Crear el Modelo Entidad-Relación del sistema

* Crear el Modelo Relacional de la base de datos del sistema

* Identificar los tipos de datos de los atributos de las entidades del sistema

* Identificar las reglas de negocio (Operaciones CRUD) del sistema

# Dato - Información
Un dato se refiere a un **elemento individual** que se utiliza como una unidad básica de información. Puede ser un número, una palabra, una imagen, un sonido o cualquier otra representación simbólica de una entidad. Por ejemplo, el número "`10`", la palabra "`perro`" o la imagen de un árbol son ejemplos de datos.

La **información**, por otro lado, es el resultado de **procesar y organizar datos de manera significativa**. Es el conocimiento derivado de los datos que proporciona sentido y contexto. Para ponerlo en perspectiva, si consideramos los datos anteriores ("`10`", "`perro`", `imagen de un árbol`"), la información sería algo como "`la edad de un niño`", "`un animal doméstico común`" o "`una representación visual de un ser vivo`".

La diferencia principal entre datos e información radica en la interpretación y el contexto. Los datos son elementos crudos sin procesar, mientras que la información es el resultado de procesar esos datos para extraer conocimiento y significado útil.

- Ejemplo:

  - Datos: juan,perez,30
  - Información: 
    - nombre:juan
    - apellido:perez
    - edad: 30
