# CRUD
CRUD es un acrónimo que hace referencia a las operaciones básicas que se pueden realizar sobre los datos en un sistema de gestión de bases de datos relacionales. Estas operaciones son fundamentales en el desarrollo de aplicaciones y sistemas que interactúan con bases de datos. Aquí te explico qué significa CRUD y qué representa cada letra:

- **C** - Create (Crear):
  La operación de Crear se refiere a la acción de añadir nuevos datos a la base de datos.
  En el contexto de una base de datos, esto implica agregar un nuevo registro o fila a una tabla existente, proporcionando los valores para cada uno de los campos de la tabla.
  Por ejemplo, en un sistema de gestión de biblioteca, la operación de Crear se utilizaría para añadir un nuevo libro a la base de datos, ingresando su título, autor, editorial, año de publicación, etc.

- **R** - Read (Leer):
  
  La operación de Leer implica recuperar datos de la base de datos para su visualización o procesamiento.
  En el contexto de una base de datos, esto se traduce en realizar consultas para obtener información específica de una tabla o varias tablas, utilizando filtros y criterios de búsqueda.
  Por ejemplo, en un sistema de gestión de empleados, la operación de Leer se utilizaría para mostrar la lista de empleados con ciertas características, como todos los empleados del departamento de ventas.

- **U** - Update (Actualizar):
  
  La operación de Actualizar implica modificar los datos existentes en la base de datos.
  En el contexto de una base de datos, esto implica modificar los valores de uno o más campos de un registro existente en una tabla.
  Por ejemplo, en un sistema de gestión de inventario, la operación de Actualizar se utilizaría para cambiar la cantidad disponible de un producto en el almacén después de una compra o una venta.

- **D** - Delete (Eliminar):
  
  La operación de Eliminar se refiere a la acción de eliminar datos de la base de datos.
  En el contexto de una base de datos, esto implica eliminar un registro o fila de una tabla existente.
  Por ejemplo, en un sistema de gestión de clientes, la operación de Eliminar se utilizaría para eliminar el registro de un cliente que ha decidido darse de baja del servicio.
