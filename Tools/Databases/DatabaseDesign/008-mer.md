# Modelo Entidad Relacion

El Modelo Entidad-Relación (ER) es un modelo conceptual utilizado en el diseño de bases de datos para representar de manera visual las entidades, atributos y relaciones entre entidades en un sistema (Estructura). Es una herramienta fundamental en la fase de análisis y diseño de bases de datos, permitiendo a los diseñadores y desarrolladores comprender la estructura y las interacciones de los datos de manera clara y sistemática.

El proceso de diseño utilizando el Modelo Entidad-Relación implica identificar y definir las entidades relevantes en el sistema, especificar los atributos de cada entidad, establecer las relaciones entre entidades y determinar las claves primarias y foráneas. Todo esto se representa gráficamente mediante diagramas ER que muestran las entidades como rectángulos, los atributos como elipsoides y las relaciones como líneas conectando las entidades.

![ModeloEntidadRelacion](/assets/0-mer.webp)


- **Rectángulo**:
  - Representa una entidad en el modelo ER.
  - Dentro del rectángulo se coloca el nombre de la entidad.
- **Elipsoide o óvalo**:
  - Representa un atributo de una entidad.
  - Se coloca dentro de la entidad correspondiente para indicar los atributos de esa entidad.
- **Rombo**
  - Representa una relación entre entidades.
  - Se utiliza para indicar cómo las entidades están conectadas y relacionadas entre sí.
- **Líneas**:
  - Se utilizan para conectar las entidades con los rombos que representan las relaciones.
  - Las líneas muestran la dirección de la relación y pueden tener adornos como "uno" o "muchos" para indicar la cardinalidad de la relación.
- **Líneas Dobles**:
  - Se utilizan para representar la identificación de una clave primaria o una clave compuesta.
  - Las líneas dobles conectan el atributo que actúa como clave primaria o compuesta dentro de una entidad.
  - Tambien se usan para describir la tablas pivots.
