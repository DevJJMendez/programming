# Base de datos
Una base de datos es un sistema organizado y estructurado que permite almacenar, gestionar y recuperar información de manera eficiente. En términos simples, es un conjunto de datos relacionados entre sí y organizados de forma que se puedan acceder, actualizar y gestionar fácilmente según las necesidades de una aplicación o sistema.

Una base de datos está compuesta por tablas que contienen filas y columnas. Cada fila representa un registro individual y cada columna representa un atributo o campo de información. La relación entre las tablas se establece mediante claves primarias y claves foráneas, lo que permite vincular y consultar datos de manera relacionada.

## Gestor de base de datos
Un gestor de base de datos (**DBMS Database Management System**) es un software que se encarga de administrar y gestionar una base de datos. Sus funciones principales incluyen:

- **Creación y mantenimiento de la base de datos**: Permite crear la estructura de la base de datos, definir tablas, establecer relaciones y gestionar la integridad de los datos.

- **Acceso y manipulación de datos**: Proporciona herramientas para insertar, actualizar, eliminar y consultar datos en la base de datos de manera segura y eficiente.

- **Control de concurrencia**: Gestiona el acceso simultáneo de múltiples usuarios a la base de datos, garantizando la consistencia y la integridad de los datos.

- **Seguridad**: Ofrece mecanismos para controlar el acceso a la base de datos mediante usuarios, roles y permisos, protegiendo la información confidencial.

- **Optimización del rendimiento**: Implementa técnicas de indexación, optimización de consultas y gestión de transacciones para mejorar el rendimiento y la velocidad de acceso a la base de datos.
