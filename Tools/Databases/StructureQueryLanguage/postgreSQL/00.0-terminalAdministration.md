Para manipular PostgreSQL desde la terminal, usarás principalmente el comando `psql`, que es el cliente de línea de comandos oficial de PostgreSQL. 

1. **Acceso a PostgreSQL desde la terminal**

    ```bash
    sudo -u postgres psql
    ```
    Aquí, `postgres` es el usuario por defecto de PostgreSQL.

## Comandos Básicos
* Crear un usuario

    ```sql
    CREATE USER userName WITH PASSWORD 'yourPassword';
    ```

* **Actualizar las credenciales de un usuario**: Si deseas actualizar la contraseña de un usuario en PostgreSQL, usa el siguiente comando:

    ```sql
    ALTER USER nombre_usuario WITH PASSWORD 'nueva_contraseña';
    ```

* **Asignar privilegios a un usuario**: Puedes otorgar privilegios de administrador (superuser) a un usuario:

    ```sql
    ALTER USER userName WITH SUPERUSER;
    ```

    O también puedes asignar privilegios más específicos, como crear bases de datos:

    ```sql
    GRANT CREATE ON DATABASE databaseName TO userName;
    ```

* **Crear una base de datos**

    ```sql
    CREATE DATABASE databaseName;
    ```

* **Listar bases de datos**

    ```sql
    \l
    ```

* **Conectarse a una base de datos**

    ```sql
    \c databaseName
    ```

* **Listar tablas**

    ```sql
    \dt
    ```

* **Ver la definición de una tabla**

    ```sql
    \d tableName
    ```

## Comandos SQL
* **Crear una tabla**

    ```sql
    CREATE TABLE productos (
        id SERIAL PRIMARY KEY,
        nombre VARCHAR(100),
        precio DECIMAL(10, 2),
        cantidad INT
    );
    ```

* **Insertar datos**

    ```sql
    INSERT INTO productos (nombre, precio, cantidad) VALUES ('Laptop', 999.99, 10);
    ```

* **Consultar datos**

    ```sql
    SELECT * FROM productos;
    ```

* **Actualizar datos**

    ```sql
    UPDATE productos SET precio = 899.99 WHERE nombre = 'Laptop';
    ```

* **Eliminar datos**

    ```sql
    DELETE FROM productos WHERE nombre = 'Laptop';
    ```

* **Eliminar una tabla**

    ```sql
    DROP TABLE productos;

    TRUNCATE TABLE productos;
    ```

## Comandos avanzados
* **Crear un índice para optimizar consultas**

    ```sql
    CREATE INDEX idx_precio ON productos (precio);
    ```

* **Agregar una columna a una tabla**

    ```sql
    ALTER TABLE productos ADD COLUMN descripcion TEXT;
    ```

* **Eliminar una columna**

    ```sql
    ALTER TABLE productos DROP COLUMN descripcion;
    ```

* **Copiar datos desde un archivo CSV**

    ```sql
    COPY productos (nombre, precio, cantidad) FROM '/ruta/al/archivo.csv' DELIMITER ',' CSV HEADER;
    ```

* **Exportar una tabla a un archivo CSV**

    ```sql
    COPY productos TO '/ruta/a/exportar.csv' DELIMITER ',' CSV HEADER;
    ```

* **Crear una función personalizada**: PostgreSQL permite crear funciones avanzadas usando lenguajes como PL/pgSQL. Aquí tienes un ejemplo básico de función:

    ```sql
    CREATE OR REPLACE FUNCTION obtener_total_precio() RETURNS NUMERIC AS $$
    DECLARE
        total NUMERIC;
    BEGIN
        SELECT SUM(precio * cantidad) INTO total FROM productos;
        RETURN total;
    END;
    $$ LANGUAGE plpgsql;
    ```
    Puedes luego ejecutar esta función con:

    ```sql
    SELECT obtener_total_precio();
    ```
* **Crear un Trigger**: Los triggers permiten ejecutar acciones automáticamente antes o después de ciertas operaciones (como INSERT, UPDATE, o DELETE).

    * Ejemplo de trigger que actualiza una columna automáticamente al insertar un registro:

    ```sql
    CREATE OR REPLACE FUNCTION actualizar_fecha_modificacion()
    RETURNS TRIGGER AS $$
    BEGIN
        NEW.fecha_modificacion = NOW();
        RETURN NEW;
    END;
    $$ LANGUAGE plpgsql;

    CREATE TRIGGER trigger_actualizacion
    BEFORE UPDATE ON productos
    FOR EACH ROW
    EXECUTE FUNCTION actualizar_fecha_modificacion();
    ```

* **EXPLAIN: Analizar una consulta**: **EXPLAIN** te muestra cómo el sistema ejecutará una consulta y es útil para detectar cuellos de botella:

    ```sql
    EXPLAIN SELECT * FROM productos WHERE precio > 500;
    ```

* **Vacuum** para limpiar y optimizar la base de datos: VACUUM limpia registros obsoletos y recupera espacio en disco:

    ```sql
    VACUUM FULL productos;
    ```

* **Análisis estadístico de la base de datos**: Para que PostgreSQL optimice las consultas, necesitas mantener estadísticas actualizadas con ANALYZE:

    ```sql
    ANALYZE productos;
    ```
