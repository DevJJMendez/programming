# Serial
El tipo de dato SERIAL en PostgreSQL es una manera conveniente de generar identificadores únicos automáticamente para las columnas. 

## ¿Qué es SERIAL?
SERIAL es un tipo de dato que se utiliza para crear columnas de enteros autoincrementales. Al definir una columna como SERIAL, PostgreSQL crea internamente una secuencia que se encarga de generar valores únicos y consecutivos para esa columna.

## Tipos de SERIAL
Existen tres variantes de SERIAL, cada una con diferentes rangos de valores:

1. `SERIAL`

   * **Rango**: 1 a 2,147,483,647 (32-bit).

   * **Tamaño**: Usa un **INTEGER** bajo el capó.

   * **Uso**: Ideal para la mayoría de los identificadores únicos.

2. `BIGSERIAL`

   * **Rango**: 1 a 9,223,372,036,854,775,807 (64-bit).

   * **Tamaño**: Usa un **BIGINT**.

   * **Uso**: Útil cuando se espera un gran número de registros.

3. `SMALLSERIAL`

   * **Rango**: 1 a 32,767 (16-bit).

   * **Tamaño**: Usa un **SMALLINT**.

   * **Uso**: Para tablas pequeñas donde se puede garantizar que no se superará este rango.

## Cómo se usa SERIAL

* **Creación de una Tabla**: Cuando defines una tabla con una columna **SERIAL**, PostgreSQL maneja automáticamente la creación de una secuencia para esa columna.

    ```sql
    CREATE TABLE users (
        user_id SERIAL PRIMARY KEY,
        user_name VARCHAR(100) NOT NULL,
        user_email VARCHAR(255) UNIQUE NOT NULL,
        created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
    );
    ```
    En este ejemplo, `user_id` es una columna **SERIAL**, lo que significa que cada vez que se inserta un nuevo registro en la tabla users, PostgreSQL generará automáticamente un valor único y consecutivo para `user_id`.

## Cómo funciona internamente
Secuencia: Cuando se define una columna como SERIAL, PostgreSQL crea una secuencia interna para esa columna. Puedes ver la secuencia creada mediante:
```sql
SELECT * FROM pg_sequences;
```
Inserción Automática: Al insertar un nuevo registro sin especificar el valor para la columna user_id, PostgreSQL llamará automáticamente a la secuencia para obtener el siguiente número.
```sql
INSERT INTO users (user_name, user_email) VALUES ('Alice', 'alice@example.com');
```
En este caso, no es necesario especificar user_id; PostgreSQL lo generará automáticamente.

## Consideraciones
No puedes reutilizar valores: Una vez que un valor es generado por la secuencia, no se puede reutilizar, incluso si se eliminan registros. Esto asegura la unicidad, pero puede causar "huecos" en los valores de user_id.

Sinónimos para secuencias: Si necesitas restablecer la secuencia (por ejemplo, después de eliminar registros), debes hacerlo manualmente. Puedes usar:
```sql
ALTER SEQUENCE users_user_id_seq RESTART WITH 1;
```
Alternativas: Para sistemas distribuidos o donde se necesita generar identificadores únicos fuera de la base de datos, considera el uso de UUID.
