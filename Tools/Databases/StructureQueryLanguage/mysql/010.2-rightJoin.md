# `RIGHT JOIN`
Un **RIGHT JOIN** en SQL es un tipo de unión que devuelve todos los registros de la tabla a la derecha (la "**tabla secundaria**"), junto con los registros coincidentes de la tabla a la izquierda. Si no hay coincidencia, los valores de la tabla izquierda aparecerán como NULL. La tabla derecha es siempre la segunda tabla mencionada en la consulta SQL.

## ¿Para qué se utiliza el RIGHT JOIN?
El **RIGHT JOIN** se utiliza para combinar datos de dos tablas, pero garantiza que todos los registros de la tabla derecha (la tabla secundaria) se incluyan en el resultado, independientemente de si existe o no una coincidencia en la tabla izquierda. Esto es útil cuando deseas obtener todos los datos de una tabla relacionada, incluso si algunos de ellos no tienen correspondencia en la tabla principal.

## ¿Qué resuelve?
Resuelve el problema de querer obtener todos los datos de una tabla secundaria, independientemente de si existen coincidencias en la tabla principal. Es el opuesto funcional de un **LEFT JOIN**, pero menos utilizado en la práctica, ya que la mayoría de las veces los **LEFT JOIN** son más fáciles de interpretar.

## ¿Cómo lo resuelve?
Devuelve:

* Todas las filas de la tabla derecha (la segunda mencionada en la consulta).

* Las filas coincidentes de la tabla izquierda. Si no hay coincidencia, los valores de las columnas de la tabla izquierda serán `NULL`.

## Sintaxis
```sql
SELECT column1, column2, ...
FROM table1
RIGHT JOIN table2
ON table1.column = table2.column;
```

## Ejemplo
Imaginemos que tenemos las mismas dos tablas: clientes y pedidos. Queremos obtener una lista de todos los pedidos, y si hay clientes asociados con esos pedidos, mostrar también su información. Si no hay cliente asociado con algún pedido, aún queremos que el pedido aparezca en la lista.

`clientes`
| cliente_id | nombre |
| ---------- | ------ |
| 1          | Juan   |
| 2          | María  |
| 3          | Pedro  |

`pedidos`
| pedido_id | cliente_id | producto |
| --------- | ---------- | -------- |
| 101       | 1          | Laptop   |
| 102       | 2          | Teléfono |
| 103       | NULL       | Tablet   |

**Consulta**
```sql
SELECT c.nombre, p.producto
FROM clientes c
RIGHT JOIN pedidos p
ON c.cliente_id = p.cliente_id;
```

**Salida**
| nombre | producto |
| ------ | -------- |
| Juan   | Laptop   |
| Juan   | Monitor  |
| NULL   | Tablet   |

## Análisis de la Consulta:
* El **RIGHT JOIN** garantiza que todos los pedidos aparezcan en el resultado, incluso aquellos que no tienen clientes asociados (como el pedido de la Tablet).

* Para los pedidos que no tienen registros en la tabla clientes, los valores para la columna nombre aparecerán como `NULL`.

## Diferencias entre RIGHT JOIN y LEFT JOIN
* **LEFT JOIN** devuelve todas las filas de la tabla izquierda (primera tabla) y las coincidencias de la tabla derecha, o NULL si no hay coincidencias.

* **RIGHT JOIN** devuelve todas las filas de la tabla derecha (segunda tabla) y las coincidencias de la tabla izquierda, o NULL si no hay coincidencias.

Ambos tipos de JOIN se usan para obtener resultados completos de una de las tablas, mientras que la otra tabla solo contribuye con datos coincidentes. En la práctica, puedes cambiar el orden de las tablas en un LEFT JOIN para lograr lo mismo que un RIGHT JOIN.

## ¿Cuándo utilizar RIGHT JOIN?
* **Datos incompletos en la tabla izquierda**: Cuando los datos de la tabla izquierda son opcionales, pero necesitas obtener todos los registros de la tabla derecha. Por ejemplo, cuando tienes una tabla de productos y deseas ver todos los pedidos, independientemente de si hay un cliente asociado o no.

* **Relaciones asimétricas**: Cuando la relación entre dos tablas es asimétrica y la tabla derecha contiene los datos más importantes.
