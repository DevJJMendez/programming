# `INNER JOIN`
El INNER JOIN es uno de los tipos más comunes de JOIN en SQL y se utiliza para combinar filas de dos o más tablas. El INNER JOIN devuelve solo las filas que tienen una coincidencia en ambas tablas involucradas en la consulta. En otras palabras, solo se obtendrán los registros donde las columnas de ambas tablas coinciden según la condición definida.

## ¿Para qué se utiliza el INNER JOIN?
El INNER JOIN se utiliza cuando deseas recuperar datos relacionados de múltiples tablas, pero solo para aquellas filas donde existe una relación válida entre ellas. Este tipo de JOIN es útil para:

* Relacionar tablas que tienen un vínculo a través de **claves primarias** y **claves foráneas**.

* Obtener información de varias tablas que comparten una relación de uno a uno o de uno a muchos.

## ¿Qué resuelve el INNER JOIN?
Resuelve el problema de combinar y recuperar datos distribuidos entre varias tablas que tienen relaciones lógicas definidas entre ellas, como relaciones de clave primaria a clave foránea. Permite evitar duplicación de datos y te ayuda a trabajar con bases de datos normalizadas.

Por ejemplo, si tienes una tabla de `empleados` y una tabla de `departamentos`, el **INNER JOIN** te permitirá extraer los datos de ambos, pero solo de los empleados que están asociados a un departamento.

## ¿Cómo lo resuelve el INNER JOIN?
El INNER JOIN realiza una comparación de los valores de las columnas entre las tablas implicadas en el JOIN. Solo se devuelven las filas en las que existe una coincidencia en los valores de las columnas especificadas en la cláusula `ON`.

## Sintaxis
```sql
SELECT column1, column2, ...
FROM table1
INNER JOIN table2
ON table1.column_name = table2.column_name;
```
* `SELECT column1, column2, ...`: Indica las columnas que deseas recuperar en el resultado.

* `FROM table1`: Especifica la tabla principal.

* `INNER JOIN table2`: Especifica la segunda tabla con la que se va a unir la primera tabla.

* `ON table1.column_name = table2.column_name`: Define la condición de combinación (la relación entre las columnas de ambas tablas).

## Ejemplo
Imaginemos que tienes dos tablas: `empleados` y `departamentos`. La tabla `empleados` contiene un campo `department_id` que se refiere a la clave primaria en la tabla `departamentos`. La consulta con un **INNER JOIN** podría ser:

```sql
SELECT empleados.first_name, empleados.last_name, departamentos.department_name
FROM empleados
INNER JOIN departamentos
ON empleados.department_id = departamentos.department_id;
```

# NESTED INNER JOINS
Un INNER JOIN anidado es un tipo de consulta en SQL donde se utilizan múltiples INNER JOINS para unir varias tablas. Básicamente, implica realizar múltiples uniones en una sola consulta, combinando más de dos tablas. Se denominan "anidados" porque las uniones se aplican de manera secuencial, con cada JOIN dependiendo del anterior.

## Sintaxis
```sql
SELECT t1.column1, t2.column2, t3.column3
FROM table1 t1
INNER JOIN table2 t2
ON t1.common_column = t2.common_column
INNER JOIN table3 t3
ON t2.common_column = t3.common_column;
```

## Ejemplo
```sql
SELECT e.first_name, d.department_name, p.project_name
FROM empleados e
INNER JOIN departamentos d
ON e.department_id = d.department_id
INNER JOIN proyectos p
ON e.empleado_id = p.empleado_id;
```
