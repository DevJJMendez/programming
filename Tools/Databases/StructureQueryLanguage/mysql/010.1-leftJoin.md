# `LEFT JOIN`
Un **LEFT JOIN** en SQL es un tipo de unión que devuelve todos los registros de la tabla a la izquierda (la "**tabla principal**"), junto con los registros coincidentes de la tabla a la derecha. Si no hay coincidencia, los valores de la tabla de la derecha aparecerán como `NULL`. La tabla izquierda es siempre la primera tabla listada en la consulta SQL.

## ¿Para qué se utiliza el LEFT JOIN?
El **LEFT JOIN** se utiliza para combinar datos de dos tablas, pero garantiza que todos los registros de la primera tabla (izquierda) se incluyan en el resultado, independientemente de si existe una coincidencia en la segunda tabla (derecha). Esto es útil cuando necesitas recuperar todos los datos de una tabla y solo los datos relacionados de otra, permitiendo que los datos no coincidentes en la tabla derecha se manejen como `NULL`.

## ¿Qué resuelve?
Resuelve el problema de querer obtener todos los datos de una tabla, pero solo aquellos que tienen coincidencias de una tabla relacionada. Es especialmente útil cuando deseas asegurarte de que los registros de la tabla principal no se pierdan, incluso si no hay datos correspondientes en la tabla secundaria.

## ¿Cómo lo resuelve?
Lo resuelve devolviendo:

* Todas las filas de la tabla izquierda (la primera mencionada en la consulta).

* Las filas coincidentes de la tabla derecha. Si no hay coincidencia, devuelve NULL para las columnas de la tabla derecha.

## Sintaxis
```sql
SELECT column1, column2, ...
FROM table1
LEFT JOIN table2
ON table1.column = table2.column;
```

## Ejemplo
Imaginemos que tenemos dos tablas: `clientes` y `pedidos`. Queremos obtener una lista de todos los clientes, y si han realizado pedidos, mostrar también la información del pedido. Si no han hecho ningún pedido, aún queremos que el cliente aparezca en la lista.

`clientes`
| cliente_id | nombre |
| ---------- | ------ |
| 1          | Juan   |
| 2          | María  |
| 3          | Pedro  |
| 4          | Ana    |

`pedidos`
| pedido_id | cliente_id | producto |
| --------- | ---------- | -------- |
| 101       | 1          | Laptop   |
| 102       | 2          | Teléfono |
| 103       | 1          | Monitor  |

**Consulta**
```sql
SELECT c.nombre, p.producto
FROM clientes c
LEFT JOIN pedidos p
ON c.cliente_id = p.cliente_id;
```

**Salida**
| nombre | producto |
| ------ | -------- |
| Juan   | Laptop   |
| Juan   | Monitor  |
| María  | Teléfono |
| Pedro  | NULL     |
| Ana    | NULL     |

**Análisis de la Consulta:**
* En este ejemplo, el **LEFT JOIN** garantiza que todos los clientes aparecen en el resultado, incluso aquellos que no tienen pedidos (como Pedro y Ana).

* Para los clientes que no tienen registros en la tabla pedidos, los valores para la columna producto aparecen como `NULL`.

## ¿Cuándo utilizar LEFT JOIN?
* **Datos incompletos**: Cuando una tabla contiene información que puede no estar presente en otra tabla. Por ejemplo, una lista de empleados y su historial de asistencia, donde algunos empleados pueden no tener registros de asistencia.

* **Informes completos**: Cuando necesitas un informe con todos los datos posibles de una tabla principal, y solo los datos relacionados (si existen) de una tabla secundaria.

* **Datos opcionales**: Cuando una relación entre tablas no es obligatoria. Por ejemplo, en una base de datos de productos, no todos los productos pueden estar asociados con un pedido, pero aún así necesitas listar todos los productos.

## Ventajas del LEFT JOIN
1. **Obtención completa de datos**: Garantiza que los datos de la tabla izquierda estén siempre presentes en los resultados, independientemente de las coincidencias en la tabla derecha.

2. **Manejo de datos faltantes**: Facilita la identificación de datos faltantes o incompletos en la tabla derecha (mostrando NULL cuando no hay coincidencias).

3. **Flexibilidad en consultas**: Permite manejar relaciones opcionales entre tablas, lo que es común en bases de datos grandes y complejas.
