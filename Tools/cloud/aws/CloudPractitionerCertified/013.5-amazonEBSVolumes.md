## Amazon EBS Volumes (EBS)
Es un servicio de almacenamiento en bloque proporcionado por AWS que permite a los usuarios crear y gestionar volúmenes de almacenamiento persistente para ser utilizados con instancias **Amazon EC2**. **EBS** es ideal para aplicaciones que requieren almacenamiento persistente, rápido y confiable, como bases de datos, sistemas de archivos, y aplicaciones que manejan grandes cantidades de datos.

### Características Principales de Amazon EBS:
1. **Almacenamiento Persistente**:
   
   * Los volúmenes de EBS son persistentes, lo que significa que los datos almacenados en un volumen de EBS se mantienen intactos incluso si la instancia EC2 asociada se detiene o se reinicia. Esto contrasta con el almacenamiento temporal (como los **Instance Store Volumes**) que se pierde cuando se detiene la instancia.

2. **Tipos de Volúmenes EBS**: Amazon EBS ofrece varios tipos de volúmenes diseñados para diferentes casos de uso:

     * **General Purpose SSD (gp3/gp2)**: Ofrece un equilibrio entre rendimiento y costo, ideal para la mayoría de las aplicaciones. Los volúmenes **gp3** permiten asignar **IOPS** y rendimiento de forma independiente del tamaño.

     * **Provisioned IOPS SSD (io2/io1)**: Diseñados para aplicaciones que requieren alto rendimiento y baja latencia, como bases de datos de misión crítica. Los volúmenes **io2** proporcionan alta durabilidad y confiabilidad.

     * **Throughput Optimized HDD (st1)**: Diseñados para cargas de trabajo que requieren un alto rendimiento de lectura/escritura secuencial, como grandes conjuntos de datos y sistemas de archivos distribuido.

     * **Cold HDD (sc1)**: Ideal para cargas de trabajo menos frecuentes que requieren almacenamiento a bajo costo, como datos de archivo.

3. **Escalabilidad y Flexibilidad**:

   * Puedes escalar el tamaño de los volúmenes, ajustar la capacidad de rendimiento (**IOPS**) y cambiar el tipo de volumen en cualquier momento sin detener las instancias asociadas, lo que permite una gran flexibilidad en la gestión de recursos.

4. **Alta Disponibilidad y Durabilidad**:

   * **EBS** replica automáticamente los datos en múltiples servidores dentro de la misma Availability Zone para garantizar la alta disponibilidad y durabilidad de los datos. Amazon EBS garantiza una durabilidad de 99.999% para los volúmenes.

5. **Snapshots y Backups**:
   
   * Los volúmenes EBS se pueden respaldar utilizando Snapshots, que son copias puntuales de los datos almacenados en un volumen EBS. Los Snapshots se almacenan en Amazon S3, proporcionando redundancia adicional y facilitando la creación de nuevos volúmenes EBS a partir de un Snapshot.

   * Los Snapshots son incrementales, lo que significa que solo se copian los bloques de datos que han cambiado desde el último Snapshot, optimizando así el uso del almacenamiento y los costos.

6. **Seguridad**:

   * **Encryption**: EBS ofrece cifrado de datos en reposo y en tránsito utilizando claves gestionadas por **AWS Key Management Service (KMS)**. Todo el tráfico entre la instancia EC2 y el volumen EBS también se cifra.

   * **Control de Acceso**: Utilizando **AWS IAM**, puedes definir políticas de control de acceso para restringir quién puede gestionar o acceder a los volúmenes y Snapshots de EBS.

6. **Integración con otros Servicios de AWS**:

   * EBS se integra perfectamente con otros servicios de AWS, como Amazon EC2, AWS Lambda, y Amazon RDS, permitiendo la utilización de volúmenes EBS en una amplia variedad de aplicaciones y cargas de trabajo.

7. **Desempeño**:

   * Los volúmenes EBS permiten ajustar el rendimiento (**IOPS**) según las necesidades de la aplicación. Los volúmenes io1 y io2, por ejemplo, permiten aprovisionar miles de IOPS, lo que los hace ideales para aplicaciones críticas de alto rendimiento.

8. **Precios y Facturación**:

   * Los costos de EBS se basan en el almacenamiento aprovisionado, el rendimiento de IOPS (para volúmenes io1/io2), y el uso de Snapshots. La capacidad de pagar solo por lo que se utiliza facilita la gestión de costos y el escalado según las necesidades del negocio.

### Escenarios de Uso de Amazon EBS:
1. **Bases de Datos Relacionales y NoSQL**:

   * EBS es ideal para bases de datos como MySQL, PostgreSQL, Oracle, y MongoDB, que requieren almacenamiento persistente de alto rendimiento.

2. **Aplicaciones de Misión Crítica**:

   * Las aplicaciones que requieren alta disponibilidad y durabilidad, como aplicaciones financieras y de salud, pueden beneficiarse de las características avanzadas de EBS, como los volúmenes io2.

3. **Sistemas de Archivos**:

   * EBS se puede utilizar para implementar sistemas de archivos persistentes para aplicaciones que requieren acceso rápido y confiable a grandes cantidades de datos.

4. **Entornos de Desarrollo y Pruebas**:

   * Al utilizar Snapshots, los desarrolladores pueden clonar entornos de desarrollo o pruebas rápidamente, mejorando la agilidad y la eficiencia.

### Consideraciones al Usar Amazon EBS:
1. **Selección del Tipo de Volumen**:

   * Es fundamental seleccionar el tipo de volumen EBS adecuado según la carga de trabajo. Por ejemplo, para bases de datos críticas, un volumen **io2** sería más adecuado, mientras que para datos de archivo, un volumen sc1 sería más rentable.

2. **Alcance de la Zona de Disponibilidad**:

   * Los volúmenes de EBS están vinculados a una **Availability Zone** específica. Para alta disponibilidad, considera replicar datos en varias zonas utilizando herramientas como AWS Elastic Disaster Recovery.

3. **Optimización de Costos**:

   * Monitorizar el uso de EBS y eliminar volúmenes no utilizados o Snapshots antiguos puede ayudar a optimizar costos. AWS Cost Explorer y AWS Trusted Advisor son herramientas útiles para esta tarea.

4. **Monitoreo y Alarmas**:

   * Utiliza Amazon CloudWatch para monitorizar el rendimiento de los volúmenes EBS y establecer alarmas basadas en umbrales de rendimiento para asegurar que las aplicaciones funcionen de manera óptima.
