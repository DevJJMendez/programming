## Licences
En AWS, la gestión de licencias es un aspecto crucial para garantizar el cumplimiento legal y optimizar los costos. AWS proporciona diversas opciones para administrar y utilizar licencias de software, ya sea mediante licencias incluidas en los servicios de AWS o mediante la reutilización de licencias existentes.

### Licencias Incluidas (License Included - LI)
En este modelo, AWS proporciona las licencias necesarias como parte del servicio. Los costos de las licencias están incluidos en las tarifas de uso del servicio.

- **Características**
  * Facilidad de Uso: No se necesita gestionar licencias por separado; todo está incluido en el servicio.

  * Pago por Uso: Se paga por las licencias en función del uso, sin necesidad de costos iniciales elevados.

  * Actualizaciones y Soporte: AWS se encarga de las actualizaciones y del soporte de las licencias.

- **Servicios Comunes**
  * Amazon RDS: Ofrece bases de datos gestionadas con licencias incluidas para motores de bases de datos como Microsoft SQL Server, Oracle, y PostgreSQL.

  * Amazon EC2: Instancias con software preinstalado, como Microsoft Windows Server y SQL Server, con licencias incluidas en el costo de la instancia.
  
- **Casos de Uso**
  * Ideal para empresas que prefieren no gestionar licencias por separado y desean una solución todo en uno.

  * Útil para escenarios donde se requiere flexibilidad y escalabilidad sin comprometerse con licencias a largo plazo.

### Traiga Su Propia Licencia (Bring Your Own License - BYOL)
El modelo BYOL permite a los clientes utilizar sus propias licencias de software en los servicios de AWS. Este modelo es útil para las organizaciones que ya han invertido en licencias y desean maximizar su uso en la nube.

- **Características**
  * Optimización de Costos: Permite reutilizar licencias existentes, optimizando la inversión en software.

  * Flexibilidad: Los clientes pueden aplicar sus propias políticas de licencia y gestión.

  * Compatibilidad: AWS proporciona herramientas y servicios para facilitar la implementación de licencias BYOL.

- Servicios Comunes
  Amazon EC2: Permite ejecutar instancias utilizando licencias propias para sistemas operativos y software como Windows Server, SQL Server, y Oracle.

  Amazon RDS: Soporta bases de datos gestionadas utilizando licencias BYOL para motores como Oracle y Microsoft SQL Server.

- **Casos de Uso**
  * Ideal para organizaciones con licencias existentes y acuerdos de licenciamiento corporativo.

  * Útil para entornos donde se requiere cumplir con políticas de licenciamiento específicas o contratos de software.

### AWS License Manager
AWS License Manager es una herramienta que ayuda a los clientes a gestionar sus licencias de software en AWS y en las instalaciones locales. Proporciona un control centralizado para definir, asignar y rastrear el uso de licencias.

- **Características**
  * Centralización: Permite gestionar todas las licencias desde un único lugar.

  * Cumplimiento: Ayuda a garantizar el cumplimiento de las políticas de licenciamiento mediante la automatización de la gestión de licencias.

  * Visibilidad: Proporciona informes y alertas sobre el uso de licencias, facilitando la auditoría y el control.

- **Funcionalidades**
  * Definición de Políticas: Permite crear reglas de licenciamiento para controlar el uso de licencias.

  * Asignación Automática: Asigna licencias automáticamente a recursos en función de las políticas definidas.

  * Rastreo y Reportes: Monitorea el uso de licencias y genera informes detallados para la gestión y auditoría.

- **Casos de Uso**
  * Ideal para organizaciones que desean simplificar y automatizar la gestión de licencias.

  * Útil para grandes empresas con múltiples acuerdos de licenciamiento y políticas complejas.
