## Key Pairs
Las Key Pairs (pares de claves) en Amazon EC2 son un mecanismo de seguridad que permite el acceso seguro a las instancias mediante autenticación basada en claves criptográficas. Un par de claves consta de una clave pública y una clave privada, que se utilizan para iniciar sesión en instancias de EC2 de manera segura, en lugar de utilizar contraseñas.

### ¿Cómo Funcionan las Key Pairs?
1. **Clave Pública**:

   * La clave pública se almacena en AWS y se asocia con la instancia de EC2 cuando la lanzas. Esta clave permite que solo aquellos que poseen la clave privada correspondiente puedan acceder a la instancia.

2. **Clave Privada**:

   * La clave privada es mantenida por el usuario. Es necesaria para descifrar la conexión y autenticar el acceso a la instancia de EC2. Se guarda localmente en tu máquina, y no debe compartirse o almacenarse de forma insegura.

### Proceso de Uso de Key Pairs en EC2
1. **Creación de un Par de Claves**:

   * Antes de lanzar una instancia de EC2, debes crear un par de claves si no tienes uno ya creado. Esto se puede hacer desde la consola de AWS, la CLI, o las API de EC2.

   * AWS te proporcionará la clave privada (en formato `.pem` o `.ppk` para **PuTTY**) en el momento de la creación, y esta es la única vez que puedes descargarla. Debes almacenarla de manera segura.

2. **Asociación de la Clave Pública**:

   * Al lanzar una instancia de EC2, seleccionas el par de claves que se asociará con esa instancia. AWS insertará la clave pública en la instancia.

3. **Conexión a la Instancia**:

   * Para iniciar sesión en la instancia de EC2 (generalmente usando SSH para instancias Linux o RDP para instancias Windows), utilizas la clave privada almacenada en tu máquina local. El software de SSH o RDP usará esta clave privada para autenticarte en la instancia.

4. **Seguridad de la Clave Privada**:

   * Es fundamental proteger la clave privada. Si la clave privada se pierde o se compromete, no podrás acceder a la instancia, y será necesario tomar medidas para recuperar o asegurar el acceso.

### Formatos de Key Pairs
* **`PEM`**:
  
  * Es el formato por defecto que Amazon EC2 proporciona al descargar una clave privada. Es un formato compatible con OpenSSH, que es comúnmente usado en sistemas Linux y macOS para conexiones SSH.

* **`PPK`**:

  * Es el formato de clave utilizado por PuTTY, un popular cliente SSH para Windows. Puedes convertir un archivo .pem a .ppk usando herramientas como PuTTYgen.

### Gestión de Claves en AWS
* **AWS Systems Manager**:

  * AWS ofrece herramientas como AWS Systems Manager para gestionar el acceso a instancias sin necesidad de distribuir claves privadas, mejorando la seguridad al reducir la exposición de claves.

* **Eliminar Pares de Claves**:

  * Si ya no necesitas un par de claves, es buena práctica eliminarlo desde la consola de AWS para mantener el entorno limpio y seguro.
## Casos de Uso
* **Acceso SSH a Instancias Linux**:

  * Utilizas la clave privada con un cliente SSH para acceder a instancias Linux.

* **Acceso RDP a Instancias Windows**:

  * Aunque las claves no son directamente usadas para RDP en Windows, las instancias de Windows pueden ser configuradas para utilizar autenticación basada en claves para mayor seguridad.
