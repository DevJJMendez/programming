## Elastic IP
Un Elastic IP en AWS es una dirección IP pública estática, diseñada para ser utilizada en instancias EC2 (o en otros recursos de AWS) para facilitar la gestión y disponibilidad de estas instancias. A diferencia de las direcciones IP dinámicas que se asignan a las instancias cuando se inician y pueden cambiar si la instancia se detiene o reinicia, una Elastic IP permanece constante, incluso si la instancia asociada se reinicia o se detiene.

### Características Clave de Elastic IP:
1. **Permanencia**:

   * Una Elastic IP es una dirección IP fija, lo que significa que no cambiará a menos que tú decidas liberarla o reasignarla a otro recurso. Esto es útil para servicios que requieren una dirección IP pública constante, como servidores web o aplicaciones críticas.

2. **Reasignable**:

   * Puedes reasignar una Elastic IP entre diferentes instancias EC2 en la misma región. Esto permite que una dirección IP pública permanezca constante incluso si la instancia subyacente debe cambiar por motivos de mantenimiento, recuperación de fallos, o actualizaciones.

3. **Costos Asociados**:

AWS cobra por el uso de Elastic IPs en ciertos casos:

   * Si no estás utilizando la Elastic IP con una instancia EC2 (es decir, está asignada pero no asociada), se te cobrará una tarifa por hora.

   * Si estás utilizando más de una Elastic IP por instancia EC2, AWS te cobrará por las direcciones adicionales.

Esto incentiva a los usuarios a utilizar Elastic IPs de manera eficiente y solo cuando es necesario.

4. **Integración con Route 53**:

   * Las Elastic IPs pueden ser integradas con **AWS Route 53**, el servicio de DNS de AWS, para configurar el enrutamiento de tráfico a tus instancias EC2.

5. **Altamente Disponible**:

   * En caso de un fallo en la instancia EC2, puedes reasignar rápidamente la Elastic IP a otra instancia, asegurando la continuidad del servicio. Esto es especialmente útil para configuraciones de alta disponibilidad y recuperación ante desastres.

6. **IPv4**:

   * Elastic IPs están limitadas a direcciones IPv4. AWS proporciona Elastic IPs solo en este formato debido a la compatibilidad y las limitaciones en la asignación de direcciones IPv6.

### Uso Típico de Elastic IP:
1. **Servicios Web**:

   * Para aplicaciones que requieren una dirección IP constante que los clientes necesitan para acceder, como un sitio web o una API, una Elastic IP asegura que la dirección IP no cambie, lo que podría romper la conectividad.

2. **Alta Disponibilidad**:

   * Si tienes configuraciones de alta disponibilidad, puedes utilizar Elastic IPs para cambiar rápidamente de una instancia fallida a una de respaldo, minimizando el tiempo de inactividad.

3. **Recuperación ante Desastres**:

   * En situaciones donde una instancia EC2 falla, puedes mover la Elastic IP a una nueva instancia, restaurando el servicio con la misma dirección IP pública.

4. **Transición de Recursos**:

   * Cuando se realizan actualizaciones o migraciones, una Elastic IP puede facilitar el proceso, permitiendo que el tráfico se redirija a una nueva instancia sin necesidad de cambiar configuraciones DNS.

### Ejemplo Práctico:
Imagina que tienes un servidor web crítico alojado en una instancia EC2 y este servidor está asociado con una Elastic IP. Si el servidor se detiene debido a un fallo, puedes iniciar una nueva instancia EC2 y reasignar la Elastic IP a esta nueva instancia. Los usuarios seguirán accediendo al servidor utilizando la misma dirección IP, sin interrupciones en el servicio.

### Consideraciones:
* **Uso Eficiente**: Dado que AWS cobra por las Elastic IPs que no están en uso, es importante liberar cualquier Elastic IP que no estés utilizando para evitar costos innecesarios.

* **Límites**: Hay un límite en el número de Elastic IPs que puedes asignar por región en tu cuenta de AWS. Si necesitas más, puedes solicitar un aumento a través del soporte de AWS.
