# Roadmap
1. Nivel 1: Fundamentos Sólidos
   * Conceptos internos de Git (cómo funciona realmente)
   * Flujo básico diario (add, commit, push, pull, fetch)
   * .gitignore profesional
   * Estados y ciclo de vida de los archivos
   * Buenas prácticas de commits (Conventional Commits)

2. Nivel 2: Ramificación y Colaboración
   * Estrategias de branching (GitHub Flow, Git Flow, Trunk-Based Development)
   * Merge vs Rebase (cuándo usar cada uno y por qué)
   * Pull Requests (PRs) avanzadas + Code Review
   * Forks, upstream, sincronización de repositorios

3. Nivel 3: Herramientas Avanzadas
   * Stash, cherry-pick, reflog, bisect
   * Interactive rebase y reescritura de historia
   * Tags y Releases (Semantic Versioning)
   * Submódulos y subárboles
   * Worktrees

4. Nivel 4: Entorno Profesional y DevOps
   * GitHub Actions + CI/CD
   * Branch Protection Rules, CODEOWNERS, required reviews
   * Monorepos vs Multi-repos (ventajas y desventajas)
   * Git LFS (Large File Storage)
   * Seguridad (git-secrets, signed commits, SSH vs HTTPS)
   * Hooks (pre-commit, pre-push)

5. Nivel 5: Arquitectura y Liderazgo
   * Diseñar flujos de trabajo para equipos grandes
   * Monorepo strategies (Nx, Turborepo, etc.)
   * Migraciones (SVN → Git, Perforce → Git)
   * Métricas de calidad en repositorios
   * Herramientas complementarias (GitHub CLI, lazygit, delta, etc.)
