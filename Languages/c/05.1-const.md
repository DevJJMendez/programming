## Constantes
En **C**, una constante es un valor **que no cambia durante la ejecución de un programa**, a diferencia de una variable, que puede modificarse a lo largo del código. Las constantes se utilizan para almacenar valores fijos que se conocen de antemano y que no deberían alterarse.

Las constantes ayudan a que el código sea más legible, mantenible y seguro, al evitar que ciertos valores sean modificados por error. Por ejemplo, valores como el número pi (π), los días de la semana o la cantidad máxima de elementos en una estructura de datos suelen ser constantes.

### Tipos de Constantes
1. **Constantes literales**: Son los valores fijos escritos directamente en el código. Por ejemplo, el número 10, el carácter 'A' o la cadena "Hola".

2. **Constantes simbólicas**: Son identificadores que representan valores fijos. Se definen utilizando la palabra clave `const` o las directivas de preprocesador `#define`.

### ¿Qué resuelven las Constantes?
1. **Evitan errores de modificación**: Al marcar un valor como constante, te aseguras de que no pueda cambiarse accidentalmente durante la ejecución del programa.

2. **Legibilidad del código**: Al usar nombres simbólicos para las constantes, es más fácil entender el propósito de un valor, en lugar de tener números mágicos (valores sin contexto) en el código.

3. **Facilitan la modificación**: Si necesitas cambiar el valor de una constante en todo el programa, solo debes modificarla en un único lugar, en lugar de buscar cada aparición del valor.

4. **Seguridad**: Las constantes protegen los datos críticos de ser alterados inadvertidamente.

### ¿Cómo se utilizan?
* Constantes literales: Son valores numéricos, caracteres o cadenas que se escriben directamente en el código:
```c
int x = 10;
char letra = 'A';
```

* **Constantes simbólicas con `#define`**: Se utilizan las directivas de preprocesador **#define** para crear constantes simbólicas, donde se establece una asociación entre un identificador y un valor constante:
```c
#define PI 3.1416
#define MAX_AGE 100
```
Estas constantes no tienen tipo, y el preprocesador sustituye directamente el identificador por el valor definido antes de compilar el programa.

Ejemplo de uso
```c
#include <stdio.h>

#define PI 3.1416
#define MAX_AGE  100

int main(){
  printf("valor de PI: %.2\n",PI);
  printf("Edad máxima: %d\n", MAX_AGE);
  return 0;
}
```

*  Constantes simbólicas con const
La palabra clave const define una variable cuyo valor no puede ser modificado después de ser asignado. A diferencia de #define, las constantes definidas con const tienen un tipo explícito y pueden ser utilizadas en operaciones y funciones:

```c
const int MAX_AGE = 100;
const float PI = 3.1416;
```

### ¿Cuándo se utilizan?
1. **Valores inmutables**: Se usan cuando tienes un valor que no debería cambiar durante la ejecución del programa, como límites, parámetros físicos o constantes matemáticas.

2. **Mejora de la legibilidad**: Usar constantes simbólicas mejora la claridad del código, ya que es más comprensible utilizar nombres descriptivos en lugar de valores numéricos arbitrarios (por ejemplo, PI en lugar de 3.14159).

3. **Mantenimiento del código**: Si necesitas cambiar el valor de una constante, solo necesitas hacerlo en una ubicación, lo cual es más eficiente y menos propenso a errores que modificar múltiples instancias del valor en el código.

4. **Protección de valores críticos**: Al usar const, proteges ciertos valores clave que no deben ser modificados, lo cual es fundamental en aplicaciones de seguridad, control y sistemas embebidos.

### Diferencias entre #define y const
* **Tipo**: `#define` no tiene un tipo de dato asociado, simplemente sustituye el identificador por su valor. `const`, en cambio, define una variable con un tipo explícito, lo que permite una mejor verificación en tiempo de compilación.

* **Alcance**: Las constantes definidas con #define son globales y tienen un alcance de preprocesador. Las constantes const respetan las reglas de alcance de las variables, pudiendo ser locales o globales.

* Depuración: Las constantes definidas con `const` son más fáciles de depurar, ya que tienen un tipo de dato y se integran mejor con las herramientas de depuración. Las constantes `#define` se reemplazan durante el preprocesamiento, por lo que no son visibles en tiempo de ejecución.
