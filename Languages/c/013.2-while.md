## `while`
El bucle **while** es una estructura de control en **C** que permite ejecutar repetidamente un bloque de código mientras una condición sea verdadera. A diferencia del bucle **for**, en el bucle **while** no se requiere la inicialización ni el incremento en la misma línea de la condición, lo que lo hace más flexible, pero también puede ser más propenso a errores si no se gestiona bien.

**Sintaxis**
```c
while (condición) {
    // Código a ejecutar mientras la condición sea verdadera
}
```
### Componentes del bucle while
1. **Condición**:

   * Es una expresión booleana que se evalúa antes de cada iteración del bucle.
   * Si la condición es verdadera, el bucle ejecuta el bloque de código.
   * Si es falsa, el bucle termina.
   * Ejemplo: `x < 10`

2. **Cuerpo del bucle**:

   * Es el bloque de código que se ejecuta en cada iteración, siempre que la condición sea verdadera.
   * Se encuentra entre las llaves `{}`.

### Flujo de ejecución del bucle while
1. **Condición**: Se evalúa antes de cada iteración.

2. **Cuerpo del bucle**: Si la condición es verdadera, se ejecuta el bloque de código dentro de las llaves.

3. **Repetición**: Después de ejecutar el cuerpo del bucle, la condición se evalúa nuevamente. Si sigue siendo verdadera, el bucle se repite; si es falsa, el bucle termina.

**Ejemplo**
```c
#include <stdio.h>

int main() {
    int i = 0; // Inicialización

    while (i < 5) { // Condición
        printf("Iteración %d\n", i);
        i++; // Incremento
    }
    return 0;
}
```

## `do while`
El bucle do...while es similar al bucle while, pero garantiza que el bloque de código se ejecutará al menos una vez, ya que la condición se evalúa después de ejecutar el bloque.

```c
#include <stdio.h>

int main() {
    int i = 0;

    do {
        printf("Iteración %d\n", i);
        i++;
    } while (i < 5);

    return 0;
}
```
