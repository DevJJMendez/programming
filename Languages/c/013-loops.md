## Bucles
Los bucles son una estructura de control de flujo en programación que permiten repetir un bloque de código varias veces mientras se cumpla una condición determinada. Se utilizan principalmente cuando necesitamos ejecutar repetidamente un conjunto de instrucciones, lo que ayuda a reducir la redundancia y optimizar el código.

### ¿Qué son los bucles?
Un bucle es una construcción que permite repetir un conjunto de operaciones hasta que una condición deja de cumplirse. Existen varios tipos de bucles en C, cada uno con características ligeramente diferentes, pero el objetivo es siempre el mismo: iterar sobre un bloque de código.

### ¿Qué resuelven los bucles?
* **Eficiencia**: Reducen la cantidad de código repetido. En lugar de escribir la misma instrucción varias veces, puedes escribirla una vez y ejecutarla múltiples veces.

* **Automatización**: Permiten realizar operaciones repetitivas, como recorrer listas o procesar datos masivos, de manera automática y dinámica.

* **Mantenimiento**: Al evitar la duplicación de código, los bucles hacen que el código sea más fácil de mantener y actualizar.

### ¿Cómo lo resuelven?
Los bucles iteran sobre un bloque de código de acuerdo a una condición lógica. Esta condición se evalúa al comienzo o al final de cada iteración, lo que determina si el bucle continúa o se detiene.

### ¿Cuándo se usan los bucles?
1. **Repetición conocida**: Usamos un bucle `for` cuando conocemos de antemano el número de veces que se debe ejecutar el código, como en la iteración sobre un arreglo o la ejecución de un bloque de código un número fijo de veces.

2. **Condición dinámica**: Utilizamos `while` o `do-while` cuando la condición para detener el bucle depende de un valor que cambia dinámicamente, como la lectura de datos hasta que se alcance un valor específico o se cumpla una condición.

* **Procesamiento de datos**: Se usan para recorrer listas, arreglos u otras estructuras de datos que contienen múltiples elementos.
