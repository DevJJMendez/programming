## `break`
La instrucción `break` se utiliza para salir inmediatamente de un bucle (`for`, `while`, `do...while`) o de un bloque switch. Cuando se encuentra un `break`, la ejecución del bucle o el bloque de código termina y el control del programa pasa a la siguiente línea fuera de ese bloque.

**Usos del break**
* Salir de un bucle cuando se cumple una condición específica.
* Detener la ejecución de un switch para evitar que continúe evaluando los otros casos.

**Ejemplo**
```c
#include <stdio.h>

int main() {
    int i;

    for (i = 0; i < 10; i++) {
        if (i == 5) {
            break;  // Salir del bucle cuando i es igual a 5
        }
        printf("i = %d\n", i);
    }

    printf("Se salió del bucle cuando i llegó a 5.\n");
    return 0;
}
```

## `continue`
La instrucción `continue` se utiliza para saltar a la siguiente iteración de un bucle. Es decir, cuando se encuentra un `continue` dentro de un bucle, el control salta inmediatamente a la siguiente iteración, omitiendo el resto del código que sigue en esa iteración actual.

**Ejemplo**
```c
#include <stdio.h>

int main() {
    int i;

    for (i = 0; i < 10; i++) {
        if (i == 5) {
            continue;  // Saltar la iteración cuando i es igual a 5
        }
        printf("i = %d\n", i);
    }

    return 0;
}
```
* Cuando `i` es igual a **5**, el `continue` hace que el bucle salte inmediatamente a la siguiente iteración sin ejecutar el `printf` para esa iteración en particular.
