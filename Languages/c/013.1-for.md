## `for`
El bucle for es una de las estructuras de control más utilizadas en C y en muchos otros lenguajes de programación. Permite ejecutar un bloque de código repetidamente, generalmente cuando se conoce de antemano cuántas veces debe iterar el ciclo.

**Sintaxis**
```c
for (inicializacion; condicion; actualizacion){
  // Código a ejecutar en cada iteración
}
```

### Componentes del bucle for
1. **Inicialización**:

   * Se ejecuta solo una vez, al inicio del bucle.

   * Se utiliza para inicializar variables de control que serán evaluadas en la condición.

   * **Ejemplo: `int i = 0;`**

2. **Condición**:

   * Es una expresión booleana (de tipo verdadero o falso) que se evalúa antes de cada iteración.

   * Si la condición es verdadera, el bucle sigue ejecutándose; si es falsa, el bucle se detiene.

   * Ejemplo: `i < 10;` (El bucle continuará mientras esta condición sea verdadera).

3. **Actualización (o incremento/decremento):**

   * Se ejecuta al final de cada iteración del bucle.

   * Es común usar una expresión que modifique el valor de la variable de control, para acercarse a la condición de parada.

   * Ejemplo: `i++` (incrementa `i` en **1** en cada iteración).

4. **Cuerpo del bucle:**

   * Es el bloque de código que se ejecuta en cada iteración, siempre que la condición sea verdadera.

   * Se encuentra entre las llaves `{}`.

**Ejemplo**
```c
int main() {
    for (int i = 0; i < 5; i++) {
        printf("Iteración %d\n", i);
    }
    return 0;
}
```

## Variantes del bucle for
1. **Bucle for sin inicialización**: La parte de inicialización es opcional. Puedes inicializar variables antes del bucle si lo deseas.

    ```c
    int i = 0;
    for (; i < 5; i++) {
        printf("Valor de i: %d\n", i);
    }
    ```

2. **Bucle for sin condición**: Si omites la condición, el bucle se considerará infinito, ya que no hay una condición para detenerlo.

    ```c
    for (int i = 0;; i++) {
        printf("Valor de i: %d\n", i);
        if (i == 5) break;  // Salir del bucle manualmente
    }
    ```

3. **Bucle for sin actualización**: Puedes omitir la actualización e implementarla dentro del cuerpo del bucle.

    ```c
    for (int i = 0; i < 5;) {
        printf("Valor de i: %d\n", i);
        i++;  // Actualización manual dentro del cuerpo
    }
    ```

4. **Bucle for infinito**: Si omites tanto la condición como la actualización, el bucle será infinito.

    ```c
    for (;;) {
        printf("Bucle infinito\n");
        break;  // Necesario para evitar un bucle infinito real
    }
    ```

## Anidación de bucles `for`
Es posible tener bucles **for** dentro de otros bucles **for**. Esto es útil para trabajar con estructuras de datos como matrices multidimensionales.

Ejemplo de bucles anidados para imprimir una tabla de multiplicar:
```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 10; i++) {
        for (int j = 1; j <= 10; j++) {
            printf("%d * %d = %d\t", i, j, i * j);
        }
        printf("\n");
    }
    return 0;
}
```
