# Array
La clase Array es una de las clases fundamentales en C# que pertenece al espacio de nombres System. En C#, los arrays son una estructura de datos que permiten almacenar múltiples valores de un mismo tipo en una única variable. Los arrays pueden ser unidimensionales (como una lista de elementos) o multidimensionales (como una matriz de valores). La clase Array proporciona métodos y propiedades útiles para manipular arrays.

1. ¿Qué es la clase Array en C#?
La clase Array es una clase estática que proporciona funcionalidades avanzadas para trabajar con arrays en C#. Un array es un conjunto de elementos de un mismo tipo almacenados en ubicaciones contiguas de memoria. Los arrays pueden tener una longitud fija una vez que se definen.

En C#, un array tiene una longitud (el número de elementos que puede almacenar) y un tipo específico (como int, string, double, etc.).

Ejemplo básico de declaración de un array:
```c#
int[] numeros = new int[5];  // Array de 5 enteros
```
Inicialización de un array con valores:
```c#
int[] numeros = { 1, 2, 3, 4, 5 };  // Array con 5 elementos
```

¿Para qué sirve la clase Array en C#?
La clase Array proporciona métodos y propiedades que permiten gestionar arrays de manera eficiente. Algunos de los principales usos incluyen:

Almacenar colecciones de datos: Un array te permite almacenar una colección de datos relacionados del mismo tipo.
Acceder a elementos por índice: Los arrays permiten acceder a los elementos mediante un índice, lo que facilita la manipulación y consulta de datos.
Operaciones avanzadas sobre colecciones: Con los métodos proporcionados por la clase Array, puedes realizar operaciones como ordenación, búsqueda y manipulación de elementos en arrays.
3. ¿Qué resuelve la clase Array?
La clase Array resuelve varios problemas relacionados con la manipulación de colecciones de elementos. Entre los problemas que resuelve están:

Manejo de colecciones fijas de datos: Los arrays permiten almacenar elementos de forma eficiente, sin necesidad de utilizar clases adicionales para gestionar los datos.
Acceso rápido y directo a elementos: Gracias a su estructura de datos contiguos, puedes acceder a cualquier elemento de un array de forma rápida mediante su índice.
Manipulación y ordenación de colecciones: La clase Array proporciona métodos para ordenar, buscar, copiar y modificar los elementos del array.
Uso de arrays multidimensionales: Para representar datos en estructuras más complejas (como matrices o tablas), puedes usar arrays multidimensionales.
4. ¿Cómo lo resuelve?
La clase Array resuelve estos problemas proporcionando varias propiedades y métodos útiles que permiten manipular arrays de manera eficiente. A continuación, te explico cómo se resuelven ciertos problemas comunes:

a) Propiedades de la clase Array
Length: Devuelve el número total de elementos en un array (independientemente de sus dimensiones).
```c#
int[] numeros = { 1, 2, 3, 4, 5 };
Console.WriteLine(numeros.Length);  // Imprime 5
```

Rank: Devuelve el número de dimensiones de un array (1 para arrays unidimensionales, 2 para bidimensionales, etc.).
```c#
int[,] matriz = new int[3, 3];
Console.WriteLine(matriz.Rank);  // Imprime 2, ya que es una matriz de 2 dimensiones
```

GetUpperBound(dimension): Devuelve el índice más alto de un array en la dimensión especificada.
```c#
int[] numeros = { 1, 2, 3 };
Console.WriteLine(numeros.GetUpperBound(0));  // Imprime 2, el índice más alto de un array unidimensional
```

## Métodos estáticos de la clase Array
Sort: Ordena los elementos del array. El método puede ordenar arrays de cualquier tipo que implemente la interfaz IComparable.
```c#
int[] numeros = { 5, 2, 8, 1, 4 };
Array.Sort(numeros);  // Ordena los números de menor a mayor
foreach (var num in numeros)
    Console.WriteLine(num);  // Imprime 1, 2, 4, 5, 8
```

Reverse: Invierte los elementos de un array.
```c#
int[] numeros = { 1, 2, 3, 4, 5 };
Array.Reverse(numeros);  // Invierte el orden de los números
foreach (var num in numeros)
    Console.WriteLine(num);  // Imprime 5, 4, 3, 2, 1
```

Copy: Copia un rango de elementos de un array a otro.
```c#
int[] numeros = { 1, 2, 3, 4, 5 };
int[] copia = new int[5];
Array.Copy(numeros, copia, 5);  // Copia todos los elementos de 'numeros' a 'copia'
```

IndexOf: Busca un elemento en el array y devuelve el índice de la primera aparición de dicho elemento.
```c#
int[] numeros = { 1, 2, 3, 4, 5 };
int index = Array.IndexOf(numeros, 3);  // Devuelve el índice de 3 en el array (2)
Console.WriteLine(index);  // Imprime 2
```

Clear: Establece los elementos de un array a su valor predeterminado (como 0 para números, false para booleanos, null para referencias, etc.).
```C#
int[] numeros = { 1, 2, 3, 4, 5 };
Array.Clear(numeros, 0, 3);  // Establece los primeros tres elementos a 0
foreach (var num in numeros)
    Console.WriteLine(num);  // Imprime 0, 0, 0, 4, 5
```

Find: Busca un elemento en el array según un predicado.
```c#
int[] numeros = { 1, 2, 3, 4, 5 };
int resultado = Array.Find(numeros, x => x > 3);  // Devuelve el primer número mayor que 3 (4)
Console.WriteLine(resultado);  // Imprime 4
```

Clone: Crea una copia superficial de un array.
```c#
int[] numeros = { 1, 2, 3, 4, 5 };
int[] copia = (int[])numeros.Clone();  // Clona el array
```

# Arrays multidimensionales
La clase Array permite trabajar con arrays multidimensionales (matrices). Los arrays multidimensionales permiten representar tablas de datos, imágenes, etc.

```c#
int[,] matriz = new int[3, 3];  // Matriz de 3x3
matriz[0, 0] = 1;
matriz[0, 1] = 2;
matriz[0, 2] = 3;
matriz[1, 0] = 4;
matriz[1, 1] = 5;
matriz[1, 2] = 6;
matriz[2, 0] = 7;
matriz[2, 1] = 8;
matriz[2, 2] = 9;

for (int i = 0; i < matriz.GetLength(0); i++)  // GetLength(0) devuelve el número de filas
{
    for (int j = 0; j < matriz.GetLength(1); j++)  // GetLength(1) devuelve el número de columnas
    {
        Console.Write(matriz[i, j] + " ");
    }
    Console.WriteLine();
}
```
