# Argumentos de Línea de Comandos
Los argumentos de línea de comandos son valores o parámetros que el usuario puede proporcionar al ejecutar un programa desde una terminal o consola. Estos argumentos permiten personalizar el comportamiento del programa sin necesidad de modificar el código fuente. En C#, los argumentos se reciben en el método Main a través del parámetro string[] args.

## ¿Qué son los argumentos de línea de comandos?
Los argumentos de línea de comandos son datos que se pasan al ejecutar un programa, generalmente desde la consola o terminal. Estos se proporcionan después del nombre del ejecutable del programa y son separados por espacios.

Por ejemplo, si ejecutamos un programa en la terminal de esta forma:
```bash
dotnet run parametro1 parametro2 --flag
```
Los tres elementos (parametro1, parametro2, --flag) son argumentos que se pasan al programa. El programa puede usar estos valores para modificar su comportamiento, como leer un archivo, cambiar una configuración, o realizar una acción específica.

## ¿Para qué sirven los argumentos de línea de comandos?
Los argumentos de línea de comandos permiten que un programa:

* Personalice su comportamiento en tiempo de ejecución: Los usuarios pueden pasar datos a la aplicación sin necesidad de modificar su código.

* Interacción con el usuario: Permiten que el usuario influya en el comportamiento del programa sin tener que modificar archivos de configuración.

* Automatización y scriptización: Permiten automatizar tareas, ejecutando el programa con diferentes parámetros desde scripts o en entornos de producción.

* Mayor flexibilidad y reutilización: Puedes usar el mismo programa con diferentes entradas para realizar tareas distintas, sin tener que crear múltiples versiones del mismo.

## ¿Qué resuelven los argumentos de línea de comandos?
Los argumentos resuelven varios problemas prácticos al permitir que la entrada de datos no dependa del código fuente o de configuraciones fijas. Esto es útil en escenarios como:

* Configuraciones dinámicas: Sin modificar el código, puedes cambiar el comportamiento del programa según el entorno o el contexto de ejecución.

* Interacción sin interfaz gráfica: En entornos donde no se dispone de una interfaz gráfica (como servidores o scripts), los argumentos de línea de comandos proporcionan una forma de recibir parámetros y valores.

* Automatización: En escenarios de automatización o scripts, se pueden pasar parámetros para personalizar el comportamiento del programa y hacer que realice tareas específicas, como generar informes o procesar datos.

## ¿Cómo resuelven los argumentos de línea de comandos estos problemas?
Los argumentos de línea de comandos resuelven estos problemas al permitir que el programa reciba entradas desde el sistema operativo o el entorno de ejecución de manera flexible y dinámica. En lugar de hacer que el usuario interactúe con una interfaz gráfica o modifique archivos de configuración estáticos, el programa puede actuar sobre los valores proporcionados al ejecutarse.

**Implementación en C#**: En C#, los argumentos de línea de comandos se reciben en el método Main a través del parámetro string[] args. Este parámetro es un arreglo de cadenas que contiene todos los valores proporcionados en la línea de comandos.

Ejemplo básico:
```c#
using System;

class Program
{
    static void Main(string[] args)
    {
        // Verifica si se pasaron argumentos
        if (args.Length > 0)
        {
            Console.WriteLine("Argumentos recibidos:");
            foreach (var arg in args)
            {
                Console.WriteLine(arg);
            }
        }
        else
        {
            Console.WriteLine("No se pasaron argumentos.");
        }
    }
}
```
Salida esperada:
Si ejecutamos el programa con los siguientes argumentos:
```bash
dotnet run argumento1 argumento2 --flag
```
La salida será:
```bash
Argumentos recibidos:
argumento1
argumento2
--flag
```

## Tipos de Argumentos de Línea de Comandos
Los argumentos se pueden dividir en diferentes tipos según el uso:

Posicionales: Son los argumentos que el programa recibe en un orden específico. Su valor es importante según el índice en el que se encuentren.

Ejemplo:
```bash
dotnet run archivo1.txt archivo2.txt
```
Aquí, archivo1.txt y archivo2.txt son argumentos posicionales, y su orden importa.

2. Opcionales (con banderas): Son argumentos que no requieren un valor y se usan para activar o desactivar características del programa.

Ejemplo
```bash
dotnet run --verbose --debug
```
Las banderas --verbose y --debug son opcionales, y pueden activarse o desactivarse sin necesidad de un valor asociado.

3. Con valor asociado: Algunos argumentos requieren un valor explícito.

Ejemplo:
```bash
dotnet run --input archivo1.txt --output archivo2.txt
```

## Manejo de Argumentos Avanzado:
A veces, en aplicaciones más complejas, se pueden usar bibliotecas para gestionar los argumentos de manera más robusta, ya que los usuarios pueden pasarlos de muchas formas, como parámetros opcionales, valores predeterminados, etc.

Una biblioteca popular es CommandLineParser, que permite gestionar los argumentos de línea de comandos de manera más estructurada.

Ejemplo con CommandLineParser:
Primero, necesitas instalar la biblioteca desde NuGet:

```bash
dotnet add package CommandLineParser
```
Luego, puedes usarla de la siguiente forma:
```c#
using CommandLine;

class Options
{
    [Option('i', "input", Required = true, HelpText = "Archivo de entrada")]
    public string Input { get; set; }

    [Option('o', "output", Required = true, HelpText = "Archivo de salida")]
    public string Output { get; set; }

    [Option('v', "verbose", HelpText = "Modo verbose")]
    public bool Verbose { get; set; }
}

class Program
{
    static void Main(string[] args)
    {
        Parser.Default.ParseArguments<Options>(args)
            .WithParsed(options =>
            {
                Console.WriteLine($"Entrada: {options.Input}");
                Console.WriteLine($"Salida: {options.Output}");
                Console.WriteLine($"Verbose: {options.Verbose}");
            })
            .WithNotParsed(errors =>
            {
                Console.WriteLine("Error al procesar los argumentos.");
            });
    }
}
```
Uso en la consola:
```bash
dotnet run --input archivo1.txt --output archivo2.txt --verbose
```
En este caso, la biblioteca CommandLineParser facilita el análisis y la validación de los argumentos, permitiendo especificar detalles como si un argumento es requerido o si es opcional.

## Beneficios de Usar Argumentos de Línea de Comandos:
* Flexibilidad: Permite que el mismo programa se ejecute de diferentes maneras según los parámetros que se pasen al iniciar.

* Automatización: Puedes automatizar la ejecución del programa, pasarle parámetros desde scripts o herramientas de automatización.

* Facilidad de uso en entornos de servidor o contenedor: Los servidores y contenedores suelen carecer de interfaces gráficas, por lo que los argumentos de línea de comandos son cruciales para interactuar con el programa.

* Configuración rápida: Puedes cambiar rápidamente el comportamiento de tu programa sin modificar el código ni la configuración interna.
