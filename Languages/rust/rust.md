# Rust
Rust es un lenguaje de programación de sistemas moderno, desarrollado por Mozilla Research. Su foco principal es:

* Seguridad (sobre todo seguridad de memoria)

* Performance brutal (nivel `C`/`C++` sin explotar todo)

* Concurrencia eficiente (¡sin miedo a los hilos!)

Es decir: **un `C++` moderno que no se dispara en el pie.**
