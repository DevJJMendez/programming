# Operadores logicos

Los operadores lógicos en PHP se utilizan para combinar o evaluar expresiones lógicas y devuelven un valor booleano (true o false) según el resultado de la operación. Los operadores lógicos son fundamentales para controlar el flujo de un programa y para tomar decisiones basadas en condiciones

---

- Y lógico (AND)(&&)

El operador AND o && devuelve true si ambas expresiones a su izquierda y derecha son verdaderas.

```php
$a = true;
$b = false;
$resultado = ($a && $b); // $resultado contendrá false
```
---
- O lógico (OR) ( | | )

El operador OR o | | devuelve true si al menos una de las expresiones a su izquierda o derecha es verdadera.
```php
$a = true;
$b = false;
$resultado = ($a || $b); // $resultado contendrá true
```
---
- No lógico (NOT) (!)

El operador NOT o ! invierte el valor de una expresión, convirtiendo true en false y false en true.
```php
$a = true;
$resultado = !$a; // $resultado contendrá false
```
---
- XOR lógico (^): El operador XOR devuelve true si exactamente una de las expresiones a su izquierda o derecha es verdadera, pero no ambas.

```php
$a = true;
$b = false;
$resultado = ($a ^ $b); // $resultado contendrá true
```
---
Estos operadores lógicos te permiten combinar condiciones y expresiones lógicas para tomar decisiones en tu código. Puedes utilizar paréntesis para controlar el orden de evaluación si tienes expresiones más complejas.

Por ejemplo, puedes utilizar operadores lógicos en una estructura if para tomar decisiones basadas en múltiples condiciones:

```php
$edad = 25;
$esEstudiante = false;

if (($edad >= 18 && $edad <= 30) || $esEstudiante) {
    echo "Eres un joven adulto o un estudiante.";
} else {
    echo "No eres un joven adulto ni un estudiante.";
}
```
