# Operadores relacionales

Los operadores relacionales en PHP se utilizan para comparar valores y expresiones, y devuelven un valor booleano (true o false) que indica si la comparación es verdadera o falsa. Estos operadores son fundamentales para las estructuras de control de flujo, como las sentencias if, else, while, for, entre otras.

---

- igual (==)

Compara si dos valores son iguales, sin importar su tipo. 

```php
$a = 5;
$b = "5";
$resultado = ($a == $b); // $resultado contendrá true
```

---

- Idéntico (===)

Compara si dos valores son iguales y del mismo tipo.
```php
$a = 5;
$b = "5";
$resultado = ($a === $b); // $resultado contendrá false
```

---

- Diferente (!=) o No igual (<>)

Compara si dos valores no son iguales, sin importar su tipo.
```php
$a = 5;
$b = "10";
$resultado = ($a != $b); // $resultado contendrá true
```

---

- Mayor que (>)

Compara si un valor es mayor que otro. 
```php
$a = 10;
$b = 5;
$resultado = ($a > $b); // $resultado contendrá true
```

---

- Menor que (<)

Compara si un valor es menor que otro.
```php
$a = 3;
$b = 7;
$resultado = ($a < $b); // $resultado contendrá true
```

---

- Mayor o igual que (>=)

Compara si un valor es mayor o igual que otro. 
```php
$a = 10;
$b = 10;
$resultado = ($a >= $b); // $resultado contendrá true
```

---

- Menor o igual que (<=)

Compara si un valor es menor o igual que otro. 
```php
$a = 3;
$b = 3;
$resultado = ($a <= $b); // $resultado contendrá true
```
---

- Operador Ternario

Es una forma concisa de expresar una condición y devolver un valor en función de si esa condición es verdadera o falsa. 

Sintaxis:

```php
(condición) ? valor_si_verdadero : valor_si_falso;
```

- condición: Es la expresión que se evalúa como verdadera o falsa.

- valor_si_verdadero: Es el valor que se devuelve si la condición es verdadera.

- valor_si_falso: Es el valor que se devuelve si la condición es falsa.

Ejemplo:

```php
$numero = 10;
$esPar = ($numero % 2 == 0) ? "Es par" : "Es impar";
echo $esPar;
```
---

Estos operadores relacionales te permiten realizar comparaciones entre valores y tomar decisiones en función de esas comparaciones en tus programas PHP. Pueden utilizarse en condiciones if, while, for, y otras estructuras de control para controlar el flujo de ejecución de tu código en función de las relaciones entre los valores.
