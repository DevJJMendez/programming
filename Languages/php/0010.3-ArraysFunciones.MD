# Array Funciones

## Busqueda y Ordenamiento

- `in_array(valor, array)`: Verifica si un valor existe en el array.

**Sintaxis**:
```php
in_array(valor, array, estricto)
```
   - **valor**: El valor que se está buscando en el array.

   - **array**: El array en el que se está buscando el valor.

   - **estricto**: (Opcional) Si se establece en true, la función también comprobará el tipo de dato de los elementos en el array. Por defecto, se establece en false.

Ejemplo sin usar _estricto_:
```php
<?php

$miArray = [1, 2, 3, 4, 5];

// Verificar si el valor 3 está presente en el array
if (in_array(3, $miArray)) {
    echo "El valor 3 está presente en el array.";
} else {
    echo "El valor 3 no está presente en el array.";
}
?>
```
En este ejemplo, tenemos un array llamado `$miArray` con los valores [1, 2, 3, 4, 5]. Utilizamos `in_array()` para verificar si el valor 3 está presente en el array.

salida por consola:
```yaml
El valor 3 está presente en el array.
```
Ejemplo usando _estricto_:
```php
<?php

$miArray = [1, 2, 3, 4, 5];

// Verificar si el valor '3' está presente en el array utilizando estricto
if (in_array('3', $miArray, true)) {
    echo "El valor '3' está presente en el array.";
} else {
    echo "El valor '3' no está presente en el array.";
}
?>
```
salida por consola:
```yaml
El valor '3' no está presente en el array.
```
`in_array()` devuelve true si el valor está presente en el array y false si no lo está. Puedes utilizar esta función para realizar verificaciones de pertenencia en tus scripts PHP.

---

- `array_search(valor, array)`: se utiliza para buscar un valor en un array y devolver la primera clave asociada a ese valor.

Sintaxis:
```php
array_search(valor, array, estricto)
```
Ejemplo:
```php
<?php
$miArray = ["a" => 1, "b" => 2, "c" => 3, "d" => 4, "e" => 5];

// Buscar la clave asociada al valor 3 en el array
$clave = array_search(3, $miArray);

if ($clave !== false) {
    echo "El valor 3 está en la clave '$clave' del array.";
} else {
    echo "El valor 3 no está presente en el array.";
}
?>
```
En este ejemplo, tenemos un array asociativo llamado $miArray. Utilizamos array_search() para buscar la clave asociada al valor 3. Si el valor está presente en el array, la función devuelve la clave; de lo contrario, devuelve false.

salida por consola:
```yaml
El valor 3 está en la clave 'c' del array.
```
Ejemplo usando _estricto_

```php
<?php
$miArray = ["a" => 1, "b" => 2, "c" => 3, "d" => 4, "e" => 5];

// Buscar la clave asociada al valor '3' en el array utilizando estricto
$clave = array_search('3', $miArray, true);

if ($clave !== false) {
    echo "El valor '3' está en la clave '$clave' del array.";
} else {
    echo "El valor '3' no está presente en el array.";
}
?>
```
salida por consola:
```yaml
El valor '3' no está presente en el array.
```
`array_search()` es útil cuando necesitas encontrar la clave asociada a un valor específico en un array.

- `sort(array)`: Ordena un array en orden ascendente.

Sintaxis:
```php
sort(array, tipo_orden)
```
- **array**: El array que deseas ordenar.

- **tipo_orden**: (Opcional) Puede ser `SORT_REGULAR`, `SORT_NUMERIC`, `SORT_STRING`, SORT_LOCALE_STRING o `SORT_NATURAL`. Por defecto, es `SORT_REGULAR`.

Ejemplo:
```php
<?php
$miArray = [4, 2, 8, 1, 6];

// Ordenar el array en orden ascendente
sort($miArray);


print_r($miArray);
?>
```
salida por consola:
```yaml
Array
(
    [0] => 1
    [1] => 2
    [2] => 4
    [3] => 6
    [4] => 8
)
```
---
- `rsort(array)`: Ordena un array en orden descendente.

Sintaxis:
```php
rsort(array, tipo_orden)
```
Ejemplo:
```php
<?php
$miArray = [4, 2, 8, 1, 6];

// Ordenar el array en orden descendente
rsort($miArray);


print_r($miArray);
?>
```
salida por consola:
```yaml
Array
(
    [0] => 8
    [1] => 6
    [2] => 4
    [3] => 2
    [4] => 1
)
```
