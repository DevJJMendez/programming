# Tipos de datos primitivos

Estos son los tipos de datos fundamentales que forman la base de la programación. 

PHP es un lenguaje de programación dinámico que admite una variedad de tipos de datos. 

---

- **Enteros (int)**

    Representan números enteros, ya sean positivos o negativos. 

    ```php
    $edad = 30;
    $cantidad = -10;
    ```

- **Números de punto flotante (float)**

    Representan números con decimales.

    ```php
    $precio = 19.99;
    $pi = 3.14159265359;
    ```

- **Cadenas de texto (string)**

    Representan texto. Pueden estar encerradas en comillas simples o dobles. 

    ```php
    $nombre = "Juan";
    $mensaje = 'Hola, soy una cadena de texto.';
    ```

- **Booleanos (bool)**

    Representan valores de verdadero (true) o falso (false).

    ```php
    $activo = true;
    $esMayorDeEdad = false;
    ```

- **NULL**

    Representa la ausencia de un valor. Puedes asignar null a una variable para indicar que no contiene ningún valor.

    ```php
    $nulo = null;
    ```
