# `PDO`

`PDO` significa `PHP Data Objects`, y es una extensión de `PHP` que proporciona una interfaz orientada a objetos para trabajar con bases de datos. Esta extensión permite a los desarrolladores interactuar con diversas bases de datos utilizando un conjunto común de métodos, independientemente del tipo de base de datos que estén utilizando.

## Características principales de PDO:

- **Soporte para múltiples bases de datos**: PDO proporciona una capa de abstracción que permite trabajar con diferentes sistemas de gestión de bases de datos (DBMS) como MySQL, PostgreSQL, SQLite, SQL Server, Oracle, entre otros. Esto significa que puedes cambiar entre diferentes bases de datos simplemente modificando la cadena de conexión, sin tener que reescribir todo el código de acceso a la base de datos.

- **Preparación de consultas y prevención de inyección SQL**: PDO admite consultas preparadas, lo que ayuda a prevenir ataques de inyección SQL al permitir la separación de los datos de la consulta SQL. Esto aumenta la seguridad de las consultas a la base de datos.

- **Manejo de errores con excepciones**: PDO admite el manejo de errores a través de excepciones, lo que facilita el control de situaciones excepcionales o errores relacionados con la base de datos.

- **Interfaz orientada a objetos**: Ofrece una interfaz orientada a objetos para trabajar con bases de datos en PHP, lo que hace que el código sea más legible, mantenible y reutilizable.

## Ejemplo de conexión usando PDO:
```php
$servername = "localhost";
$username = "usuario_db";
$password = "contraseña_db";
$dbname = "nombre_base_de_datos";

try {

    $conection = new PDO("mysql:host=$servername;dbname=$dbname", $username, $password);

    // Configurar el modo de error para que lance excepciones en caso de error

    $conection->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

    echo "Conexión exitosa";

} catch(PDOException $e) {
    
    die("Conexión fallida: " . $e->getMessage());
}
```
