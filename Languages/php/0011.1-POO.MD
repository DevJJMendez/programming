- **Abstracción**

Es un concepto fundamental en la programación orientada a objetos (POO) que se centra en la creación de modelos simplificados y abstractos de la realidad.

---

- **Clases**

Para definir una clase en PHP, puedes utilizar la palabra clave `class`. Una clase es como un plano para crear objetos. Contiene propiedades y métodos.

```php
class Persona {
    
}
```

---
- **Propiedades**

Las propiedades son variables que pertenecen a un objeto. Pueden ser públicas (accesibles desde fuera de la clase), privadas (accesibles solo desde dentro de la clase) o protegidas (accesibles dentro de la clase y sus subclases).
```php
class Persona {
    public $nombre;
    public $edad;
}
```
---

- **Creación de Objetos**

Una vez que has definido una clase, puedes crear objetos a partir de esa clase utilizando la palabra clave new.
```php
$juan = new Persona();
$juan->nombre = "Juan";
$juan->edad = 30;

echo $juan->nombre;
```

---

- **Métodos**

Los métodos son funciones que pertenecen a un objeto. Al igual que las propiedades, pueden ser públicos, privados o protegidos.
```php
class Persona {

    public function saludar() {
        echo "Hola, soy una persona.";
    }
}

```

---
- **Constructor**
El método constructor se llama automáticamente cuando se crea un objeto. Es útil para inicializar propiedades u realizar tareas de configuración.
```php
class Persona {
    public function __construct($nombre, $edad) {
        
        $this->nombre = $nombre;
        $this->edad = $edad;
    }
}
```
---
- **Destructor**
El método destructor se llama automáticamente cuando un objeto es destruido (por ejemplo, al finalizar el script). Puedes utilizarlo para realizar tareas de limpieza.
```php
class Persona {
    public function __destruct() {

        echo "Adiós, {$this->nombre} ha sido destruido.";
    }
}
```
---
- **Herencia**

La herencia permite que una clase herede propiedades y métodos de otra clase. En PHP, se utiliza la palabra clave `extends` para establecer la herencia.
```php
class Estudiante extends Persona {
    public $curso;

    public function estudiar() {

        echo "{$this->nombre} está estudiando en el curso de {$this->curso}.";
    }
}
```

---

- **Polimorfismo**

Es otro principio fundamental de la programación orientada a objetos (POO) que permite que objetos de diferentes clases respondan a la misma interfaz de manera diferente.

En PHP, el polimorfismo se manifiesta a través de métodos y clases que pueden tener múltiples formas. Hay dos tipos principales de polimorfismo: el polimorfismo de sobrecarga y el polimorfismo de sobreescritura.

- **Polimorfismo de Sobrecarga**:

La sobrecarga de métodos en PHP se refiere a la capacidad de una clase de proporcionar varios métodos con el mismo nombre pero con diferentes parámetros. Sin embargo, a diferencia de algunos lenguajes de programación, PHP no permite la sobrecarga de métodos de manera directa. Se puede simular utilizando argumentos opcionales y valores predeterminados.
```php
class Calculadora {
    public function sumar($a, $b) {
        return $a + $b;
    }

    public function sumarTres($a, $b, $c = 0) {
        return $a + $b + $c;
    }
}

$calc = new Calculadora();
$resultado1 = $calc->sumar(5, 3);
$resultado2 = $calc->sumarTres(2, 4, 6);
```
En este ejemplo, la clase `Calculadora` tiene dos métodos llamados `sumar`, uno que toma dos parámetros y otro que toma tres (con uno de los parámetros como opcional). Esto permite que la misma clase tenga múltiples formas de realizar la operación de suma.

- **Polimorfismo de Sobreescritura**

El polimorfismo de sobreescritura se refiere a la capacidad de una clase hija de proporcionar una implementación específica para un método que ya está definido en su clase base (o clase padre). Esto se logra mediante el uso de métodos abstractos o mediante la implementación de interfaces.

```php
abstract class Animal {
    abstract public function hacerSonido();
}

class Perro extends Animal {

    public function hacerSonido() {
        return "¡Guau!";
    }
}

class Gato extends Animal {

    public function hacerSonido() {
        return "¡Miau!";
    }
}

$perro = new Perro();
$gato = new Gato();

echo $perro->hacerSonido(); // Imprime: ¡Guau!
echo $gato->hacerSonido();  // Imprime: ¡Miau!
```

En este ejemplo, la clase abstracta Animal tiene un método abstracto llamado hacerSonido. Las clases concretas Perro y Gato implementan este método según su propio comportamiento. Cuando se llama al método hacerSonido en instancias de estas clases, se obtiene el sonido específico de cada animal.

El polimorfismo permite tratar a objetos de diferentes clases de manera uniforme a través de una interfaz común. Esto mejora la flexibilidad y el mantenimiento del código al permitir que nuevas clases se integren sin modificar el código existente.
