# Funciones para manipulación de Arrays


PHP ofrece una amplia variedad de funciones para manipular arrays, lo que facilita la gestión y el procesamiento de datos estructurados en tus aplicaciones. 

---

- Acceso a Elementos

- array[index]: Accede a un elemento específico en el array por su índice.
    ```php
    <?php
    $factoryEmployees = ["Joe", "Ryan", "Jake", "Jane", "Karla", "John", "Nikola", "Greta", "Kelvin", "Albert", "Ismael"];

    echo $factoryEmployees[2];
    ```
    salida por consola:
    ```yaml
    Jake
    ```
- count(array): Devuelve el número de elementos en el array.
    ```php
    count($factoryEmployees);
    ```
    salida por consola:
    ```yaml
    10
    ```
- `isset(array[index])`: Se utiliza para comprobar si una variable o un elemento de un array está definido y no es nulo. Puedes utilizar `isset()` para determinar si un índice específico de un array está definido antes de intentar acceder a él.

    ```php
    if (isset($factoryEmployees[1])) {
        echo "El elemento $factoryEmployees[1] esta definido";
    } else {
        echo "El elemento no esta definido";
    }t
    ```
    salida por consola:
    ```yaml
    El elemento Ryan esta definido
    ```

**Usando arrays asociativos**

```php
$fruitList = ["manzana" => "roja", "banana" => "amarilla", "uva" => "morada"];

if (isset($fruitList["manzana"])) {
    echo "El índice 'manzana' está definido en el array.";
} else {
    echo "El índice 'manzana' no está definido en el array.";
}
```
salida por consola:
```yaml
El índice 'manzana' está definido en el array.
```

En este ejemplo, primero tenemos un array asociativo $fruitList. Luego, utilizamos isset() para verificar si el índice "manzana" está definido en el array. Si está definido, se ejecutará el primer bloque if, y si no lo está, se ejecutará el segundo bloque else.

---

La función `isset()` también se puede utilizar para verificar si una variable en general está definida. Aquí tienes un ejemplo:
```php
$miVariable;

if (isset($miVariable)) {
    echo "La variable está definida.";
} else {
    echo "La variable no está definida.";
}

```

En este caso, `$miVariable` no ha sido inicializada previamente, por lo que `isset()` devuelve false, y se ejecuta el bloque else.

`isset()` es útil para evitar errores cuando intentas acceder a variables o elementos de arrays que podrían no existir. Puedes usarlo para asegurarte de que una variable o un índice de un array estén definidos antes de trabajar con ellos, lo que ayuda a evitar mensajes de error no deseados.
