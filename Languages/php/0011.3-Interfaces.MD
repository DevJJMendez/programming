# Interfaces

Una interfaz en PHP define un conjunto de métodos que deben ser implementados por cualquier clase que la implemente. A diferencia de las clases abstractas, las interfaces pueden ser implementadas por varias clases, permitiendo la implementación de múltiples interfaces en una sola clase.

Las interfaces son útiles cuando quieres definir un contrato que las clases deben seguir. 

Ejemplo:

Supongamos que queremos definir un conjunto de métodos para vehículos.
```php
interface Vehiculo {
    public function acelerar();
    public function frenar();
}

class Coche implements Vehiculo {
    public function acelerar() {
        echo "El coche está acelerando";
    }

    public function frenar() {
        echo "El coche está frenando";
    }
}

class Moto implements Vehiculo {
    public function acelerar() {
        echo "La moto está acelerando";
    }

    public function frenar() {
        echo "La moto está frenando";
    }
}
```

En este ejemplo:

- `Vehiculo` es una interfaz que define los métodos `acelerar()` y `frenar()`.

- `Coche` y `Moto` son clases que implementan la interfaz `Vehiculo`.

- Cada clase implementa los métodos definidos en la interfaz, proporcionando su propia funcionalidad para `acelerar` y `frenar`.

Ahora, podemos crear instancias de las clases Coche y Moto y llamar a los métodos `acelerar()` y `frenar()`:
```php
$coche = new Coche();
$coche->acelerar(); // Imprime: El coche está acelerando.
$coche->frenar();   // Imprime: El coche está frenando.

$moto = new Moto();
$moto->acelerar();  // Imprime: La moto está acelerando.
$moto->frenar();    // Imprime: La moto está frenando.
```

Este ejemplo demuestra cómo las interfaces en PHP permiten definir un conjunto de métodos que las clases deben implementar. Esto asegura que las clases cumplan con un contrato específico definido por la interfaz, lo que facilita la consistencia y el mantenimiento del código.
