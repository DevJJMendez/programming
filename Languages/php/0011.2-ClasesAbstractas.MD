# Clases Abstractas

las clases abstractas son útiles para definir un modelo base que otras clases pueden extender, pero no pueden ser instanciadas directamente. Las clases abstractas pueden contener métodos abstractos (métodos sin implementación) que deben ser implementados por las clases que heredan de ellas.

Ejemplo:

Supongamos que queremos crear un modelo para diferentes tipos de formas geométricas con un método para calcular el área.

```php
abstract class Figura {
    abstract public function calcularArea();
}

class Circulo extends Figura {
    private $radio;

    public function __construct($radio) {
        $this->radio = $radio;
    }

    public function calcularArea() {
        return pi() * $this->radio * $this->radio;
    }
}

class Rectangulo extends Figura {
    private $base;
    private $altura;

    public function __construct($base, $altura) {
        $this->base = $base;
        $this->altura = $altura;
    }

    public function calcularArea() {
        return $this->base * $this->altura;
    }
}
```
- `Figura` es una clase abstracta que define el método abstracto `calcularArea()`.

- `Circulo` y `Rectangulo` son clases concretas que heredan de `Figura`.

- Cada clase concreta implementa su propia versión del método `calcularArea()` para calcular el área según la fórmula específica de cada forma geométrica.

Ahora, podemos crear instancias de las clases `Circulo` y `Rectangulo` y llamar al método `calcularArea()` para obtener el área de cada forma:
```php
$circulo = new Circulo(5);
echo "Área del círculo: " . $circulo->calcularArea(); // Imprime: Área del círculo: 78.539816339745

$rectangulo = new Rectangulo(4, 6);
echo "Área del rectángulo: " . $rectangulo->calcularArea(); // Imprime: Área del rectángulo: 24
```

Este ejemplo ilustra cómo las clases abstractas pueden definir un comportamiento común a través de métodos abstractos, permitiendo a las clases concretas implementar esos métodos de acuerdo con su funcionalidad específica.
