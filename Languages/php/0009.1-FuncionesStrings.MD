# Funciones para manipulación de Strings

Estas funciones te permiten realizar operaciones comunes como búsqueda, reemplazo, extracción, concatenación, formateo y mucho más en cadenas de texto.

---

- Longitud de cadena - **strlen()**:

Devuelve la longitud de una cadena.

```php
<?php
$userName = "Jhaminton Junior Mendez Cadena";

echo strlen($userName);
```

salida por consola:

```yaml
30
```

- Extracción y División:

    - **substr(cadena, inicio, longitud)**: Se utiliza para extraer una parte de una cadena de texto. Puedes especificar la cadena original, la posición de inicio y la longitud de la subcadena que deseas extraer.

        ```php
        $cadena = "Esta es una cadena de ejemplo";
        $subcadena = substr($cadena, 5, 10);

        echo "La subcadena es: " . $subcadena;
        ```
        salida por consola:
        ```yaml
        La subcadena es: es una cad
        ```

        **cadena**: La cadena de texto de la cual deseas extraer una parte.

        **inicio**: La posición de inicio desde la cual deseas comenzar a extraer la subcadena. Puedes utilizar valores negativos para contar desde el final de la cadena.

        **longitud** (opcional): La longitud de la subcadena que deseas extraer. Si no se proporciona, se extraerán todos los caracteres desde la posición de inicio hasta el final de la cadena.

        Ten en cuenta que la posición de inicio y la longitud se basan en índices, donde el primer carácter tiene un índice de 0, el segundo 1, y así sucesivamente.

    - explode(delimitador, cadena): Se utiliza para dividir una cadena de texto en un array de subcadenas basadas en un delimitador especificado.

        ```php
        $cadena = "Manzana,Plátano,Naranja,Pera";
        $frutas = explode(",", $cadena);

        foreach ($frutas as $fruta) {
            echo $fruta . "<br>";
        }
        ```

        salida por consola:

        ```yaml
        Manzana
        Plátano
        Naranja
        Pera
        ```
        **delimitador**: El carácter o cadena de texto que se utilizará para dividir la cadena original en subcadenas. En el ejemplo anterior, usamos una coma (,) como delimitador.

        **cadena**: La cadena de texto que deseas dividir en subcadenas.

        La función explode() es útil cuando necesitas separar datos que están en una cadena y convertirlos en elementos de un array para su posterior procesamiento, como cuando trabajas con listas de elementos separados por comas, tabulaciones u otros delimitadores.

- Reemplazo

    - **str_replace()**: Esta función realiza reemplazos de manera sensible a mayúsculas y minúsculas. Es decir, distingue entre letras mayúsculas y minúsculas al buscar coincidencias.

    ```php
    <?php

    $userName = "Jhaminton Mndz mndz";

    $nameCorrection = str_replace("Mndz", "Mendez", $userName);

    echo $userName;

    echo $nameCorrection;
    ```

    salida por consola:

    ```yaml
    Jhaminton Mndz mndz
    Jhaminton Mendez mndz
    ```

    - **str_ireplace()**: Esta función realiza reemplazos sin distinguir entre mayúsculas y minúsculas, lo que significa que es insensible a mayúsculas y minúsculas.

    ```php
    <?php

    $userName = "Jhaminton Mndz mndz";

    $nameCorrection = str_ireplace("Mndz", "Mendez", $userName);

    echo $userName;
    echo $nameCorrection;
    ```
    salida por consola:
    ```yaml
    Jhaminton Mndz mndz
    Jhaminton Mendez Mendez
    ```

- Búsqueda

    - strpos(): Se utiliza para encontrar la posición de la primera aparición de una subcadena dentro de una cadena de texto. Puedes usar esta función para determinar dónde comienza una subcadena en una cadena más grande. 

    ```php
    $cadena = "Esta es una cadena de ejemplo";
    $buscar = "es";
    $posicion = strpos($cadena, $buscar);

    if ($posicion !== false) {
        echo "La subcadena '$buscar' comienza en la posición $posicion.";
    } else {
        echo "La subcadena '$buscar' no se encontró en la cadena.";
    }
    ```
    salida por consola:

    ```php
    La subcadena 'es' comienza en la posición 28.
    ```

    - strrpos(): e utiliza para encontrar la posición de la última aparición de una subcadena dentro de una cadena de texto. A diferencia de strpos(), que encuentra la primera aparición, strrpos() busca la última aparición de la subcadena. 

    ```php
    $cadena = "Esta es una cadena de ejemplo. Es una cadena larga.";

    $buscar = "es";
    $posicion = strrpos($cadena, $buscar);

    if ($posicion !== false) {
        echo "La última subcadena '$buscar' comienza en la posición $posicion.";
    } else {
        echo "La subcadena '$buscar' no se encontró en la cadena.";
    }
    ```
    salida por consola:
    ```yaml
    La última subcadena 'es' comienza en la posición 28.
    ```

    - **strstr() / stristr()**: Se utilizan para encontrar la primera aparición de una subcadena en una cadena de texto y devolver la subcadena a partir de ese punto hasta el final de la cadena. La principal diferencia entre ellas es que strstr() realiza la búsqueda de manera sensible a mayúsculas y minúsculas, mientras que stristr() es insensible a mayúsculas y minúsculas.

    Utilizando strstr()  (sensible a mayúsculas y minúsculas):
    ```php
    $cadena = "Esto es una cadena de ejemplo. Esto es otra parte de la cadena.";
    $subcadena = "esto";

    $resultado = strstr($cadena, $subcadena);

    if ($resultado !== false) {
        echo "La subcadena encontrada es: " . $resultado;
    } else {
        echo "La subcadena no se encontró en la cadena.";
    }
    ```

    - Utilizando stristr() (insensible a mayúsculas y minúsculas):
    ```php
    $cadena = "Esto es una cadena de ejemplo. Esto es otra parte de la cadena.";
    $subcadena = "esto";

    $resultado = stristr($cadena, $subcadena);

    if ($resultado !== false) {
        echo "La subcadena encontrada es: " . $resultado;
    } else {
        echo "La subcadena no se encontró en la cadena.";
    }
    ```
    Ten en cuenta que ambas funciones pueden devolver false si la subcadena no se encuentra en la cadena. Por lo tanto, es una buena práctica verificar si la función devuelve false antes de intentar usar el resultado.

- Mayúsculas y Minúsculas:

    - strtolower(cadena): Convierte una cadena a minúsculas.

    - strtoupper(cadena): Convierte una cadena a mayúsculas.

    - ucfirst(cadena): Convierte el primer carácter de una cadena a mayúsculas.

    ```php
    <?php
    $name = "alicia";
    $lastName = "MENDEZ";
    $newUser = "jhaminton";

    echo strtoupper($name);
    echo strtolower($lastName);

    echo "$name $lastName";
    echo ucfirst($newUser);
    ```
    salida por consola:
    ```yaml
    ALICIA mendez
    Jhaminton
    ```
