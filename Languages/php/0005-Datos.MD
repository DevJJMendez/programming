# Clasificación de datos

## **Datos Primitivos (Tipos Básicos)**

Estos son los tipos de datos fundamentales que forman la base de la programación. Los ejemplos incluyen:

- Enteros (int): Para representar números enteros.

- Números de Punto Flotante (float): Para representar números con decimales.

- Cadenas de Texto (string): Para representar texto.

- Booleanos (bool): Para representar valores verdaderos o falsos.

- Caracteres (char): Para representar caracteres individuales.

- NULL: Para representar la ausencia de un valor.

- Recursos: Para representar manejadores de recursos externos, como conexiones a bases de datos.

---

## **Datos Estructurados**

Estos datos están organizados en estructuras más complejas y pueden incluir colecciones de datos de tipos primitivos.

- Arrays: Para almacenar colecciones ordenadas de valores.

- Objetos: Para representar estructuras de datos más complejas con propiedades y métodos.

- Registros: Estructuras de datos que contienen campos con valores específicos, similares a las bases de datos.

---

## **Datos compuestos**

Estos son datos que combinan varios elementos en una sola unidad. 

- Listas: Estructuras de datos ordenadas que pueden contener elementos de tipos variados.

- Diccionarios: Colecciones de datos que asocian claves con valores, como en PHP o Python.

- Tuplas: Secuencias ordenadas e inmutables de elementos.
