# Array Funciones

## Iteración sobre Arrays

- `array_map(función, array)`:  se utiliza para aplicar una función a cada elemento de uno o más arrays, devolviendo un nuevo array con los resultados.

Sintaxis:
```php
array_map(callback, array1, array2, ...)
```
- **callback**: La función que se aplicará a cada elemento del array.

- **array1, array2, ...**: Los arrays que serán procesados por la función de devolución de llamada.

Puedes pasar múltiples arrays a array_map() y la función de devolución de llamada recibirá los elementos correspondientes de cada array. La longitud del array resultante será la misma que la longitud del array más largo proporcionado.

Ejemplo:
```php
<?php
$miArray = [1, 2, 3, 4, 5];

// Definir una función que eleve al cuadrado cada elemento
function ElevaCuadrado($numero) {
    return $numero * $numero;
}

// Aplicar la función a cada elemento del array
$nuevoArray = array_map("ElevaCuadrado", $miArray);

// Imprimir el nuevo array
print_r($nuevoArray);
?>
```

salida por consola:
```yaml
Array
(
    [0] => 1
    [1] => 4
    [2] => 9
    [3] => 16
    [4] => 25
)
```

# Eliminación de Arrays:

- `unset(array[index])`: Elimina un elemento del array.


Ejemplo:
```php
<?php
$miArray = [1, 2, 3, 4, 5];

// Eliminar el segundo elemento del array
unset($miArray[1]);


print_r($miArray);
?>
```
salida por consola:
```yaml
Array
(
    [0] => 1
    [2] => 3
    [3] => 4
    [4] => 5
)
```
