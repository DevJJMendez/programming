- **Arrays** 
Para almacenar colecciones ordenadas de valores. Los elementos de un array pueden ser de cualquier tipo, incluyendo otros arrays.

```php
$frutas = array("manzana", "banana", "cereza");
$persona = array("nombre" => "Juan", "edad" => 30);
```

---

- **Recursos (resource)**

Los recursos son tipos de datos especiales utilizados para representar manejadores de recursos externos, como conexiones a bases de datos o archivos abiertos.

---

- **Callable** 

Es un tipo de datos que representa una función o un método que se puede llamar. Esto permite el uso de funciones y métodos como datos en PHP.

---

- **iterable**

Introducido en PHP 7.1, representa una colección de elementos que se pueden iterar, como arrays y objetos que implementan la interfaz Traversable.

---

- **Tipos Escalares**

A partir de PHP 7.0, puedes declarar el tipo de dato esperado para parámetros y valores de retorno en funciones y métodos. Los tipos escalares incluyen int, float, string, bool, y iterable.
