# `Promise.all(iterable)`
El método Promise.all(iterable) es un método estático de la clase Promise en JavaScript. Es muy útil para manejar múltiples promesas de manera simultánea, permitiendo esperar a que todas se resuelvan antes de ejecutar una acción. Es ampliamente utilizado en programación asíncrona cuando se requiere ejecutar varias operaciones en paralelo y se necesita el resultado de todas ellas para continuar.

## ¿Qué es Promise.all(iterable)?
* `Promise.all`: Es un método estático de la clase Promise, que recibe como argumento un iterable (como un array) de promesas.

* **Funcionalidad principal**: Retorna una nueva promesa que se resuelve cuando todas las promesas en el iterable proporcionado se han resuelto, o se rechaza si alguna de las promesas se rechaza.

## ¿Para qué sirve?
* **Sincronización de múltiples promesas**: `Promise.all` permite ejecutar varias promesas de forma simultánea y esperar a que todas se completen antes de continuar.

* **Recolección de resultados**: Devuelve un solo array con los resultados de todas las promesas resueltas en el mismo orden en que se proporcionaron.

* **Manejo de errores**: Si una promesa se rechaza, Promise.all se rechaza inmediatamente con el valor del error de la primera promesa rechazada, sin esperar a que las demás se completen.

## ¿Qué resuelve?
* **Control de concurrencia**: Simplifica el manejo de operaciones asíncronas concurrentes cuando se necesita esperar por todas antes de continuar.

* **Consolidación de errores**: Si una promesa en el conjunto falla, se puede manejar el error en un solo lugar sin la necesidad de manejar cada error de forma individual.

* **Eficiencia**: Al no depender de la secuencialidad, permite realizar múltiples tareas al mismo tiempo y esperar los resultados eficientemente.

## ¿Cómo lo resuelve?
* **Ejecuta todas las promesas simultáneamente**: Promise.all comienza a ejecutar todas las promesas en paralelo.

* **Espera a que todas se resuelvan o alguna falle**: La promesa combinada que devuelve Promise.all espera hasta que todas las promesas individuales hayan completado su ejecución.

* **Resultado en un array**: Si todas las promesas se resuelven, Promise.all devuelve un array de resultados en el mismo orden.

* **Fallo temprano en caso de error**: Si alguna promesa es rechazada, Promise.all rechaza inmediatamente su promesa combinada con el primer error encontrado, optimizando el flujo de errores.

## Sintaxis
```js
Promise.all(iterable)
```
* **`iterable`**: Un iterable (usualmente un array) de promesas u otros valores (si no son promesas, se convierten en promesas resueltas inmediatamente).

## Ejemplo básico
```js
const promesa1 = Promise.resolve(3);
const promesa2 = 42;
const promesa3 = new Promise((resolve, reject) => {
  setTimeout(resolve, 100, "foo");
});

Promise.all([promesa1, promesa2, promesa3]).then((valores) => {
  console.log(valores); // [3, 42, "foo"]
});
```
Aquí, Promise.all espera a que todas las promesas se resuelvan. Cuando se resuelven, se devuelve un array [3, 42, "foo"] con los resultados.

Ejemplo con manejo de errores
```js
const promesa1 = new Promise((resolve, reject) => {
  setTimeout(resolve, 1000, "Primera promesa completada");
});
const promesa2 = new Promise((resolve, reject) => {
  setTimeout(reject, 2000, "Segunda promesa fallida");
});
const promesa3 = new Promise((resolve, reject) => {
  setTimeout(resolve, 3000, "Tercera promesa completada");
});

Promise.all([promesa1, promesa2, promesa3])
  .then((resultados) => {
    console.log("Todas las promesas resueltas:", resultados);
  })
  .catch((error) => {
    console.error("Error en una de las promesas:", error); // "Segunda promesa fallida"
  });
```
En este ejemplo, aunque solo la segunda promesa falla, Promise.all se rechaza inmediatamente con el error "Segunda promesa fallida", sin esperar a que las demás promesas terminen.

## Consideraciones importantes
* **Orden de los resultados**: El array de resultados respeta el orden de las promesas en el iterable, no el orden de finalización.

* **Manejo de valores no promesas**: Si el iterable contiene valores que no son promesas, se convierten automáticamente en promesas resueltas.

* **Compatibilidad y control de errores**: Útil para manejar operaciones en paralelo, aunque en algunos casos puede ser mejor Promise.allSettled si necesitas saber el estado de todas las promesas sin rechazar inmediatamente ante un fallo.
