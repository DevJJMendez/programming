# Immediately Invoked Function Expressions
Las Funciones Autoejecutables (IIFE, por sus siglas en inglés de Immediately Invoked Function Expressions) son una técnica en JavaScript que permite definir y ejecutar una función inmediatamente después de su declaración. Esta técnica es especialmente útil para crear un nuevo ámbito y evitar la contaminación del ámbito global.

## ¿Qué es una Función Autoejecutable (IIFE)?
Una IIFE es una función que se define y se ejecuta al mismo tiempo. Se puede crear utilizando la siguiente sintaxis:
```js
(function() {
    // Código aquí
})();
```
O utilizando la sintaxis de arrow functions:
```js
(() => {
    // Código aquí
})();
```

## ¿Para qué Sirve?
Las IIFE son utilizadas principalmente para:

Crear un ámbito local: Al ejecutar la función inmediatamente, las variables y funciones definidas dentro de ella no son accesibles desde el ámbito global o el ámbito superior, lo que ayuda a evitar conflictos de nombres.
Encapsular código: Permiten organizar el código de manera que ciertas variables y funciones queden encapsuladas y no interfieran con otras partes del código.
Inicialización de módulos: Se utilizan comúnmente para inicializar módulos, configuraciones o cualquier lógica que deba ejecutarse una vez al cargar un script.

## ¿Qué Resuelve?
Las IIFE ayudan a:

Evitar la contaminación del ámbito global: Cualquier variable o función definida dentro de una IIFE no afectará el contexto global, lo que reduce el riesgo de colisiones de nombres.
Mantener el código limpio y organizado: Al encapsular lógica dentro de funciones autoejecutables, se mejora la legibilidad y la mantenibilidad del código.
Controlar la visibilidad: Permiten definir variables y funciones que son privadas y no accesibles desde el exterior, mejorando la encapsulación.

## ¿Cómo lo Resuelve?
Las IIFE funcionan mediante la creación de un nuevo contexto de ejecución al definir y ejecutar una función en la misma expresión. Esto significa que las variables definidas dentro de la función no son accesibles desde fuera de ella.

## Detalles Técnicos y Ejemplos
1. Creación Básica de una IIFE
Aquí hay un ejemplo simple de una IIFE:
```js
(function() {
    const mensaje = "Hola desde la IIFE!";
    console.log(mensaje);
})(); // Imprime: Hola desde la IIFE!
```
En este caso, la variable mensaje es privada y no puede ser accedida desde el ámbito global.

2. IIFE con Parámetros
Las IIFE pueden aceptar argumentos como cualquier otra función:
```js
(function(nombre) {
    console.log("Hola, " + nombre + "!");
})("Juan"); // Imprime: Hola, Juan!
```

3. Usar IIFE para Modularidad
Las IIFE son muy útiles para crear módulos en JavaScript. A continuación, se presenta un ejemplo en el que se encapsulan variables y funciones:
```js
const miModulo = (function() {
    let contador = 0; // Variable privada

    return {
        incrementar: function() {
            contador++;
            console.log(contador);
        },
        reiniciar: function() {
            contador = 0;
            console.log("Contador reiniciado");
        }
    };
})();

miModulo.incrementar(); // Imprime: 1
miModulo.incrementar(); // Imprime: 2
miModulo.reiniciar();   // Imprime: Contador reiniciado
```
En este caso, contador es una variable privada que no puede ser accedida directamente desde el exterior del módulo.

4. IIFE y el Alcance de Variables
Las IIFE son útiles cuando se necesita crear variables que no deben ser accesibles globalmente. Por ejemplo:
```js
var globalVar = "Soy global";

(function() {
    var localVar = "Soy local";
    console.log(localVar); // Imprime: Soy local
})();

console.log(globalVar); // Imprime: Soy global
// console.log(localVar); // Error: localVar no está definida
```

## Ventajas y Limitaciones de las IIFE
Ventajas:

Encapsulación: Permiten encapsular variables y funciones, evitando el acceso no deseado desde el exterior.
Evitar conflictos de nombres: Al crear un nuevo ámbito, se reducen los riesgos de colisión entre variables y funciones.
Mejora en la organización del código: Las IIFE facilitan la creación de bloques de código que se ejecutan de forma aislada.
Limitaciones:

Acceso a variables: Las variables definidas dentro de una IIFE son inaccesibles desde el exterior, lo que puede ser una limitación si se necesita acceder a ellas más tarde.
Complejidad adicional: Aunque son útiles, pueden agregar un poco de complejidad al código, especialmente para los principiantes.
Buenas Prácticas
Usar IIFE cuando sea necesario: Utiliza IIFE cuando desees encapsular código que no necesita ser accesible globalmente.
Mantenlo claro y simple: Aunque las IIFE pueden ser útiles, asegúrate de que su uso no haga que el código sea más difícil de entender.
Combinar con módulos ES6: Con la introducción de módulos en ES6, el uso de IIFE ha disminuido en algunos contextos, pero sigue siendo útil en ciertos casos.
