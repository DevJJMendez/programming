# `async`
se utilizada para definir funciones asíncronas, las cuales permiten manejar promesas de manera más clara y legible. Al usar async, estamos indicando que una función manejará código asíncrono y retornará una promesa, facilitando el uso de await para escribir operaciones asíncronas de forma secuencial.

## ¿Qué es async?
La palabra clave async se coloca antes de una función para convertirla en una función asíncrona. Una función asíncrona es aquella que siempre devuelve una promesa, permitiendo utilizar await dentro de ella para suspender su ejecución hasta que una promesa específica se resuelva o sea rechazada.

## ¿Para qué sirve async?
async se utiliza para simplificar el manejo de operaciones asíncronas, eliminando la necesidad de utilizar múltiples .then() y .catch(). Al declarar una función como async, podemos utilizar await dentro de ella, lo cual permite escribir código que se lee de forma secuencial, pero que en realidad no bloquea el hilo principal.

## ¿Qué resuelve async?
async resuelve principalmente el problema de lectura y manejo complicado de promesas en JavaScript. Sin async y await, el manejo de promesas tiende a crear código menos legible, debido a la estructura en cadena de .then() y .catch(). Además, permite capturar errores en un solo bloque try...catch, mejorando la claridad y mantenibilidad del código.

## ¿Cómo lo resuelve?
async resuelve estos problemas al hacer que cualquier valor retornado por la función se envuelva automáticamente en una promesa. Esto permite que la función asíncrona espere a que cualquier operación asíncrona se complete antes de continuar, gracias a await. Como resultado, el código escrito dentro de una función async se asemeja a código secuencial, lo cual facilita su lectura y depuración.

##  Todo lo que debes saber sobre async
* Declaración de funciones async
Una función async se puede declarar de varias formas:

Función tradicional:
```js
async function ejemploAsync() {
    return "Resultado";
}
```
Función anónima:
```js
const ejemploAsync = async function() {
    return "Resultado";
};
```
Función de flecha:
```js
const ejemploAsync = async () => "Resultado";
```

* Funcionamiento de async
Al declarar una función con async, se garantiza que la función devolverá una promesa, incluso si retorna un valor normal. Esto significa que el valor de retorno se convierte automáticamente en una promesa resuelta.

```js
async function ejemplo() {
    return "Valor devuelto"; // Es equivalente a Promise.resolve("Valor devuelto")
}

ejemplo().then(console.log); // Salida: "Valor devuelto"
```

* async y await juntos
El verdadero poder de async se ve al combinarlo con await, que permite detener la ejecución de la función async hasta que una promesa se resuelva.
```js
async function obtenerDatos() {
    const respuesta = await fetch("https://api.example.com/data");
    const datos = await respuesta.json();
    return datos;
}

obtenerDatos().then(console.log);
```
En este ejemplo:
* La función obtenerDatos se define como async, por lo tanto, devuelve una promesa.

* Usamos await para esperar a que fetch obtenga la respuesta y luego el método json() convierta la respuesta en datos de JavaScript.

* Manejo de errores en funciones async
Dentro de una función async, se pueden capturar errores con try...catch, lo cual mejora la claridad al manejar errores sin necesidad de usar .catch().
```js
async function obtenerDatos() {
    try {
        const respuesta = await fetch("https://api.example.com/data");
        const datos = await respuesta.json();
        return datos;
    } catch (error) {
        console.error("Error al obtener datos:", error);
        throw error; // Opcional, reenvía el error para manejarlo en otro lugar
    }
}
```

* Ejecución en paralelo usando async
Si necesitas realizar varias tareas asíncronas al mismo tiempo, puedes iniciarlas sin await inmediatamente, y luego esperar a que todas se completen usando Promise.all.

```js
async function cargarDatos() {
    const [data1, data2] = await Promise.all([
        fetch("https://api.example.com/data1"),
        fetch("https://api.example.com/data2")
    ]);

    console.log("Datos cargados:", data1, data2);
}
```

* Retorno implícito de promesas
En una función async, puedes retornar valores normales o promesas. Si devuelves una promesa, async no la envolverá en otra promesa, sino que esperará a que esa promesa se resuelva.

```js
async function fetchConRetorno() {
    return fetch("https://api.example.com/data"); // Devuelve directamente la promesa de fetch
}
```
