# `await`
se utiliza dentro de funciones async para pausar la ejecución de la función hasta que una promesa se resuelva o rechace. await simplifica el trabajo con promesas y ayuda a escribir código asíncrono de manera que parezca síncrono, lo cual hace que el código sea más legible y fácil de depurar.

##  ¿Qué es await?
await es una palabra clave que solo puede ser utilizada dentro de una función declarada con async. Pausa la ejecución de la función async hasta que la promesa que sigue a await se resuelva. Si la promesa se cumple, await devuelve el resultado de la promesa; si la promesa se rechaza, lanza el error de rechazo, el cual puede ser capturado en un bloque try...catch.

## ¿Para qué sirve await?
await se usa para simplificar la estructura del código asíncrono en JavaScript. En lugar de encadenar métodos .then() y .catch() para manejar promesas, await permite escribir código que se lee de forma secuencial, incluso si involucra operaciones que requieren tiempo, como una solicitud a una API.

## ¿Qué resuelve await?
await resuelve el problema de legibilidad y manejabilidad del código asíncrono. Sin await, el código asíncrono en JavaScript requiere trabajar con promesas utilizando .then() y .catch(), lo cual puede llevar a código más difícil de leer y comprender, sobre todo cuando hay múltiples niveles de operaciones asíncronas.

## ¿Cómo lo resuelve?
Al utilizar await, JavaScript permite que la función espere el resultado de una promesa y continúe ejecutando el código solo una vez que la promesa se ha resuelto. Esto elimina la necesidad de usar múltiples .then() y mejora la claridad al permitir un enfoque secuencial.

## Todo lo que debes saber sobre await
* Uso básico de await
Cuando usas await, debes recordar que siempre debe estar dentro de una función async. Si intentas usar await fuera de una función async, obtendrás un error de sintaxis.

Ejemplo básico
```js
async function obtenerUsuario() {
    const respuesta = await fetch("https://jsonplaceholder.typicode.com/users/1");
    const usuario = await respuesta.json();
    console.log(usuario);
}

obtenerUsuario();
```
En este ejemplo:
* await fetch(...) detiene la ejecución de la función hasta que fetch complete la solicitud HTTP.

* Luego, await respuesta.json() detiene la ejecución hasta que la respuesta se convierta en JSON.

* console.log(usuario); se ejecuta solo después de que ambos await hayan completado sus operaciones.

*  Manejo de errores con await
El uso de await se integra bien con try...catch, lo cual permite manejar errores de una manera sencilla y eficiente dentro de funciones async.
```js
async function obtenerUsuario() {
    try {
        const respuesta = await fetch("https://jsonplaceholder.typicode.com/users/1");
        if (!respuesta.ok) throw new Error("Error en la solicitud");
        const usuario = await respuesta.json();
        console.log(usuario);
    } catch (error) {
        console.error("Error al obtener el usuario:", error);
    }
}

obtenerUsuario();
```
Aquí, si ocurre un error en cualquier await, este es capturado en el bloque catch, evitando que el código falle sin control.

* Ejecución en paralelo con await
Aunque await facilita un flujo secuencial, a veces es conveniente realizar operaciones en paralelo. Para esto, se puede iniciar cada promesa y luego esperar a todas al mismo tiempo usando Promise.all.
```js
async function cargarDatos() {
    const promesa1 = fetch("https://jsonplaceholder.typicode.com/posts");
    const promesa2 = fetch("https://jsonplaceholder.typicode.com/comments");

    // Espera a que ambas promesas se resuelvan en paralelo
    const [posts, comments] = await Promise.all([promesa1, promesa2]);

    const datosPosts = await posts.json();
    const datosComments = await comments.json();

    console.log(datosPosts, datosComments);
}
```
En este ejemplo:

* promesa1 y promesa2 se ejecutan en paralelo en lugar de una tras otra.

* Con Promise.all, se espera a que ambas se resuelvan antes de proceder.

* Uso de await con valores no promesas
Aunque await se usa principalmente con promesas, también funciona con valores no promesas. Si await encuentra un valor que no es una promesa, lo convierte en una promesa resuelta automáticamente.
```js
async function ejemplo() {
    const valor = await 42; // Esto no es una promesa, pero `await` lo maneja
    console.log(valor); // Salida: 42
}
```
