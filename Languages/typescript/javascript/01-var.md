# `var`
`var` es una palabra clave de JavaScript que permite declarar variables. Es una de las formas más antiguas para declarar variables en el lenguaje, y tiene un alcance y un comportamiento específicos que la diferencian de `let` y `const`.

## ¿Para qué sirve?
`var` sirve para almacenar valores en una variable que se puede reutilizar y manipular más adelante en el código. Al igual que `let` y `const`, permite almacenar cualquier tipo de dato (números, strings, objetos, etc.).

**Ejemplo**
```js
var nombre = "Juan";
var edad = 25;
console.log(nombre); // Juan
console.log(edad);   // 25
```
