# Instancias
Una instancia es un objeto específico creado a partir de una clase. Mientras que una clase actúa como una plantilla o modelo que define las propiedades (atributos) y comportamientos (métodos), una instancia es una realización concreta de esa plantilla. Cada instancia tiene su propio conjunto de valores para los atributos definidos por la clase.

**Analogía**: Si pensamos en una clase como un plano arquitectónico para construir una casa, entonces una instancia sería una casa específica construida a partir de ese plano. Puedes construir múltiples casas (instancias) a partir del mismo plano (clase), pero cada casa puede tener diferentes características (como el color de las paredes o el mobiliario).

Ejemplo
```java
public class Cliente {
    private String nombre;
    private String email;

    public Cliente(String nombre, String email) {
        this.nombre = nombre;
        this.email = email;
    }

    public String getNombre() {
        return nombre;
    }

    public String getEmail() {
        return email;
    }
}

// Creando dos instancias de la clase Cliente
Cliente cliente1 = new Cliente("Juan", "juan@example.com");
Cliente cliente2 = new Cliente("Maria", "maria@example.com");
```
En este caso, `cliente1` y `cliente2` son dos instancias diferentes de la clase `Cliente`, cada una con sus propios valores para los atributos `nombre` y `email`.

## ¿Cuáles Son Sus Tipos?
El concepto de "tipos de instancias" no es estrictamente formal, pero podemos clasificarlas de la siguiente manera, basado en cómo se crean y cómo se utilizan:

1. **Instancias Únicas (Singleton)**:

   * Solo se crea una única instancia de la clase durante la ejecución del programa.

   * **Ejemplo**: En aplicaciones empresariales, se puede usar un Singleton para administrar conexiones a la base de datos, asegurando que solo haya una conexión activa.

2. **Instancias Independientes (Estándar)**:

   * Las instancias se crean cada vez que se necesita un nuevo objeto, y cada uno actúa de forma independiente.

   * **Ejemplo**: Un sistema de gestión de clientes puede tener múltiples instancias de Cliente, donde cada instancia representa un cliente único con sus propios atributos.

3. **Instancias Copiadas (Clonación)**:

   * Se crean a partir de una instancia existente, copiando sus valores. Esto puede hacerse utilizando la clonación profunda o superficial.

   * **Ejemplo**: Si deseas copiar los datos de un Pedido para realizar un duplicado, podrías crear una instancia clonada.

## ¿Para Qué Sirven?
1. **Representación de Entidades Únicas**: Las instancias permiten modelar y representar entidades únicas en tu sistema. Cada instancia creada a partir de una clase representa un objeto del mundo real o una entidad abstracta con atributos y comportamientos específicos.

2. **Reutilización de la Lógica de la Clase**: Crear instancias permite reutilizar la lógica definida en la clase, evitando duplicación de código. Puedes instanciar múltiples objetos que compartan los mismos métodos y estructura, pero que mantengan su propio estado.

3. **Modularidad y Escalabilidad**: Al crear diferentes instancias, puedes gestionar diferentes partes de tu sistema de manera modular. Por ejemplo, cada Pedido en un sistema de ecommerce es una instancia única que se gestiona de forma independiente.

## ¿Qué Resuelven?
1. **Modelar el Mundo Real de Forma Concreta**: Mientras que una clase define un concepto general (como un Producto), las instancias permiten dar vida a esos conceptos de manera concreta (por ejemplo, un producto específico "Laptop Dell Inspiron").

2. **Separación de Estado**: Cada instancia mantiene su propio estado independiente. Esto significa que puedes tener múltiples objetos de la misma clase funcionando simultáneamente sin que el estado de uno afecte al otro. Esto es crucial en aplicaciones donde múltiples entidades similares necesitan gestionarse al mismo tiempo.

3. **Reutilización y Extensibilidad**: Puedes crear múltiples instancias de una clase sin tener que definir nuevas estructuras de datos o comportamientos cada vez. Esto hace que el código sea más modular y reutilizable.

## ¿Cómo Lo Resuelven?
1. **A través del Uso del Operador new en Java**: Para crear una instancia, utilizas el operador new que asigna memoria para el nuevo objeto y llama al constructor de la clase.

**Ejemplo**:
```java
Cliente cliente = new Cliente("Carlos", "carlos@example.com");
```
Aquí, `new Cliente(...)` crea una nueva instancia de la clase `Cliente`.

2. **Mediante Constructores**: Los constructores se utilizan para inicializar los atributos de una instancia cuando se crea. Esto asegura que el objeto siempre esté en un estado válido cuando se use.

**Ejemplo**
```java
public class Producto {
    private String nombre;
    private double precio;

    public Producto(String nombre, double precio) {
        this.nombre = nombre;
        this.precio = precio;
    }
}

Producto laptop = new Producto("Laptop Dell", 750.00);
```

3. **Asignando y Accediendo a Valores de Atributos Únicos**: Cada instancia mantiene su propio conjunto de valores para los atributos, lo que significa que laptop y otro producto tendrán sus propios valores de nombre y precio, sin interferir entre sí.

**Ejemplo**:
```java
Producto producto1 = new Producto("Teclado", 20.00);
Producto producto2 = new Producto("Monitor", 150.00);

System.out.println(producto1.getNombre()); // Teclado
System.out.println(producto2.getNombre()); // Monitor
```
