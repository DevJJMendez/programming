# Viewport
El viewport es el área visible de una página web dentro del navegador. En términos simples, es la "ventana" a través de la cual los usuarios ven el contenido del sitio web. Su tamaño puede variar según el dispositivo y las dimensiones de la ventana del navegador; un monitor de computadora de escritorio tendrá un viewport grande, mientras que un dispositivo móvil tendrá uno pequeño.

## ¿Para qué sirve el Viewport?
El viewport es fundamental en diseño web responsivo y adaptable, ya que establece el área en la que se muestra la página y define la escala inicial de la página en el dispositivo. Con la configuración del viewport, los diseñadores pueden controlar cómo se renderiza y escala el contenido en diferentes tamaños de pantalla, optimizando la experiencia de usuario en cualquier dispositivo.

## ¿Qué resuelve el Viewport?
El viewport es clave para:

* Mejorar la legibilidad y accesibilidad en dispositivos de distintos tamaños.

* Ajustar el diseño de la página web para dispositivos móviles y de escritorio, lo que permite que el contenido se adapte sin perder funcionalidad o estética.

* Establecer un punto de referencia para unidades relativas en CSS (como vw y vh), que dependen del tamaño del viewport para definir elementos adaptativos.

Sin el control del viewport, una página web podría mostrarse de manera incorrecta o ilegible en pantallas pequeñas o grandes. Antes del diseño responsivo, las páginas solían verse igual en todos los dispositivos, haciendo que el contenido en dispositivos pequeños fuera difícil de visualizar.

## ¿Cómo lo resuelve el Viewport?
El viewport se controla mediante la metaetiqueta HTML <meta name="viewport" ...>, que se ubica en la cabecera de un documento HTML. Con esta etiqueta, es posible ajustar las propiedades del viewport y, en combinación con CSS, permite crear un diseño adaptable.

La configuración más común es la siguiente:
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
En este caso:

* `width=device-width`: Ajusta el ancho del viewport al ancho del dispositivo.

* `initial-scale=1.0`: Establece la escala inicial del contenido al 100% (sin zoom).

## Parámetros Importantes en la Configuración del Viewport
* width: Define el ancho del viewport. Valores comunes son device-width (ajusta el ancho según el dispositivo).

* height: Define el alto del viewport, aunque se usa menos frecuentemente.

* initial-scale: Controla la escala inicial de la página.

* minimum-scale, maximum-scale: Define el nivel mínimo y máximo de zoom que los usuarios pueden aplicar.

* user-scalable: Permite o restringe el zoom manual por parte del usuario.

Ejemplo
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no">
```
En este ejemplo, el usuario no puede hacer zoom (por ejemplo, en aplicaciones web que necesitan un tamaño fijo).

## Unidades Relativas Basadas en el Viewport
CSS incluye unidades relativas que dependen del tamaño del viewport:

* vw (Viewport Width): 1 vw es igual al 1% del ancho del viewport. Así, 50vw ocuparía el 50% del ancho de la pantalla.

* vh (Viewport Height): 1 vh es igual al 1% de la altura del viewport.

* vmin y vmax: vmin usa el valor más pequeño entre vw y vh, y vmax el valor más grande. Útiles para elementos que deben adaptarse a cualquier orientación de pantalla.
