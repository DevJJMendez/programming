# Grid Line Names
La grid line name o "nombre de línea de grid" es una funcionalidad avanzada de CSS Grid que permite asignar nombres específicos a las líneas de las columnas y filas del grid. Esto permite referenciar esas líneas por nombre, en lugar de por número de línea, al ubicar los grid items.

## ¿Qué es grid line name?
En CSS Grid, los contenedores de grid están definidos por una serie de líneas de grid que separan las filas y columnas. Normalmente, al colocar un grid item, usas números de línea para definir su inicio y fin. Sin embargo, con grid line name, puedes asignar nombres a estas líneas, lo que hace que la organización y posicionamiento de los elementos sea más legible y fácil de manejar, especialmente en layouts complejos.

## ¿Para qué sirve grid line name?
* Organización del código: Permite un código más legible y organizado, ya que en lugar de referenciar líneas por número, se puede referenciar por nombres descriptivos.

* Flexibilidad en el diseño: Hace que el diseño sea más fácil de ajustar y entender, especialmente cuando se trabaja en layouts complejos con muchos elementos.

* Mantenimiento y escalabilidad: Los nombres de línea facilitan el mantenimiento y la escalabilidad del diseño, pues si las líneas cambian de posición, puedes simplemente cambiar el nombre en un solo lugar.

## ¿Qué resuelve grid line name?
grid line name resuelve varios problemas típicos en CSS Grid:

* Confusión en el posicionamiento: En layouts grandes, recordar qué número de línea corresponde a cada sección puede ser complicado. Los nombres de línea ayudan a identificar mejor las áreas del diseño.

* Legibilidad del código: Facilita que el código sea comprensible para otros desarrolladores, ya que los nombres pueden describir la función de una línea (por ejemplo, sidebar-start o content-end).

* Reutilización y adaptabilidad: Permite la reutilización de nombres en diferentes áreas del grid, facilitando la configuración de elementos sin depender de la estructura específica del grid.

## ¿Cómo lo resuelve?
La asignación de nombres de línea en CSS Grid se logra al definir nombres en las propiedades grid-template-columns y grid-template-rows. Luego, puedes referenciarlos en las propiedades grid-column y grid-row de los grid items.

## Sintaxis de grid line name
Los nombres de línea se asignan utilizando corchetes `[nombre]` en la declaración de columnas y filas dentro de grid-template-columns o grid-template-rows.

**Ejemplo básico:**
```css
.grid-container {
  display: grid;
  grid-template-columns: [inicio] 1fr [medio] 1fr [fin];
  grid-template-rows: [fila1] 100px [fila2] 100px [fila3];
}
```
En este caso:

* La línea de inicio de la primera columna se llama inicio, la línea entre las dos columnas se llama medio y la última línea se llama fin.

* Las filas tienen nombres de línea fila1, fila2 y fila3.

## Ejemplo de uso con grid items:
```css
.grid-container {
  display: grid;
  grid-template-columns: [sidebar-start] 200px [sidebar-end content-start] 1fr [content-end];
  grid-template-rows: [header-start] 100px [header-end main-start] 1fr [main-end footer-start] 50px [footer-end];
}

.sidebar {
  grid-column: sidebar-start / sidebar-end;
}

.content {
  grid-column: content-start / content-end;
  grid-row: header-end / footer-start;
}

.header {
  grid-row: header-start / header-end;
  grid-column: sidebar-start / content-end;
}

.footer {
  grid-row: footer-start / footer-end;
  grid-column: sidebar-start / content-end;
}
```
**En este ejemplo:**
* La columna del sidebar ocupa desde la línea sidebar-start hasta sidebar-end.

* El content ocupa desde content-start hasta content-end, y desde header-end hasta footer-start en filas.

* La header ocupa toda la fila superior desde sidebar-start hasta content-end.

* La footer ocupa toda la fila inferior, similar a la header.

## Consejos para nombrar líneas de grid
* Usa nombres descriptivos: Como header-start, sidebar-start, content-end, etc.

* Evita nombres ambiguos o genéricos: Nombres como line1 o sectionA no ayudan a entender la estructura.

* Usa nombres de líneas que correspondan a la función de cada sección, en lugar de su posición específica en el grid. Esto hace que tu diseño sea más adaptable.
