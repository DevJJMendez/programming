# `auto-fit`
auto-fit es un valor utilizado en la función repeat() de CSS Grid para controlar cómo las columnas o filas de una grilla se ajustan al espacio disponible en el contenedor. La principal característica de auto-fit es que las columnas (o filas) se expanden automáticamente para llenar el espacio restante, incluso si hay menos elementos en la grilla.

## ¿Para qué sirve?
auto-fit sirve para crear diseños flexibles y adaptativos, permitiendo que las columnas o filas:

* Se ajusten dinámicamente al espacio disponible.

* Llenen todo el ancho (o alto) del contenedor sin dejar huecos.

* Se reduzcan o amplíen según sea necesario, mejorando la apariencia de la grilla en diferentes tamaños de pantalla.

## ¿Qué resuelve?
Resuelve el problema de:

* Espacios vacíos en la grilla: A diferencia de auto-fill, auto-fit elimina columnas o filas "vacías" cuando no hay suficientes elementos para llenar el espacio disponible.

* Diseño adaptativo: Permite que el diseño responda al tamaño del contenedor sin necesidad de utilizar media queries.

* Distribución del espacio sobrante: Si hay más espacio que elementos, lo distribuye entre las columnas o filas existentes, logrando una apariencia consistente y centrada.

## ¿Cómo lo resuelve?
Mediante la combinación de:

* La función repeat(): Para definir el número y el tamaño de las columnas o filas.

* La función minmax(): Para establecer un tamaño mínimo y máximo que garantiza flexibilidad.

* Unidades fraccionales (fr): Para distribuir el espacio de manera proporcional.

Cuando se utiliza auto-fit, las columnas o filas se "colapsan" si no hay elementos suficientes, dejando más espacio para los elementos presentes. Esto lo diferencia de auto-fill, que deja huecos en el diseño al mantener las columnas vacías visibles.

## Ejemplo
```html
<div class="container">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
```
```css
.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
  gap: 20px;
}

.item {
  background-color: #4caf50;
  color: white;
  text-align: center;
  padding: 20px;
  font-size: 1.2rem;
}
```
**Explicación:**
* grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));:
  * Crea tantas columnas como puedan caber en el ancho del contenedor.

  * Cada columna tiene un ancho mínimo de 150px y puede crecer hasta ocupar una fracción del espacio restante (1fr).

* Si hay más espacio que elementos, las columnas se expanden proporcionalmente.

## Casos prácticos
* Listas de productos en ecommerce: Diseña catálogos donde las tarjetas de producto se distribuyen automáticamente según el espacio disponible.

* Galerías de imágenes: Crea galerías que se ajustan dinámicamente al tamaño del viewport sin dejar columnas vacías.

* Tablas dinámicas: Permite que las columnas de una tabla se expandan o contraigan según el contenido y el tamaño del contenedor.

## auto-fill vs auto-fit
Es común confundir auto-fill con auto-fit. Ambos son similares, pero hay una diferencia importante:

* `auto-fill`: Rellena el contenedor con tantas columnas o filas como sea posible. Si hay espacio restante, las columnas o filas adicionales seguirán existiendo, pero podrían quedar vacías.
```css
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
```
En este caso, si el contenedor tiene espacio extra, se crearán más columnas, pero las que no tengan contenido estarán vacías.

* auto-fit: Similar a auto-fill, pero cuando hay espacio sobrante, las columnas o filas se ajustan para llenar ese espacio, lo que puede hacer que las columnas se expandan para ocupar todo el espacio disponible, y no habrá "columnas vacías".
```css
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
```

## Cuándo usar auto-fill vs auto-fit
* Usa auto-fill cuando quieras que el contenedor se llene con el mayor número posible de elementos, pero permitiendo que haya columnas vacías si no hay suficiente contenido.

* Usa auto-fit cuando desees que las columnas se ajusten para llenar todo el espacio disponible, evitando columnas vacías.
