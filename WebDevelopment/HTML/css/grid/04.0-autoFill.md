# `auto-fill`
La propiedad auto-fill es una característica de CSS Grid Layout que se utiliza en combinación con grid-template-columns o grid-template-rows para crear un diseño flexible que ajusta automáticamente el número de columnas o filas dentro de una grilla, de acuerdo con el espacio disponible y el tamaño de los elementos dentro de la grilla.

## ¿Qué es auto-fill?
auto-fill es una de las funciones utilizadas dentro de las propiedades grid-template-columns o grid-template-rows. Permite llenar automáticamente el espacio de una grilla con el mayor número posible de elementos, repitiendo una unidad de grilla definida tantas veces como sea necesario, sin exceder el espacio disponible. Es una forma dinámica de manejar el número de filas o columnas dentro de un contenedor sin necesidad de calcular explícitamente el número exacto de columnas o filas.

Cuando usas auto-fill, CSS intenta colocar tantas unidades como sea posible en el contenedor. Si hay más espacio disponible del que puede llenar con las unidades especificadas, el espacio restante se distribuye uniformemente entre las columnas o filas.

## ¿Para qué sirve auto-fill?
La propiedad auto-fill es útil para crear diseños receptivos y flexibles en los que el número de columnas o filas se ajuste automáticamente al tamaño del contenedor. Sirve para:

* Crear diseños fluidos que respondan al tamaño del contenedor (por ejemplo, en sitios web responsivos donde las columnas se ajustan dependiendo del tamaño de la pantalla).

* Evitar el cálculo manual de las columnas o filas. Al usar auto-fill, CSS calcula dinámicamente cuántas columnas o filas puede encajar dentro del espacio disponible, ahorrándote la necesidad de manejar el número exacto de elementos.

* Optimizar la distribución de los elementos dentro de una grilla. Cuando el tamaño de los elementos es variable (como en un diseño de tarjetas), auto-fill organiza automáticamente los elementos para que se adapten al espacio disponible sin dejar espacios vacíos innecesarios.

## ¿Qué resuelve auto-fill?
auto-fill resuelve varios problemas comunes de diseño:

* Adaptabilidad: Permite crear diseños que se adaptan automáticamente al tamaño del contenedor, sin necesidad de redimensionar manualmente las columnas o filas.

* Eficiencia en el uso del espacio: Maximiza el uso del espacio dentro del contenedor, llenando las filas o columnas disponibles hasta que ya no quepa más contenido, lo que mejora la distribución de los elementos.

* Reactividad: Permite que el diseño de la grilla se ajuste a los cambios del tamaño de la ventana del navegador o del dispositivo, sin requerir intervenciones manuales adicionales.

## ¿Cómo lo resuelve auto-fill?
auto-fill resuelve estos problemas ajustando dinámicamente el número de columnas o filas dentro de una grilla. Lo hace de la siguiente manera:

* Al usar auto-fill, defines un tamaño mínimo para los elementos de la grilla (por ejemplo, minmax(100px, 1fr)).

* CSS Grid calcula cuántos elementos pueden caber dentro del contenedor, creando tantas columnas o filas como sea posible.

* Si hay más espacio disponible en el contenedor después de colocar las columnas o filas necesarias, auto-fill rellenará ese espacio, repitiendo las columnas o filas adicionales según el espacio restante.

## Ejemplo de uso
```html
<div class="grid-container">
  <div class="grid-item">Item 1</div>
  <div class="grid-item">Item 2</div>
  <div class="grid-item">Item 3</div>
  <div class="grid-item">Item 4</div>
  <div class="grid-item">Item 5</div>
  <div class="grid-item">Item 6</div>
</div>
```
```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)); /* Se llenan automáticamente las columnas */
  gap: 10px;
}

.grid-item {
  background-color: lightblue;
  padding: 20px;
  text-align: center;
}
```
**Explicación del ejemplo:**
* grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)): Este código indica que las columnas deben ocupar un mínimo de 200px y pueden expandirse hasta ocupar el espacio restante disponible. Usando auto-fill, CSS repetirá esta unidad de columna tantas veces como sea posible, ajustando el número de columnas al espacio disponible.

* minmax(200px, 1fr): Esta función permite establecer un tamaño mínimo de 200px y un tamaño máximo flexible de 1fr (fracción del espacio disponible). De este modo, las columnas tienen un tamaño mínimo, pero pueden crecer si hay espacio disponible.
