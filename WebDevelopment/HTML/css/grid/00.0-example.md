## Ejemplo de Layout Básico
```html
<div class="grid-container">
    <div class="header">Header</div>
    <div class="sidebar">Sidebar</div>
    <div class="main-content">Main Content</div>
    <div class="footer">Footer</div>
</div>
```
```css
.grid-container {
    display: grid;
    grid-template-columns: 200px 1fr; /* Una columna fija y otra flexible */
    grid-template-rows: 100px auto 100px; /* Tres filas, central flexible */
    gap: 10px; /* Espacio entre filas y columnas */
}

.header {
    grid-column: 1 / span 2; /* Ocupa las dos columnas */
    background: #3498db;
}

.sidebar {
    grid-row: 2; /* Posicionado en la segunda fila */
    background: #2ecc71;
}

.main-content {
    grid-row: 2; /* También en la segunda fila */
    background: #e74c3c;
}

.footer {
    grid-column: 1 / span 2; /* También ocupa las dos columnas */
    background: #9b59b6;
}
```
En este ejemplo:
* **`grid-template-columns: 200px 1fr`** crea dos columnas, la primera de `200px` y la segunda flexible.

* **`grid-template-rows: 100px auto 100px`** crea tres filas: la primera y tercera de `100px` y la central flexible.

* `grid-column: 1 / span 2` en `.header` y `.footer` hace que ocupen ambas columnas.
