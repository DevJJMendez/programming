# Border
El border es la línea que rodea el padding y el contenido de un elemento en CSS. Es una capa adicional en el Box Model, ubicada entre el padding y el margin, y tiene propiedades propias para definir su color, estilo y grosor. Se puede usar para crear bordes sólidos, líneas punteadas, dobles, entre otros estilos, lo que da flexibilidad en el diseño de elementos.

## ¿Cómo se calcula su tamaño?
El tamaño del border se calcula en función de su grosor, el cual se define mediante la propiedad border-width. Este grosor es agregado al tamaño total del elemento si se usa `box-sizing: content-box` (donde se suma al ancho y alto especificados del contenido). Si se usa `box-sizing: border-box`, el grosor del `border` queda incluido dentro del tamaño total especificado.

Las propiedades del `border` que afectan su tamaño y estilo son:

* **`border-width`**: Controla el grosor del `border` (`e.g.`, `1px`, `5px`, etc.).

* **`border-style`**: Define el estilo de la línea del `border`, como `solid`, `dashed`, `dotted`, `double`, etc.

* **`border-color`**: Establece el color del `border`.

**Abreviado**
```css
.box {
    border: 3px solid #333; /* 3px de grosor, estilo sólido, color gris oscuro */
}
```

**Ejemplo de cálculo con `border-box` y `content-box`**
Si tienes un elemento con un width: 200px, padding: 20px, y border: 5px solid:

1. **Con `box-sizing: content-box`**:
   * El tamaño total del elemento será 200px + (2 * 20px) + (2 * 5px) = 250px de ancho.

2. **Con `box-sizing: border-box`**:
   * El `border` y el padding están incluidos en el ancho total, por lo que el ancho final del elemento sigue siendo 200px.

## ¿Para qué sirve el Border?
El border tiene múltiples propósitos en CSS:

* **Delimita visualmente elementos**: Ayuda a destacar o separar un elemento específico del resto de la página.

* **Resalta secciones importantes**: Con bordes más gruesos o de color diferente, puedes señalar contenido de interés, como cuadros de advertencia o secciones destacadas.

* **Define estructura y contornos**: Permite crear la ilusión de "cajas" o separaciones entre los componentes de una página.

## Tipos de Bordes
CSS permite definir bordes específicos para cada lado del elemento si se necesita personalización adicional:

1. **Bordes Uniformes**: Se aplica el mismo grosor, color y estilo en todos los lados.
```css
border: 2px solid black;
```

2. **Bordes por Lado**: Define los bordes en cada lado (`top`, `right`, `bottom`, `left`) por separado.
```css
border-top: 2px solid red;
border-right: 2px dashed green;
border-bottom: 2px double blue;
border-left: 2px dotted yellow;
```

3. **Esquinas Redondeadas**: Con la propiedad `border-radius`, puedes redondear las esquinas de un borde para un efecto más suave y moderno.
```css
border: 1px solid black;
border-radius: 10px; /* Bordes redondeados */
```
