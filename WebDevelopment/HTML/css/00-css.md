# Cascading Style Sheets
CSS (Cascading Style Sheets) es un lenguaje de hojas de estilo utilizado para describir la presentación de un documento HTML o XML (que incluye XHTML, SVG, y otros). Su función principal es separar el contenido (HTML) de la presentación visual (CSS).

## ¿Para qué sirve CSS?
CSS es responsable de dar estilo a los elementos de una página web. Esto incluye la definición de aspectos visuales como:

* Colores (de fondo, texto, bordes, etc.).

* Fuentes (tipo, tamaño, peso, estilo).

* Espaciado (márgenes, relleno, altura y ancho de los elementos).

* Distribución en la pantalla (layout, flexibilidad).

* Posicionamiento (donde aparecen los elementos en la página).

* Sombra y efectos visuales (sombra en texto, bordes redondeados, transiciones, etc.).

En resumen, CSS permite que los desarrolladores web definan cómo se verá una página web.

## ¿Qué resuelve CSS?
Antes de la creación de CSS, todo el formato visual de una página web tenía que ser incluido dentro del propio código HTML, lo que resultaba en un código desordenado y difícil de mantener. Las ventajas de CSS incluyen:

* **Separación de estructura y presentación**: Permite mantener el contenido HTML limpio y centrado en la estructura, mientras que el estilo (la apariencia visual) se maneja de forma separada en las hojas de estilo CSS.

* **Reusabilidad**: Puedes definir un conjunto de estilos y aplicarlos en varias páginas de tu sitio, lo que facilita la consistencia visual en todo el sitio web.

* **Mantenimiento**: Si quieres cambiar el diseño de tu sitio, solo necesitas modificar el archivo CSS, no el código HTML de cada página. Esto facilita la actualización y mantenimiento del sitio.

* **Optimización y rendimiento**: CSS permite que los elementos sean mostrados de manera eficiente, ya que puedes controlar la disposición y visibilidad de los elementos sin modificar el HTML, lo que reduce la necesidad de recargar contenido repetitivo.

* **Accesibilidad**: CSS ofrece opciones de personalización que pueden hacer que el sitio sea accesible para personas con diferentes capacidades (como opciones de cambio de contraste, tamaños de fuente ajustables, etc.).

## ¿Cómo lo resuelve?
CSS resuelve los problemas mencionados de diversas formas, principalmente a través de:

1. **Selectores**

2. **Propiedades y Valores**

3. **Cascada y Especificidad**

4. **Posicionamiento**

5. **Flexbox y Grid Layout**

6. **Media Queries**

7. **Transiciones y Animaciones**
