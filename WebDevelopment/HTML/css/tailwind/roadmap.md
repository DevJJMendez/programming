# Nivel	Concepto clave	Qué debes aprender
* Básico	Clases utilitarias	Margin, Padding, Color, Border, Radius, Typography
* Intermedio	Layouts	Flexbox, Grid, Responsivo (sm:, md:, lg:), Dark Mode
* Avanzado	Componentización	Extraer componentes, usar @apply, escribir clases dinámicas
* Experto	Personalización y optimización	Configurar tailwind.config.js, crear tu Design System, usar Plugins

## Conceptos principales que debes entender y dominar:
Spacing: m-4, p-2, gap-6, etc.

Sizing: w-1/2, h-96, max-w-sm.

Typography: text-lg, font-bold, leading-6.

Colors: bg-blue-500, text-gray-700.

Flexbox: flex, justify-between, items-center.

Grid: grid, grid-cols-3, gap-4.

Positioning: relative, absolute, top-0.

Responsive: sm:, md:, lg:, xl:.

Pseudo-classes: hover:bg-blue-600, focus:outline-none.

Dark Mode: dark:bg-gray-800.

Animation: transition, duration-300, ease-in-out.

Customization: Modificar tailwind.config.js para colores, breakpoints, fonts, etc.
