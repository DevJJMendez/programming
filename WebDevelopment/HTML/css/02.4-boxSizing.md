# `box-sizing`
La propiedad box-sizing en CSS define cómo se calculan las dimensiones de los elementos, es decir, si el tamaño especificado para el ancho (**`width`**) y la altura (**`height`**) de un elemento incluye solo el área de contenido o si también incorpora el **`padding`** y el **`border`** del elemento. El box-sizing es una propiedad clave para controlar el diseño y evitar problemas de ajuste, especialmente cuando estás diseñando layouts precisos o responsivos.

## ¿Qué es box-sizing?
box-sizing es una propiedad de CSS que permite cambiar el modelo de caja de un elemento, influenciando el cálculo total de su **`width`** y **`height`**. El modelo de caja determina cómo se suman los diferentes componentes de un elemento (contenido, padding, borde) para calcular su tamaño final en pantalla.

## ¿Para qué sirve box-sizing?
box-sizing sirve para:

* Controlar cómo se calcula el tamaño de los elementos al incluir o excluir padding y borde dentro de **`width`** y **`height`**.

* Simplificar la construcción de layouts: ayuda a que el diseño de los elementos sea más predecible, ya que los **`bordes`** y el **`padding`** no aumentan el tamaño total del elemento.

* Mantener un diseño consistente: particularmente útil para diseños responsivos o layouts complejos donde el espacio disponible es limitado.

## ¿Qué resuelve box-sizing?
Sin box-sizing, los elementos tienden a crecer cuando se les aplica padding o borde, lo que puede hacer que se desborden o que afecten el diseño general. box-sizing resuelve problemas como:

* Control inconsistente del tamaño de los elementos cuando se agregan estilos adicionales como padding o bordes.

* Desbordamientos no deseados en contenedores, ya que en el modelo de caja tradicional, cada capa suma espacio al total de la caja, haciendo más difícil mantener un diseño alineado.

* Problemas de precisión en layouts que requieren tamaños específicos, especialmente al construir interfaces complejas.

## ¿Cómo lo resuelve?
El valor predeterminado de box-sizing es content-box, donde solo el área de contenido se incluye en las dimensiones especificadas, mientras que border-box incluye el padding y el borde en el tamaño total del elemento.

### Principales valores de box-sizing
1. **`content-box` (valor por defecto)**:

   * El tamaño de width y height afecta solo el contenido del elemento, excluyendo padding y borde.

   * Cualquier padding y borde se agregan al tamaño total de la caja, haciendo que el elemento ocupe más espacio del especificado.

```css
.content-box {
    box-sizing: content-box;
    width: 300px;
    padding: 20px;
    border: 5px solid black;
    /* Tamaño total = 300px + 2 * (padding + borde) = 350px */
}
```

2. **`border-box`**:

   * El width y height especificados incluyen el padding y el borde.

   * El tamaño total del elemento se mantiene en lo especificado, lo que lo hace más manejable y predecible.

```css
.border-box {
    box-sizing: border-box;
    width: 300px;
    padding: 20px;
    border: 5px solid black;
    /* Tamaño total = 300px (padding y borde están incluidos en este valor) */
}
```
Al usar border-box, el diseño es más predecible, ya que el tamaño total del elemento siempre permanece igual a los valores especificados, sin que se agreguen "extras".


## Ejemplo de comparación
```html
<div class="content-box">Content-box</div>
<div class="border-box">Border-box</div>
```
```css
* {
    box-sizing: border-box; /* Hace que todos los elementos utilicen border-box */
}

.content-box {
    box-sizing: content-box;
    width: 200px;
    padding: 20px;
    border: 5px solid red;
}

.border-box {
    box-sizing: border-box;
    width: 200px;
    padding: 20px;
    border: 5px solid blue;
}
```
En este ejemplo, .content-box tendrá un tamaño total mayor que .border-box debido a la suma del padding y borde. .border-box se ajustará exactamente al tamaño de width especificado, ya que incluye el padding y el borde en el tamaño total de la caja.

## ¿Cómo se aplica en la práctica?
Una práctica común en CSS es establecer el valor box-sizing: border-box; para todos los elementos al inicio de los estilos. Esto se logra con el siguiente CSS:

```css
*,
*::before,
*::after {
    box-sizing: border-box;
}
```
Esto asegura que todos los elementos y pseudo-elementos en la página usen el mismo modelo de caja, simplificando el diseño y evitando problemas de cálculo en los layouts.
