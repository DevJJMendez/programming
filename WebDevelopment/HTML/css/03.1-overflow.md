# Overflow
overflow es una propiedad CSS que define cómo debe manejarse el contenido cuando supera el tamaño asignado de un elemento contenedor. Al establecer su valor, puedes elegir entre mostrar, ocultar o permitir el desplazamiento del contenido desbordado.

## ¿Para qué sirve overflow?
La propiedad overflow sirve para:

* Controlar la visualización de contenido excedente en un área limitada, como una tarjeta de información o un cuadro de texto.

* Mejorar la experiencia del usuario, evitando que el contenido se desborde y afecte el diseño visual de la página.

* Establecer barras de desplazamiento (scroll) en áreas específicas sin afectar el diseño global.

## ¿Qué resuelve overflow?
overflow resuelve el problema del desbordamiento de contenido en elementos con dimensiones fijas. Sin esta propiedad, el contenido que excede el tamaño del contenedor se mostraría fuera de los límites, lo cual puede desordenar el diseño, interferir con otros elementos o hacer difícil la legibilidad.

Por ejemplo:

* En un cuadro con un límite de altura, overflow permite restringir el contenido que no cabe, evitando el desbordamiento visual.

* En galerías de imágenes o áreas con listas extensas, overflow permite la creación de barras de desplazamiento para visualizar el contenido adicional.

## ¿Cómo lo resuelve?
La propiedad overflow tiene varios valores que determinan cómo se maneja el contenido que excede el área del contenedor:

* `visible` (valor predeterminado): el contenido desbordado se muestra sin restricción, aunque salga del contenedor.

* `hidden`: el contenido desbordado queda oculto y no es visible ni accesible fuera del área del contenedor.

* `scroll`: siempre se muestra una barra de desplazamiento, sin importar si el contenido es más grande que el contenedor.

* `auto`: muestra una barra de desplazamiento solo si el contenido excede el tamaño del contenedor.

## Valores adicionales: overflow-x y overflow-y
CSS permite especificar el comportamiento del desbordamiento de forma independiente en las direcciones horizontal y vertical:

* **`overflow-x`**: controla el desbordamiento horizontal.

* **`overflow-y`**: controla el desbordamiento vertical.

**Ejemplo de uso:**
```css
.box {
    width: 200px;
    height: 100px;
    border: 1px solid #000;
    overflow-x: auto; /* Scroll solo en horizontal si es necesario */
    overflow-y: hidden; /* Oculta cualquier desbordamiento vertical */
}
```
