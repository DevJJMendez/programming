# Visibility
visibility es una propiedad de CSS que determina si un elemento es visible o no, sin afectar la disposición general del diseño. Se utiliza para ocultar o mostrar elementos sin eliminar su espacio en el documento, lo que significa que los elementos adyacentes no se reubican ni cambian de tamaño.

## ¿Para qué sirve visibility?
La propiedad visibility sirve para:

* Ocultar temporalmente un elemento sin alterar el layout o flujo de la página.

* Controlar la accesibilidad y la interactividad de un elemento en casos donde deba permanecer en su lugar sin que el usuario lo vea.

* Mostrar y ocultar contenido dinámicamente en aplicaciones donde el espacio debe reservarse, como en menús desplegables, animaciones, y transiciones en interfaz.

## ¿Qué resuelve visibility?
La propiedad visibility resuelve la necesidad de ocultar elementos en una interfaz sin cambiar la estructura del diseño. Esto es especialmente útil cuando un cambio de diseño (por ejemplo, con display: none) podría provocar que el layout se ajuste, lo cual podría no ser deseado en algunos casos.

Por ejemplo:

* Si tienes un mensaje de error o una notificación que necesitas mostrar solo cuando sea necesario, visibility permite ocultarlo sin cambiar la disposición de otros elementos.

* En animaciones, es útil para iniciar o detener la visibilidad de un elemento sin afectar otros elementos en pantalla.

## ¿Cómo lo resuelve?
visibility tiene tres valores principales que controlan su comportamiento:

* `visible`: el elemento es visible en la página (valor predeterminado).

* `hidden`: el elemento está oculto, pero su espacio sigue reservado en el layout.

* `collapse`: es específico para elementos en tablas y puede ocultar elementos sin que ocupen espacio, similar a `display: none`.

```css
.hidden-element {
    visibility: hidden;
}
```

## Ejemplo básico de uso de visibility
Supongamos que tienes un mensaje de advertencia en tu página que debe estar siempre en la misma posición, incluso si no es visible.

```html
<div class="container">
    <p class="info">Información importante aquí.</p>
    <p class="warning">Este es un mensaje de advertencia.</p>
</div>
```
```css
.warning {
    visibility: hidden; /* El mensaje de advertencia no es visible */
}
```
En este caso, `.warning` estará oculto pero continuará ocupando el mismo espacio en la página, lo cual es útil si luego deseas mostrar el mensaje sin que se realinee el resto del contenido.
