# Tablas
Las etiquetas para tablas en HTML son un conjunto de elementos que permiten crear una tabla, donde los datos se organizan en una cuadrícula de filas y columnas. Estas etiquetas son fundamentales para representar información numérica, categórica, o cualquier dato que necesite una estructura ordenada y fácil de leer.

## ¿Cuáles son los tipos de etiquetas para tablas?
Las etiquetas principales para construir tablas en HTML son:

1. **`<table>`**: Representa el contenedor principal de la tabla.

2. **`<tr>` (Table Row)**: Define una fila dentro de la tabla. Cada fila puede contener celdas de encabezado o celdas de datos.

3. **`<th>` (Table Header)**: Define una celda de encabezado, que suele utilizarse para los títulos de las columnas o filas de la tabla. Los datos en `<th>` generalmente se muestran en negrita y están centrados de forma predeterminada.

4. **`<td>` (Table Data)**: Representa una celda de datos en la tabla, donde se almacenan los valores específicos.

5. `<thead>`: Define el encabezado de la tabla, agrupando todas las celdas de encabezado (`<th>`) en una sola sección. Esto ayuda a organizar visualmente la tabla y proporciona un contexto claro a los datos.

6. **`<tbody>`**: Agrupa el contenido principal de la tabla, es decir, las filas y celdas de datos (<tr> y <td>). Es útil para separar los datos de los encabezados o pies de tabla.

7. `<tfoot>`: Define el pie de la tabla, que puede contener información adicional, como totales o sumarios.

## ¿Para qué sirven las etiquetas para tablas?
Estas etiquetas sirven para estructurar datos complejos en un formato visual y coherente, lo que facilita su lectura, comparación y análisis. Las tablas son especialmente útiles en informes, bases de datos visuales, inventarios, estadísticas y otros contextos donde el usuario necesita comparar múltiples elementos a la vez.

## ¿Qué problemas resuelven las etiquetas para tablas?
Las tablas resuelven varios problemas comunes:

1. **Organización de grandes volúmenes de datos**: Permiten estructurar datos extensos, haciéndolos fáciles de seguir y comparar.

2. **Legibilidad y claridad**: Mejoran la presentación de datos complejos y jerárquicos, haciendo que los usuarios puedan interpretar la información de forma intuitiva.

3. **Accesibilidad y estructura semántica**: Proporcionan una estructura que facilita la navegación para tecnologías de asistencia, como lectores de pantalla.

## ¿Cómo resuelven estos problemas las etiquetas para tablas?
Las etiquetas de tablas resuelven estos problemas al proporcionar una estructura semántica clara y soporte de estilo para presentar datos tabulares. Las etiquetas `<thead>`, `<tbody>`, y `<tfoot>`, junto con `<tr>`, `<th>`, y `<td>`, permiten dividir visual y semánticamente la tabla, haciendo que la información sea accesible y fácil de comprender. Los navegadores y los lectores de pantalla pueden interpretar correctamente la estructura, mejorando la experiencia de usuario.

## Ejemplo de una tabla completa en HTML
```html
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ejemplo de Tabla en HTML</title>
</head>
<body>
    <h2>Lista de Productos</h2>
    <table border="1">
        <!-- Encabezado de la tabla -->
        <thead>
            <tr>
                <th>ID</th>
                <th>Nombre del Producto</th>
                <th>Categoría</th>
                <th>Precio</th>
            </tr>
        </thead>

        <!-- Cuerpo de la tabla -->
        <tbody>
            <tr>
                <td>1</td>
                <td>Camiseta</td>
                <td>Ropa</td>
                <td>$20</td>
            </tr>
            <tr>
                <td>2</td>
                <td>Pantalón</td>
                <td>Ropa</td>
                <td>$40</td>
            </tr>
            <tr>
                <td>3</td>
                <td>Zapatillas</td>
                <td>Calzado</td>
                <td>$60</td>
            </tr>
        </tbody>

        <!-- Pie de la tabla -->
        <tfoot>
            <tr>
                <td colspan="3">Total</td>
                <td>$120</td>
            </tr>
        </tfoot>
    </table>
</body>
</html>
```
1. **Encabezado de la tabla (`<thead>`)**
   * Aquí se definen los títulos de cada columna. En este caso, ID, Nombre del Producto, Categoría y Precio. Estos encabezados ayudan a dar contexto a los datos en cada columna.

2. **Cuerpo de la tabla (`<tbody>`)**
   * Contiene las filas de datos (`<tr>`) que corresponden a los productos. Cada fila contiene celdas (`<td>`) con información específica: el ID del producto, su nombre, categoría y precio.

3. **Pie de la tabla (`<tfoot>`)**
   * Contiene información final o sumaria, como el total de precios en este caso. El uso de `<tfoot>` permite resaltar la conclusión o el resumen de los datos.

## Buenas prácticas al trabajar con tablas en HTML
1. **Utilizar `<thead>`, `<tbody>`, y `<tfoot>` adecuadamente**
   * Estas etiquetas ayudan a segmentar la tabla y mejoran la accesibilidad, permitiendo que los lectores de pantalla identifiquen fácilmente la estructura.

2. **Evitar usar tablas para diseño**
   * Aunque es posible utilizar tablas para organizar el diseño de una página, esto es considerado una mala práctica. Las tablas deben usarse exclusivamente para datos tabulares.

3. **Agregar scope a `<th>` para accesibilidad**
   * El atributo scope indica la relación de la celda con las filas o columnas, mejorando la accesibilidad para tecnologías de asistencia.

```html
<th scope="col">Nombre</th>
<th scope="row">Precio</th>
```

4. **Usar estilos CSS para personalizar la tabla**
   * En lugar de usar el atributo border directamente en HTML, es preferible estilizar las tablas con CSS para un mayor control y flexibilidad.

5. **Simplificar la estructura cuando sea posible**
   * Evita sobrecargar la tabla con demasiadas filas o columnas, ya que esto puede reducir la legibilidad. Si tienes mucha información, considera dividirla en varias tablas o secciones.

6. **Optimizar para dispositivos móviles**
   * Las tablas pueden ser difíciles de visualizar en pantallas pequeñas. En algunos casos, es conveniente usar soluciones de CSS, como estilos responsive, para que las tablas sean más legibles en móviles.
