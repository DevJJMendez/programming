# Tipos de algoritmos
1. **Algoritmos de Búsqueda y Ordenamiento**
   * Búsqueda: Encuentran elementos específicos dentro de estructuras de datos.

   * Ejemplo: Búsqueda lineal, Búsqueda binaria.

   * Ordenamiento: Organizan elementos según un criterio.

   * Ejemplo: Bubble Sort, Merge Sort.

1. **Algoritmos Recursivos**
   * Definición: Aquellos que se llaman a sí mismos para resolver subproblemas más pequeños.

   * Ejemplo: Búsqueda binaria, cálculo de factorial, Fibonacci.

   * Ventaja: Reduce la complejidad de algunos problemas.

   * Problema que resuelven: Dividir problemas grandes en partes más pequeñas.

2. **Algoritmos Iterativos**
   * Definición: Utilizan bucles para repetir un conjunto de instrucciones.

   * Ejemplo: Suma de los elementos de un arreglo.

   * Ventaja: Más eficientes en el uso de memoria que los recursivos.

3. **Algoritmos Divide y Vencerás**
   * Definición: Dividen un problema en subproblemas, resuelven cada uno y combinan los resultados.

   * Ejemplo: Merge Sort, Quick Sort, búsqueda binaria.

   * Problema que resuelven: Grandes volúmenes de datos o problemas con estructura jerárquica.

4. **Algoritmos Greedy (Avariciosos)**
   * Definición: Toman decisiones óptimas locales en cada paso con la esperanza de llegar a la solución global óptima.

   * Ejemplo: Algoritmo de Kruskal para árboles generadores mínimos.

   * Problema que resuelven: Optimización combinatoria (como encontrar caminos más cortos).

5. **Algoritmos Dinámicos**
   * Definición: Resuelven problemas complejos dividiéndolos en subproblemas más simples y almacenando soluciones intermedias para evitar cálculos repetidos.

   * Ejemplo: Mochila 0/1, cadenas de ADN.

   * Problema que resuelven: Problemas con subproblemas solapados.

6. **Algoritmos Backtracking**
   * Definición: Intentan resolver problemas retrocediendo y deshaciendo pasos si una solución no funciona.

   * Ejemplo: Problemas de laberintos, Sudoku.

   * Problema que resuelven: Búsqueda de soluciones en problemas combinatorios.

7. **Algoritmos de Fuerza Bruta (Brute Force)**
   * Definición: Prueban todas las combinaciones posibles hasta encontrar una solución.

   * Ejemplo: Fuerza bruta para encontrar contraseñas.

   * Ventaja: Garantizan encontrar una solución, pero son ineficientes.

   * Problema que resuelven: Casos pequeños o cuando no hay otra alternativa.

8. **Algoritmos Probabilísticos**
   * Definición: Utilizan la probabilidad para tomar decisiones en cada paso.

   * Ejemplo: Algoritmo de Monte Carlo.

   * Problema que resuelven: Casos donde no es posible una solución determinista.

9.  **Algoritmos de Hashing**
    * Definición: Transforman entradas en claves únicas mediante funciones hash.

    * Ejemplo: Tablas hash, sistemas de búsqueda rápida.

    * Problema que resuelven: Búsqueda rápida y eficiente de datos.

10. **Algoritmos de Grafos**
    * Propósito: Manipular y analizar grafos.

    * Problemas que resuelven: Conectividad, rutas más cortas, flujo máximo, detección de ciclos.

    * Ejemplos: BFS, DFS, Dijkstra, Algoritmo de Bellman-Ford.

    * ¿Cómo lo resuelven?: Utilizan estructuras de datos especializadas como listas de adyacencia y matrices para navegar a través de los nodos y bordes.
