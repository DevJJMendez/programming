# Algoritmos
Un algoritmo es un conjunto **finito** de pasos o **instrucciones** bien definidas y ordenadas que resuelven un problema o realizan una tarea específica.

Características clave:
* **Finitud**: Todo algoritmo debe terminar después de un número finito de pasos.

* **Precisión**: Cada paso debe estar claramente definido y no debe dar lugar a ambigüedades.

* **Entrada y salida**: Puede tomar entradas y siempre produce una salida.

* **Eficiencia**: Debe optimizar el tiempo y el uso de recursos.

## ¿Para qué sirven los algoritmos?
Los algoritmos son esenciales para:

* **Resolver problemas computacionales**: Como ordenar, buscar, calcular rutas óptimas, etc.

* **Automatizar tareas repetitivas**: Ahorran tiempo al realizar procesos complejos automáticamente.

* **Optimizar recursos**: Reducen tiempo y espacio en problemas grandes.

* **Estandarizar procesos**: Proveen pasos claros para lograr resultados consistentes.

## ¿Qué problemas resuelven?
* **Búsqueda**: Encontrar un dato en una gran colección -> **Algoritmos de búsqueda**

* **Ordenamiento**: Organizar datos para facilitar su análisis -> **Algoritmos de ordenamiento**

* **Optimización**: Encontrar la mejor solución entre varias opciones -> Ejemplo: `Algoritmo de Dijkstra`.

* **Reconocimiento de patrones**: Identificar patrones en datos no estructurados -> Ejemplo: `Algoritmos de machine learning`.

* **División y conquista**: Resolver problemas grandes dividiéndolos en partes manejables -> Ejemplo: `Quick Sort`.

## ¿Cómo resuelven problemas los algoritmos?
1. **Análisis del problema**: Comprenden el problema y definen claramente las entradas y salidas.

2. **División en pasos**: Establecen un conjunto de instrucciones claras y finitas.

3. **Ejecución eficiente**:
   * Utilizan estructuras de datos adecuadas para optimizar el rendimiento.

   * Por ejemplo, un árbol binario para búsquedas rápidas.

4. **Validación y refinamiento**: Se prueban con varios casos para garantizar que funcionan correctamente.

5. **Optimización**: Se mejora la complejidad del algoritmo (tiempo y espacio) usando técnicas como:
   * **Almacenamiento intermedio**: Usado en programación dinámica.
   
   * **Poda**: Para eliminar caminos innecesarios (como en Backtracking).
