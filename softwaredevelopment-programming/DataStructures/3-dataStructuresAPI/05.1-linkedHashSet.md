`LinkedHashSet`
La clase LinkedHashSet en Java es una implementación de la interfaz Set que combina las características de un HashSet y una lista enlazada (Linked List). Es parte de la colección de clases en Java y ofrece un conjunto ordenado y eficiente para almacenar elementos únicos, manteniendo el orden de inserción.

## ¿Qué es LinkedHashSet?
Un LinkedHashSet es una clase que almacena elementos en un conjunto de forma que no permite duplicados (similar a HashSet) y además mantiene el orden de inserción de los elementos (a diferencia de HashSet). Internamente, utiliza una tabla hash para la eficiencia en la búsqueda y una lista doblemente enlazada para mantener el orden de los elementos.

## ¿Para Qué Sirve LinkedHashSet?
1. **Almacenar Elementos Únicos con Orden de Inserción**: Se utiliza cuando necesitas asegurarte de que cada elemento en la colección sea único y, además, que los elementos se mantengan en el orden en que se insertaron.

2. **Eficiencia en Búsqueda, Inserción y Eliminación**: Permite realizar operaciones como búsqueda, inserción y eliminación de elementos de manera eficiente, aunque es un poco más lento que un HashSet debido a la estructura adicional para el orden.

## ¿Qué Problema Resuelve LinkedHashSet?
1. **Duplicados y Orden de Inserción**: Al igual que HashSet, evita los duplicados, pero a diferencia de HashSet, preserva el orden de inserción de los elementos. Esto es útil en situaciones donde el orden de los datos importa, como mostrar una lista de usuarios en el orden en que se registraron.

2. **Eficiencia en Operaciones**: Proporciona operaciones más eficientes que otras estructuras de datos que también mantienen el orden, como ArrayList, en términos de búsquedas y eliminaciones.

## ¿Cómo lo Resuelve?
Internamente, LinkedHashSet utiliza:

1. **Tabla Hash**: Para almacenar los elementos y asegurarse de que no haya duplicados. Las operaciones de búsqueda, inserción y eliminación tienen una complejidad promedio de O(1) (constante), lo que es muy eficiente.

2. **Lista Doblemente Enlazada**: Para mantener el orden de inserción de los elementos. Cada nodo en la tabla hash está vinculado a la lista para conservar el orden.

## Ejemplo de Uso de LinkedHashSet
Veamos un ejemplo práctico para entender cómo funciona:

```java
import java.util.LinkedHashSet;

public class EjemploLinkedHashSet {
    public static void main(String[] args) {
        LinkedHashSet<String> nombres = new LinkedHashSet<>();

        // Añadir elementos
        nombres.add("Ana");
        nombres.add("Carlos");
        nombres.add("Beatriz");
        nombres.add("Daniel");
        nombres.add("Ana"); // Duplicado, no se añadirá

        // Mostrar los elementos
        System.out.println(nombres); // Output: [Ana, Carlos, Beatriz, Daniel]

        // Comprobar si contiene un elemento
        boolean contieneCarlos = nombres.contains("Carlos");
        System.out.println("¿Contiene Carlos? " + contieneCarlos); // Output: true

        // Eliminar un elemento
        nombres.remove("Beatriz");
        System.out.println(nombres); // Output: [Ana, Carlos, Daniel]
    }
}
```

## Métodos
La clase LinkedHashSet en Java hereda la mayoría de sus métodos de la interfaz Set, la clase HashSet, y las interfaces que implementan éstas (Collection, Iterable).

1. **`boolean add(E e)`**: Añade el elemento especificado al conjunto si aún no está presente. Si el elemento ya existe, no hace nada y devuelve false.
```java
LinkedHashSet<String> nombres = new LinkedHashSet<>();
nombres.add("Juan");
nombres.add("Pedro");
nombres.add("Juan"); // No se añadirá porque ya existe.
```

2. **`boolean remove(Object o)`**: Elimina el elemento especificado del conjunto si está presente.
```java
nombres.remove("Pedro"); // Eliminará "Pedro" del conjunto.
```

3. **`boolean contains(Object o)`**: Verifica si el conjunto contiene el elemento especificado.
```java
if (nombres.contains("Juan")) {
    System.out.println("Juan está en el conjunto.");
}
```

4. **`int size()`**: Devuelve el número de elementos en el conjunto.
```java
System.out.println("Tamaño del conjunto: " + nombres.size());
```

5. **`void clear()`**: Elimina todos los elementos del conjunto, dejándolo vacío.

6. **`boolean isEmpty()`**: Devuelve true si el conjunto no contiene ningún elemento.

7. **`boolean addAll(Collection<? extends E> c)`**: Añade todos los elementos de la colección especificada al conjunto si aún no están presentes.
```java
LinkedHashSet<String> otrosNombres = new LinkedHashSet<>();
otrosNombres.add("Ana");
otrosNombres.add("Mario");
nombres.addAll(otrosNombres); // Agrega "Ana" y "Mario".
```

8. **`boolean retainAll(Collection<?> c)`**: Conserva solo los elementos del conjunto que están contenidos en la colección especificada.
```java
LinkedHashSet<String> nombresAConservar = new LinkedHashSet<>();
nombresAConservar.add("Juan");
nombres.retainAll(nombresAConservar); // Mantendrá solo "Juan".
```

9. **`boolean removeAll(Collection<?> c)`**: Elimina todos los elementos del conjunto que están contenidos en la colección especificada.
```java
LinkedHashSet<String> nombresAEliminar = new LinkedHashSet<>();
nombresAEliminar.add("Ana");
nombres.removeAll(nombresAEliminar); // Elimina "Ana" si está presente.
```
