# `LinkedHashMap`
LinkedHashMap es una clase en Java que extiende HashMap y, al igual que esta, implementa la interfaz Map. La diferencia clave es que LinkedHashMap mantiene el orden de inserción de los elementos, lo que significa que cuando recorres el mapa, los elementos aparecerán en el mismo orden en que se agregaron. Esto se logra manteniendo una lista doblemente enlazada que registra el orden de inserción.

## ¿Para qué sirve LinkedHashMap?
LinkedHashMap es útil en situaciones donde necesitas almacenar pares clave-valor como en HashMap, pero además deseas preservar el orden de inserción de los elementos. Algunos casos de uso incluyen:

1. **Cachés de uso reciente**: Se puede usar para implementar algoritmos de caché como LRU (Least Recently Used) donde los elementos menos recientemente utilizados se eliminan primero.

2. **Aplicaciones donde el orden importa**: Como al imprimir resultados en el orden exacto de llegada, configuraciones ordenadas, etc.

3. **Visualización ordenada de datos**: Por ejemplo, al crear reportes o listas donde el orden de las entradas es crucial.

## ¿Qué resuelve LinkedHashMap?
LinkedHashMap resuelve el problema de la falta de orden en HashMap. A diferencia de HashMap, que no garantiza el orden de los elementos, LinkedHashMap mantiene el orden en el que se insertan los pares clave-valor o, si se desea, el orden de acceso más reciente. Esto es particularmente valioso cuando:

1. **El orden importa**: Quieres preservar el orden de entrada original para fines de presentación o lógica de negocios.

2. **Optimización de cachés**: Necesitas mantener un caché con una política de eliminación basada en el acceso más reciente.

##¿Cómo lo resuelve LinkedHashMap?
1. **Lista doblemente enlazada**: LinkedHashMap mantiene una lista doblemente enlazada que registra el orden en que se agregaron las entradas. Esta lista se actualiza automáticamente cuando se agregan, eliminan o acceden a elementos. Como resultado, puedes recorrer el LinkedHashMap en el orden exacto de inserción o de acceso.

2. **Opcionalmente mantiene el orden de acceso**: LinkedHashMap puede configurarse para ordenar los elementos en función de su acceso más reciente. Esto se logra mediante un parámetro booleano adicional en el constructor (accessOrder). Cuando se establece en true, los elementos se ordenan en función del orden de acceso en lugar del orden de inserción.

## Características Clave de LinkedHashMap
* **Preserva el orden de inserción**: Los elementos se recorren en el mismo orden en que fueron agregados.

* **Orden basado en acceso**: Puede configurarse para ordenar los elementos según el acceso más reciente, ideal para cachés LRU.

* **Permite claves y valores null**: Similar a HashMap, admite una clave null y valores null.

* **No es seguro para hilos**: No es seguro para entornos multihilo. Si necesitas una versión sincronizada, debes manejar la sincronización manualmente o usar una implementación como ConcurrentHashMap.

6. **`entrySet()`**

7. **`containsKey(Object key)`**

8. **`containsValue(Object value)`**

9. **`getOrDefault(Object key, V defaultValue)`**: Devuelve el valor asociado a la clave o un valor predeterminado si la clave no existe.

