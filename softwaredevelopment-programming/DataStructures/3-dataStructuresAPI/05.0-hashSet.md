# `HashSet`
La clase HashSet es una implementación concreta de la interfaz Set en Java que utiliza una tabla hash para almacenar sus elementos. Es parte del paquete java.util. A diferencia de otras colecciones como List, un HashSet no permite elementos duplicados y no garantiza el orden de los elementos.

## ¿Qué es HashSet?
HashSet es una clase que implementa la interfaz Set y se basa en el uso de una tabla hash para almacenar sus elementos. Los HashSet son eficientes para realizar operaciones básicas como añadir, eliminar y verificar la existencia de un elemento. Estas operaciones suelen tener una complejidad de tiempo promedio de `O(1)`.

## ¿Para qué sirve HashSet?
HashSet es útil cuando necesitas:

1. **Almacenar elementos únicos**: Ideal para escenarios donde se requiere garantizar la unicidad de los elementos, como listas de usuarios únicos, ID únicos, etc.

2. **Operaciones rápidas de inserción, eliminación y búsqueda**: Al estar basado en una tabla hash, HashSet es muy eficiente en términos de tiempo para estas operaciones.

3. **Eliminar duplicados**: Si tienes una colección de elementos y deseas asegurarte de que no haya duplicados, puedes almacenarlos en un HashSet.

## ¿Qué resuelve HashSet?
HashSet resuelve varios problemas comunes al trabajar con colecciones de datos:

1. **Gestión de elementos únicos**: Asegura que no haya duplicados en la colección.

2. **Eficiencia en operaciones básicas**: Proporciona una forma rápida de verificar la existencia de un elemento, agregar nuevos elementos y eliminar existentes.

3. **Eliminación automática de duplicados**: No necesitas preocuparte por implementar lógica adicional para evitar elementos repetidos; HashSet lo hace por ti.

## ¿Cómo lo resuelve HashSet?
1. **Uso de una Tabla `Hash`**: HashSet utiliza una tabla hash (hash table) para almacenar los elementos. Cada elemento que agregas se convierte en una posición única en la tabla a través de un código hash (hash code). Si dos elementos producen el mismo código hash, se manejan mediante un mecanismo de "encadenamiento" (chaining) que almacena ambos elementos en la misma posición, pero como una lista de valores.

2. **Métodos Importantes**
   * `add(E e)`: Agrega el elemento al conjunto si no está ya presente. Si el elemento ya existe, no se añadirá.

   * `remove(Object o)`: Elimina el elemento especificado del conjunto.

   * `contains(Object o)`: Verifica si el elemento existe en el conjunto.

   * `size()`: Devuelve el número de elementos en el HashSet.

   * `isEmpty()`: Verifica si el HashSet está vacío.

   * `clear()`: Elimina todos los elementos del HashSet.

## Detalles Técnicos de HashSet
1. **Estructura Interna**:

   * HashSet se basa en una tabla hash. Los elementos se colocan en "cubetas" (buckets) en función del valor de su código hash (hashCode()).

   * Cada cubeta puede contener múltiples elementos, pero si varios elementos caen en la misma cubeta (colisiones), estos se almacenan como una lista dentro de esa cubeta.

2. **Código Hash y Colisiones**:

   * HashSet utiliza el método hashCode() para calcular el índice de almacenamiento en la tabla hash.

   * Cuando dos elementos tienen el mismo código hash (colisión), HashSet los almacena en una lista vinculada en esa posición de la tabla.

3. **Orden de los Elementos**:

   * **No garantiza orden**: Los elementos en un HashSet no tienen un orden específico. Esto se debe a cómo se distribuyen en la tabla hash, y no hay ninguna garantía de que se mantenga el orden de inserción.

4. **Capacidad y Factor de Carga**:

   * HashSet tiene un concepto de capacidad y factor de carga.

     * **Capacidad**: Número total de cubetas disponibles en la tabla hash.

     * **Factor de carga**: Medida de cuán llena puede estar la tabla antes de que se realice una reestructuración. El valor por defecto es 0.75, lo que significa que si el HashSet está lleno al 75%, se duplicará el número de cubetas.


   * **Redimensionamiento**: Si la cantidad de elementos supera la capacidad multiplicada por el factor de carga, HashSet aumentará la capacidad para mejorar el rendimiento.

## Ventajas del uso de HashSet
1. **Eficiencia**: Proporciona operaciones de inserción, eliminación y búsqueda rápidas.

2. **No permite duplicados**: Ideal para gestionar listas de elementos únicos sin necesidad de lógica adicional.

3. **Fácil de usar**: Su interfaz es sencilla y proporciona métodos útiles para manipular el conjunto.

## Desventajas del uso de HashSet
1. **No mantiene el orden**: Si necesitas mantener el orden de inserción, debes usar LinkedHashSet.

2. **Rendimiento dependiente del hashCode()**: Un mal diseño del método hashCode() para los elementos puede afectar el rendimiento de HashSet debido a las colisiones.

## ¿Cuándo usar HashSet?
* **Almacenar elementos únicos**: Cuando necesitas asegurar que no haya duplicados.

* **Operaciones rápidas**: HashSet es más rápido que otras estructuras como ArrayList para verificar si un elemento existe, agregar y eliminar.

* **Grandes colecciones**: HashSet es adecuado para manejar grandes cantidades de datos porque maneja eficientemente la inserción y búsqueda.
