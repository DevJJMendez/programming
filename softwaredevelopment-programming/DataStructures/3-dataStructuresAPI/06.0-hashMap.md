# `HashMap`
La clase HashMap en Java es una implementación de la interfaz Map que utiliza una tabla hash para almacenar pares clave-valor. Es una estructura de datos que permite almacenar objetos de manera que puedas acceder a los valores asociados a las claves de manera rápida y eficiente. Cada clave en un HashMap es única, y el uso de tablas hash proporciona una excelente eficiencia para la inserción, eliminación y búsqueda de elementos.

## ¿Para qué sirve HashMap?
HashMap es ideal para situaciones donde necesitas almacenar y acceder rápidamente a datos utilizando una clave única. Algunos casos de uso comunes incluyen:

1. **Almacenar configuraciones o preferencias de usuario**: donde las claves pueden ser los nombres de las configuraciones, y los valores pueden ser los ajustes específicos.

2. **Contadores de elementos**: como un contador de palabras en un texto, donde las claves son palabras y los valores son sus conteos.

3. **Asociaciones de búsqueda**: como una agenda telefónica donde las claves son nombres y los valores son números de teléfono.

## ¿Qué resuelve HashMap?
HashMap resuelve problemas relacionados con la necesidad de almacenar datos en pares clave-valor y acceder a ellos de manera eficiente. Es particularmente útil para:

1. **Búsquedas rápidas**: Puedes recuperar un valor usando su clave en tiempo constante promedio `O(1)`, lo que es mucho más rápido que otras estructuras como listas o árboles.

2. Inserción y eliminación rápidas: La inserción y eliminación de pares clave-valor también se realizan en tiempo constante promedio `O(1)`.

3. Gestión de grandes cantidades de datos: Puede manejar grandes volúmenes de datos sin afectar significativamente el rendimiento.

## ¿Cómo lo resuelve HashMap?
1. **Uso de tablas hash**: Internamente, HashMap utiliza una tabla hash para almacenar los datos. Cada clave se convierte a un "código hash" mediante el método hashCode(). Este código hash se utiliza para determinar la posición (o "bucket") donde se almacenará el valor correspondiente. Cuando se necesita acceder a un valor, se calcula el código hash de la clave y se accede directamente al "bucket" correspondiente.

2. **Gestión de colisiones**: En ocasiones, dos claves diferentes pueden producir el mismo código hash, lo que causa una "colisión". HashMap maneja estas colisiones mediante listas enlazadas (y en versiones más recientes de Java, también utiliza árboles balanceados para mejorar el rendimiento en caso de colisiones frecuentes).

3. **Rehashing (Redimensionamiento)**: Cuando la tabla hash alcanza un cierto nivel de capacidad, HashMap se redimensiona automáticamente para evitar un deterioro en el rendimiento. Esto significa que la tabla se agranda, y todos los elementos se vuelven a distribuir según sus códigos hash.

## Características Clave de HashMap
* **No mantiene el orden**: Los elementos en un HashMap no tienen un orden específico. Si necesitas mantener el orden de inserción, considera usar LinkedHashMap.

* **Permite claves y valores null**: HashMap permite una clave null y múltiples valores null.

* **No es sincronizado**: No es seguro para el uso en entornos multihilo. Si necesitas un Map sincronizado, puedes usar Collections.synchronizedMap(new HashMap<>()) o considerar ConcurrentHashMap.

## Principales Métodos de `HashMap`
1. **`put(K key, V value)`**: Inserta o actualiza un par clave-valor.
```java
HashMap<String, Integer> ages = new HashMap<>();
ages.put("Alice", 25);
ages.put("Bob", 30);
```

2. **`get(Object key)`**: Recupera el valor asociado a la clave especificada.
```java
int age = ages.get("Alice"); // Devuelve 25
```

3. **`remove(Object key)`**: Elimina el par clave-valor asociado a la clave especificada.
```java
ages.remove("Bob");
```

4. **`containsKey(Object key)`**: Verifica si el mapa contiene la clave especificada.
```java
boolean exists = ages.containsKey("Alice"); // true
```

5. **`containsValue(Object value)`**: Verifica si el mapa contiene el valor especificado.
```java
boolean hasValue = ages.containsValue(25); // true
```

6. **`keySet()`**: Devuelve un conjunto de todas las claves en el HashMap.
```java
Set<String> keys = ages.keySet(); // ["Alice"]
```

7. **`values()`**: Devuelve una colección de todos los valores en el HashMap.
```java
Collection<Integer> values = ages.values(); // [25]
```

8. **`entrySet()`**: Devuelve un conjunto de todas las entradas (pares clave-valor) en el HashMap.
```java
for (Map.Entry<String, Integer> entry : ages.entrySet()) {
    System.out.println(entry.getKey() + ": " + entry.getValue());
}
```

## Ventajas:
* **Acceso rápido a datos**: Ofrece operaciones de acceso, inserción y eliminación en tiempo constante promedio `O(1)`.

* **Permite null como clave y valor**: Flexibilidad en algunos escenarios donde se necesita soportar null.

* **Escalabilidad**: Se adapta a grandes cantidades de datos con el redimensionamiento automático.

## Desventajas:
* **No es seguro para hilos**: No se puede usar de manera segura en aplicaciones multihilo sin sincronización.

* **No mantiene el orden**: No se puede garantizar el orden de los elementos almacenados.

* **Sobrecarga de memoria**: Puede consumir más memoria que otras estructuras de datos debido a la necesidad de mantener una tabla hash interna.
