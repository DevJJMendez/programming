# `HashTable`
Hashtable es una clase en Java que implementa la interfaz Map y se utiliza para almacenar pares clave-valor. Es una estructura de datos basada en una tabla hash, similar a HashMap, pero con algunas diferencias importantes en su funcionamiento y características. Hashtable es parte del paquete java.util y ha estado disponible desde las primeras versiones de Java.

## ¿Para qué sirve Hashtable?
Hashtable sirve para almacenar y gestionar datos en forma de pares clave-valor. Es especialmente útil cuando se necesita acceder rápidamente a datos usando una clave única. Algunos casos de uso incluyen:

1. Almacenamiento y búsqueda de datos: Proporciona acceso eficiente a los datos a través de claves únicas.

2. Aplicaciones de caché: Donde se necesita almacenar temporalmente datos para una recuperación rápida.

3. Implementaciones de directorios: Donde se mapean identificadores únicos (como nombres de usuario, ID, etc.) a objetos o datos.

## ¿Qué resuelve Hashtable?
Hashtable resuelve el problema del acceso rápido y eficiente a datos mediante el uso de claves únicas. En estructuras como listas o arrays, buscar un elemento específico puede tener una complejidad de tiempo de `O(N)` en el peor de los casos, ya que es necesario recorrer todos los elementos. Hashtable, sin embargo, permite el acceso a los valores en un tiempo cercano a `O(1)`, haciendo que las búsquedas sean más rápidas.

1. Acceso rápido a datos: Permite insertar, eliminar y buscar datos de forma eficiente.

2. Evita duplicados de claves: Cada clave es única, por lo que no hay riesgo de tener múltiples valores para la misma clave.

3. Seguridad en múltiples hilos: Es seguro para el uso en entornos multihilo, a diferencia de HashMap, ya que Hashtable sincroniza sus métodos de forma interna.

## ¿Cómo lo resuelve Hashtable?
1. Estructura de tabla hash: Hashtable utiliza una estructura de tabla hash para almacenar pares clave-valor. Las claves se pasan a través de una función de hash que genera un índice en la tabla para almacenar el valor. Esto hace que las operaciones de búsqueda, inserción y eliminación sean rápidas.

2. Sincronización interna: Todos los métodos de Hashtable son sincronizados, lo que significa que solo un hilo puede acceder a ellos a la vez. Esto lo hace seguro para el uso en aplicaciones multihilo sin tener que añadir sincronización manual.

3. No permite claves ni valores null: A diferencia de HashMap, Hashtable no permite almacenar null como clave o valor. Esto evita posibles errores relacionados con referencias nulas.

## Características clave de Hashtable
* Sincronización interna: Todos los métodos están sincronizados, lo que significa que es seguro para el acceso concurrente. Sin embargo, esto puede afectar el rendimiento en comparación con otras implementaciones no sincronizadas como HashMap.

* No permite null como clave o valor: Esta es una diferencia importante frente a HashMap.

* Acceso cercano a `O(1)`: Utiliza la estructura de hash para acceder rápidamente a los valores.

* Herencia de la clase Dictionary: Hashtable es una subclase de Dictionary, una clase abstracta que es menos comúnmente usada en implementaciones modernas de Java.
