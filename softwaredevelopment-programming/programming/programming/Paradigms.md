# Paradigmas
Un paradigma de programación es un enfoque o modelo que define cómo estructurar y desarrollar programas. Es una forma de pensar sobre la resolución de problemas mediante el uso de conceptos, principios y técnicas específicas. Cada paradigma establece ciertas reglas, estilos y formas de trabajar con el código.

En resumen:
* Son filosofías o estilos para escribir programas.

* Determinan cómo organizar el código y cómo interactúan los elementos del programa.

* Facilitan el desarrollo de software dependiendo del tipo de problema que se quiera resolver.
