# Listener
Los listeners (escuchadores) son componentes fundamentales en la programación orientada a eventos. Su propósito principal es esperar a que ocurra un evento específico y, cuando ese evento sucede, ejecutar una acción predefinida. Los listeners permiten que las aplicaciones reaccionen a eventos de manera eficiente, haciendo que el código sea más dinámico y modular.

## ¿Qué es un Listener?
Un listener es un objeto que "escucha" un evento específico en el sistema, como un clic del usuario, una acción en una interfaz gráfica, la llegada de datos a un servidor, o el cambio de estado de una aplicación. Cuando se produce el evento que el listener está esperando, se invoca un manejador de eventos asociado a dicho listener, que se encargará de ejecutar la lógica predefinida.

## ¿Para qué sirven los Listeners?
Los listeners son esenciales para detectar y manejar eventos. Se utilizan para crear interactividad en aplicaciones, permitiendo que el programa reaccione a las acciones del usuario o a cambios en el sistema de manera eficiente. Son muy comunes en interfaces gráficas, aplicaciones web, sistemas de mensajería, y en cualquier sistema que requiera reaccionar a estímulos externos.

## ¿Qué problemas resuelven los Listeners?
Los listeners resuelven varios problemas que surgen cuando se necesita manejar eventos en sistemas asíncronos o basados en interacción con usuarios.

**Problemas que resuelven:**
* **Reacción a eventos en tiempo real**: Permiten que el sistema responda automáticamente cuando ocurre un evento, sin necesidad de que el código principal esté monitoreando activamente.

* **Modularidad**: Separan la lógica de la aplicación en partes independientes, donde cada listener se encarga de gestionar eventos específicos.

* **Asincronía**: Los listeners funcionan de manera no bloqueante, permitiendo que el programa continúe con otras tareas mientras espera que ocurran los eventos que manejan.

## ¿Cómo resuelven estos problemas?
Los listeners se registran en el sistema para eventos específicos. Cuando el evento ocurre, el sistema invoca automáticamente el listener correspondiente, ejecutando la lógica definida en su manejador de eventos. Esto permite que el código sea más limpio, modular, y que la aplicación responda de manera inmediata sin bloquear otras operaciones.

## Ejemplo de Uso
1. Listeners en JavaScript (Web): En JavaScript, los listeners son esenciales para manejar interacciones del usuario en la web:
```js
document.getElementById("miBoton").addEventListener("click", function() {
    console.log("¡Botón clickeado!");
});
```
Aquí, `addEventListener` es la forma de registrar un listener que "escucha" el evento de clic en el botón con el id miBoton. Cuando se produce el clic, se ejecuta la función anónima que se pasó como manejador de eventos.

## Ventajas de Usar Listeners
* **Eficiencia**: Permiten manejar eventos de forma eficiente y no bloqueante.

* **Modularidad y Mantenibilidad**: Separan el manejo de eventos en piezas de código independientes, facilitando el mantenimiento y la escalabilidad del sistema.

* **Reactividad**: Las aplicaciones pueden reaccionar automáticamente a eventos del usuario o del sistema, mejorando la experiencia del usuario.

## Tipos Comunes de Listeners
1. **Listeners de UI (Interfaz de Usuario)**: Usados para manejar eventos como clics de botones, selección de menús, arrastre de elementos, etc. Ejemplos: ActionListener, MouseListener en Java Swing, o EventListener en JavaScript.

2. **Listeners de Red**: Usados para manejar eventos de red, como la llegada de datos desde un servidor. Ejemplos: WebSocket Listeners, Socket Listeners.

3. **Listeners de Eventos del Sistema**: Usados para reaccionar a cambios en el estado del sistema, como la inserción de un dispositivo USB o un cambio en la conexión de red.
