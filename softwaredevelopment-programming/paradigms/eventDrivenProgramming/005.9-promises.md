# Promises
Las promises (promesas) son un concepto clave en la programación asíncrona, especialmente en lenguajes como JavaScript. Son una forma de gestionar operaciones asíncronas de manera más ordenada y predecible que con callbacks tradicionales, y facilitan el **manejo de resultados que aún no están disponibles**. Las promises proporcionan una estructura para trabajar con tareas que pueden completarse en el futuro, como solicitudes HTTP, consultas a bases de datos, y operaciones de lectura/escritura de archivos.

## ¿Qué es una Promise?
Una promise es un objeto que representa la eventual finalización (o fallo) de una operación asíncrona y su valor resultante. Cuando creas una promise, defines el trabajo que debe realizarse y lo que debe suceder cuando el trabajo se complete con éxito o falle.

**Una promise puede tener tres estados:**
1. **Pending (pendiente)**: La operación aún no ha finalizado.

2. **Fulfilled (completada)**: La operación se completó con éxito.

3. **Rejected (rechazada)**: La operación falló.

## ¿Para Qué Sirven las Promises?
Las promises sirven para:

1. Manejar operaciones asíncronas de manera más legible y estructurada.

2. Evitar el "callback hell", que ocurre cuando hay múltiples callbacks anidados que hacen que el código sea difícil de leer y mantener.

3. Encadenar operaciones asíncronas de forma secuencial o paralela, facilitando la gestión de flujos de trabajo complejos.

4. Manejar errores en operaciones asíncronas de manera coherente.

## ¿Qué Problemas Resuelven las Promises?
1. **Callback Hell**: Las promesas permiten que el código sea más limpio y fácil de leer al evitar múltiples callbacks anidados.

2. **Manejo de Errores**: Las promises simplifican la gestión de errores asíncronos, proporcionando métodos dedicados para manejar casos de éxito y fallos.

3. **Encadenamiento de Operaciones**: Permiten encadenar múltiples operaciones asíncronas, gestionando el flujo de datos entre ellas de manera ordenada.

4. **Control de Ejecución**: Facilitan la ejecución de operaciones asíncronas en secuencia o de manera concurrente, dando más control sobre cuándo y cómo se completan las tareas.

## ¿Cómo Resuelven Estos Problemas?
Las promises lo hacen mediante el uso de una API con métodos específicos:

* `.then()`: Se utiliza para manejar el resultado de una operación asíncrona cuando la promise se cumple.

* `.catch()`: Se utiliza para manejar errores cuando la promise es rechazada.

* `.finally()`: Se ejecuta independientemente de si la promise se cumplió o fue rechazada, permitiendo realizar tareas de limpieza.

## Sintaxis Básica de una Promise
Veamos cómo se crea y se utiliza una promise en JavaScript:

```java
const myPromise = new Promise((resolve, reject) => {
    const success = true;
    
    if (success) {
        resolve("La operación se completó con éxito");
    } else {
        reject("La operación falló");
    }
});

// Manejo de la promesa
myPromise
    .then((result) => {
        console.log(result); // Se ejecuta si la promesa se cumple
    })
    .catch((error) => {
        console.error(error); // Se ejecuta si la promesa falla
    })
    .finally(() => {
        console.log("La operación ha finalizado.");
    });
```
En este ejemplo:

1. **Creación de la promise**: El constructor de `Promise` recibe una función con dos parámetros `(resolve, reject)`. Si la operación es exitosa, llamamos a `resolve();` si falla, llamamos a `reject()`.

2. **Manejo de la promise**: Usamos `.then()` para manejar el resultado exitoso, `.catch()` para manejar errores, y `.finally()` para ejecutar código sin importar el resultado.

## Encadenamiento de Promises
Una de las características más poderosas de las promises es la capacidad de encadenarlas para ejecutar múltiples operaciones asíncronas en secuencia.

```js
fetchUserData()
    .then((user) => {
        return fetchUserPosts(user.id);
    })
    .then((posts) => {
        console.log("Posts del usuario:", posts);
    })
    .catch((error) => {
        console.error("Hubo un error:", error);
    });
```
En este ejemplo:

1. Primero, obtenemos datos de un usuario usando `fetchUserData()`.

2. Luego, si es exitoso, usamos el resultado para llamar a `fetchUserPosts()`.

3. Si alguna de las promesas falla, el flujo se interrumpe y se ejecuta `.catch()` para manejar el error.
