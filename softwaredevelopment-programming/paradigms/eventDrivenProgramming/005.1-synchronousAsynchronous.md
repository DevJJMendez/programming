# Sincronía
La sincronía se refiere a la ejecución de tareas de manera secuencial, una después de otra. Cuando una tarea es sincrónica, el programa espera a que la tarea termine antes de continuar con la siguiente. Esto significa que, si una operación toma tiempo (como leer un archivo, realizar una consulta a una base de datos o hacer una solicitud a un servidor), el programa se detiene y espera a que termine antes de seguir con el siguiente paso.

## Características de la Sincronía
* **Bloqueante**: Si una tarea está en progreso, ninguna otra tarea puede ejecutarse hasta que la primera termine.

* **Predecible**: El flujo de ejecución es fácil de seguir porque cada línea de código se ejecuta en el orden en que se escribe.

* **Más simple de entender**: Al ser secuencial, es más sencillo de leer y depurar, pero puede llevar a problemas de rendimiento si hay operaciones lentas.

## Ejemplo en Java: Operación Sincrónica
```java
public class SincronicoEjemplo {
    public static void main(String[] args) {
        System.out.println("Inicio");
        String resultado = operacionLenta(); // El programa espera aquí hasta que esta operación termine.
        System.out.println("Resultado: " + resultado);
        System.out.println("Fin");
    }

    public static String operacionLenta() {
        try {
            Thread.sleep(3000); // Simula una operación lenta (espera de 3 segundos)
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
        return "Operación completa";
    }
}
```
Salida esperada:

1. "Inicio" se imprime.

2. El programa se detiene durante 3 segundos.

3. "Resultado: Operación completa" se imprime.

4. "Fin" se imprime.

## Ventajas:
* **Fácil de implementar**: La lógica es simple porque se ejecuta de forma secuencial.

* **Predecible**: El flujo de ejecución es directo.

## Desventajas:
* **Ineficiente para operaciones lentas**: Si una tarea tarda mucho (por ejemplo, una solicitud de red), todo el programa se detendrá y esperará, lo que afecta el rendimiento.

* **No adecuado para aplicaciones que necesitan manejar muchas tareas simultáneamente**, como servidores web.

# Asincronía
La asincronía permite que las tareas se ejecuten independientemente del flujo principal del programa. En este modelo, el programa no se bloquea esperando que una tarea termine; en su lugar, continúa ejecutando otras tareas. Cuando la operación asincrónica se completa, el programa recibe una notificación (a través de un **callback**, **promise** u otro mecanismo) y ejecuta la lógica que necesita para manejar el resultado.

## Características de la Asincronía
* **No bloqueante**: Las tareas se inician y el programa sigue adelante sin esperar que terminen.

* **Más difícil de seguir**: El flujo de ejecución puede ser menos intuitivo porque las tareas se completan en diferentes momentos.

* **Mejora la eficiencia**: Es útil para aplicaciones que necesitan manejar múltiples tareas simultáneamente (por ejemplo, servidores que manejan múltiples solicitudes de usuarios).

## Ejemplo en Java: Operación Asincrónica
```java
import java.util.concurrent.CompletableFuture;

public class AsincronicoEjemplo {
    public static void main(String[] args) {
        System.out.println("Inicio");
        CompletableFuture<String> future = operacionAsincrona();
        future.thenAccept(resultado -> System.out.println("Resultado: " + resultado));
        System.out.println("Fin"); // No espera a que la operación asincrónica termine
    }

    public static CompletableFuture<String> operacionAsincrona() {
        return CompletableFuture.supplyAsync(() -> {
            try {
                Thread.sleep(3000); // Simula una operación lenta (espera de 3 segundos)
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
            return "Operación completa";
        });
    }
}
```
Salida esperada:

1. "Inicio" se imprime.

2. "Fin" se imprime inmediatamente después (no espera 3 segundos).

3. Luego de 3 segundos, se imprime "Resultado: Operación completa".

## Ventajas:
* **Eficiencia**: Permite que el programa realice múltiples tareas al mismo tiempo, lo que es esencial para aplicaciones que manejan múltiples solicitudes concurrentes, como servidores web.

* **No bloqueante**: Las operaciones lentas no detienen la ejecución del programa.

## Desventajas:
* **Más difícil de implementar**: La lógica asincrónica puede ser más difícil de leer, depurar y mantener.

* **Necesita manejo cuidadoso**: Hay que manejar posibles errores y excepciones que ocurran en procesos que pueden finalizar en diferentes momentos.
