# `currentThread()`
La función `currentThread()` es un método estático de la clase `Thread` en Java que se utiliza para obtener una referencia al hilo que está ejecutando el código en el momento en que se llama. Esta funcionalidad es esencial para acceder y manipular información sobre el hilo actual sin necesidad de tener una referencia directa al objeto `Thread`. 

##  ¿Qué es currentThread()?
* **Definición**: `Thread.currentThread()` devuelve una referencia al hilo que está ejecutando actualmente el código.

* **Uso**: Permite acceder a propiedades y métodos del hilo actual para consultar o modificar su estado.

* **Contexto**: Es especialmente útil para depurar, registrar, o gestionar tareas específicas del hilo actual.

## ¿Para qué sirve `currentThread()`?
* **Identificación del hilo actual**: Es fundamental para averiguar cuál hilo está ejecutando una determinada sección de código.

* **Administración de tareas de hilos**: Permite que el código que se ejecuta en un hilo particular modifique las propiedades de ese hilo (por ejemplo, su nombre o prioridad).

* **Depuración y monitoreo**: Ayuda a generar registros (logs) o depurar aplicaciones concurrentes mostrando el hilo que está ejecutando cierto código.

## Métodos asociados con el uso de `currentThread()`
Una vez que tenemos acceso al hilo actual utilizando `Thread.currentThread()`, podemos utilizar varios métodos para trabajar con ese hilo. Aquí algunos de los métodos más importantes:

* **`getName() y setName(String name)`**

  * `getName()` devuelve el nombre del hilo actual.

  * `setName(String name)` establece un nuevo nombre para el hilo actual.

* **Uso**: Para identificar hilos de manera clara y hacer seguimiento a tareas concurrentes. Renombrar hilos puede ser útil para depuración y monitoreo.

```java
Thread t = Thread.currentThread();
System.out.println("Nombre del hilo actual: " + t.getName());
t.setName("HiloPrincipal");
System.out.println("Nuevo nombre del hilo: " + t.getName());
```

* `getId()`
  * **Descripción**: Devuelve un identificador único para el hilo.

  * **Uso**: Para distinguir hilos de manera inequívoca durante su ciclo de vida. Es útil para el monitoreo de aplicaciones multihilo.

```java
long id = Thread.currentThread().getId();
System.out.println("ID del hilo actual: " + id);
```

* **`getPriority()` y `setPriority(int priority)`**
  * **Descripción**:
    * `getPriority()` devuelve la prioridad del hilo actual.

    * `setPriority(int priority)` establece la prioridad del hilo actual.

* **Uso**: En algunos sistemas, los hilos con mayor prioridad pueden ejecutarse con más frecuencia que aquellos con baja prioridad. Sin embargo, el manejo de prioridad puede variar dependiendo del sistema operativo.

* **Valores de prioridad**: `MIN_PRIORITY (1)`, `NORM_PRIORITY (5)`, `MAX_PRIORITY (10)`.

```java
Thread t = Thread.currentThread();
System.out.println("Prioridad del hilo actual: " + t.getPriority());
t.setPriority(Thread.MAX_PRIORITY);
System.out.println("Nueva prioridad del hilo: " + t.getPriority());
```

* `isAlive()`
  * **Descripción**: Devuelve true si el hilo está vivo (es decir, si ha comenzado pero no ha terminado).

  * **Uso**: Para verificar si un hilo sigue en ejecución o si ha terminado su tarea.

```java
Thread t = new Thread(() -> {
    System.out.println("Hilo en ejecución...");
});
System.out.println("¿El hilo está vivo?: " + t.isAlive());
t.start();
System.out.println("¿El hilo está vivo?: " + t.isAlive());
```

* `isInterrupted()`
  * **Descripción**: Devuelve true si el hilo actual ha sido interrumpido.

  * **Uso**: Para verificar si se ha enviado una señal de interrupción al hilo actual, lo que permite tomar decisiones para finalizar o interrumpir la tarea en ejecución.

```java
Thread t = Thread.currentThread();
System.out.println("¿El hilo actual está interrumpido?: " + t.isInterrupted());
```

* `interrupt()`
  * **Descripción**: Envía una señal para interrumpir el hilo actual. Esto no detiene el hilo inmediatamente, pero establece el estado de interrupción.

  * **Uso**: Utilizado para interrumpir hilos que están esperando, durmiendo o bloqueados en operaciones de E/S.

```java
Thread t = new Thread(() -> {
    try {
        Thread.sleep(10000);
    } catch (InterruptedException e) {
        System.out.println("El hilo fue interrumpido.");
    }
});
t.start();
t.interrupt();
```
