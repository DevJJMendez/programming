# `Thread`
La clase **Thread** en Java es una de las principales formas de manejar la concurrencia y el multithreading en el lenguaje. Es una representación directa de un hilo de ejecución dentro de una aplicación. Los hilos permiten que el programa ejecute múltiples tareas al mismo tiempo, de manera concurrente, lo que puede mejorar el rendimiento y la eficiencia, especialmente en aplicaciones que necesitan hacer varias cosas simultáneamente, como gestionar múltiples conexiones, realizar cálculos en paralelo o responder rápidamente a eventos del usuario.

## ¿Qué es la Clase Thread?
La clase **Thread** es una parte de la biblioteca estándar de Java que se utiliza para crear y controlar hilos. Cada instancia de **Thread** representa un hilo separado de ejecución dentro del programa. Cuando se inicia `start()`, el hilo ejecuta el código definido en el método `run()`.

**Jerarquía de la Clase Thread:**
* `java.lang.Object`
  * `java.lang.Thread`

## ¿Para Qué Sirve?
La clase **Thread** permite a los desarrolladores crear hilos adicionales en sus aplicaciones, permitiendo la concurrencia. Esto significa que diferentes partes de un programa pueden ejecutarse al mismo tiempo (o casi al mismo tiempo), en lugar de ejecutarse de manera secuencial. Por ejemplo, una aplicación de servidor web podría usar múltiples hilos para manejar múltiples solicitudes de clientes simultáneamente.

## ¿Qué Resuelve?
La clase **Thread** resuelve el problema de la ejecución simultánea de tareas. Si un programa tiene que esperar a que termine una operación (como la lectura de datos de una red o un archivo), usar un hilo puede evitar que el programa se bloquee, permitiendo que otras partes del programa sigan ejecutándose mientras la tarea espera.

**Problemas comunes que aborda la clase Thread:**
1. **Operaciones largas y bloqueantes**: Permite que la interfaz de usuario permanezca receptiva mientras se realizan tareas en segundo plano.

2. **Procesamiento paralelo**: Divide el trabajo entre múltiples hilos para aprovechar los procesadores multinúcleo.

3. **Gestión de tareas simultáneas**: Ideal para aplicaciones que deben manejar múltiples tareas simultáneamente (servidores, juegos, aplicaciones interactivas).

## ¿Cómo Lo Resuelve?
Java proporciona dos formas principales de usar la clase Thread:

1. Extender la clase `Thread`.

2. Implementar la interfaz `Runnable`.

Ambas formas definen el comportamiento del hilo a través del método `run()`. Sin embargo, la forma más flexible y recomendada es implementar la interfaz Runnable porque permite heredar de otras clases y no solo de `Thread`.

## Métodos Importantes de la Clase `Thread`
Los métodos de la clase Thread en Java proporcionan las herramientas fundamentales para crear y controlar hilos de ejecución en una aplicación. Cada uno de estos métodos tiene un propósito específico y su correcto uso es crucial para manejar tareas concurrentes de manera eficiente.

### `start()`
* **¿Qué es?**: El método `start()` se utiliza para iniciar la ejecución de un nuevo hilo. Cuando se llama a este método, el hilo se inicializa y comienza a ejecutar el código definido en el método `run()` de la clase **Thread** o la implementación de **Runnable**.

* **¿Cómo Funciona?**
  * No se debe llamar directamente al método `run()`, porque esto no iniciará un nuevo hilo; simplemente ejecutará el método `run()` en el hilo actual.

  * Al llamar a `start()`, se crea un nuevo hilo y este se ejecuta concurrentemente con el hilo que llamó a `start()`.

* **Ejemplo**
```java
public class MyThread extends Thread {
    @Override
    public void run() {
        System.out.println("Hilo en ejecución: " + Thread.currentThread().getName());
    }

    public static void main(String[] args) {
        MyThread hilo = new MyThread();
        hilo.start(); // Inicia un nuevo hilo
    }
}
```
Salida
```plaintext
Hilo en ejecución: Thread-0
```

### `run()`
* **¿Qué es?**: El método `run()` contiene el código que se ejecutará cuando se inicie el hilo. Este es el método que se debe sobreescribir cuando se extiende la clase Thread o cuando se implementa Runnable.

* **¿Cómo Funciona?**: Aunque se puede llamar directamente a `run()`, esto no iniciará un nuevo hilo. Ejecutará el código de `run()` en el hilo actual. Debes usar `start()` para que `run()` se ejecute en un hilo separado.

* Ejemplo
```java
public class MyRunnable implements Runnable {
    @Override
    public void run() {
        System.out.println("Hilo en ejecución: " + Thread.currentThread().getName());
    }

    public static void main(String[] args) {
        MyRunnable runnable = new MyRunnable();
        Thread hilo = new Thread(runnable);
        hilo.run(); // Esto no inicia un nuevo hilo, solo ejecuta el código en el hilo actual
    }
}
```
Salida
```plaintext
Hilo en ejecución: main
```

## `sleep(long millis)`
* **¿Qué es?**: El método `sleep()` se utiliza para pausar la ejecución de un hilo durante un tiempo específico (en milisegundos).

* **¿Cómo Funciona?**: Este método pausa el hilo actual y permite que otros hilos se ejecuten mientras el hilo actual está "durmiendo".

* Puede lanzar una `InterruptedException` si el hilo es interrumpido mientras está durmiendo.

Ejemplo
```java
public class MyThread extends Thread {
    @Override
    public void run() {
        try {
            System.out.println("Hilo en ejecución: " + Thread.currentThread().getName());
            Thread.sleep(2000); // Pausa el hilo durante 2 segundos
            System.out.println("Hilo despertado: " + Thread.currentThread().getName());
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
    }

    public static void main(String[] args) {
        MyThread hilo = new MyThread();
        hilo.start();
    }
}
```
Salida
```plaintext
Hilo en ejecución: Thread-0
(Hilo se pausa por 2 segundos)
Hilo despertado: Thread-0
```

### `join()`
* **¿Qué es?**: El método `join()` hace que el hilo que lo invoca espere hasta que el hilo sobre el que se ha llamado `join()` termine.

* **¿Cómo Funciona?**: Es útil para situaciones en las que deseas asegurar que una tarea haya finalizado antes de que el programa continúe. Por ejemplo, podrías querer que todos los hilos terminen antes de proceder a una operación final en el hilo principal.

* **Ejemplo**
```java
public class MyThread extends Thread {
    @Override
    public void run() {
        try {
            System.out.println("Hilo en ejecución: " + Thread.currentThread().getName());
            Thread.sleep(3000); // Pausa el hilo durante 3 segundos
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
    }

    public static void main(String[] args) {
        MyThread hilo1 = new MyThread();
        MyThread hilo2 = new MyThread();

        hilo1.start();
        try {
            hilo1.join(); // Espera a que hilo1 termine
        } catch (InterruptedException e) {
            e.printStackTrace();
        }

        hilo2.start(); // Se inicia después de que hilo1 ha terminado
    }
}
```
Salida
```plaintext
Hilo en ejecución: Thread-0
(Hilo1 se pausa por 3 segundos y termina)
Hilo en ejecución: Thread-1
```

## `interrupt()`
* **¿Qué es?**: El método `interrupt()` se usa para señalar a un hilo que debería detenerse. No lo detiene directamente, sino que establece una bandera de interrupción.

* **¿Cómo Funciona?**: Cuando se llama a `interrupt()`, el hilo no se detiene inmediatamente. Depende del código del hilo verificar si ha sido interrumpido usando `isInterrupted()` o manejar la `InterruptedException` si el hilo está en estado de espera, como al usar `sleep()`, `wait()`, o `join()`.

* Ejemplo
```java
public class MyThread extends Thread {
    @Override
    public void run() {
        try {
            while (!isInterrupted()) {
                System.out.println("Hilo en ejecución: " + Thread.currentThread().getName());
                Thread.sleep(1000);
            }
        } catch (InterruptedException e) {
            System.out.println("Hilo interrumpido");
        }
    }

    public static void main(String[] args) {
        MyThread hilo = new MyThread();
        hilo.start();

        try {
            Thread.sleep(3000); // Deja que el hilo corra por 3 segundos
            hilo.interrupt(); // Interrumpe el hilo
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
    }
}
```
Salida
```plaintext
Hilo en ejecución: Thread-0
Hilo en ejecución: Thread-0
Hilo en ejecución: Thread-0
Hilo interrumpido
```

### `isAlive()`
* **¿Qué es?**: El método `isAlive()` verifica si el hilo ha terminado su ejecución o sigue activo.

* **¿Cómo Funciona?**: Devuelve `true` si el hilo ha sido iniciado y no ha terminado de ejecutarse, y `false` si el hilo ha terminado.

* **Ejemplo**
```plaintext
Hilo activo antes de start(): false
Hilo activo después de start(): true
Hilo en ejecución: Thread-0
Hilo activo después de terminar: false
```
