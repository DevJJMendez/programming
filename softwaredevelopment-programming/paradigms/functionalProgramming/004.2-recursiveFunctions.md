# Funciones Recursivas
Las funciones recursivas son un concepto central en la programación funcional, y también tienen su lugar en otros paradigmas como la programación imperativa. La recursión es una técnica en la que una función se llama a sí misma directa o indirectamente para resolver un problema. Esta técnica es útil cuando un problema puede dividirse en subproblemas más pequeños y de estructura similar al original.

## ¿Qué es una función recursiva?
Una función recursiva es aquella que se llama a sí misma durante su ejecución. Para que la recursión sea útil y no conduzca a un bucle infinito, debe tener al menos dos componentes clave:

* **Caso base**: Es la condición que detiene la recursión. Sin un caso base, la función se llamaría indefinidamente.

* **Paso recursivo**: Es la llamada a la función dentro de sí misma, donde se trabaja sobre una versión más pequeña o más simple del problema original.

## ¿Para qué sirve?
* **Descomposición de problemas**: La recursión es ideal para problemas que pueden dividirse en versiones más simples de sí mismos. Problemas como el cálculo de factoriales, la serie de Fibonacci, recorrer estructuras jerárquicas (como árboles), entre otros, se resuelven de manera natural con recursión.

* **Simplicidad**: En muchos casos, las soluciones recursivas son más fáciles de entender y más elegantes que las soluciones iterativas, aunque a veces puedan ser menos eficientes.

## ¿Qué problemas resuelve?
Problemas que tienen una estructura repetitiva o fractal: Estos problemas pueden dividirse en subproblemas idénticos al original. Ejemplos incluyen:

* Cálculo de factoriales.

* Cálculo de la serie de Fibonacci.

* Búsqueda y recorridos en estructuras de datos como árboles y grafos.

* Problemas de "divide y vencerás", como la ordenación por merge sort o quick sort.

## Ejemplo básico: Factorial de un número en Java
Un caso típico de recursión es el cálculo del factorial de un número. El factorial de un número `𝑛` se define como el producto de todos los enteros positivos menores o iguales a `𝑛`, es decir:

`n! = n x n (n - 1) x (n - 2) x ... x 1` El caso base es 0! = 1.

```java
public class RecursionEjemplo {
    
    // Método recursivo para calcular el factorial de un número
    public static int factorial(int n) {
        // Caso base: si n es 0, retornamos 1 (por definición 0! = 1)
        if (n == 0) {
            return 1;
        }
        // Llamada recursiva: n * factorial(n - 1)
        return n * factorial(n - 1);
    }

    public static void main(String[] args) {
        int numero = 5;
        int resultado = factorial(numero);
        System.out.println("Factorial de " + numero + " es: " + resultado); // Salida: 120
    }
}
```
**¿Cómo lo resuelve?**
* **Caso base**: Cuando el número es 0, el resultado es 1.

* **Paso recursivo**: La función se llama a sí misma con `𝑛 − 1` hasta que llega al caso base.

## Recursión y eficiencia
Un punto importante a considerar con la recursión es su impacto en la eficiencia. Si bien las soluciones recursivas pueden ser elegantes, no siempre son las más eficientes debido al consumo de memoria de pila. Cada vez que una función se llama a sí misma, se coloca una nueva instancia en la pila de ejecución. Esto significa que si la profundidad de la recursión es grande, la pila puede llenarse y generar un `StackOverflowError`.

Por ejemplo, en el cálculo de la serie de Fibonacci, la recursión sin optimización puede ser muy ineficiente debido a la repetición de cálculos:

```java
public class FibonacciRecursivo {
    
    // Método recursivo para calcular el n-ésimo número de Fibonacci
    public static int fibonacci(int n) {
        // Casos base: F(0) = 0 y F(1) = 1
        if (n == 0) {
            return 0;
        } else if (n == 1) {
            return 1;
        }
        // Llamada recursiva
        return fibonacci(n - 1) + fibonacci(n - 2);
    }

    public static void main(String[] args) {
        int numero = 10;
        int resultado = fibonacci(numero);
        System.out.println("Fibonacci de " + numero + " es: " + resultado); // Salida: 55
    }
}
```
Este código es correcto, pero muy ineficiente porque repite cálculos innecesarios, como calcular el mismo número de Fibonacci varias veces. Para evitar esto, se pueden usar técnicas como memorización o reescribir el algoritmo de manera iterativa.

## Tipos de recursión
1. **Recursión directa**: La función se llama a sí misma directamente.

   * Ejemplo: `factorial(n)`.

* **Recursión indirecta**: Una función **A** llama a una función **B**, que luego vuelve a llamar a **A**.

  * Ejemplo: A llama a B, B llama a A, y así sucesivamente.

* **Recursión de cola (Tail Recursion)**: En este tipo de recursión, la llamada recursiva es la última operación realizada por la función. Los compiladores pueden optimizar las funciones de cola recursiva eliminando las llamadas adicionales de la pila, lo que mejora la eficiencia.

**En Java, sin embargo, la optimización de la recursión de cola no está habilitada de forma nativa, pero este es un concepto importante en lenguajes como Haskell o Scheme.**

## ¿Cuándo usar recursión?
* **Estructuras de datos jerárquicas**: Como árboles, donde cada nodo se trata de forma similar a sus subnodos.

* **Problemas que se resuelven con divide y vencerás**: Como algoritmos de ordenamiento (quick sort, merge sort).

* **Cálculos matemáticos que dependen de subproblemas**: Factoriales, Fibonacci, combinatorias, etc.
