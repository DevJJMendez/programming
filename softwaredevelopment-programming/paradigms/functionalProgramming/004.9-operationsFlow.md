# Flujo de operaciones
En la API Streams de Java, las **operaciones intermedias** y **operaciones terminales** son fundamentales para manipular y procesar flujos de datos. Ambas categorías son esenciales para trabajar con Streams, pero tienen comportamientos y propósitos diferentes.

## Operaciones intermedias
Las operaciones intermedias transforman un **Stream** en otro **Stream**. Son **lazy** (perezosas), lo que significa que no se ejecutan hasta que se realiza una operación terminal. Estas operaciones no consumen los elementos del **Stream** y siempre devuelven otro **Stream**, permitiendo encadenar múltiples operaciones intermedias.

**Lista de operaciones intermedias comunes:**
1. **`filter(Predicate<T> predicate)`**:

   * Filtra los elementos que cumplen con una condición.

   * **Ejemplo**: Filtrar una lista de números para quedarnos con los números pares

```java
List<Integer> numbers = List.of(1, 2, 3, 4, 5);
Stream<Integer> evenNumbers = numbers.stream().filter(n -> n % 2 == 0);
```

2. **`map(Function<T, R> mapper)`**:

   * Transforma cada elemento del stream aplicando una función.

   * **Ejemplo**: Transformar una lista de nombres en una lista de longitudes.

```java
List<String> names = List.of("Juan", "Maria", "Carlos");
Stream<Integer> nameLengths = names.stream().map(String::length);
```

3. **`flatMap(Function<T, Stream<R>> mapper)`**:

   * Aplana un Stream de Streams en un solo Stream.

   * **Ejemplo**: Convertir una lista de listas de números en un único Stream de números.

```java
List<List<Integer>> numbers = List.of(List.of(1, 2), List.of(3, 4));
Stream<Integer> flatStream = numbers.stream().flatMap(List::stream);
```

4. **`distinct()`**:

   * Elimina los elementos duplicados del Stream.

   * **Ejemplo**: Remover duplicados de una lista de números

```java
List<Integer> numbers = List.of(1, 2, 2, 3);
Stream<Integer> distinctNumbers = numbers.stream().distinct();
```

5. **`sorted()`**:

   * Ordena los elementos del Stream según su orden natural o mediante un Comparator.

   * **Ejemplo**: Ordenar una lista de nombres alfabéticamente.

```java
Stream<String> sortedNames = names.stream().sorted();
```

6. **`sorted(Comparator<T> comparator)`**:

   * Ordena los elementos usando un comparador personalizado.

   * **Ejemplo**: Ordenar por longitud de nombre.

```java
Stream<String> sortedByLength = names.stream().sorted(Comparator.comparingInt(String::length));
```

7. **`limit(long maxSize)`**:

   * Limita el número de elementos que el Stream procesará.

   * **Ejemplo**: Tomar los primeros 3 elementos de una lista.

```java
Stream<Integer> limitedStream = numbers.stream().limit(3);
```

8. **`skip(long n)`**:

   * Omite los primeros n elementos y procesa los siguientes.

   * **Ejemplo**: Saltar los primeros 2 elementos de una lista.

```java
Stream<Integer> skippedStream = numbers.stream().skip(2);
```

9. **`peek(Consumer<T> action)`**:

   * Permite realizar una acción sobre cada elemento sin modificar el Stream.

   * **Ejemplo**: Imprimir cada elemento mientras se procesan.

```java
Stream<String> peekStream = names.stream().peek(System.out::println);
```

## Operaciones terminales
Las operaciones terminales son aquellas que consumen el Stream y producen un resultado final. Estas operaciones desencadenan el procesamiento de las operaciones intermedias.

**Lista de operaciones terminales comunes:**
1. **`forEach(Consumer<T> action)`**:

   * Aplica una acción a cada elemento del Stream.

   * **Ejemplo**: Imprimir cada nombre en la lista.

```java
names.stream().forEach(System.out::println);
```

2. `collect(Collector<T, A, R> collector)`:

   * Recoge los elementos del Stream y los acumula en una colección, como una lista o un conjunto.

   * **Ejemplo**: Convertir un Stream de nombres en una lista.

```java
List<String> nameList = names.stream().collect(Collectors.toList());
```

3. `reduce(BinaryOperator<T> accumulator)`:

   * Reduce los elementos a un solo valor, usando un acumulador.

   * **Ejemplo**: Sumar todos los números en un Stream

```java
Optional<Integer> sum = numbers.stream().reduce(Integer::sum);
```

4. `count()`:

   * Devuelve el número de elementos en el Stream.

   * **Ejemplo**: Contar cuántos elementos hay en un Stream.

```java
long count = numbers.stream().count();
```

5. `findFirst()`:

   * Devuelve el primer elemento del Stream como un `Optional`.

   * **Ejemplo**: Obtener el primer número de una lista.

```java
Optional<Integer> first = numbers.stream().findFirst();
```

6. `findAny()`:

   * Devuelve un elemento cualquiera del Stream como un Optional, útil en operaciones paralelas.

   * **Ejemplo**: Encontrar cualquier número en el Stream.

```java
Optional<Integer> any = numbers.stream().findAny();
```

7. `allMatch(Predicate<T> predicate)`:

   * Devuelve `true` si todos los elementos cumplen con una condición.

   * **Ejemplo**: Verificar si todos los números son positivos

```java
boolean allPositive = numbers.stream().allMatch(n -> n > 0);
```

8. `anyMatch(Predicate<T> predicate)`:

   * Devuelve `true` si algún elemento cumple con una condición.

   * **Ejemplo**: Verificar si hay algún número par.

```java
boolean anyEven = numbers.stream().anyMatch(n -> n % 2 == 0);
```

9. **`noneMatch(Predicate<T> predicate)`**:

   * Devuelve `true` si ninguno de los elementos cumple con una condición.

   * **Ejemplo**: Verificar si no hay números negativos.

```java
boolean noNegatives = numbers.stream().noneMatch(n -> n < 0);
```

10. **`min(Comparator<T> comparator)`**:

    * Encuentra el elemento mínimo según un comparador.

    * **Ejemplo**: Obtener el número más pequeño.

```java
Optional<Integer> min = numbers.stream().min(Integer::compareTo);
```

11. **`max(Comparator<T> comparator)`**:

    * Encuentra el elemento máximo según un comparador.

    * **Ejemplo**: Obtener el número más grande.

```java
Optional<Integer> max = numbers.stream().max(Integer::compareTo);
```

# Jerarquía entre operaciones intermedias y terminales
* Las **operaciones intermedias** siempre devuelven un Stream, por lo que se pueden encadenar para construir una secuencia de transformación de datos. Sin embargo, no se ejecutan inmediatamente, ya que son lazy. Esto significa que simplemente describen una serie de transformaciones que serán aplicadas a los datos, pero no las ejecutan hasta que se encuentra una operación terminal.

* Las **operaciones terminales** desencadenan el procesamiento de las operaciones intermedias. Cuando una operación terminal es invocada, se activa todo el pipeline de procesamiento, procesando los datos a medida que se pasa por las operaciones intermedias.

**Ejemplo combinado de operaciones intermedias y terminales**
```java
List<String> names = List.of("Alice", "Bob", "Charlie", "David", "Edward");

// Operaciones intermedias: Filtrar, mapear, y ordenar
Stream<String> nameStream = names.stream()
                                 .filter(name -> name.length() > 3)  // Filtrar nombres con más de 3 letras
                                 .map(String::toUpperCase)            // Convertir a mayúsculas
                                 .sorted();                           // Ordenar alfabéticamente

// Operación terminal: Recolectar en una lista
List<String> result = nameStream.collect(Collectors.toList());

System.out.println(result);  // Output: [ALICE, CHARLIE, DAVID, EDWARD]
```
Aquí vemos cómo las operaciones intermedias se encadenan y no se ejecutan hasta que se invoca la operación terminal `collect()`, que desencadena el procesamiento del Stream.
