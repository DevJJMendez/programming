# `BiPredicate<>`
`BiPredicate<T, U>` es una interfaz funcional en Java que representa una función que toma dos argumentos de tipos `T` y `U`, y devuelve un valor booleano. Esta interfaz se utiliza para evaluar si dos entradas cumplen una condición determinada, devolviendo true o false en función del resultado.

**Definición de la interfaz**
```java
@FunctionalInterface
public interface BiPredicate<T, U> {
    boolean test(T t, U u);
}
```

## ¿Qué es BiPredicate<T, U>?
`BiPredicate<T, U>` es una interfaz que permite evaluar una condición basada en dos argumentos. A diferencia de `Predicate<T>`, que toma un solo argumento, BiPredicate toma dos entradas. El método principal de esta interfaz es `test(T t, U u)`, que devuelve un valor booleano.

## ¿Para qué sirve?
`BiPredicate<T, U>` se utiliza para:

* Validar relaciones entre dos objetos, por ejemplo, si un empleado pertenece a un departamento o si dos números cumplen una condición matemática.

* Filtrar colecciones que involucren pares de objetos.

* Aplicar condiciones lógicas en funciones que requieren dos argumentos.

## ¿Qué resuelve?
Resuelve la necesidad de aplicar una condición sobre dos entradas en lugar de una, lo cual es útil en situaciones donde dos objetos deben ser comparados o evaluados conjuntamente. Por ejemplo:

* Comparar dos objetos de distinto tipo.

* Evaluar si dos elementos cumplen una relación lógica.

## ¿Cómo lo resuelve?
Lo resuelve proporcionando una interfaz que encapsula la lógica de validación entre dos argumentos en una función reutilizable. Al utilizar BiPredicate, puedes realizar comparaciones o validaciones entre dos objetos sin escribir estructuras de control imperativas, lo que permite un código más limpio y declarativo.

## Ejemplo básico:
Veamos un ejemplo sencillo para determinar si la longitud de una cadena es igual a un número dado:

```java
import java.util.function.BiPredicate;

public class EjemploBiPredicate {
    public static void main(String[] args) {
        // Definir un BiPredicate para verificar si la longitud de una cadena es igual a un número dado
        BiPredicate<String, Integer> esLongitudIgual = (cadena, longitud) -> cadena.length() == longitud;

        // Probar el BiPredicate
        System.out.println(esLongitudIgual.test("Hola", 4));  // true
        System.out.println(esLongitudIgual.test("Mundo", 6)); // false
    }
}
```
**Salida**
```plaintext
true
false
```
En este ejemplo, el `BiPredicate<String, Integer>` toma una cadena y un número entero como entrada, y verifica si la longitud de la cadena es igual al número entero proporcionado.

## Composición de BiPredicate:
De forma similar a Predicate, BiPredicate también ofrece métodos como and(), or(), y negate() para combinar varias condiciones.

**Ejemplo de combinación de predicados:**
```java
import java.util.function.BiPredicate;

public class EjemploBiPredicateCombinado {
    public static void main(String[] args) {
        // Verificar si una cadena comienza con una letra específica y si su longitud es mayor que un número dado
        BiPredicate<String, Integer> empiezaConA = (cadena, longitud) -> cadena.startsWith("A");
        BiPredicate<String, Integer> esLongitudMayor = (cadena, longitud) -> cadena.length() > longitud;

        // Combinar los predicados usando and()
        BiPredicate<String, Integer> empiezaConAYLongitudMayor = empiezaConA.and(esLongitudMayor);

        System.out.println(empiezaConAYLongitudMayor.test("Ana", 2));  // true
        System.out.println(empiezaConAYLongitudMayor.test("Ana", 3));  // false
    }
}
```
**Salida**
```plaintext
true
false
```
En este caso, combinamos dos predicados: uno que verifica si una cadena empieza con "A" y otro que verifica si la longitud de la cadena es mayor a un número determinado. Usando `and()`, los predicados se combinan y ambos deben ser `true` para que el resultado final sea `true`.

## Uso en situaciones más complejas:
**BiPredicate** puede ser especialmente útil en situaciones donde se necesita comparar objetos más complejos o aplicar validaciones entre dos tipos de datos diferentes. Por ejemplo, en una lista de empleados, podríamos querer verificar si un empleado pertenece a un departamento específico.

**Ejemplo práctico: Comparar empleados y departamentos**
```java
import java.util.function.BiPredicate;

class Empleado {
    private String nombre;
    private String departamento;

    public Empleado(String nombre, String departamento) {
        this.nombre = nombre;
        this.departamento = departamento;
    }

    public String getDepartamento() {
        return departamento;
    }

    @Override
    public String toString() {
        return nombre + " del departamento " + departamento;
    }
}

public class EjemploBiPredicateEmpleado {
    public static void main(String[] args) {
        Empleado empleado1 = new Empleado("Juan", "Ventas");
        Empleado empleado2 = new Empleado("Ana", "Recursos Humanos");

        // Definir un BiPredicate para verificar si el empleado pertenece a un departamento dado
        BiPredicate<Empleado, String> perteneceADepartamento = (empleado, departamento) -> empleado.getDepartamento().equals(departamento);

        // Probar el BiPredicate
        System.out.println(perteneceADepartamento.test(empleado1, "Ventas"));         // true
        System.out.println(perteneceADepartamento.test(empleado2, "Ventas"));         // false
    }
}
```
**Salida**
```plaintext
true
false
```
En este ejemplo, el `BiPredicate<Empleado, String>` toma un empleado y un departamento como argumentos, y verifica si el empleado pertenece al departamento dado.
