# `BiFunction<>`
`BiFunction<T, U, R> `es una interfaz funcional en Java que representa una función que toma dos argumentos de tipos genéricos `T` y `U` y devuelve un resultado de tipo `R`. Es útil cuando se requiere realizar una operación que involucra dos entradas y produce un único resultado.

**Definiciónn de la interfaz**
```java
@FunctionalInterface
public interface BiFunction<T, U, R> {
    R apply(T t, U u);
}
```

## ¿Qué es BiFunction<T, U, R>?
* `BiFunction<T, U, R>` es una interfaz funcional que recibe dos parámetros de tipos `T` y `U`, y devuelve un valor de tipo `R`.

* Tiene un único método abstracto: `R apply(T t, U u)`, el cual realiza una operación sobre los dos argumentos de entrada y devuelve un resultado.

## ¿Para qué sirve?
**BiFunction** es útil cuando tienes una operación que necesita dos entradas y devuelve un único valor. Se puede utilizar para realizar operaciones aritméticas, combinaciones de datos, transformaciones, comparaciones o cualquier tarea que involucre dos entradas.

**Por ejemplo:**

* Suma de dos números.

* Concatenación de dos cadenas.

* Comparación de dos objetos.

## ¿Qué resuelve?
Resuelve la necesidad de manejar operaciones que involucran dos entradas. En lugar de crear clases o métodos adicionales para combinar dos valores, puedes utilizar BiFunction para crear funciones reutilizables y más declarativas. Esto también facilita el uso de funciones como argumentos en otros métodos o flujos de datos.

## ¿Cómo lo resuelve?
Lo resuelve proporcionando una interfaz genérica para trabajar con dos entradas y un resultado. Al encapsular la lógica de la función dentro de una BiFunction, puedes aplicar esa función de manera consistente y reutilizable en varios contextos, como colecciones, procesamiento de datos, etc.

## Ejemplo básico
A continuación, un ejemplo donde sumamos dos números usando BiFunction:

```java
import java.util.function.BiFunction;

public class EjemploBiFunction {
    public static void main(String[] args) {
        // Definir una BiFunction que suma dos números enteros
        BiFunction<Integer, Integer, Integer> suma = (a, b) -> a + b;

        // Aplicar la función
        int resultado = suma.apply(5, 3);
        System.out.println("El resultado de la suma es: " + resultado);
    }
}
```
**Salida**
```plaintext
El resultado de la suma es: 8
```
Aquí, `BiFunction<Integer, Integer, Integer>` representa una función que toma dos enteros como entrada y devuelve un entero como resultado.

## Métodos adicionales:
Además del método `apply()`, la interfaz BiFunction tiene otros métodos útiles para la composición de funciones:

1. `andThen()`: Permite encadenar una función adicional que se ejecutará después de aplicar la BiFunction. Toma el resultado de la primera función como entrada para una segunda función.

  ```java
  BiFunction<Integer, Integer, Integer> multiplicar = (a, b) -> a * b;
  Function<Integer, String> convertirAString = resultado -> "El resultado es: " + resultado;

  // Aplicar primero la multiplicación y luego convertir el resultado a String
  BiFunction<Integer, Integer, String> funcionCompuesta = multiplicar.andThen(convertirAString);

  System.out.println(funcionCompuesta.apply(3, 4)); // Salida: El resultado es: 12
  ```
  En este caso, se realiza la multiplicación de los dos números y luego se convierte el resultado en una cadena.

## BiFunction en Streams:
BiFunction no se usa directamente en Streams de la misma manera que Function, pero puedes utilizarla para tareas específicas que involucren dos entradas. Por ejemplo, podrías usar una BiFunction en una operación personalizada de reducción (`reduce()`).

```java
import java.util.Arrays;
import java.util.List;
import java.util.function.BiFunction;

public class EjemploBiFunctionStream {
    public static void main(String[] args) {
        List<Integer> numeros = Arrays.asList(1, 2, 3, 4, 5);

        // BiFunction que suma dos números
        BiFunction<Integer, Integer, Integer> sumar = (a, b) -> a + b;

        // Usar reduce() con una BiFunction
        int resultado = numeros.stream().reduce(0, (a, b) -> sumar.apply(a, b));
        System.out.println("La suma de todos los números es: " + resultado);
    }
}
```
**Salida**
```plaintext
La suma de todos los números es: 15
```
Aquí, la **BiFunction** se usa dentro del método `reduce()` para sumar los elementos de una lista.
