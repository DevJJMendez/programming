# `andThen()`
El método `andThen()` es parte de la interfaz funcional `Consumer<T>` en Java. Se utiliza para encadenar varias operaciones o acciones que consumen un objeto del mismo tipo y aplicarlas secuencialmente. Básicamente, permite ejecutar un **Consumer** y luego ejecutar otro **Consumer** inmediatamente después, en el mismo objeto.

## ¿Qué es andThen()?
`andThen()` es un método por defecto en la interfaz `Consumer<T>` de Java, y permite combinar múltiples operaciones en una sola. El primer **Consumer** se ejecuta primero y, a continuación, se ejecuta el segundo **Consumer** que se pasa como argumento.

**Firma del método**
```java
default Consumer<T> andThen(Consumer<? super T> after)
```
1. **Parámetro**:
   * `after`: otro `Consumer<T>` que se ejecutará después del actual.

2. **Retorno**:
   * Devuelve un `Consumer<T>` que es la combinación del actual y el pasado como parámetro.

3. **Excepción**:
   * Lanza una `NullPointerException` si el Consumer pasado como parámetro es `null`.

## ¿Para qué sirve?
Sirve para realizar operaciones encadenadas sobre el mismo objeto sin tener que escribir múltiples líneas de código o ejecutar acciones en pasos separados. Esto es útil cuando tienes varias operaciones que quieres realizar sobre un objeto y quieres que se ejecuten de manera secuencial.

## ¿Qué resuelve?
El método `andThen()` resuelve la necesidad de escribir operaciones consecutivas sobre un mismo objeto en varias líneas. En lugar de llamar a múltiples `Consumer` uno después del otro manualmente, puedes encadenarlos usando `andThen()`, lo que mejora la legibilidad del código y reduce la posibilidad de errores.

## ¿Cómo lo resuelve?
Lo resuelve proporcionando un mecanismo funcional para componer consumidores, es decir, puedes aplicar una operación a un objeto y luego aplicar otra en una sola llamada. Esto sigue el principio de la composición de funciones, característica de la programación funcional, donde se pueden combinar varias funciones para operar en un flujo.

## Ejemplo básico
**Ejemplo básico de `andThen()`**: Supongamos que tienes dos acciones: una que imprime un valor al cuadrado y otra que imprime el valor al cubo. Puedes combinarlas usando `andThen()`.

```java
import java.util.function.Consumer;

public class EjemploAndThen {
    public static void main(String[] args) {
        // Primer Consumer: imprimir el valor al cuadrado
        Consumer<Integer> cuadrado = x -> System.out.println("Cuadrado: " + (x * x));

        // Segundo Consumer: imprimir el valor al cubo
        Consumer<Integer> cubo = x -> System.out.println("Cubo: " + (x * x * x));

        // Usamos andThen para encadenar las operaciones
        Consumer<Integer> cuadradoYCubo = cuadrado.andThen(cubo);

        // Ejecutamos las operaciones encadenadas
        cuadradoYCubo.accept(3);
    }
}
```
Salida:
```plaintext
Cuadrado: 9
Cubo: 27
```
Explicación:
* cuadrado es un `Consumer` que toma un número y lo eleva al cuadrado.

* `cubo` es un `Consumer` que toma un número y lo eleva al cubo.

* Usando `cuadrado.andThen(cubo)`, estamos creando un nuevo Consumer que primero ejecuta el cálculo del cuadrado y luego el del cubo sobre el mismo número.

* La llamada a `cuadradoYCubo.accept(3)` ejecuta ambos consumidores secuencialmente sobre el valor 3.

## Ejemplo más práctico
Imagina que tienes una lista de nombres y quieres realizar dos operaciones sobre cada nombre:

1. Imprimir el nombre en mayúsculas.

2. Imprimir la longitud del nombre.

Puedes usar `andThen()` para combinar ambas operaciones.

```java
import java.util.function.Consumer;
import java.util.List;

public class EjemploAndThen {
    public static void main(String[] args) {
        List<String> nombres = List.of("Juan", "Maria", "Carlos");

        // Primer Consumer: convertir el nombre a mayúsculas y mostrarlo
        Consumer<String> imprimirMayusculas = nombre -> System.out.println(nombre.toUpperCase());

        // Segundo Consumer: mostrar la longitud del nombre
        Consumer<String> imprimirLongitud = nombre -> System.out.println("Longitud: " + nombre.length());

        // Usamos andThen para encadenar las operaciones
        Consumer<String> imprimirMayusculasYLongitud = imprimirMayusculas.andThen(imprimirLongitud);

        // Aplicamos el Consumer encadenado a cada nombre en la lista
        nombres.forEach(imprimirMayusculasYLongitud);
    }
}
```
**Salida**
```plaintext
JUAN
Longitud: 4
MARIA
Longitud: 5
CARLOS
Longitud: 6
```

## Beneficios de `andThen()`:
1. **Modularidad**: Puedes separar diferentes operaciones en distintos consumidores, manteniendo el código más limpio y modular.

2. **Reutilización**: Al usar `andThen()`, puedes combinar consumidores reutilizables de manera flexible, sin duplicar código.

3. **Legibilidad**: Al encadenar operaciones, el código se vuelve más fácil de entender porque todas las acciones relacionadas con el objeto se agrupan de manera clara.

## Consideraciones:
* `NullPointerException`: Si intentas encadenar un `Consumer` que es `null`, se lanzará una excepción. Es importante asegurarse de que todos los consumidores sean válidos antes de encadenarlos.

* **Inmutabilidad**: Aunque puedes encadenar consumidores para modificar un objeto, es preferible, en muchos casos, seguir el principio de inmutabilidad, especialmente en un entorno de programación funcional.
