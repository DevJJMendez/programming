# Funciones Anónimas
Las funciones anónimas son funciones que no tienen un nombre explícito asociado. En esencia, son funciones que se definen en el momento de su uso y que generalmente no se reutilizan fuera del contexto donde fueron creadas. Este tipo de funciones es común en muchos lenguajes de programación y tiene aplicaciones tanto en programación imperativa como funcional.

En Java, las funciones anónimas se representan principalmente a través de clases anónimas (antes de Java 8) o expresiones lambda (a partir de Java 8). Aunque ya has visto las lambdas, las funciones anónimas tienen un significado más amplio en otros paradigmas y lenguajes.

## ¿Qué es una función anónima?
Una función anónima es una función definida sin un nombre y generalmente se utiliza de manera directa, sin la intención de ser reutilizada en múltiples lugares del código. En Java, se pueden implementar de dos maneras:

1. **Clase anónima**: Una forma de definir una clase y crear una instancia de ella en el mismo lugar. Esta clase implementa una interfaz o extiende una clase, pero no tiene un nombre explícito.

2. **Expresión lambda**: Introducida en Java 8, una lambda es una forma más moderna y concisa de definir funciones anónimas. Es útil especialmente en el contexto de programación funcional y mejora la legibilidad.

## ¿Para qué sirven las funciones anónimas?
Las funciones anónimas sirven principalmente para:

* Evitar la creación de clases o métodos innecesarios cuando se necesita implementar un comportamiento específico solo en un lugar del código.

* Simplificar la programación funcional permitiendo pasar funciones como parámetros a otros métodos.

* Implementar comportamientos temporales que no necesitan un nombre o definición formal, como `callbacks` o `handlers` en eventos.

## ¿Qué resuelven?
Antes de la introducción de las funciones anónimas y las expresiones lambda, si se deseaba pasar comportamientos como parámetros o implementar pequeñas operaciones, era necesario definir clases o métodos completos. Esto producía mucho código "boilerplate" (código repetitivo o innecesario). Las funciones anónimas resuelven este problema al permitir definir comportamientos en línea y de manera concisa.

**Problemas que resuelven:**

* **Complejidad innecesaria**: Antes de las lambdas, Java requería la creación de clases anónimas para implementar pequeñas piezas de comportamiento. Esto hacía el código más extenso y difícil de leer.

* **Manejo de eventos o callbacks**: En interfaces gráficas o sistemas asíncronos, las funciones anónimas permiten manejar eventos o respuestas sin la necesidad de definir clases completas.

## ¿Cómo lo resuelven?
Las funciones anónimas simplifican la manera en que se implementan comportamientos en el código al eliminar la necesidad de escribir clases o métodos adicionales. A continuación te muestro cómo se puede usar en Java.

* **Clase anónima (antes de Java 8)**: Antes de Java 8, cuando querías implementar una interfaz funcional (una interfaz con un solo método abstracto), tenías que usar una clase anónima.

  ```java
  public class ClaseAnonimaEjemplo {
      public static void main(String[] args) {
          // Clase anónima que implementa la interfaz Runnable
          Runnable runnable = new Runnable() {
              @Override
              public void run() {
                  System.out.println("Hola desde una clase anónima");
              }
          };

          runnable.run();
      }
  }
  ```
  En este ejemplo, se crea una instancia de la interfaz Runnable mediante una clase anónima. Sin embargo, el código es más extenso de lo necesario para realizar una tarea simple.

* **Expresión lambda (a partir de Java 8)**: Con la llegada de Java 8, las lambdas hicieron que las funciones anónimas fueran mucho más fáciles de escribir y comprender.

  ```java
  public class LambdaEjemplo {
      public static void main(String[] args) {
          // Expresión lambda que implementa Runnable
          Runnable runnable = () -> System.out.println("Hola desde una lambda");

          runnable.run();
      }
  }
  ```
  Aquí, el código es mucho más compacto y hace lo mismo que la clase anónima anterior, pero con una sintaxis más simple y directa.

## Características principales de las funciones anónimas
1. **No tienen nombre**: Se definen y se usan en el mismo lugar sin necesidad de asociarlas con un identificador.

2. **Usan interfaces funcionales**: En Java, las funciones anónimas (lambdas) se basan en interfaces que solo tienen un método abstracto.

3. **Concisión**: Reducen la cantidad de código necesario para implementar un comportamiento en línea.
Ámbito limitado: Al no tener nombre, no están destinadas a ser reutilizadas en otros contextos.

## Ventajas de las funciones anónimas
1. **Reducción del código repetitivo**: No necesitas crear métodos o clases completos solo para implementar una funcionalidad temporal o pequeña.

2. **Mejora de la legibilidad**: En muchos casos, como en el manejo de eventos o en la programación funcional, las funciones anónimas hacen que el código sea más claro y conciso.

3. **Mayor flexibilidad**: Te permiten definir funciones específicas para su uso en ese momento, lo que es ideal para callbacks y programación funcional.
