# Composición de Funciones
La composición de funciones es uno de los pilares fundamentales de la programación funcional. Este concepto se refiere a la capacidad de combinar dos o más funciones para crear una nueva función, donde la salida de una función es la entrada de otra. Este proceso permite construir programas de forma modular, reutilizando funciones pequeñas y sencillas para crear otras más complejas.

## ¿Qué es la composición de funciones?
La composición de funciones consiste en encadenar funciones, de manera que el resultado de una función se pasa como argumento a la siguiente. Formalmente, si tienes dos funciones `f(x)` y `g(x)`, la composición de funciones `f(g(x))` significa que primero se ejecuta `g(x)` y luego su resultado se pasa como entrada a `f(x)`.

En notación matemática, se expresa como `f ∘ g(x) = f(g(x))`.

## ¿Para qué sirve la composición de funciones?
1. **Modularidad**: Permite dividir un problema en pequeñas funciones especializadas, que luego se pueden combinar para resolver problemas más grandes. Esto facilita la reutilización y mejora la mantenibilidad del código.

2. **Legibilidad**: El código es más legible y expresivo, ya que las funciones se componen en pasos claros, lo que mejora la claridad del flujo de datos a través de un sistema.

3. **Reutilización**: Las funciones pueden definirse una sola vez y luego utilizarse en múltiples contextos diferentes al componerlas con otras funciones.

## ¿Qué problemas resuelve?
1. **Reducción de complejidad**: En lugar de tener una única función gigante que haga muchas cosas, puedes dividir el trabajo en varias funciones más pequeñas, cada una con una responsabilidad clara, y luego componerlas.

2. **Repetición de código**: Al definir funciones modulares y composables, reduces la duplicación de código. En lugar de escribir el mismo proceso en varias partes del programa, puedes componer funciones existentes.

3. **Facilita el mantenimiento**: Al dividir la lógica en funciones más pequeñas y composables, es más fácil modificar o mejorar partes del código sin afectar el sistema completo.

## Ejemplo en `Java`
Aunque **Java** no es un lenguaje puramente funcional, es posible realizar composición de funciones usando interfaces funcionales como `Function<T, R>` desde Java 8.

**Ejemplo con funciones simples**: Supongamos que queremos realizar dos operaciones: primero, duplicar un número y luego incrementarlo en 3. En lugar de escribir una única función que haga ambas cosas, podemos definir dos funciones pequeñas y componerlas.

```java
import java.util.function.Function;

public class ComposicionFunciones {

    public static void main(String[] args) {
        // Definimos una función que duplica el valor
        Function<Integer, Integer> duplicar = x -> x * 2;

        // Definimos una función que incrementa el valor en 3
        Function<Integer, Integer> incrementar = x -> x + 3;

        // Componemos ambas funciones
        Function<Integer, Integer> duplicarLuegoIncrementar = duplicar.andThen(incrementar);

        // Aplicamos la composición a un valor
        int resultado = duplicarLuegoIncrementar.apply(5); // Resultado: (5 * 2) + 3 = 13
        System.out.println("Resultado: " + resultado); // Salida: Resultado: 13
    }
}
```
En este ejemplo:

* Tenemos dos funciones: `duplicar` y `incrementar`.

* Usamos la función `andThen` para componerlas de modo que primero se duplique el número y luego se incremente en 3.

* Llamamos a `duplicarLuegoIncrementar.apply(5)` para obtener el resultado.

## ¿Cómo lo resuelve?
La composición de funciones permite que se enfoquen en hacer solo una cosa bien (principio de responsabilidad única en SOLID). Después, estas funciones pequeñas se pueden combinar de forma flexible para crear procesos más complejos, pero sin perder la simplicidad en cada paso individual.

## Composición usando `compose` y `andThen`
Java ofrece dos formas principales para componer funciones con la interfaz `Function<T, R>`:

1. `andThen`: Comienza ejecutando la primera función y luego pasa su resultado a la segunda función.

  ```java
  Function<Integer, Integer> f1 = x -> x + 2;
  Function<Integer, Integer> f2 = x -> x * 3;

  Function<Integer, Integer> f3 = f1.andThen(f2); // Primero suma, luego multiplica
  System.out.println(f3.apply(5)); // (5 + 2) * 3 = 21
  ```

2. `compose`: Ejecuta primero la segunda función, y luego pasa su resultado a la primera función.

  ```java
  Function<Integer, Integer> f1 = x -> x + 2;
  Function<Integer, Integer> f2 = x -> x * 3;

  Function<Integer, Integer> f3 = f1.compose(f2); // Primero multiplica, luego suma
  System.out.println(f3.apply(5)); // (5 * 3) + 2 = 17
  ```

* Ejemplo con varias composiciones

  ```java
  import java.util.function.Function;

  public class ComposicionMultiple {

      public static void main(String[] args) {
          // Función que multiplica el valor por 2
          Function<Integer, Integer> multiplicarPorDos = x -> x * 2;

          // Función que le resta 5
          Function<Integer, Integer> restarCinco = x -> x - 5;

          // Función que eleva al cuadrado
          Function<Integer, Integer> elevarAlCuadrado = x -> x * x;

          // Composición: multiplicarPorDos, luego restarCinco, luego elevarAlCuadrado
          Function<Integer, Integer> funcionCompuesta = multiplicarPorDos
                  .andThen(restarCinco)
                  .andThen(elevarAlCuadrado);

          // Aplicamos la función compuesta
          int resultado = funcionCompuesta.apply(3); // ((3 * 2) - 5)^2 = 1
          System.out.println("Resultado: " + resultado); // Salida: 1
      }
  }
  ```
  Aquí se componen tres funciones y cada una realiza una transformación antes de pasar el resultado a la siguiente.

## Ventajas de la composición de funciones
* **Reducción de la complejidad**: Facilita la creación de soluciones más complejas mediante el uso de funciones simples que, al componerse, resuelven problemas mayores sin complicar la lógica.

* **Reutilización**: Cada función puede reutilizarse en diferentes partes del código, mejorando la mantenibilidad y reduciendo la duplicación.

* **Legibilidad**: Al definir funciones pequeñas y combinarlas, el flujo de datos es más claro y el código más fácil de leer y entender.

## Desventajas potenciales
* **Dificultad en el seguimiento**: Si abusas de la composición, podría volverse complicado seguir el flujo del programa, especialmente en proyectos grandes donde las funciones se componen en varios niveles.

* **Performance**: Aunque la composición es eficiente, en algunos casos puede haber sobrecarga de performance si se utilizan funciones innecesariamente complejas o demasiado anidadas.
