# Lambdas
Las funciones lambda son una característica introducida en Java 8 que permiten crear funciones anónimas (es decir, funciones que no están asociadas a un nombre específico). Estas funciones proporcionan una forma concisa de expresar bloques de código que se pueden pasar como parámetros, almacenar en variables o utilizar como retorno de otras funciones, lo cual es esencial en la programación funcional.

## ¿Qué es una función lambda?
Una lambda en Java es esencialmente una función anónima que se puede definir de manera concisa, sin necesidad de crear una clase explícita o un método con nombre. Las funciones lambda se basan en interfaces funcionales, que son interfaces que tienen un solo método abstracto.

La sintaxis de una lambda es la siguiente:
```java
(argumentos) -> { cuerpo de la función }
```
* **Argumentos**: Los parámetros que recibe la función.

* **Flecha `->`**: Separa los parámetros del cuerpo de la función.

* **Cuerpo**: El código que se ejecuta al invocar la función.

## ¿Para qué sirven las funciones lambda?
Las lambdas sirven para expresar comportamientos de una manera más compacta y directa, sin la necesidad de definir clases anónimas o métodos tradicionales. Se utilizan principalmente para:

* **Simplificar el código**: Reducen el código boilerplate (redundante) al no tener que definir clases completas o métodos adicionales.

* **Facilitar la programación funcional**: Las lambdas permiten pasar funciones como argumentos a otras funciones o métodos, lo que es fundamental para usar APIs funcionales como Streams.

* **Mejorar la legibilidad**: Hacen que el código sea más fácil de entender y más limpio en casos donde se utiliza programación funcional o se implementan patrones que involucran pasar comportamientos.

## ¿Qué resuelven?
Antes de la introducción de las lambdas, cuando se quería pasar una función o comportamiento a un método, era necesario crear clases anónimas o implementar interfaces, lo que resultaba en un código más largo y repetitivo. Las lambdas resuelven este problema proporcionando una manera de escribir funciones anónimas de manera compacta.

Por ejemplo, si antes se usaban clases anónimas para implementar una interfaz funcional, ahora una expresión lambda puede hacer el mismo trabajo con una sintaxis mucho más sencilla.

## ¿Cómo lo resuelven?
Las lambdas simplifican el proceso de definir comportamientos personalizados. Aquí está la comparación entre el uso de una clase anónima y una lambda en Java:

**Sin lambdas (clase anónima)**
```java
// Interfaz funcional
interface Operacion {
    int calcular(int a, int b);
}

public class ClaseAnonimaEjemplo {
    public static void main(String[] args) {
        Operacion suma = new Operacion() {
            @Override
            public int calcular(int a, int b) {
                return a + b;
            }
        };

        System.out.println("Suma: " + suma.calcular(5, 3));  // Salida: 8
    }
}
```

**Con lambdas**
```java
public class LambdaEjemplo {
    public static void main(String[] args) {
        // Definición de una lambda para sumar dos números
        Operacion suma = (a, b) -> a + b;

        System.out.println("Suma: " + suma.calcular(5, 3));  // Salida: 8
    }
}

@FunctionalInterface
interface Operacion {
    int calcular(int a, int b);
}
```
Como puedes ver, el código con lambdas es mucho más conciso y evita toda la estructura adicional de las clases anónimas.

## Características principales de las lambdas
1. **Concisión**: Reducen la cantidad de código que necesitas escribir.

2. **Uso de interfaces funcionales**: Las lambdas se utilizan con interfaces funcionales, como Runnable, Callable o interfaces personalizadas con un solo método abstracto.

3. **Código más legible**: Hacen que el código sea más fácil de leer, especialmente cuando se trabaja con APIs funcionales como Stream.

4. **Flexibilidad**: Puedes pasar funciones como parámetros, retornarlas y almacenarlas en variables.

## Ejemplos en Java
* Expresión lambda básica

  ```java
  public class LambdaSimple {
      public static void main(String[] args) {
          // Una lambda que imprime un mensaje
          Runnable runnable = () -> System.out.println("¡Hola desde una lambda!");

          // Ejecutar la lambda
          runnable.run();
      }
  }
  ```

* **Lambda con múltiples argumentos**

  ```java
  @FunctionalInterface
  interface Calculadora {
      int operar(int a, int b);
  }

  public class LambdaCalculadora {
      public static void main(String[] args) {
          // Lambda para sumar dos números
          Calculadora sumar = (a, b) -> a + b;

          // Lambda para multiplicar dos números
          Calculadora multiplicar = (a, b) -> a * b;

          System.out.println("Suma: " + sumar.operar(5, 3));          // Salida: 8
          System.out.println("Multiplicación: " + multiplicar.operar(5, 3));  // Salida: 15
      }
  }
  ```

* **Uso de lambdas con Streams**: Las lambdas son extremadamente útiles cuando se utilizan en conjunto con la API de Streams, lo que permite manipular colecciones de una manera funcional.

  ```java
  import java.util.Arrays;
  import java.util.List;

  public class LambdaStream {
      public static void main(String[] args) {
          List<Integer> numeros = Arrays.asList(1, 2, 3, 4, 5);

          // Usamos lambdas para sumar los números de una lista
          int suma = numeros.stream()
              .mapToInt(n -> n)
              .sum();

          System.out.println("Suma: " + suma);  // Salida: 15
      }
  }
  ```
  En este ejemplo, la lambda `n -> n` pasa cada elemento de la lista al método `mapToInt`, que luego se suma.


## Ventajas de las funciones lambda
1. **Reducción del código boilerplate**: Se elimina la necesidad de escribir clases anónimas que implementan interfaces, lo que hace que el código sea más simple.

2. **Mejora de la legibilidad**: Las lambdas proporcionan una forma más clara y concisa de expresar la lógica en comparación con las clases anónimas.

3. **Promueven la programación funcional**: Facilitan el uso de patrones de programación funcional en Java, como la manipulación de colecciones usando Streams, map, filter, etc.

4. **Mayor flexibilidad**: Te permiten escribir código más flexible y reutilizable al tratar funciones como ciudadanos de primera clase, es decir, puedes pasar y devolver funciones fácilmente.

## Casos de uso comunes
1. **API de Streams**: Las lambdas se usan comúnmente con Streams para manipular colecciones de datos, como filtrado, mapeo y reducción.

2. **Eventos y callbacks**: En el manejo de eventos y callbacks, como en GUIs o sistemas reactivos, las lambdas simplifican el código.

3. **Concurrente y asíncrono**: Son útiles para simplificar el manejo de tareas concurrentes o asíncronas, como cuando se usan junto con Runnable o Callable en programación concurrente.

## Limitaciones de las lambdas
1. **Complejidad excesiva**: Aunque las lambdas hacen que el código sea más conciso, pueden llegar a ser difíciles de entender si se usan para lógica compleja. Es mejor mantener las lambdas simples y cortas.

2. **Solo con interfaces funcionales**: En Java, las lambdas solo pueden implementarse con interfaces que tengan un único método abstracto, lo que limita un poco su flexibilidad en comparación con lenguajes funcionales más completos.
