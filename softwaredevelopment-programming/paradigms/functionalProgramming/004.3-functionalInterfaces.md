# Interfaces Funcionales
Las interfaces funcionales son un concepto clave en la programación funcional en Java, especialmente a partir de la versión 8, donde las expresiones lambda se introdujeron como una manera más concisa de escribir código. Las interfaces funcionales permiten tratar las funciones como valores, lo que facilita la adopción de un enfoque más funcional en Java, un lenguaje tradicionalmente orientado a objetos.

## ¿Qué es una interfaz funcional?
Una interfaz funcional es una interfaz en Java que contiene exactamente un método abstracto (aunque puede tener métodos por defecto o estáticos). Este único método abstracto define el contrato que debe implementar cualquier clase que la use, o que puede ser directamente expresado mediante una **lambda**.

Una interfaz funcional en Java puede ser fácilmente identificada porque lleva la anotación `@FunctionalInterface`. Aunque esta anotación es opcional, es recomendable utilizarla, ya que fuerza al compilador a garantizar que la interfaz cumple con las características de una interfaz funcional (es decir, que solo tiene un método abstracto).

**Ejemplo**
```java
@FunctionalInterface
public interface Operacion {
    int calcular(int a, int b);
}
```
En este ejemplo, `Operacion` es una interfaz funcional porque tiene un solo método abstracto: `calcular`.

## ¿Para qué sirven las interfaces funcionales?
Las interfaces funcionales son la base para usar expresiones lambda y referencias a métodos en Java. Se utilizan para pasar comportamientos (funciones) como parámetros a métodos, lo cual es un concepto central en la programación funcional. Su propósito principal es permitir que las lambdas sean asignadas o utilizadas en contextos donde se espera una interfaz funcional.

**Sirven para:**

* Representar funciones y pasar comportamientos como parámetros.

* Mejorar la legibilidad y reducir el código redundante.

* Facilitar la implementación de operaciones de alto nivel, como las operaciones con colecciones (Streams API).

## ¿Qué resuelven las interfaces funcionales?
Antes de la introducción de las interfaces funcionales y las lambdas en Java, era necesario crear clases anónimas completas solo para implementar un comportamiento simple. Este enfoque generaba mucho "boilerplate" o código repetitivo, especialmente en operaciones simples como iteraciones o cálculos.

Las interfaces funcionales resuelven este problema de varias maneras:

* **Reducen la verbosidad del código**: En lugar de crear una clase anónima para implementar una interfaz funcional, se puede usar una lambda.

* **Mejoran la claridad y legibilidad**: Las lambdas son más concisas y expresan de manera más directa lo que se quiere hacer.

* **Permiten una mayor flexibilidad** en la programación, ya que las funciones pueden ser tratadas como ciudadanos de primera clase (valores que se pueden pasar como parámetros o devolver como resultados).

## ¿Cómo lo resuelven?
Las interfaces funcionales proporcionan un contrato simple con un solo método abstracto, lo que permite que las expresiones lambda o las referencias a métodos sean asignadas y utilizadas en esos contextos.

* **Concisión**: Al permitir expresiones lambda, Java puede eliminar mucho del código repetitivo que solía ser necesario.

* **Abstracción del comportamiento**: Permiten que el comportamiento (la lógica) sea abstracto y se pase como argumento a otros métodos o funciones, lo que es esencial en el paradigma funcional.

* **Compatibilidad con el legado**: Son compatibles con el enfoque de programación orientada a objetos, lo que permite mezclar ambos paradigmas.
