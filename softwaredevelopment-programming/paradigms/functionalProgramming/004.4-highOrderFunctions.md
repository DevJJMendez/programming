# Funciones de Alto Orden
En programación funcional, las funciones de alto orden (Higher-Order Functions, HOFs) son una de las características más poderosas y fundamentales. Son funciones que pueden recibir otras funciones como parámetros o devolver funciones como resultado. Este enfoque permite construir abstracciones más flexibles y modulares, promoviendo el código reutilizable y más fácil de mantener.

## ¿Qué es una función de alto orden?
Una función de alto orden es una función que cumple con una de estas dos condiciones (o ambas):

1. **Recibe una función como argumento**: Puedes pasar una función como parámetro a otra función.

2. **Devuelve una función**: El resultado de la función es otra función.

Estas funciones permiten manejar funciones como valores y hacer que el código sea más dinámico y flexible. Se utilizan ampliamente en operaciones como la manipulación de listas, eventos, cálculos complejos, etc.

## ¿Para qué sirven las funciones de alto orden?
Las funciones de alto orden son útiles en los siguientes casos:

* **Abstracción de comportamiento**: Permiten abstraer operaciones comunes, como aplicar una operación a cada elemento de una lista (por ejemplo, con `map` o `filter`).

* **Modularidad**: Facilitan la creación de soluciones modulares, donde la lógica puede ser encapsulada en funciones más pequeñas que pueden ser combinadas o reutilizadas fácilmente.

* **Reutilización de código**: Reducen la duplicación de código al encapsular patrones comunes.

## ¿Qué problemas resuelven?
* **Procesamiento de colecciones**: Son ideales para operar sobre colecciones (listas, conjuntos, etc.) de manera declarativa, aplicando funciones como `map`, `reduce` o `filter`.

* **Evitan bucles explícitos**: En lugar de utilizar bucles como for o while, se pueden utilizar funciones de alto orden para realizar tareas como iterar sobre colecciones de una manera más clara y concisa.

* **Configuración dinámica de comportamientos**: Permiten pasar funciones como argumentos, lo que hace que el comportamiento de una función sea configurable y adaptable sin necesidad de cambiar la lógica principal.

## Ejemplos comunes de funciones de alto orden
Las funciones de alto orden suelen aparecer en operaciones que involucran listas o colecciones, como `map`, `filter` y `reduce`. Veamos cómo funcionan en Java.

A pesar de que Java no es un lenguaje funcional puro, a partir de Java 8, la introducción de lambdas y el API de Streams lo acercó más al paradigma funcional, permitiendo un uso más extensivo de las funciones de alto orden.

* Ejemplo 1: `map` (Aplicar una función a cada elemento de una lista)

  ```java
  import java.util.Arrays;
  import java.util.List;
  import java.util.stream.Collectors;

  public class FuncionesDeAltoOrden {
      public static void main(String[] args) {
          List<Integer> numeros = Arrays.asList(1, 2, 3, 4, 5);

          // Usamos la función map para aplicar una función que multiplica cada número por 2
          List<Integer> numerosMultiplicados = numeros.stream()
              .map(n -> n * 2)
              .collect(Collectors.toList());

          System.out.println("Números multiplicados: " + numerosMultiplicados);  // Salida: [2, 4, 6, 8, 10]
      }
  }
  ```
  En este ejemplo, la función de alto orden `map` toma una función **lambda `(n -> n * 2)`** y la aplica a cada elemento de la lista `numeros`. Devuelve una nueva lista con los resultados.

* **Ejemplo 2**: `filter` (filtrar elementos de una lista)

  ```java
  import java.util.Arrays;
  import java.util.List;
  import java.util.stream.Collectors;

  public class FiltrarNumeros {
      public static void main(String[] args) {
          List<Integer> numeros = Arrays.asList(1, 2, 3, 4, 5, 6);

          // Usamos filter para quedarnos con los números pares
          List<Integer> numerosPares = numeros.stream()
              .filter(n -> n % 2 == 0)
              .collect(Collectors.toList());

          System.out.println("Números pares: " + numerosPares);  // Salida: [2, 4, 6]
      }
  }
  ```
  Aquí, `filter` es una función de alto orden que toma una función (en este caso, `n -> n % 2 == 0`) que evalúa si un número es par. Filtra los elementos de la lista según esa condición.

* **Ejemplo 3**: `reduce` (reducir una lista a un solo valor)

  ```java
  import java.util.Arrays;
  import java.util.List;

  public class ReducirNumeros {
      public static void main(String[] args) {
          List<Integer> numeros = Arrays.asList(1, 2, 3, 4, 5);

          // Usamos reduce para sumar todos los números
          int suma = numeros.stream()
              .reduce(0, (a, b) -> a + b);

          System.out.println("Suma de los números: " + suma);  // Salida: 15
      }
  }
  ```
  En este ejemplo, reduce es una función de alto orden que combina todos los elementos de la lista en un solo valor (en este caso, la suma de todos los números). El primer parámetro (0) es el valor inicial, y el segundo es una función que toma dos argumentos y devuelve su suma.

## ¿Cómo lo resuelven?
Las funciones de alto orden resuelven problemas de forma declarativa y modular. En lugar de escribir bucles y lógica repetitiva, puedes delegar comportamientos específicos a funciones que encapsulan la lógica y que se pueden combinar entre sí para producir resultados complejos.

* **Abstracción de lógica**: No tienes que escribir un bucle manual para recorrer una lista o aplicar una operación. Simplemente defines qué operación quieres aplicar (map, filter, etc.) y Java maneja los detalles del bucle por ti.

* **Composición**: Puedes componer funciones de manera que una función tome el resultado de otra. Esto permite crear pipelines de procesamiento de datos de manera limpia.

* **Reutilización**: Puedes reutilizar funciones de manera más fácil porque las funciones de alto orden permiten escribir código más genérico y flexible.

## Ventajas de las funciones de alto orden
1. **Reutilización de código**: Al tener funciones que operan sobre otras funciones, puedes reutilizar bloques de lógica sin necesidad de duplicar código.

2. **Abstracción de la complejidad**: Puedes enfocarte en lo que quieres hacer (por ejemplo, mapear o filtrar) en lugar de cómo hacerlo (por ejemplo, implementar bucles manualmente).

3. **Mayor legibilidad**: El código que utiliza funciones de alto orden tiende a ser más conciso y más fácil de entender, porque no tienes que manejar detalles de control explícito como los bucles.

4. **Modularidad**: Puedes construir piezas de funcionalidad más pequeñas y luego combinarlas para construir soluciones más grandes.

## Funciones de alto orden y lambdas
Las funciones de alto orden suelen combinarse con expresiones **lambda**, que son una forma concisa de definir funciones anónimas. En Java, esto es particularmente útil con el **API** de **Streams**. Por ejemplo, en el código anterior, `n -> n * 2` es una expresión **lambda** que se pasa como argumento a la función `map`.

## Función de alto orden que devuelve otra función
También puedes crear una función que devuelva otra función. Esto es útil cuando quieres generar funciones personalizadas basadas en algún parámetro.

```java
import java.util.function.Function;

public class GenerarFuncion {

    // Función de alto orden que devuelve una función personalizada
    public static Function<Integer, Integer> multiplicador(int factor) {
        return n -> n * factor;
    }

    public static void main(String[] args) {
        // Creamos una función que multiplica por 3
        Function<Integer, Integer> porTres = multiplicador(3);

        // Aplicamos la función generada
        int resultado = porTres.apply(5);
        System.out.println("Resultado: " + resultado);  // Salida: 15
    }
}
```
En este ejemplo, la función `multiplicador` devuelve una función que multiplica un número por un factor dado. En el `main`, usamos esa función para multiplicar el número 5 por 3.
